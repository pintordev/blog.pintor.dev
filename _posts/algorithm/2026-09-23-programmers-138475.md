## 문제

> 링크: [프로그래머스 138475](https://school.programmers.co.kr/learn/courses/30/lessons/138475)

1억 x 1억 크기의 억억단에서, [s, e] 범위의 수 중 가장 많이 등장하는 수(동률이면 가장 작은 수)를 구하는 문제.

## 접근

### 약수 개수로 치환

억억단의 (i, j) 위치 값은 i × j이므로, 값 k가 등장하는 횟수는 k = i × j를 만족하는 (i, j) 쌍의 개수, 즉 k의 약수 개수와 같다. e ≤ 5,000,000으로 1억보다 훨씬 작아 모든 약수쌍이 유효 범위 안에 들어오기 때문에 이 치환이 성립한다.

### 약수 개수 전처리

1부터 e까지 각 수의 약수 개수를 구해야 하는데, 매 수마다 개별로 계산하면 O(e√e)로 시간 초과가 난다. 대신 d를 1부터 e까지 순회하며 d의 배수마다 카운트를 올리는 방식(divisor sieve)을 쓰면 전체 반복 횟수가 조화급수 합인 O(e log e)로 줄어든다.

### 뒤에서부터 누적 최댓값

e부터 1까지 역순으로 순회하면서 지금까지 본 최대 약수 개수(max)를 유지한다. 현재 수의 약수 개수가 max보다 작으면 이전 최적값을 그대로 이어받고, max 이상이면(동률 포함) 현재 수로 갱신한다. 큰 수에서 작은 수로 내려가며 동률일 때 갱신하므로 자연스럽게 "가장 작은 수" 우선순위가 보장된다. 이렇게 만든 배열을 각 시작값 쿼리에 O(1)로 조회하면 된다.

## 풀이

```java
public int[] solution(int e, int[] starts) {
    int[] cnt = new int[e + 1];
    for (int d = 1; d <= e; d++) {
        for (int multiple = d; multiple <= e; multiple += d) {
            cnt[multiple]++;
        }
    }
    int[] best = new int[e + 1];
    int max = 0;
    for (int k = e; k >= 1; k--) {
        if (cnt[k] < max) best[k] = best[k + 1];
        else {
            max = cnt[k];
            best[k] = k;
        }
    }
    for (int i = 0; i < starts.length; i++) {
        starts[i] = best[starts[i]];
    }
    return starts;
}
```
