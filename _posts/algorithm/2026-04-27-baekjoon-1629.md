## 문제

> 링크: [백준 1629](https://www.acmicpc.net/problem/1629)

자연수 A를 B번 곱한 값을 C로 나눈 나머지를 구한다. (A, B, C ≤ 2,147,483,647)

## 접근

### 분할정복 거듭제곱

B가 최대 21억이므로 단순 반복으로는 시간 초과다. 분할정복을 적용하면 O(log B)로 줄일 수 있다.

- `pow(a, b, c)` = `pow(a, b/2, c)` 의 제곱을 c로 나눈 나머지
- b가 홀수이면 거기에 `a % c`를 한 번 더 곱함
- 중간 값이 long 범위를 초과할 수 있으므로 각 곱셈마다 즉시 `% c` 처리

## 풀이

```java
import java.io.IOException;

public class Solution {
    public static void main(String[] args) throws IOException {
        long a = read();
        long b = read();
        long c = read();

        System.out.println(pow(a, b, c));
    }

    private static long pow(long a, long b, long c) {
        if (b == 0) return 1;

        long p = pow(a, b / 2, c);
        long pp = p * p % c;
        if (b % 2 == 1) pp = pp * (a % c) % c;
        return pp;
    }

    private static int read() throws IOException {
        int c, n = System.in.read() & 15;
        boolean negative = n == 13;
        if (negative) n = System.in.read() & 15;
        while ((c = System.in.read()) > 32) {
            n = (n << 3) + (n << 1) + (c & 15);
        }
        return negative ? ~n + 1 : n;
    }
}
```
