## 문제

> 링크: [프로그래머스 131704](https://school.programmers.co.kr/learn/courses/30/lessons/131704)

메인 벨트(큐)와 보조 벨트(스택)를 이용해 지정된 순서대로 상자를 트럭에 싣고, 실을 수 있는 최대 상자 수를 반환하는 문제.

## 접근

### 스택 시뮬레이션

각 `order[i]`에 대해 두 가지 경우를 처리한다.

1. 보조 스택 top이 `order[i]`와 일치하면 바로 꺼내 적재한다.
2. 아니면 메인 벨트에서 `order[i]`가 나올 때까지 스택에 push한다. 벨트가 소진될 때까지 못 찾으면 즉시 종료한다.

`while (top < 0 || stack[top] != order[i])` 조건을 쓰면 스택 확인과 벨트 당기기를 하나의 루프로 처리할 수 있어 코드가 단순해진다. 루프 탈출 시점에는 항상 `stack[top] == order[i]`가 보장되므로 별도 분기 없이 pop + cnt++로 마무리한다.

## 풀이

```java
public int solution(int[] order) {
    int n = order.length;
    int[] stack = new int[n];
    int cnt = 0, top = -1, next = 1;
    for (int i = 0; i < n; i++) {
        while (top < 0 || stack[top] != order[i]) {
            if (next > n) return cnt;
            stack[++top] = next++;
        }
        top--;
        cnt++;
    }
    return cnt;
}
```
