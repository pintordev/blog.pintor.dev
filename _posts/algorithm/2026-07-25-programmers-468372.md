## 문제

> 링크: [프로그래머스 468372](https://school.programmers.co.kr/learn/courses/30/lessons/468372)

루트 노드, 리프 노드, 분배 노드로 구성된 트리에서, 분배 노드는 최대 `dist_limit`개까지만 쓸 수 있고 모든 리프 노드의 분배도(루트까지 경로상 자식 수의 곱)는 `split_limit` 이하여야 한다는 조건 아래 리프 노드 개수를 최대화하는 문제다.

## 접근

### 트리를 (2분배 층 개수, 3분배 층 개수) 조합으로 단순화

같은 깊이의 분배 노드는 반드시 같은 자식 수(2 또는 3)를 가져야 한다는 조건 덕분에, 어떤 깊이에서 동시에 확장 중인 노드들은 항상 같은 분배도를 공유한다. 즉 트리는 "2 또는 3을 하나씩 골라 나가는 수열"로 단순화할 수 있고, 이때 노드 수와 분배도는 항상 같은 값(지금까지 고른 인수들의 곱)이 된다.

### 오름차순 배치가 예산 효율적

2의 개수 `p`, 3의 개수 `q`를 고정했을 때, 이 인수들을 배치하는 순서에 따라 소모되는 분배 노드 수(각 층 노드 수의 누적합)가 달라진다. 인접한 두 인수 `x < y`의 순서를 바꿔보면, `x`를 먼저 배치할 때의 누적 비용이 항상 더 작다는 걸 교환 논증으로 확인할 수 있다. 그래서 2분배 층을 모두 상단에 배치하고 그 아래에 3분배 층을 배치하는 순서가 주어진 `(p, q)`에 대한 최소 비용 배치가 된다.

### 완전 탐색 + 마지막 층 부분 확장

`p`, `q`는 `2^p * 3^q ≤ split_limit`을 만족해야 하므로 각각 최대 30, 19 수준으로 범위가 매우 작다. 이 범위를 이중 루프로 탐색하면서, 예산이 남았을 때 마지막 층 일부 노드만 한 단계 더 확장(부분 분배)하는 경우까지 함께 고려해 최댓값을 갱신한다. 부분 확장 시 노드 하나를 쪼갤 때마다 리프 수는 `(자식 수 - 1)`만큼 순증가한다.

## 풀이

```java
public int solution(int dist_limit, int split_limit) {
    int res = 1;
    for (int p = 0; ; p++) {
        long pow2 = (long) Math.pow(2, p);
        if (pow2 > split_limit) break;
        for (int q = 0; ; q++) {
            long pow3 = (long) Math.pow(3, q);
            if (split_limit / pow2 < pow3) break;
            long currentSplitValue = pow2 * pow3;
            if (split_limit / currentSplitValue >= 2) res = Math.max(res, calculateMaxLeaves(p, q, 2, dist_limit));
            if (split_limit / currentSplitValue >= 3) res = Math.max(res, calculateMaxLeaves(p, q, 3, dist_limit));
            res = Math.max(res, calculateMaxLeaves(p, q, 0, dist_limit));
        }
    }
    return res;
}

public int calculateMaxLeaves(int p, int q, int extraType, int distLimit) {
    int nodes = 1;
    for (int i = 0; i < p; i++) {
        if (distLimit < nodes) return 0;
        distLimit -= nodes;
        nodes *= 2;
    }
    for (int i = 0; i < q; i++) {
        if (distLimit < nodes) return 0;
        distLimit -= nodes;
        nodes *= 3;
    }
    int totalLeaves = nodes;
    if (extraType > 0 && distLimit > 0) totalLeaves += Math.min(nodes, distLimit) * (extraType - 1);
    return totalLeaves;
}
```
