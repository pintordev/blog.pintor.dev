## 문제

> 링크: [프로그래머스 154539](https://school.programmers.co.kr/learn/courses/30/lessons/154539)

배열의 각 원소에 대해, 뒤에 있는 수 중 자신보다 크면서 가장 가까운 수(뒷 큰수)를 구한다. 없으면 -1.

## 접근

### 단조 감소 스택 (Monotonic Stack)

배열 길이가 최대 1,000,000이므로 O(n²) 브루트포스는 시간 초과다.

**단조 감소 스택**을 사용하면 O(n)으로 해결할 수 있다.
스택에 **값이 아닌 인덱스**를 저장하고, 현재 원소가 스택 top이 가리키는 원소보다 크면 → 그 위치의 뒷 큰수가 확정된다.

`Stack<Integer>` 대신 `int[]` + `top` 포인터로 배열 스택을 직접 구현하면 오토박싱 오버헤드를 제거할 수 있다.

## 풀이

```java
public int[] solution(int[] numbers) {
    int n = numbers.length;
    int[] res = new int[n];
    int[] stack = new int[n];
    int top = -1;
    for (int i = 0; i < n; i++) {
        while (top >= 0 && numbers[stack[top]] < numbers[i]) {
            res[stack[top--]] = numbers[i];
        }
        stack[++top] = i;
    }
    while (top >= 0) {
        res[stack[top--]] = -1;
    }
    return res;
}
```

## 회고

`Arrays.fill(res, -1)`로 전체를 초기화하는 대신, 루프 후 스택에 남은 인덱스만 -1로 채우는 방식이 더 효율적이다.
