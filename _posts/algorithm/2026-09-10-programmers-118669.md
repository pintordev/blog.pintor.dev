## 문제

> 링크: [프로그래머스 118669](https://school.programmers.co.kr/learn/courses/30/lessons/118669)

출입구 한 곳에서 출발해 산봉우리 하나만 방문하고 같은 출입구로 돌아오는 등산코스 중, 휴식 없이 이동해야 하는 구간의 최대 시간(intensity)이 최소가 되는 코스를 찾는다.

## 접근

### intensity = 경로 상 최대 간선

쉼터와 산봉우리에서는 언제든 휴식할 수 있고, 휴식 대상이 아닌 지점은 출입구뿐이다. 따라서 코스의 intensity는 결국 **지나는 간선 가중치의 최댓값**이 된다. 왕복은 대칭이므로 편도(출입구 → 산봉우리)만 따지면 된다.

### 최대 간선을 최소화하는 minimax 다익스트라

"경로 상 최대 간선을 최소화"하는 문제이므로, 다익스트라의 거리 갱신식을 합이 아닌 최댓값으로 바꾼다.

```
dist[v] = min(dist[v], max(dist[u], w))
```

모든 출입구를 거리 0으로 우선순위 큐에 넣는 다중 시작점 방식을 쓰면, `dist[산봉우리]`가 곧 그 산봉우리를 목적지로 하는 코스의 최소 intensity가 된다.

산봉우리는 도착점으로만 쓰여야 하므로 `dist`는 갱신하되 **큐에는 넣지 않는다.** 그러면 산봉우리에서 이웃으로 확장되지 않아, 산봉우리를 두 개 지나는 경로가 자연히 배제된다.

출입구 경유는 따로 막지 않아도 된다. 다른 노드에서 출입구로 relax를 시도하면 `max(dist[u], w) ≥ w ≥ 1 > 0 = dist[출입구]`라 항상 거부되므로, 각 출입구는 자기 시작점으로만 동작한다.

마지막으로 모든 산봉우리의 `dist`를 훑어 최솟값과 그 번호(동점이면 작은 번호)를 반환한다.

정점 5만, 간선 20만 규모에서 `O((V + E) log E)` 다익스트라로 통과한다.

## 풀이

```java
import java.util.ArrayList;
import java.util.List;
import java.util.PriorityQueue;

int n;
List<Node>[] graph;
boolean[] summit;

public int[] solution(int n, int[][] paths, int[] gates, int[] summits) {
    this.n = n;
    graph = new List[n + 1];
    for (int i = 1; i <= n; i++) {
        graph[i] = new ArrayList<>();
    }
    for (int[] path : paths) {
        graph[path[0]].add(new Node(path[1], path[2]));
        graph[path[1]].add(new Node(path[0], path[2]));
    }
    summit = new boolean[n + 1];
    for (int s : summits) summit[s] = true;
    return dijkstra(gates);
}

public int[] dijkstra(int[] gates) {
    int[] dist = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        dist[i] = Integer.MAX_VALUE;
    }
    PriorityQueue<Node> pq = new PriorityQueue<>();
    for (int gate : gates) {
        dist[gate] = 0;
        pq.add(new Node(gate, 0));
    }
    while (!pq.isEmpty()) {
        Node cur = pq.poll();
        if (cur.time > dist[cur.to]) continue;
        for (Node next : graph[cur.to]) {
            int nd = Math.max(dist[cur.to], next.time);
            if (dist[next.to] <= nd) continue;
            dist[next.to] = nd;
            if (summit[next.to]) continue;
            pq.add(new Node(next.to, nd));
        }
    }
    int minSummit = 0;
    int minIntensity = Integer.MAX_VALUE;
    for (int i = 1; i <= n; i++) {
        if (!summit[i] || dist[i] >= minIntensity) continue;
        minSummit = i;
        minIntensity = dist[i];
    }
    return new int[]{minSummit, minIntensity};
}

class Node implements Comparable<Node> {
    int to;
    int time;

    public Node(int to, int time) {
        this.to = to;
        this.time = time;
    }

    @Override
    public int compareTo(Node o) {
        return this.time - o.time;
    }
}
```
