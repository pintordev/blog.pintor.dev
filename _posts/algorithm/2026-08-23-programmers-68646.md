## 문제

> 링크: [프로그래머스 68646](https://school.programmers.co.kr/learn/courses/30/lessons/68646)

일렬로 나열된 풍선들을 인접한 쌍끼리 터트려 1개만 남길 때, "번호가 더 작은 풍선을 터트리는" 행위를 최대 1번만 허용하는 조건 아래 최후까지 남을 수 있는 풍선의 개수를 구하는 문제다.

## 접근

### prefix min / suffix min 스캔

"번호가 더 작은 풍선을 터트리는 행위는 최대 1번만 허용된다"는 조건을 뒤집어 생각하면, 풍선 i가 끝까지 살아남으려면 자신을 기준으로 왼쪽 구간 전체의 최솟값이거나, 오른쪽 구간 전체의 최솟값이어야 한다.

왼쪽 최솟값인 경우, 왼쪽에 있는 풍선들은 인접한 쌍에서 항상 "더 큰 쪽"을 터트려 나가면 되므로 작은 번호를 터트리는 횟수를 전혀 쓰지 않고 i만 남길 수 있다. 이후 오른쪽 풍선들을 병합할 때 마지막 순간에 "더 작은 쪽 터트리기" 1회를 사용해 i를 최종적으로 남기면 된다. 오른쪽 최솟값인 경우도 대칭적으로 동일하게 성립한다.

따라서 각 인덱스 i에 대해 `a[i]`가 `a[0..i]`의 최솟값이거나 `a[i..n-1]`의 최솟값이면 생존 가능한 풍선으로 판단하면 된다. 왼쪽에서 오른쪽으로 한 번, 오른쪽에서 왼쪽으로 한 번 스캔하면 각각의 prefix min, suffix min을 O(n)에 구할 수 있다.

a의 길이가 최대 1,000,000이므로 O(n) 스캔이면 충분하고, 값이 모두 서로 다르다는 조건 덕분에 최솟값과의 동등 비교만으로 조건 판정이 가능하다.

## 풀이

```java
public int solution(int[] a) {
    int n = a.length;
    int[] prefixMin = new int[n];
    prefixMin[0] = a[0];
    for (int i = 1; i < n; i++) {
        prefixMin[i] = Math.min(prefixMin[i - 1], a[i]);
    }
    int[] suffixMin = new int[n];
    suffixMin[n - 1] = a[n - 1];
    for (int i = n - 2; i >= 0; i--) {
        suffixMin[i] = Math.min(suffixMin[i + 1], a[i]);
    }
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] == prefixMin[i] || a[i] == suffixMin[i]) cnt++;
    }
    return cnt;
}
```
