## 문제

> 링크: [프로그래머스 12945](https://school.programmers.co.kr/learn/courses/30/lessons/12945)

n번째 피보나치 수를 1234567로 나눈 나머지를 반환하라.

## 접근

### 슬라이딩 변수로 O(1) 공간 계산

배열 없이 변수 2개(fa, fb)만 유지하며 순차적으로 계산한다. 매 스텝마다 `% 1234567`을 적용해 누적 오버플로우를 방지한다.

## 풀이

```java
public int solution(int n) {
    int mod = 1234567;
    int fa = 0, fb = 1;
    for (int i = 2; i <= n; i++) {
        int fn = (fa + fb) % mod;
        fa = fb;
        fb = fn;
    }
    return fb;
}
```

## 회고

매 스텝 mod 연산을 적용하지 않으면 n이 100000에 이를 때 int 범위를 초과한다. 중간 합산 시마다 나머지를 취해야 최종 결과도 올바르게 유지된다.
