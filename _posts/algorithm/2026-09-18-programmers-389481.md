## 문제

> 링크: [프로그래머스 389481](https://school.programmers.co.kr/learn/courses/30/lessons/389481)

알파벳 소문자 11자 이하로 이루어진 모든 문자열을 길이 순, 같은 길이면 사전순으로 나열한 주문서에서 `bans`에 있는 문자열들을 제외한 뒤 `n`번째 주문을 구하는 문제.

## 접근

### 비지티브(bijective) 26진법을 이용한 순번 변환

알파벳 소문자로 이루어진 모든 문자열을 길이 순 → 사전순으로 나열한 목록은, 각 문자를 1~26으로 매핑하는 비지티브 26진법 순번 체계와 정확히 일치한다. 이 성질을 이용하면 길이별로 구간을 나누는 과정 없이 문자열 하나를 정수 하나로, 정수 하나를 문자열 하나로 바로 변환할 수 있다.

풀이는 세 단계로 진행한다.

1. `bans`에 있는 모든 문자열을 비지티브 26진법 순번으로 변환하고 오름차순 정렬한다.
2. 정렬된 순번을 순서대로 보면서, 현재 순번이 `n` 이하이면 `n`을 하나씩 밀어 올린다. 밴 처리로 밀려난 만큼을 보정해서, 밴이 없었다면 원래 몇 번째였을지를 구하는 과정이다.
3. 보정된 순번을 다시 비지티브 26진법으로 디코딩해서 문자열로 변환한다.

## 풀이

```java
import java.util.Arrays;

public String solution(long n, String[] bans) {
    long[] banRanks = new long[bans.length];
    for (int i = 0; i < bans.length; i++) {
        String ban = bans[i];
        long rank = 0;
        for (int j = 0; j < ban.length(); j++) {
            rank = rank * 26 + (ban.charAt(j) - 'a' + 1);
        }
        banRanks[i] = rank;
    }
    Arrays.sort(banRanks);
    for (long banRank : banRanks) {
        if (banRank > n) break;
        n++;
    }
    StringBuilder sb = new StringBuilder();
    while (n > 0) {
        n--;
        sb.append((char) ('a' + n % 26));
        n /= 26;
    }
    return sb.reverse().toString();
}
```
