## 문제

> 링크: [프로그래머스 150369](https://school.programmers.co.kr/learn/courses/30/lessons/150369)

일렬로 나열된 n개의 집에 최대 cap개씩 실을 수 있는 트럭으로 배달과 수거를 모두 마치고 물류창고까지 돌아오는 최소 이동 거리를 구하는 문제다.

## 접근

### 뒤에서부터 그리디 (배달·수거 동시 처리)

트럭은 가장 먼 곳에 남은 수요(배달이든 수거든)가 있는 집까지는 반드시 왕복해야 한다. 이 점에서 착안해 인덱스를 가장 먼 집부터 가까운 집 방향으로 훑으면서 각 집의 배달량과 수거량을 누적한다.

누적된 배달량 또는 수거량이 남아있는 동안에는 현재 위치까지 왕복하며 한 번에 cap만큼씩 배달량과 수거량을 동시에 소진시킨다. 한 번의 왕복 트립으로 배달 상자와 수거 상자를 동시에 처리할 수 있기 때문에, 두 자원을 하나의 while 루프에서 함께 줄여나가는 것이 핵심이다.

배달과 수거를 완전히 분리해서 각각 계산하면, 같은 집으로 가는 왕복이 두 자원 모두에 필요한 경우를 반영하지 못해 실제 정답보다 큰 값이 나올 수 있다. 두 자원을 같은 이동에서 함께 고려해야 최소 거리가 나온다.

## 풀이

```java
public long solution(int cap, int n, int[] deliveries, int[] pickups) {
    long res = 0;
    int ds = 0;
    int ps = 0;
    for (int i = n - 1; i >= 0; i--) {
        ds += deliveries[i];
        ps += pickups[i];
        while (ds > 0 || ps > 0) {
            res += (i + 1) << 1;
            ds -= cap;
            ps -= cap;
        }
    }
    return res;
}
```
