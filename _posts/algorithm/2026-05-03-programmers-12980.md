## 문제

> 링크: [프로그래머스 12980](https://school.programmers.co.kr/learn/courses/30/lessons/12980)

N 위치까지 이동하는 데 필요한 최소 건전지 사용량을 구하는 문제. 1칸 점프(배터리 1 소모)와 현재 위치 × 2 순간이동(무료) 두 가지 이동 방법이 주어진다.

## 접근

### 역방향으로 추적하기

N에서 0으로 거꾸로 추적하면 규칙이 명확해진다.

- **N이 짝수** → 절반 위치에서 순간이동으로 왔다 (`/2`, 배터리 0)
- **N이 홀수** → 1칸 점프로 왔다 (`-1`, 배터리 1 소모), 이후 짝수가 되므로 다시 /2

이 과정을 반복하면 홀수인 경우에만 배터리가 소모된다. 즉, **N을 이진수로 표현했을 때 1비트의 개수**가 정답이다.

| N | 이진수 | 1비트 수 | 결과 |
|---|--------|---------|------|
| 5 | `101` | 2 | 2 |
| 6 | `110` | 2 | 2 |
| 5000 | `1001110001000` | 5 | 5 |

## 풀이

```java
public int solution(int n) {
    return Integer.bitCount(n);
}
```

## 회고

N을 앞에서부터 만들어가는 방향으로 생각하면 복잡해지지만, 역방향으로 뒤집으면 규칙이 명확해진다. 짝수는 무조건 순간이동(`/2`), 홀수만 점프(`-1`)가 필요하다는 점이 그대로 이진수의 1비트와 대응된다. 이 관찰을 `Integer.bitCount` 한 줄로 표현할 수 있다.
