## 문제

> 링크: [프로그래머스 64065](https://school.programmers.co.kr/learn/courses/30/lessons/64065)

집합 표기법 문자열 `{{a1},{a1,a2},...,{a1,...,an}}` 을 파싱해 원래 튜플 배열을 반환하는 문제.

## 접근

### 빈도 카운팅

튜플 `(a1, a2, ..., an)` 에서 `a1` 은 n개의 집합 모두에, `a2` 는 n-1개의 집합에, ..., `an` 은 1개의 집합에만 등장한다.

즉 **각 원소의 출현 빈도 = 튜플 내 역순 인덱스** 이므로, 집합을 직접 파싱하는 대신 전체 문자열에서 각 숫자의 출현 횟수를 세고 빈도 내림차순으로 정렬하면 튜플이 복원된다.

문자열 파싱은 `split("[{},]+")` 한 번으로 숫자 토큰을 추출한다. 맨 앞 `{{` 때문에 첫 번째 결과가 빈 문자열이므로 인덱스 1부터 사용한다.

## 풀이

```java
import java.util.*;

public int[] solution(String s) {
    int[] parsed = parse(s);
    Map<Integer, Integer> map = new HashMap<>();
    for (int n : parsed) {
        map.merge(n, 1, Integer::sum);
    }
    return sortByValueDesc(map);
}

public int[] parse(String s) {
    String[] split = s.split("[{},]+");
    int[] parsed = new int[split.length - 1];
    for (int i = 0; i < split.length - 1; i++) {
        parsed[i] = Integer.parseInt(split[i + 1]);
    }
    return parsed;
}

public int[] sortByValueDesc(Map<Integer, Integer> map) {
    List<Map.Entry<Integer, Integer>> list = new ArrayList<>(map.entrySet());
    list.sort(Map.Entry.comparingByValue(Comparator.reverseOrder()));
    int[] res = new int[list.size()];
    for (int i = 0; i < list.size(); i++) {
        res[i] = list.get(i).getKey();
    }
    return res;
}
```

## 회고

집합을 크기순으로 정렬해 새 원소를 찾는 방식도 가능하지만, 빈도 카운팅 접근이 훨씬 단순하다. 집합 구조를 분석하는 대신 전체 문자열에서의 출현 횟수만으로 순서를 결정할 수 있다는 점이 핵심 발상이었다.
