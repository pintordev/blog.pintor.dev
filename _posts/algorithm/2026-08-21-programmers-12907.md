## 문제

> 링크: [프로그래머스 12907](https://school.programmers.co.kr/learn/courses/30/lessons/12907)

n원을 화폐 단위 money의 조합으로 거슬러 주는 방법의 수를 구하는 문제다.

## 접근

### 1차원 DP (동전 조합 카운팅)

`dp[j]`를 j원을 만드는 조합의 수로 정의한다. `dp[0] = 1`로 초기화한 뒤, 화폐를 바깥 루프로, 금액을 안쪽 루프로 돌며 `dp[j] += dp[j - coin]`을 누적한다.

화폐를 바깥 루프에 두는 게 핵심이다. 각 화폐가 "몇 개 쓸지"를 한 번씩만 결정하게 되어, 1+2와 2+1처럼 순서만 다른 조합이 중복으로 카운트되지 않는다. 반대로 금액을 바깥 루프에 두면 화폐를 선택하는 순서까지 구분하게 되어 순열을 세는 꼴이 된다.

n ≤ 100,000, 화폐 종류 ≤ 100이므로 전체 연산량은 최대 10,000,000회로 시간복잡도 상 충분히 통과 가능하다. dp 값끼리의 합도 int 범위 내에서 안전하게 처리된다.

## 풀이

```java
public int solution(int n, int[] money) {
    int MOD = 1_000_000_007;
    int[] dp = new int[n + 1];
    dp[0] = 1;
    for (int coin : money) {
        for (int j = coin; j <= n; j++) {
            dp[j] = (dp[j] + dp[j - coin]) % MOD;
        }
    }
    return dp[n];
}
```
