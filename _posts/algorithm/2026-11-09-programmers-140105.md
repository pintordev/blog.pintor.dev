## 문제

> 링크: [프로그래머스 140105](https://school.programmers.co.kr/learn/courses/30/lessons/140105)

높이 1~n의 빌딩이 2채씩 일렬로 서 있고 같은 높이 사이에 더 높은 빌딩이 없을 때, 한쪽에서 보이는 높이가 정확히 count종류인 배치의 수를 구하는 문제.

## 접근

### 가장 낮은 쌍을 끼워 넣는 DP

높은 빌딩부터 차례로 배치한다고 생각하면, 새로 넣는 높이는 항상 이미 놓인 모든 빌딩보다 낮다. 같은 높이 두 채 사이에 더 높은 빌딩이 오면 안 되므로 새 쌍은 반드시 붙어서 한 자리에 들어간다. 또 새 쌍은 가장 낮기 때문에 기존 빌딩의 보임 여부에 영향을 주지 않는다.

- 맨 앞에 넣으면 가리는 빌딩이 없으므로 보이는 종류가 1 늘어난다.
- 그 외 자리에 넣으면 앞의 더 높은 빌딩에 가려진다. 기존 2(i-1)채 각각의 뒤가 후보이므로 2(i-1)가지다.

`dp[i][j]`를 높이 i종류까지 배치했을 때 j종류가 보이는 경우의 수로 두면 다음 점화식이 나온다.

```
dp[i][j] = dp[i-1][j-1] + dp[i-1][j] × 2(i-1)
```

초기값은 `dp[1][1] = 1`이다. 곱셈 결과가 int 범위를 넘을 수 있어 long 배열을 쓰고 매번 1,000,000,007로 나눈 나머지를 취한다. 시간복잡도는 O(n × count)다.

## 풀이

```java
public int solution(int n, int count) {
    int mod = 1_000_000_007;
    long[][] dp = new long[n + 1][count + 1];
    dp[1][1] = 1;
    for (int i = 2; i <= n; i++) {
        for (int j = 1; j <= count; j++) {
            dp[i][j] = (dp[i - 1][j - 1] + dp[i - 1][j] * 2 * (i - 1)) % mod;
        }
    }
    return (int) dp[n][count];
}
```
