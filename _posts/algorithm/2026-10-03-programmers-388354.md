## 문제

> 링크: [프로그래머스 388354](https://school.programmers.co.kr/learn/courses/30/lessons/388354)

루트가 정해지지 않은 포레스트에서, 루트를 적절히 정했을 때 홀짝 트리가 될 수 있는 트리의 수와 역홀짝 트리가 될 수 있는 트리의 수를 구하는 문제.

## 접근

### 루트를 정하지 않고 노드 번호와 degree의 홀짝으로 판정

루트를 직접 시도하면 트리마다 후보가 너무 많아진다. 대신 루트의 자식 수는 `degree`, 루트가 아닌 노드의 자식 수는 `degree - 1`이라는 점을 이용한다.

노드 번호와 `degree`의 홀짝이 같은 노드를 A, 다른 노드를 B로 나눈다.

- 루트가 A면 홀수/짝수 노드, 루트가 B면 역홀수/역짝수 노드가 된다.
- 루트가 아닌 노드는 반대로, B면 홀수/짝수 노드, A면 역홀수/역짝수 노드가 된다.

따라서 한 트리가 홀짝 트리가 되려면 루트만 A이고 나머지는 모두 B여야 하므로 A가 정확히 1개여야 한다. 역홀짝 트리는 루트만 B이고 나머지는 모두 A여야 하므로 B가 정확히 1개여야 한다. 두 조건은 독립이라 한 트리가 둘 다 만족할 수도 있다(노드 2개짜리 트리). 간선이 없는 단독 노드도 하나의 트리이며, `degree`가 0이라 번호가 짝수면 A, 홀수면 B로 계산된다.

### Union-Find로 트리 구분

간선을 읽으면서 `degree`를 세고 union으로 같은 트리끼리 묶는다. 이후 `nodes`를 순회하며 각 노드를 대표 노드 기준으로 A/B 개수에 누적하고, 대표 노드마다 A가 1인지, B가 1인지를 센다. 노드 번호가 최대 1,000,000이므로 배열 인덱싱으로 처리하며, 시간복잡도는 사실상 O(N + E)이다.

## 풀이

```java
int[] parent = new int[1000001];

public int[] solution(int[] nodes, int[][] edges) {
    int[] degree = new int[1000001];
    for (int node : nodes) {
        parent[node] = node;
    }
    for (int[] edge : edges) {
        degree[edge[0]]++;
        degree[edge[1]]++;
        union(edge[0], edge[1]);
    }
    int[] same = new int[1000001];
    int[] diff = new int[1000001];
    for (int node : nodes) {
        int root = find(node);
        if (node % 2 == degree[node] % 2) same[root]++;
        else diff[root]++;
    }
    int[] res = new int[2];
    for (int node : nodes) {
        if (parent[node] != node) continue;
        if (same[node] == 1) res[0]++;
        if (diff[node] == 1) res[1]++;
    }
    return res;
}

public void union(int a, int b) {
    parent[find(a)] = find(b);
}

public int find(int x) {
    while (parent[x] != x) {
        parent[x] = parent[parent[x]];
        x = parent[x];
    }
    return x;
}
```
