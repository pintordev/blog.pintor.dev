## 문제

> 링크: [프로그래머스 92335](https://school.programmers.co.kr/learn/courses/30/lessons/92335)

양의 정수 n을 k진수로 변환한 뒤, 0을 구분자로 나눈 각 수가 10진법 소수인지 판별하여 개수를 반환하는 문제

## 접근

### k진수 변환 후 0 기준 분리

`Integer.toString(n, k)`로 k진수 문자열을 얻은 뒤 `split("0+")`으로 0을 구분자 삼아 토큰을 추출한다. 각 토큰을 `long`으로 파싱해 소수 판별하면 된다.

주의할 점은 소수 판별 루프의 `i * i` 계산이다. k진수 토큰을 10진수로 해석한 값이 수백억이 될 수 있어 `i`를 `int`로 두면 `i * i`가 int 범위를 초과해 음수로 오버플로우된다. 루프 변수를 `long`으로 선언해야 정확한 비교가 보장된다.

## 풀이

```java
public int solution(int n, int k) {
    int cnt = 0;
    for (String token : Integer.toString(n, k).split("0+")) {
        if (isPrime(token)) cnt++;
    }
    return cnt;
}

public boolean isPrime(String s) {
    if (s.isBlank() || s.equals("1")) return false;
    long n = Long.parseLong(s);
    for (long i = 2; i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}
```

## 회고

처음 작성할 때 `for (int i = 2; i * i <= n; i++)`로 썼다가 오버플로우 버그를 발견했다. k=3처럼 작은 진수로 변환하면 토큰을 10진수로 해석한 값이 수백억에 달할 수 있고, 이때 `int i`의 `i * i`가 2^31을 넘어 음수로 wrap되면 루프 조건이 항상 참이 되어 비정상 동작한다. 루프 변수를 `long`으로 바꿔 해결했다.
