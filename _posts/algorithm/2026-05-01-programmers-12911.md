## 문제

> 링크: [프로그래머스 12911](https://school.programmers.co.kr/learn/courses/30/lessons/12911)

n보다 크고, 이진수로 변환 시 1의 개수가 같은 수 중 가장 작은 수를 구하라.

## 접근

### 비트 재배치 (Gosper's Hack)

i개의 연속 자연수를 이진수로 보면, 같은 popcount를 가진 다음 큰 수는 오른쪽의 `0...01...1` 패턴을 찾아 재배치하면 구할 수 있다.

```
78 = 1001110
        ↑↑↑↑
    c0=1(trailing 0), c1=3(trailing 1), p=4
```

3단계로 변환한다.

1. p번 비트를 1로 올린다 — n보다 커지는 최소 위치
2. p 미만 비트를 전부 0으로 클리어 — 이 자리를 최소화할 준비
3. 최하위에 (c1-1)개의 1을 몰아넣는다 — 남은 1을 최하위에 배치해 최솟값 확보

## 풀이

```java
public int solution(int n) {
    int c = n;
    int c0 = 0, c1 = 0;
    while ((c & 1) == 0 && c != 0) {c0++; c >>= 1;}
    while ((c & 1) == 1) {c1++; c >>= 1;}
    int p = c0 + c1;
    n |= (1 << p);
    n &= ~((1 << p) - 1);
    n |= (1 << (c1 - 1)) - 1;
    return n;
}
```

## 회고

Gosper's Hack이라 불리는 비트 트릭이다. 핵심은 오른쪽 `01...1` 패턴의 0을 1로 올리고, 아래 비트를 전부 클리어한 뒤 1을 최하위에 몰아넣는 것이다. O(1) 연산으로 해결된다.
