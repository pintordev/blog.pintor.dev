## 문제

> 링크: [프로그래머스 17685](https://school.programmers.co.kr/learn/courses/30/lessons/17685)

학습된 단어들을 각각 검색할 때, 다른 단어와 구분되는 최소 앞부분까지만 입력한다고 가정하고 전체 입력 글자 수의 합을 구하는 문제.

## 접근

### 트라이 + 통과 횟수

단어 개수 N이 최대 100,000, 글자 수 총합 L이 최대 1,000,000이라 단어 쌍을 전부 비교하면 시간 초과가 난다. 접두사를 공유하는 구조를 한 번에 다루는 트라이를 쓰면 O(L)에 해결된다.

1. 모든 단어를 트라이에 삽입하면서 지나가는 노드마다 `cnt`(그 노드를 지나는 단어 수)를 1씩 올린다.
2. 각 단어를 루트부터 다시 따라 내려가며 글자를 하나 입력할 때마다 입력 수를 1 늘린다. 도달한 노드의 `cnt`가 1이면 다른 단어와 구분된 것이므로 거기서 멈춘다.
3. 끝까지 `cnt == 1`이 되지 않으면 단어 전체를 입력해야 한다. 다른 단어의 접두사인 경우이며, 루프가 끝까지 돌면서 단어 길이만큼 더해진다.

`gone`은 `g`, `go`에서 `cnt`가 2이고 `gon`에서 1이 되므로 3글자, 접두사 단어 `go`는 끝까지 `cnt`가 2 이상이라 2글자를 입력한다.

## 풀이

```java
Node root;

public int solution(String[] words) {
    root = new Node();
    for (String word : words) {
        insert(word);
    }
    int res = 0;
    for (String word : words) {
        Node cur = root;
        for (char ch : word.toCharArray()) {
            cur = cur.next[ch - 'a'];
            res++;
            if (cur.cnt == 1) break;
        }
    }
    return res;
}

public void insert(String word) {
    Node cur = root;
    for (char ch : word.toCharArray()) {
        if (cur.next[ch - 'a'] == null) cur.next[ch - 'a'] = new Node();
        cur = cur.next[ch - 'a'];
        cur.cnt++;
    }
}

class Node {
    Node[] next = new Node[26];
    int cnt;
}
```
