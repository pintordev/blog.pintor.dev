## 문제

> 링크: [프로그래머스 43238](https://school.programmers.co.kr/learn/courses/30/lessons/43238)

n명이 줄을 서 있고, 각 심사관마다 한 명을 심사하는데 걸리는 시간이 다를 때, 모든 사람이 심사를 마치는데 걸리는 최소 시간을 구하는 문제다.

## 접근

### 이분 탐색(Parametric Search)

n이 최대 10억이라 사람 수만큼 순회하거나 시뮬레이션하는 방식으로는 시간 초과가 난다. 대신 "특정 시간 t 안에 n명을 모두 심사할 수 있는가"를 판정하는 함수를 만들고, 이 판정이 참이 되는 최소 t를 이분 탐색으로 찾는 방식으로 접근한다.

시간 t가 주어지면 심사관 i는 `t / times[i]`명을 처리할 수 있으므로, 모든 심사관의 처리량 합이 n 이상이면 t 안에 심사를 마칠 수 있다. 탐색 구간은 `lo = 0`, `hi = n * times[마지막 인덱스]`로 잡는다. 심사관 하나만으로 n명을 처리한다고 가정한 시간이므로 항상 유효한 상한이 된다. 이 구간에서 `lo + 1 < hi`인 동안 이분 탐색을 반복해 조건을 만족하는 최소 t(hi)를 구한다.

## 풀이

```java
public long solution(int n, int[] times) {
    int tLen = times.length;
    long lo = 0, hi = (long) n * times[tLen - 1];
    while (lo + 1 < hi) {
        long mid = (lo + hi) >> 1;
        long cnt = 0;
        for (int i = 0; i < tLen && cnt < n; i++) {
            cnt += mid / times[i];
        }
        if (cnt < n) lo = mid;
        else hi = mid;
    }
    return hi;
}
```
