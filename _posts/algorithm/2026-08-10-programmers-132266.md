## 문제

> 링크: [프로그래머스 132266](https://school.programmers.co.kr/learn/courses/30/lessons/132266)

여러 지역에 흩어져 임무를 수행 중인 부대원들이 각자 위치에서 부대(destination)까지 복귀하는 데 걸리는 최단 시간을 구하는 문제다. 복귀 경로가 없으면 -1을 반환해야 한다.

## 접근

### destination을 시작점으로 하는 단일 BFS

모든 도로는 왕복 가능하고 통과 시간이 1로 동일하므로, 최단 시간은 곧 최단 경로의 간선 수와 같다. `sources`마다 개별로 BFS를 돌릴 수도 있지만, 그래프가 무방향이라는 점을 이용하면 `destination` 하나를 시작점으로 BFS를 한 번만 수행해 모든 지역까지의 최단 거리를 구할 수 있다. 이후 `sources`의 각 원소에 대해 미리 구해둔 거리를 조회만 하면 된다.

거리 배열은 -1로 초기화해 미방문 상태를 표시하고, `destination`의 거리만 0으로 시작한다. BFS가 끝난 뒤에도 -1로 남아있는 노드는 도달 불가능한 지역이므로 그대로 -1을 반환하면 된다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.Queue;

public int[] solution(int n, int[][] roads, int[] sources, int destination) {
    List<Integer>[] graph = new List[n + 1];
    for (int i = 1; i <= n; i++) {
        graph[i] = new ArrayList<>();
    }
    for (int[] road : roads) {
        int a = road[0];
        int b = road[1];
        graph[a].add(b);
        graph[b].add(a);
    }

    int[] dist = new int[n + 1];
    Arrays.fill(dist, -1);
    Queue<Integer> queue = new ArrayDeque<>();
    queue.add(destination);
    dist[destination] = 0;
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        for (int next : graph[cur]) {
            if (dist[next] != -1) continue;
            dist[next] = dist[cur] + 1;
            queue.add(next);
        }
    }

    int[] res = new int[sources.length];
    for (int i = 0; i < sources.length; i++) {
        res[i] = dist[sources[i]];
    }
    return res;
}
```
