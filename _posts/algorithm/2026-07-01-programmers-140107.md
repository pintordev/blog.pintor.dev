## 문제

> 링크: [프로그래머스 140107](https://school.programmers.co.kr/learn/courses/30/lessons/140107)

x, y 모두 k의 배수인 격자점 중 원점으로부터 거리가 d 이하인 점의 개수를 구하는 문제.

## 접근

### x를 k 간격으로 순회하며 유효한 y 개수 합산

x = 0, k, 2k, ... 순으로 순회하면서, 각 x에 대해 `x² + y² ≤ d²`를 만족하는 y(k의 배수)의 개수를 구한다.

특정 x에서 유효한 최대 y는 `sqrt(d² - x²)`이며, k의 배수 중 이 이하인 수의 개수는 `floor(sqrt(d² - x²) / k) + 1`이다.

x 순회 횟수는 최대 d/k + 1 = 10⁶번이므로 O(d/k) 안에 해결된다.

## 풀이

```java
public long solution(int k, int d) {
    long cnt = 0;
    long ds = (long) d * d;
    for (long i = 0; i <= d; i += k) {
        cnt += (long) Math.sqrt(ds - i * i) / k + 1;
    }
    return cnt;
}
```
