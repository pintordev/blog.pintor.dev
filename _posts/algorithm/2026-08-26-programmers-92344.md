## 문제

> 링크: [프로그래머스 92344](https://school.programmers.co.kr/learn/courses/30/lessons/92344)

N x M 크기의 건물 내구도 배열에 여러 번의 공격(내구도 감소)과 회복(내구도 증가) 스킬을 직사각형 범위로 적용한 뒤, 파괴되지 않은(내구도 1 이상) 건물의 개수를 구한다.

## 접근

### 2D 차분 배열(difference array)

skill의 개수는 최대 250,000개, 보드는 최대 1,000 x 1,000이다. 스킬마다 직사각형 범위를 직접 순회하며 내구도를 갱신하면 최악의 경우 O(K·N·M)이 되어 시간초과가 난다.

각 스킬은 직사각형 범위 전체에 동일한 값을 더하거나 빼는 연산이므로, 범위의 네 꼭짓점에만 표시를 남기고 나중에 한 번의 누적합으로 복원하는 2D 차분 배열을 쓸 수 있다. 좌상단 `(r1, c1)`에 `val`을 더하고, `(r1, c2+1)`과 `(r2+1, c1)`에 `-val`을, `(r2+1, c2+1)`에 `val`을 더해두면 각 스킬을 O(1)에 기록할 수 있다.

스킬 기록이 끝나면 배열 전체에 2D 누적합(가로 누적 + 세로 누적 - 좌상단 중복 제거)을 한 번 돌려 각 칸에 최종적으로 적용된 변화량을 구한다. 이때 배열을 `[n+2][m+2]`로 한 칸씩 밀어서 잡아두면(1-based 패딩) 0번 행·열이 항상 0이 되므로, 경계에서 `r > 0`, `c > 0` 같은 조건 분기 없이 누적합 공식을 그대로 적용할 수 있다.

## 풀이

```java
public int solution(int[][] board, int[][] skill) {
    int n = board.length;
    int m = board[0].length;
    int[][] diff = new int[n + 2][m + 2];
    for (int[] sk : skill) {
        int val = sk[0] == 1 ? -sk[5] : sk[5];
        diff[sk[1] + 1][sk[2] + 1] += val;
        diff[sk[1] + 1][sk[4] + 2] -= val;
        diff[sk[3] + 2][sk[2] + 1] -= val;
        diff[sk[3] + 2][sk[4] + 2] += val;
    }

    int cnt = 0;
    for (int r = 1; r <= n; r++) {
        for (int c = 1; c <= m; c++) {
            diff[r][c] += diff[r - 1][c] + diff[r][c - 1] - diff[r - 1][c - 1];
            if (board[r - 1][c - 1] + diff[r][c] > 0) cnt++;
        }
    }
    return cnt;
}
```
