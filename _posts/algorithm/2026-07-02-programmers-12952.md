## 문제

> 링크: [프로그래머스 12952](https://school.programmers.co.kr/learn/courses/30/lessons/12952)

n×n 체스판에 n개의 퀸을 서로 공격할 수 없도록 배치하는 경우의 수를 구한다.

## 접근

### 비트마스킹 백트래킹

각 행에 퀸을 정확히 1개씩 배치한다는 관찰에서 출발한다. 열·대각선 충돌 여부를 비트마스크 3개로 관리하고, 행을 내려갈 때마다 대각선 마스크를 1비트씩 시프트해 이전 행 퀸의 공격 범위를 다음 행에 자동 반영한다.

- `c`: 점유된 열
- `ld`: `\` 대각선 — 한 행 내려갈 때마다 `<< 1`
- `rd`: `/` 대각선 — 한 행 내려갈 때마다 `>> 1`

`available = full & ~(c | ld | rd)`로 현재 행의 후보 열을 한 번에 구하고, `pick = available & -available`로 후보를 하나씩 추출해 재귀 탐색한다.

## 풀이

```java
int n;
int cnt;
int full;

public int solution(int n) {
    this.n = n;
    this.cnt = 0;
    full = (1 << n) - 1;
    dfs(0, 0, 0, 0);
    return cnt;
}

public void dfs(int r, int c, int ld, int rd) {
    if (r == n) {
        cnt++;
        return;
    }
    int available = full & ~(c | ld | rd);
    while (available != 0) {
        int pick = available & -available;
        available -= pick;
        dfs(r + 1, c | pick, (ld | pick) << 1, (rd | pick) >> 1);
    }
}
```
