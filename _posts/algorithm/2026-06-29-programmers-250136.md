## 문제

> 링크: [프로그래머스 250136](https://school.programmers.co.kr/learn/courses/30/lessons/250136)

n×m 격자에서 세로 시추관 1개를 하나의 열에 설치했을 때 획득 가능한 석유의 최댓값을 구하는 문제다.

## 접근

### BFS로 덩어리 사전계산 후 열별 누적합

열마다 독립적으로 BFS를 수행하면 O(n·m·m)이 되어 500×500 격자에서 TLE가 발생한다.

대신 모든 연결 덩어리를 한 번만 BFS로 탐색하면서, 각 덩어리가 교차하는 열 집합과 크기를 함께 구한다. 덩어리 탐색이 끝나면 교차하는 열 각각에 해당 덩어리의 크기를 누적한다. 이렇게 만들어진 `flat[j]`는 j열에 시추관을 설치했을 때 얻는 석유량과 같다. 전체 탐색이 O(n·m)에 끝나므로 효율성을 만족한다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.HashSet;
import java.util.Queue;
import java.util.Set;

int n, m;
int[][] land;
boolean[][] visited;
int[] dr = {-1, 0, 1, 0};
int[] dc = {0, -1, 0, 1};
int[] flat;

public int solution(int[][] land) {
    n = land.length;
    m = land[0].length;
    this.land = land;
    visited = new boolean[n][m];
    flat = new int[m];
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (land[i][j] == 0 || visited[i][j]) continue;
            bfs(i, j);
        }
    }
    int max = 0;
    for (int f : flat) {
        max = Math.max(max, f);
    }
    return max;
}

public void bfs(int i, int j) {
    Set<Integer> set = new HashSet<>();
    int amt = 0;
    Queue<Node> q = new ArrayDeque<>();
    q.add(new Node(i, j));
    visited[i][j] = true;
    amt++;
    set.add(j);
    while (!q.isEmpty()) {
        Node cur = q.poll();
        for (int d = 0; d < 4; d++) {
            int nr = cur.r + dr[d];
            int nc = cur.c + dc[d];
            if (!isAvailable(nr, nc)) continue;
            q.add(new Node(nr, nc));
            visited[nr][nc] = true;
            amt++;
            set.add(nc);
        }
    }
    for (int c : set) {
        flat[c] += amt;
    }
}

public boolean isAvailable(int r, int c) {
    if (r < 0 || r >= n || c < 0 || c >= m) return false;
    if (land[r][c] == 0) return false;
    return !visited[r][c];
}

class Node {
    int r, c;
    Node(int r, int c) {
        this.r = r;
        this.c = c;
    }
}
```
