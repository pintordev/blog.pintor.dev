## 문제

> 링크: [프로그래머스 12900](https://school.programmers.co.kr/learn/courses/30/lessons/12900)

2 x n 크기의 직사각형을 2 x 1 타일로 채우는 방법의 수를 1,000,000,007로 나눈 나머지를 반환한다.

## 접근

### 피보나치 점화식

n번째 열을 채우는 방법은 두 가지다.

- 직전 열(n-1)에 세로 타일 1개를 세우는 경우
- 두 칸 전(n-2)에 가로 타일 2개를 눕히는 경우

따라서 `dp[n] = dp[n-1] + dp[n-2]`가 성립한다. 초기값은 `dp[1] = 1`, `dp[2] = 2`.

배열 없이 변수 두 개로 롤링하면 O(1) 공간으로 처리할 수 있다.

## 풀이

```java
public int solution(int n) {
    int a = 1, b = 2;
    for (int i = 1; i < n; i++) {
        int c = (a + b) % 1_000_000_007;
        a = b;
        b = c;
    }
    return a;
}
```
