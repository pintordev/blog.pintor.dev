## 문제

> 링크: [프로그래머스 92342](https://school.programmers.co.kr/learn/courses/30/lessons/92342)

양궁대회에서 라이언이 n발의 화살로 어피치를 가장 큰 점수 차로 이기기 위한 화살 배분을 구하는 문제.

## 접근

### 백트래킹

n ≤ 10, 점수 존 수 = 11이므로 완전탐색이 가능하다.

각 점수 존(10점~1점)마다 "이길지 / 포기할지" 두 가지를 DFS로 탐색하고, 마지막 0점 존에 남은 화살을 모두 투입한 뒤 점수 차를 계산한다.

- 이기는 경우: `info[d] + 1`발 배치 (남은 화살이 충분할 때만)
- 포기하는 경우: 0발 배치

최대 점수 차를 내는 배분이 여러 가지라면, 낮은 점수 존에 더 많은 화살을 쏜 배분을 선택한다 — 인덱스 10(0점)부터 역순으로 비교해 라이언 화살이 더 많은 쪽을 채택한다.

## 풀이

```java
int[] info;
int[] best;
int bestDiff;

public int[] solution(int n, int[] info) {
    this.info = info;
    best = null;
    bestDiff = 0;
    dfs(0, n, new int[11]);
    return best == null ? new int[]{-1} : best;
}

public void dfs(int d, int remain, int[] ryan) {
    if (d == 10) {
        ryan[10] = remain;
        int diff = calDiff(ryan);
        if (diff > 0 && (diff > bestDiff || (diff == bestDiff && isBetter(ryan)))) {
            best = ryan.clone();
            bestDiff = diff;
        }
        ryan[10] = 0;
        return;
    }
    int need = info[d] + 1;
    if (remain >= need) {
        ryan[d] = need;
        dfs(d + 1, remain - need, ryan);
        ryan[d] = 0;
    }
    dfs(d + 1, remain, ryan);
}

public int calDiff(int[] ryan) {
    int rs = 0, as = 0;
    for (int i = 0; i < 11; i++) {
        if (ryan[i] == 0 && info[i] == 0) continue;
        int s = 10 - i;
        if (ryan[i] > info[i]) rs += s;
        else as += s;
    }
    return rs - as;
}

public boolean isBetter(int[] ryan) {
    for (int i = 10; i >= 0; i--) {
        if (ryan[i] != best[i]) return ryan[i] > best[i];
    }
    return false;
}
```

## 회고

초기 구현에서 `bestDiff`를 별도로 추적하지 않고 `isBetter`만으로 갱신 여부를 판단했다. `isBetter`는 점수 차가 아닌 배분 배열만 비교하기 때문에, 점수 차가 낮은 배분이 "낮은 인덱스에 화살이 더 많다"는 이유로 best 자리를 유지하는 버그가 발생했다. `diff > bestDiff` 조건을 추가해 점수 차가 클 때는 무조건 갱신하고, 같을 때만 `isBetter`로 판단하도록 수정했다.
