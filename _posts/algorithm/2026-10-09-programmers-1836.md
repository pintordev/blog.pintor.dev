## 문제

> 링크: [프로그래머스 1836](https://school.programmers.co.kr/learn/courses/30/lessons/1836)

같은 글자의 타일 두 개를 꺾임 1회 이하의 경로로 이을 수 있을 때 제거하며, 모든 타일을 제거하는 순서 중 사전순으로 가장 앞선 것을 구하는 문제. 불가능하면 `IMPOSSIBLE`을 반환한다.

## 접근

### 그리디 반복 제거

타일을 하나 제거하면 보드가 비어 갈 뿐 다른 쌍의 경로를 새로 막지 않는다. 따라서 지금 제거할 수 있는 쌍은 나중에도 계속 제거할 수 있고, 제거 가능한 쌍 중 알파벳이 가장 앞선 것을 먼저 제거해도 손해가 없다. 이 선택이 곧 사전순 최소 조건이 된다.

1. 보드를 한 번 훑어 글자별 두 타일의 좌표를 `TreeMap`에 저장한다. 키가 자동 정렬되므로 알파벳 순회가 그대로 사전순이 된다.
2. 글자를 순서대로 보며 제거 가능한 첫 글자를 찾아 제거하고, 다시 `A`부터 검사한다. 제거 후 앞선 글자의 경로가 새로 열릴 수 있기 때문이다.
3. 한 바퀴를 돌아도 제거되는 글자가 없으면 `IMPOSSIBLE`, `TreeMap`이 비면 누적한 문자열을 반환한다.

제거 가능 판정은 두 타일의 위치에 따라 나눈다.

- 같은 행이나 같은 열이면 두 점 사이 구간만 검사한다.
- 그 외에는 꺾이는 모서리가 `(r1, c2)`와 `(r2, c1)` 두 곳이다. 위·아래 가로선과 왼쪽·오른쪽 세로선을 먼저 계산해 두고, 대각선 방향에 따라 `(위 && 오른쪽) || (아래 && 왼쪽)` 또는 `(위 && 왼쪽) || (아래 && 오른쪽)`으로 조합한다.

구간 검사는 양 끝점을 포함하고 같은 글자는 통과시킨다. 그러면 끝점 제외 처리가 필요 없고, 모서리 칸이 비어 있는지도 구간 검사에 함께 포함된다.

타일은 최대 26종이므로 라운드 수와 글자 수가 각각 26 이하이고, 판정 한 번은 `O(m + n)`이라 시간은 문제가 되지 않는다.

## 풀이

```java
import java.util.Map;
import java.util.TreeMap;

Map<Character, int[][]> coords;
char[][] map;

public String solution(int m, int n, String[] board) {
    coords = new TreeMap<>();
    map = new char[m][n];
    for (int r = 0; r < m; r++) {
        for (int c = 0; c < n; c++) {
            map[r][c] = board[r].charAt(c);
            if (map[r][c] < 'A') continue;
            int[][] coord = coords.putIfAbsent(map[r][c], new int[][]{{r, c}, {r, c}});
            if (coord != null) coord[1] = new int[]{r, c};
        }
    }
    StringBuilder res = new StringBuilder();
    L:
    while (!coords.isEmpty()) {
        for (char key : coords.keySet()) {
            if (!canRemove(key)) continue;
            remove(key);
            res.append(key);
            continue L;
        }
        return "IMPOSSIBLE";
    }
    return res.toString();
}

public boolean canRemove(char key) {
    int[][] coord = coords.get(key);
    int r1 = coord[0][0];
    int c1 = coord[0][1];
    int r2 = coord[1][0];
    int c2 = coord[1][1];
    int minC = Math.min(c1, c2);
    int maxC = Math.max(c1, c2);
    if (r1 == r2) return checkH(minC, maxC, r1, key);
    if (c1 == c2) return checkV(r1, r2, c1, key);
    boolean u = checkH(minC, maxC, r1, key);
    boolean d = checkH(minC, maxC, r2, key);
    boolean l = checkV(r1, r2, minC, key);
    boolean r = checkV(r1, r2, maxC, key);
    if (c1 < c2) return (u && r) || (d && l);
    return (u && l) || (d && r);
}

public boolean checkH(int c1, int c2, int r, char key) {
    for (int c = c1; c <= c2; c++) {
        if (map[r][c] != '.' && map[r][c] != key) return false;
    }
    return true;
}

public boolean checkV(int r1, int r2, int c, char key) {
    for (int r = r1; r <= r2; r++) {
        if (map[r][c] != '.' && map[r][c] != key) return false;
    }
    return true;
}

public void remove(char key) {
    int[][] coord = coords.remove(key);
    map[coord[0][0]][coord[0][1]] = '.';
    map[coord[1][0]][coord[1][1]] = '.';
}
```
