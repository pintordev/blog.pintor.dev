## 문제

> 링크: [프로그래머스 154540](https://school.programmers.co.kr/learn/courses/30/lessons/154540)

격자 지도에서 상하좌우로 연결된 땅(숫자)들의 합을 섬별로 구해 오름차순으로 반환한다.

## 접근

### BFS로 연결 요소 탐색

격자를 순회하면서 방문하지 않은 땅 셀을 발견하면 BFS를 시작해 하나의 섬 전체를 탐색한다. 탐색 중 만나는 숫자를 누적해 섬의 합계를 구하고, 모든 섬의 합계를 오름차순 정렬해 반환한다. 섬이 하나도 없으면 `[-1]`을 반환한다.

## 풀이

```java
import java.util.*;

String[] maps;
int n, m;
int[] dr = {-1, 0, 1, 0};
int[] dc = {0, 1, 0, -1};
boolean[][] visited;

public int[] solution(String[] maps) {
    this.maps = maps;
    this.n = maps.length;
    this.m = maps[0].length();
    visited = new boolean[n][m];
    List<Integer> list = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (!isAvailable(nr, nc)) continue;
            list.add(bfs(i, j));
        }
    }
    if (list.isEmpty()) return new int[]{-1};
    Collections.sort(list);
    int[] res = new int[list.size()];
    for (int i = 0; i < list.size(); i++) {
        res[i] = list.get(i);
    }
    return res;
}

public int bfs(int r, int c) {
    Queue<Node> q = new ArrayDeque<>();
    q.add(new Node(r, c));
    visited[r][c] = true;
    int sum = maps[r].charAt(c) - '0';
    while (!q.isEmpty()) {
        Node cur = q.poll();
        for (int i = 0; i < dr.length; i++) {
            int nr = cur.r + dr[i];
            int nc = cur.c + dc[i];
            if (!isAvailable(nr, nc)) continue;
            q.add(new Node(nr, nc));
            visited[nr][nc] = true;
            sum += maps[nr].charAt(nc) - '0';
        }
    }
    return sum;
}

public boolean isAvailable(int nr, int nc) {
    if (nr < 0 || nr >= n || nc < 0 || nc >= m) return false;
    if (maps[nr].charAt(nc) == 'X') return false;
    if (visited[nr][nc]) return false;
    return true;
}

class Node {
    int r, c;
    public Node(int r, int c) {
        this.r = r;
        this.c = c;
    }
}
```
