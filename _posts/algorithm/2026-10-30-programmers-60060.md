## 문제

> 링크: [프로그래머스 60060](https://school.programmers.co.kr/learn/courses/30/lessons/60060)

접두사 또는 접미사 위치에만 와일드카드 `?`가 있는 키워드마다, 길이가 같고 `?` 외의 글자가 일치하는 단어의 수를 구하는 문제.

## 접근

### 길이별 정렬 + 이분탐색

단어 수와 키워드 수가 각각 최대 10만 개이므로 모든 (단어, 키워드) 쌍을 비교하는 방식은 효율성 테스트를 통과하지 못한다.

`?`는 글자 하나와 매치되므로 키워드와 길이가 같은 단어만 후보가 된다. 단어를 길이별로 나누어 사전순으로 정렬해 두면, `?`를 `a`로 채운 문자열이 하한, `z`로 채운 문자열이 상한이 된다. `fro??`라면 `froaa` 이상 `frozz` 이하인 단어가 매치되는 단어다. 이분탐색으로 두 경계의 위치를 구하고 그 차이를 답으로 한다.

- 하한은 첫 `>=` 위치, 상한은 첫 `>` 위치를 구한다. 하한을 "이하" 기준으로 구하면 `?` 자리가 전부 `a`인 단어(`froaa` 등)가 빠진다.
- `?`가 접두사 위치에 있는 키워드(`????o`)는 단어와 키워드를 모두 뒤집어서 같은 방식으로 처리한다. 뒤집은 단어 배열을 따로 정렬해 둔다.
- 경계 문자열을 매번 만들지 않고, 비교할 때 `?`를 `a` 또는 `z`로 간주해 직접 비교한다.
- 길이별 배열은 `String[10_001][]`로 두어 해시 조회 없이 접근한다. 해당 길이의 단어가 없으면 길이 0인 배열이라 결과가 0이 된다.

시간복잡도는 정렬이 O(L log W), 키워드 하나당 검색이 O(len log W)이다. L은 단어 길이의 합, W는 단어 수이다. 공간복잡도는 O(L)이다.

### 트라이와의 비교

길이별 정방향·역방향 트라이에 지나간 단어 수를 저장하는 방법도 있다. 시간복잡도는 O(L)로 더 좋지만 노드를 최대 약 2·10^6개 만들어야 하고, 같은 입력에서 정렬 방식보다 메모리를 더 쓰는 경우가 많았다. 속도 차이도 수십 ms 수준이라 구현이 짧은 정렬 + 이분탐색을 택했다.

## 풀이

```java
import java.util.Arrays;

String[][] front = new String[10_001][];
String[][] back = new String[10_001][];

public int[] solution(String[] words, String[] queries) {
    int[] cnt = new int[10_001];
    for (String word : words) {
        cnt[word.length()]++;
    }
    for (int len = 1; len <= 10_000; len++) {
        front[len] = new String[cnt[len]];
        back[len] = new String[cnt[len]];
    }
    for (String word : words) {
        int len = word.length();
        front[len][--cnt[len]] = word;
        back[len][cnt[len]] = reverse(word);
    }
    for (int len = 1; len <= 10_000; len++) {
        Arrays.sort(front[len]);
        Arrays.sort(back[len]);
    }
    int[] res = new int[queries.length];
    for (int i = 0; i < queries.length; i++) {
        String query = queries[i];
        if (query.charAt(0) != '?') res[i] = match(front[query.length()], query);
        else res[i] = match(back[query.length()], reverse(query));
    }
    return res;
}

public int match(String[] arr, String query) {
    return bs(arr, query, 'z', true) - bs(arr, query, 'a', false);
}

public int bs(String[] arr, String query, char fill, boolean upper) {
    int lo = 0, hi = arr.length - 1;
    while (lo < hi + 1) {
        int mid = (lo + hi) >> 1;
        int diff = compare(arr[mid], query, fill);
        if (upper ? diff <= 0 : diff < 0) lo = mid + 1;
        else hi = mid - 1;
    }
    return lo;
}

public int compare(String word, String query, char fill) {
    for (int i = 0; i < word.length(); i++) {
        char c = query.charAt(i) == '?' ? fill : query.charAt(i);
        if (word.charAt(i) != c) return word.charAt(i) - c;
    }
    return 0;
}

public String reverse(String str) {
    return new StringBuilder(str).reverse().toString();
}
```
