## 문제

> 링크: [프로그래머스 12929](https://school.programmers.co.kr/learn/courses/30/lessons/12929)

n쌍의 괄호로 만들 수 있는 올바른 괄호 문자열의 개수를 구하는 문제.

## 접근

### 1차원 DP (카탈란 점화식)

`dp[i]`를 i쌍의 괄호로 만들 수 있는 올바른 괄호 문자열의 수로 정의한다. 문자열의 첫 `(`와 짝이 되는 `)`를 기준으로 나누면 `(` + 안쪽 j쌍 + `)` + 바깥쪽 i-1-j쌍 형태가 된다. 안쪽과 바깥쪽은 서로 독립이므로 경우의 수를 곱하고, j를 0부터 i-1까지 돌며 더한다.

`dp[i] = Σ dp[j] * dp[i-1-j]` (j = 0..i-1), `dp[0] = 1`

n ≤ 14에서 답은 최대 2,674,440이므로 `int`로 충분하다. 시간복잡도는 O(n²), 공간복잡도는 O(n)이다.

## 풀이

```java
public int solution(int n) {
    int[] dp = new int[n + 1];
    dp[0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            dp[i] += dp[j] * dp[i - 1 - j];
        }
    }
    return dp[n];
}
```
