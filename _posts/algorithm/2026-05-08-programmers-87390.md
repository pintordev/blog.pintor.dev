## 문제

> 링크: [프로그래머스 87390](https://school.programmers.co.kr/learn/courses/30/lessons/87390)

n×n 배열을 규칙에 따라 채운 뒤 1차원으로 펼쳐서 [left, right] 구간의 배열을 반환하는 문제.

## 접근

### 좌표 수식으로 직접 계산

n이 최대 10^7이라 2차원 배열을 직접 생성하면 메모리 초과가 발생한다.

1차원 인덱스 `k`에서 행·열을 수식으로 바로 구할 수 있다.

- `row = k / n` (0-indexed)
- `col = k % n` (0-indexed)

배열이 i×i 정사각형을 숫자 i로 덮어쓰는 구조이므로, 해당 칸의 값은 행·열 중 더 큰 쪽(1-indexed)이 된다.

- `arr[k] = Math.max(row + 1, col + 1)`

`right - left < 10^5`이므로 해당 범위만큼만 순회하면 충분하다.

## 풀이

```java
public int[] solution(long n, long left, long right) {
    int[] slice = new int[(int) (right - left + 1)];
    for (long i = left; i <= right; i++) {
        slice[(int) (i - left)] = (int) Math.max(i / n + 1, i % n + 1);
    }
    return slice;
}
```
