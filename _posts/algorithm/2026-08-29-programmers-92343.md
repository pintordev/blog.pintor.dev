## 문제

> 링크: [프로그래머스 92343](https://school.programmers.co.kr/learn/courses/30/lessons/92343)

이진 트리 모양 초원의 각 노드에 양 또는 늑대가 한 마리씩 있다. 루트(항상 양)에서 출발해 이미 방문한 노드와 인접한 노드로 이동하며 양과 늑대를 데려가다가, 누적 늑대 수가 누적 양 수 이상이 되면 그 순간 양이 전부 잡아먹힌다. 잡아먹히지 않으면서 모을 수 있는 최대 양의 수를 구한다.

## 접근

### 방문 집합을 비트마스크 상태로 표현

이동은 스택처럼 한 방향으로만 진행하는 것이 아니라, **지금까지 방문한 노드 전체의 인접 노드 중 아무 곳**으로나 갈 수 있다. 즉 다음에 갈 수 있는 후보(프런티어)는 "방문 순서"가 아니라 "지금까지 방문한 노드 집합" 그 자체로 결정된다. 그래서 상태를 방문 노드 집합의 비트마스크(`mask`) 하나로 표현하면, 그 상태에서 도달 가능한 최대 양의 수도 `mask`만의 함수가 된다.

- `sheepMask`, `wolfMask`: 각 노드가 양인지 늑대인지를 미리 비트마스크로 분류해두고, 특정 상태의 양/늑대 수는 `Integer.bitCount(mask & sheepMask)`처럼 바로 계산한다.
- `frontierMask(mask)`: 방문된 노드들의 인접 노드 중 아직 방문하지 않은 노드들을 모아 비트마스크로 반환한다. 그래프를 양방향으로 구성해두면, 이미 방문한 부모 노드는 `mask`에 포함돼 있어 자연스럽게 후보에서 빠지고 자식 노드만 후보로 남는다.
- `dfs(mask)`: 지금 상태에서 멈추는 경우(현재 양 수)와, 프런티어의 각 후보를 추가로 방문했을 때(늑대 < 양인 경우만) 재귀로 얻는 값 중 최댓값을 반환한다. 같은 `mask`는 어떤 순서로 도달했든 이후 탐색 결과가 동일하므로 `memo[mask]`에 결과를 캐싱해 중복 계산을 막는다.
- 프런티어 후보를 순회할 때는 `for (int f = frontier; f != 0; f &= f - 1)` 관용구로 켜진 비트를 하나씩 뽑아내고, `Integer.numberOfTrailingZeros(f)`로 그 비트가 몇 번 노드인지 얻는다.

## 풀이

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

int n;
List<Integer>[] graph;
int sheepMask;
int wolfMask;
int[] memo;

public int solution(int[] info, int[][] edges) {
    n = info.length;
    graph = new List[n];
    for (int i = 0; i < n; i++) {
        graph[i] = new ArrayList<>();
    }
    for (int[] e : edges) {
        graph[e[0]].add(e[1]);
        graph[e[1]].add(e[0]);
    }
    sheepMask = 0;
    wolfMask = 0;
    for (int i = 0; i < n; i++) {
        if (info[i] == 0) sheepMask |= (1 << i);
        else wolfMask |= (1 << i);
    }
    memo = new int[1 << n];
    Arrays.fill(memo, -1);
    return dfs(1);
}

public int dfs(int mask) {
    if (memo[mask] != -1) return memo[mask];
    int best = Integer.bitCount(mask & sheepMask);
    int frontier = frontierMask(mask);
    for (int f = frontier; f != 0; f &= f - 1) {
        int v = Integer.numberOfTrailingZeros(f);
        int newMask = mask | (1 << v);
        int sheep = Integer.bitCount(newMask & sheepMask);
        int wolf = Integer.bitCount(newMask & wolfMask);
        if (wolf < sheep) best = Math.max(best, dfs(newMask));
    }
    return memo[mask] = best;
}

public int frontierMask(int mask) {
    int res = 0;
    for (int u = 0; u < n; u++) {
        if ((mask & (1 << u)) == 0) continue;
        for (int v : graph[u]) {
            if ((mask & (1 << v)) == 0) res |= (1 << v);
        }
    }
    return res;
}
```
