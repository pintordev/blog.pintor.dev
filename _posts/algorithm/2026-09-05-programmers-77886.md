## 문제

> 링크: [프로그래머스 77886](https://school.programmers.co.kr/learn/courses/30/lessons/77886)

0과 1로 이루어진 문자열에서 `"110"`을 뽑아 임의의 위치에 다시 삽입하는 연산을 원하는 만큼 반복해, 사전 순으로 가장 앞에 오는 문자열을 만든다.

## 접근

### 110 덩어리를 전부 떼어내고 한 곳에 몰아넣기

`"110"`은 위치를 자유롭게 옮길 수 있으므로, 최종 문자열은 **"떼어낼 수 있는 `110`의 개수"** 와 **"`110`을 모두 제거한 나머지 문자열 `L`"** 만으로 결정된다.

**1. `110` 제거 (스택)**

왼쪽부터 문자를 스택에 쌓다가, 현재 문자가 `'0'`이고 스택 top 2개가 모두 `'1'`이면 셋을 제거하고 카운트를 올린다. 처리 후 스택에 남은 것이 `L`이다.

`L`에는 `"110"` 부분문자열이 없다. 따라서 `"11"`이 한 번이라도 등장하면 그 뒤는 전부 `1`이어야 한다. 즉 `L`은 **(앞부분) + (뒤쪽에 몰린 `1`들의 연속)** 꼴이 된다.

**2. `110 × cnt` 삽입 위치**

`110`은 `'1'`로 시작하므로, `L`의 앞쪽 `0`들은 최대한 그대로 두고 **마지막 `'0'` 바로 뒤**에 `110`을 전부 몰아넣는 것이 사전 순으로 가장 작다.

- 그보다 앞에 넣으면: 그 자리가 `'0'`이면 그대로 두는 게 이득이고, `'1'`이면 `L`에 `110`이 없다는 성질상 바로 다음 글자가 `'0'`이라 역시 손해다.
- 그보다 뒤(꼬리 `1` 구간)에 넣으면: `110`의 세 번째 글자 `'0'`이 나오기 전에 `1`이 더 붙어 손해다.

**3. 구현**

`StringBuilder` 하나가 스택 겸 결과 버퍼 역할을 한다. `append`가 push, `setLength(len - 2)`가 pop이다. 마지막에 `lastIndexOf("0") + 1` 위치로 `insert`하면 되는데, `'0'`이 하나도 없으면 `-1 + 1 = 0`으로 맞아떨어져 맨 앞에 삽입된다.

제거한 글자 수(`3 * cnt`)와 다시 넣는 글자 수(`3 * cnt`)가 같아 결과 길이는 원본과 동일하다. 원소당 O(n), 전체 O(모든 원소 길이의 합)으로 제한(합 ≤ 1,000,000)을 통과한다.

## 풀이

```java
public String[] solution(String[] s) {
    for (int i = 0; i < s.length; i++) {
        s[i] = transform(s[i]);
    }
    return s;
}

public String transform(String x) {
    StringBuilder sb = new StringBuilder(x.length());
    int cnt = 0;
    for (int i = 0; i < x.length(); i++) {
        char c = x.charAt(i);
        int len = sb.length();
        if (c == '0' && len >= 2 && sb.charAt(len - 1) == '1' && sb.charAt(len - 2) == '1') {
            sb.setLength(len - 2);
            cnt++;
            continue;
        }
        sb.append(c);
    }
    int cut = sb.lastIndexOf("0") + 1;
    sb.insert(cut, "110".repeat(cnt));
    return sb.toString();
}
```
