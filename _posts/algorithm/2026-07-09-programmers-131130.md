## 문제

> 링크: [프로그래머스 131130](https://school.programmers.co.kr/learn/courses/30/lessons/131130)

상자를 순서대로 열며 사이클(그룹)을 찾아, 가장 큰 두 그룹의 크기를 곱해 최고 점수를 구하는 문제입니다.

## 접근

### 인덱스 순회로 사이클(그룹) 찾기

`cards`는 1~n의 순열이므로, 각 상자를 열면 반드시 어딘가의 사이클에 속하게 됩니다. 왼쪽부터 아직 방문하지 않은 상자를 시작점으로 잡고 `cards[idx] - 1`을 따라가며 체인을 이어가다가, 이미 방문한 상자에 도달하면 그 체인이 하나의 그룹으로 완성됩니다. 이때 그룹 크기를 최대힙(`PriorityQueue`)에 저장해두고, 다음 미방문 상자로 넘어가 같은 과정을 반복합니다. 모든 상자를 다 돌고 나면 힙에서 가장 큰 두 값을 꺼내 곱하면 되고, 그룹이 하나뿐이라면 두 번째 그룹을 고를 수 없으므로 0을 반환합니다.

## 풀이

```java
import java.util.Comparator;
import java.util.PriorityQueue;

public int solution(int[] cards) {
    PriorityQueue<Integer> q = new PriorityQueue<>(Comparator.reverseOrder());
    boolean[] visited = new boolean[cards.length];
    int idx = 0, cnt = 0;
    while (idx < cards.length) {
        if (!visited[idx]) {
            visited[idx] = true;
            cnt++;
            idx = cards[idx] - 1;
        } else {
            if (cnt != 0) q.add(cnt);
            cnt = 0;
            idx++;
        }
    }
    return q.size() == 1 ? 0 : q.poll() * q.poll();
}
```

## 회고

처음에는 union-find로 그룹을 묶은 뒤 크기 배열을 정렬하는 방식으로 풀었다. 정답은 맞았지만, 문제에서 설명하는 절차(임의의 상자를 열어 이미 열린 상자에 도달할 때까지 따라가고, 남은 상자로 반복)를 그대로 시뮬레이션하면 union-find 없이도 한 번의 순회로 더 간결하게 풀린다는 걸 알게 되었다.
