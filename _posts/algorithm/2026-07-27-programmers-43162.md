## 문제

> 링크: [프로그래머스 43162](https://school.programmers.co.kr/learn/courses/30/lessons/43162)

컴퓨터 개수 n과 연결 정보를 담은 인접 행렬 computers가 주어질 때, 네트워크(연결 요소)의 개수를 구하는 문제다.

## 접근

### DFS로 연결 요소 개수 세기

방문하지 않은 컴퓨터를 시작점으로 DFS를 돌려 도달 가능한 모든 컴퓨터를 같은 네트워크로 묶는다. 모든 컴퓨터를 순회하면서 아직 방문하지 않은 컴퓨터를 만날 때마다 DFS를 한 번 더 호출하는데, 이 호출 횟수가 곧 네트워크 개수가 된다.

n, computers, visited를 solution 메서드마다 갱신되는 인스턴스 필드로 두면 dfs 메서드에 매번 인자로 넘기지 않아도 돼서 시그니처가 간단해진다.

n이 최대 200으로 작아서 인접 행렬을 그대로 스캔해도 O(n²)로 충분히 통과 가능하다.

## 풀이

```java
int n;
int[][] computers;
boolean[] visited;

public int solution(int n, int[][] computers) {
    this.n = n;
    this.computers = computers;
    visited = new boolean[n];
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (visited[i]) continue;
        dfs(i);
        cnt++;
    }
    return cnt;
}

public void dfs(int cur) {
    visited[cur] = true;
    for (int next = 0; next < n; next++) {
        if (computers[cur][next] != 1 || visited[next]) continue;
        dfs(next);
    }
}
```
