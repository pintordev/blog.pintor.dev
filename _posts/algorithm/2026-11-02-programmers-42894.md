## 문제

> 링크: [프로그래머스 42894](https://school.programmers.co.kr/learn/courses/30/lessons/42894)

N×N 보드에 놓인 블록들 위로 검은 1×1 블록을 자유롭게 떨어뜨려, 속이 꽉 찬 직사각형을 만들어 없앨 수 있는 블록 개수의 최댓값을 구하는 문제.

## 접근

### 바운딩 박스 + 반복 제거

보드 위의 블록은 모두 칸 4개로 이루어져 있고, 바운딩 박스는 2×3 또는 3×2다. 검은 블록으로 직사각형을 완성하려면 박스 안의 나머지 빈 칸 2개를 채울 수 있어야 하므로, 박스 넓이가 6인 블록만 후보가 된다.

후보 블록의 박스 안에서 해당 블록이 아닌 칸은 모두 0이어야 하고, 그 칸의 위쪽(같은 열)도 보드 맨 위까지 전부 0이어야 검은 블록이 떨어져 들어갈 수 있다. 이 조건을 만족하면 블록을 제거하고 답을 1 늘린다.

블록을 제거하면 가려져 있던 다른 블록이 드러날 수 있으므로, 더 이상 제거되는 블록이 없을 때까지 블록 번호 1~200을 반복해서 확인한다. 검은 블록은 개수 제한이 없으므로 제거 순서는 결과에 영향을 주지 않는다.

번호별 바운딩 박스는 처음에 한 번만 구하고, 제거한 블록은 박스를 무효화해 다시 후보가 되지 않게 한다. 한 라운드에서 최소 1개가 제거되므로 라운드는 최대 200번이고, 라운드당 비용은 O(N² + 블록 수 × N)이라 충분히 빠르다.

## 풀이

```java
import java.util.Arrays;

int[][] board;
int n;
int[] sr = new int[201];
int[] er = new int[201];
int[] sc = new int[201];
int[] ec = new int[201];

public int solution(int[][] board) {
    this.board = board;
    n = board.length;
    Arrays.fill(sr, n);
    Arrays.fill(sc, n);
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < n; c++) {
            int v = board[r][c];
            if (v == 0) continue;
            sr[v] = Math.min(sr[v], r);
            er[v] = Math.max(er[v], r);
            sc[v] = Math.min(sc[v], c);
            ec[v] = Math.max(ec[v], c);
        }
    }
    int res = 0;
    boolean changed = true;
    while (changed) {
        changed = false;
        for (int v = 1; v <= 200; v++) {
            if (!removable(v)) continue;
            remove(v);
            res++;
            changed = true;
        }
    }
    return res;
}

public boolean removable(int v) {
    if (sr[v] == n) return false;
    if ((er[v] - sr[v] + 1) * (ec[v] - sc[v] + 1) != 6) return false;
    for (int r = sr[v]; r <= er[v]; r++) {
        for (int c = sc[v]; c <= ec[v]; c++) {
            if (board[r][c] == v) continue;
            if (board[r][c] != 0) return false;
            if (!open(r, c)) return false;
        }
    }
    return true;
}

public boolean open(int r, int c) {
    for (int i = 0; i < r; i++) {
        if (board[i][c] != 0) return false;
    }
    return true;
}

public void remove(int v) {
    for (int r = sr[v]; r <= er[v]; r++) {
        for (int c = sc[v]; c <= ec[v]; c++) {
            if (board[r][c] == v) board[r][c] = 0;
        }
    }
    sr[v] = n;
}
```
