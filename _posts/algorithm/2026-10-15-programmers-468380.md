## 문제

> 링크: [프로그래머스 468380](https://school.programmers.co.kr/learn/courses/30/lessons/468380)

arr[i]를 arr[i]번씩 이어 붙인 배열 brr에서 구간 [l, r]의 합 K와, 길이가 같으면서 합이 K인 부분 배열의 개수 C를 구하는 문제.

## 접근

### 블록 단위 누적합 + 구간별 일차식

brr의 길이는 최대 약 10^10이라 직접 만들 수 없다. brr는 "값 a_i가 a_i번 반복되는 블록"의 나열이므로 블록 단위로만 다룬다.

- `len[i]`: 앞 i개 블록의 길이 누적합
- `sq[i]`: 앞 i개 블록의 원소 합(a_i²) 누적합

위치 x가 속한 블록 b를 이진 탐색으로 찾으면 앞 x개 원소의 합은 `sq[b] + arr[b] * (x - len[b])`이다. K는 `prefix(r) - prefix(l - 1)`로 구한다.

C는 길이 L = r - l + 1인 창의 시작 위치 s를 1부터 `전체 길이 - L + 1`까지 밀면서 합이 K인 s의 개수를 센다.

- 창의 왼쪽 끝이 블록 i, 오른쪽 끝이 블록 j에 있는 동안 s가 1 증가하면 창의 합은 `arr[j] - arr[i]`만큼 변한다. 즉 구간 안에서 합은 s에 대한 일차식이다.
- 두 끝 중 하나가 블록 경계를 넘을 때만 기울기가 바뀌므로 구간은 최대 2N개이고, 투 포인터로 순서대로 순회한다.
- 구간의 시작점에서 합을 구한 뒤, 기울기가 0이면 합이 K일 때 구간 전체를 더하고, 아니면 `(K - 합) / 기울기`가 구간 안의 정수일 때 1개를 더한다.

시간복잡도는 O(N + log N), 공간복잡도는 O(N)이다. 합과 위치는 모두 `long`으로 다룬다.

## 풀이

```java
int[] arr;
long[] len;
long[] sq;

public long[] solution(int[] arr, long l, long r) {
    this.arr = arr;
    int n = arr.length;
    len = new long[n + 1];
    sq = new long[n + 1];
    for (int i = 0; i < n; i++) {
        len[i + 1] = len[i] + arr[i];
        sq[i + 1] = sq[i] + (long) arr[i] * arr[i];
    }
    long k = prefix(r) - prefix(l - 1);
    long size = r - l + 1;
    long last = len[n] - size + 1;
    int i = 0;
    int j = block(size);
    long count = 0;
    long s = 1;
    while (s <= last) {
        long end = Math.min(len[i + 1], Math.min(len[j + 1] - size + 1, last));
        long diff = k - (sum(j, s + size - 1) - sum(i, s - 1));
        long d = arr[j] - arr[i];
        if (d == 0) {
            if (diff == 0) count += end - s + 1;
        } else if (diff % d == 0 && diff / d >= 0 && diff / d <= end - s) {
            count++;
        }
        s = end + 1;
        if (s > len[i + 1]) i++;
        if (s + size - 1 > len[j + 1]) j++;
    }
    return new long[]{k, count};
}

public long prefix(long x) {
    if (x == 0) return 0;
    return sum(block(x), x);
}

public long sum(int b, long x) {
    return sq[b] + (long) arr[b] * (x - len[b]);
}

public int block(long x) {
    int lo = 0;
    int hi = arr.length - 1;
    while (lo < hi) {
        int mid = (lo + hi) >> 1;
        if (len[mid + 1] >= x) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```
