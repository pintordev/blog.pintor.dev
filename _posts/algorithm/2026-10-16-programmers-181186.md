## 문제

> 링크: [프로그래머스 181186](https://school.programmers.co.kr/learn/courses/30/lessons/181186)

ㄱ자 L 타일(3칸)과 1×3 직사각형 타일을 회전해 가며 가로 n, 세로 3인 판을 빈틈없이 채우는 경우의 수를 1,000,000,007로 나눈 나머지로 구하는 문제.

## 접근

### 세로 절단선 기준으로 분해하는 DP

`f(n)`을 가로 n짜리 판을 채우는 경우의 수로 두고 `f(0) = 1`로 정한다. 판을 왼쪽부터 보면서 처음으로 세로 절단선이 생기는 폭을 k라 하면, 그 폭까지는 더 쪼갤 수 없는 한 덩어리이고 나머지는 `f(n-k)`가 된다. 더 쪼갤 수 없는 덩어리의 경우의 수를 `g(k)`라 하면 다음과 같다.

```
f(n) = Σ g(k) · f(n-k)
```

`g(k)`는 직접 세어서 구한다.

- `g(1) = 1`: 세로 막대 1개
- `g(2) = 2`: L 타일 두 개를 맞물리는 방법
- `g(3) = 5`: 가로 막대 3개 1가지, 가로 막대 1개 + L 타일 2개 4가지
- `g(k)` (k ≥ 4): 가로 막대와 L 타일을 지그재그로 이어 붙이는 배치뿐이다. k를 3으로 나눈 나머지에 따라 `2, 2, 4`가 반복된다.

이 식을 그대로 계산하면 O(n²)이다. 그런데 `k ≥ 4`에서 `g`가 3 주기로 반복되므로 `f(n)`에서 `f(n-3)`을 빼면 `k ≥ 7`인 항이 모두 소거된다.

```
f(n) = f(n-1) + 2f(n-2) + 6f(n-3) + f(n-4) - f(n-6)
```

초기값은 `f(0..5) = 1, 1, 3, 10, 23, 62`이고, `n = 6`부터 점화식을 적용한다. 뺄셈이 있어서 mod를 더한 뒤 나머지를 취해야 음수를 피할 수 있다. 시간복잡도는 O(n), 공간복잡도는 O(n)이다.

## 풀이

```java
public int solution(int n) {
    int mod = 1_000_000_007;
    long[] dp = new long[Math.max(n + 1, 6)];
    dp[0] = 1;
    dp[1] = 1;
    dp[2] = 3;
    dp[3] = 10;
    dp[4] = 23;
    dp[5] = 62;
    for (int i = 6; i <= n; i++) {
        dp[i] = (dp[i - 1] + 2 * dp[i - 2] + 6 * dp[i - 3] + dp[i - 4] - dp[i - 6] + mod) % mod;
    }
    return (int) dp[n];
}
```
