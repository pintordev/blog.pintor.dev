## 문제

> 링크: [프로그래머스 131129](https://school.programmers.co.kr/learn/courses/30/lessons/131129)

`target` 점수를 다트 점수의 합으로 정확히 만들 때, 최소 다트 수와 그 최소 다트 수를 달성하는 경우들 중 싱글·불 적중 횟수의 최댓값을 구한다.

## 접근

### 최소 다트 수 DP + 적중 수 2차 기준

한 다트로 얻을 수 있는 점수는 싱글 `1~20`, 더블 `2~40`, 트리플 `3~60`, 불 `50`이다. 이 중 싱글과 불만 "적중"으로 센다.

- `minDarts[t]` = 합 `t`를 만드는 최소 다트 수
- `maxHits[t]` = 그 최소 다트 수 해들 중 싱글·불 적중 횟수의 최댓값

동전 교환(coin change)과 같은 구조다. `t`를 1부터 올리며 마지막에 던진 다트 점수 `score`를 하나 고정하면

- `minDarts[t] = min(minDarts[t - score] + 1)`
- 2차 기준: `minDarts[t - score] + 1`이 현재 최소와 **같을 때만** `maxHits[t] = max(maxHits[t], maxHits[t - score] + gain)`

`relax(t, score, gain)` 헬퍼가 다트 하나에 대한 완화를 맡고, 점수 목록은 루프에서 `50`과 `n`, `2n`, `3n` (`n = 1..20`)으로 생성한다. 싱글 1점이 항상 존재해 모든 `t`가 도달 가능하므로 불능 처리는 필요 없다.

상태는 `target`개, 각 상태에서 다트 61종을 훑으므로 시간복잡도는 `O(target)`. `target ≤ 100,000`이라 충분하다.

정답은 `[minDarts[target], maxHits[target]]`.

## 풀이

```java
int[] minDarts;
int[] maxHits;

public int[] solution(int target) {
    minDarts = new int[target + 1];
    maxHits = new int[target + 1];
    for (int t = 1; t <= target; t++) {
        minDarts[t] = Integer.MAX_VALUE;
        relax(t, 50, 1);
        for (int n = 1; n <= 20; n++) {
            relax(t, n, 1);
            relax(t, 2 * n, 0);
            relax(t, 3 * n, 0);
        }
    }
    return new int[]{minDarts[target], maxHits[target]};
}

public void relax(int t, int score, int gain) {
    if (t < score) return;
    if (minDarts[t] > minDarts[t - score] + 1) {
        minDarts[t] = minDarts[t - score] + 1;
        maxHits[t] = maxHits[t - score] + gain;
    } else if (minDarts[t] == minDarts[t - score] + 1) {
        maxHits[t] = Math.max(maxHits[t], maxHits[t - score] + gain);
    }
}
```
