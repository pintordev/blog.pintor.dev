## 문제

> 링크: [프로그래머스 150368](https://school.programmers.co.kr/learn/courses/30/lessons/150368)

이모티콘 m개에 각각 10/20/30/40% 할인율을 배정하여, 이모티콘 플러스 가입자 수를 최대화하고 (차순으로) 판매액을 최대화한다.

## 접근

### 비트마스크 완전탐색

할인율이 4가지이므로 이모티콘 하나당 2비트로 표현할 수 있다. m개의 이모티콘 전체 할인율 조합을 `2*m`비트 정수 하나로 인코딩하면, `0`부터 `4^m - 1`(= `1 << 2*m`)까지 순회하는 것으로 모든 조합을 탐색할 수 있다.

이모티콘 i의 할인율 인덱스는 `(mask >> (2 * i)) & 3`으로 추출하고, `{10, 20, 30, 40}` 배열에 매핑한다.

각 조합마다 모든 사용자를 시뮬레이션하여 구매 합계가 한도 이상이면 가입자로, 미만이면 판매액에 누적한다. 가입자 수 우선, 동수이면 판매액 기준으로 최적값을 갱신한다.

m ≤ 7이므로 최대 조합 수는 `4^7 = 16,384`이고, 전체 시간복잡도는 `O(4^m × n × m) ≈ 11,000,000`으로 충분히 통과한다.

## 풀이

```java
public int[] solution(int[][] users, int[] emoticons) {
    int[] rates = {10, 20, 30, 40};
    int m = emoticons.length;
    int[] best = {0, 0};
    for (int mask = 0; mask < (1 << (2 * m)); mask++) {
        int subscribers = 0;
        int sales = 0;
        for (int[] user : users) {
            int threshold = user[0];
            int limit = user[1];
            int total = 0;
            for (int i = 0; i < m; i++) {
                int rate = rates[(mask >> (2 * i)) & 3];
                if (rate >= threshold) total += emoticons[i] * (100 - rate) / 100;
            }
            if (total >= limit) subscribers++;
            else sales += total;
        }
        if (subscribers > best[0] || (subscribers == best[0] && sales > best[1])) {
            best[0] = subscribers;
            best[1] = sales;
        }
    }
    return best;
}
```
