## 문제

> 링크: [프로그래머스 148652](https://school.programmers.co.kr/learn/courses/30/lessons/148652)

n번째 유사 칸토어 비트열에서 구간 [l, r]에 포함된 1의 개수를 구한다.

## 접근

### 재귀적 자기 유사 구조를 이용한 prefix count

유사 칸토어 비트열은 0번째 "1"에서 시작해, 1을 "11011"로 0을 "00000"으로 치환하며 만들어진다. 이 치환은 준동형사상이라 n번째 비트열은 항상 다음과 같은 자기 유사 구조를 가진다. 크기 5^(level-1)인 블록 5개로 나뉘고, 블록 순서는 "1,1,0,1,1" 패턴을 따르며, '1' 위치의 블록은 (level-1)번째 비트열 자체이고 가운데(index 2) 블록은 전부 0으로 채워진 블록이다.

l, r은 최대 5^20까지 커질 수 있어 문자열을 직접 만들 수 없다. 대신 `countOnes(level, x)` = level번째 비트열의 앞 x개(1..x, 1-based) 안에 있는 1의 개수를 재귀로 구하고, 정답은 `countOnes(n, r) - countOnes(n, l - 1)`로 계산한다.

`countOnes`는 매 레벨에서 5개 블록을 순서대로 소비하면서, x가 완전히 포함하는 블록은 미리 계산해둔 4^(level-1)(그 블록에 들어있는 1의 총 개수)을 바로 더하고, x가 걸쳐있는 블록 하나만 한 단계 낮은 레벨로 재귀한다. 그 결과 재귀 깊이는 n(최대 20)에 불과하고, range 크기(r - l)는 계산량에 전혀 영향을 주지 않는다.

## 풀이

```java
long[] pow5;
long[] pow4;

public int solution(int n, long l, long r) {
    pow5 = new long[n + 1];
    pow4 = new long[n + 1];
    pow5[0] = 1;
    pow4[0] = 1;
    for (int i = 1; i <= n; i++) {
        pow5[i] = pow5[i - 1] * 5;
        pow4[i] = pow4[i - 1] * 4;
    }
    return (int) (countOnes(n, r) - countOnes(n, l - 1));
}

public long countOnes(int level, long x) {
    if (x <= 0) return 0;
    if (level == 0) return 1;
    long bs = pow5[level - 1];
    long remain = x;
    long total = 0;
    for (int b = 0; b < 5 && remain > 0; b++) {
        long covered = Math.min(remain, bs);
        if (b != 2) total += covered == bs ? pow4[level - 1] : countOnes(level - 1, covered);
        remain -= covered;
    }
    return total;
}
```

## 회고

처음에는 위치 하나하나가 1인지를 O(n)에 판정하는 함수를 만들어 [l, r] 구간을 전부 순회하는 방식으로 접근했다. 정답은 나오지만 시간복잡도가 O((r - l) × n)이라, 제약상 r - l이 최대 천만에 n이 최대 20이면 최악의 경우 2억 번 연산이 필요해 range 크기에 성능이 좌우되는 구조였다.

구간을 순회하지 않고 prefix 함수 두 번의 차로 답을 구하는 방식으로 바꾸니, range 크기와 무관하게 O(n)만에 끝나게 됐다. 완전히 포함되는 블록을 재귀로 다시 들어가지 않고 4^(level-1) 값으로 바로 처리하는 부분이 핵심이었는데, 이 컷오프가 없으면 재귀가 O(5^n)까지 폭발할 수 있다는 점도 함께 확인했다.
