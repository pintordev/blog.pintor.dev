## 문제

> 링크: [백준 1931](https://www.acmicpc.net/problem/1931)

N개의 회의에 대해 시작 시간과 종료 시간이 주어질 때, 하나의 회의실에서 겹치지 않게 배정할 수 있는 최대 회의 수를 구한다. 한 회의가 끝나는 시각에 다음 회의를 시작할 수 있다.

## 접근

### 그리디

종료 시간이 가장 빠른 회의를 우선 선택하면 이후에 더 많은 회의를 배정할 수 있다.

1. 종료 시간 오름차순으로 정렬 (종료 시간이 같으면 시작 시간 오름차순)
2. 현재 끝난 시각 이후에 시작하는 회의를 순서대로 선택

종료 시간 기준 정렬이 최적인 이유는, 어떤 선택 집합에서 종료 시간이 더 늦은 회의를 종료 시간이 더 이른 회의로 교체해도 유효성이 유지되거나 개선되기 때문이다(Exchange Argument).

> 시작/종료 시간이 `0 이상 2³¹-1 이하`이므로 `int` 범위를 초과할 수 있다. `long`으로 읽어야 한다.

## 풀이

```java
import java.io.IOException;
import java.util.Arrays;

public class Solution {
    public static void main(String[] args) throws IOException {
        int n = (int) read();
        long[][] meetings = new long[n][2];
        for (int i = 0; i < n; i++) {
            meetings[i][0] = read();
            meetings[i][1] = read();
        }

        Arrays.sort(meetings, (a, b) -> {
            if (a[1] != b[1]) return Long.compare(a[1], b[1]);
            return Long.compare(a[0], b[0]);
        });

        int cnt = 0;
        long et = 0;
        for (long[] meeting : meetings) {
            if (meeting[0] >= et) {
                cnt++;
                et = meeting[1];
            }
        }

        System.out.println(cnt);
    }

    public static long read() throws IOException {
        int c;
        long n = System.in.read() & 15;
        while ((c = System.in.read()) > 32) {
            n = (n << 3) + (n << 1) + (c & 15);
        }
        return n;
    }
}
```
