## 문제

> 링크: [프로그래머스 64064](https://school.programmers.co.kr/learn/courses/30/lessons/64064)

응모자 아이디 중 일부 문자가 `*`로 가려진 불량 사용자 아이디 목록이 주어질 때, 가능한 제재 아이디 조합의 개수를 구하는 문제다.

## 접근

### 백트래킹 + 비트마스크로 중복 제거

`banned_id`의 각 원소는 길이가 같은 `user_id`와 `*`가 아닌 위치의 문자가 모두 일치해야 매칭된다. 이 매칭 여부를 먼저 `matched[i][j]` 테이블로 계산해둔다.

이후 `banned_id`를 인덱스 순서대로 하나씩 처리하면서, 아직 배정되지 않은 `user_id` 중 매칭되는 것을 선택해 재귀적으로 다음 `banned_id`로 넘어간다. 배정 여부는 `user_id` 인덱스를 비트로 표현한 정수 `mask`로 관리한다.

모든 `banned_id`를 배정하고 나면, 그 시점의 `mask` 값을 결과 집합(`HashSet<Integer>`)에 담는다. `banned_id` 순서와 무관하게 같은 사용자 조합이면 같은 `mask` 값이 되기 때문에, 이 방식만으로 중복 조합이 자연스럽게 제거된다. 예를 들어 두 개의 `banned_id`가 똑같이 `*rodo` 패턴이고 `frodo`, `crodo` 둘 다에 매칭될 때, 어느 쪽을 먼저 배정하든 최종 `mask`는 같은 값이 된다.

`user_id.length`, `banned_id.length` 모두 최대 8이라 최악의 경우도 `8! = 40320`을 넘지 않아 완전탐색으로 충분하다.

## 풀이

```java
import java.util.HashSet;
import java.util.Set;

int n, m;
boolean[][] matched;
Set<Integer> combinations;

public int solution(String[] user_id, String[] banned_id) {
    n = user_id.length;
    m = banned_id.length;
    matched = new boolean[m][n];
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            matched[i][j] = isMatched(banned_id[i], user_id[j]);
        }
    }
    combinations = new HashSet<>();
    dfs(0, 0);
    return combinations.size();
}

public boolean isMatched(String banned, String user) {
    if (banned.length() != user.length()) return false;
    for (int i = 0; i < banned.length(); i++) {
        if (banned.charAt(i) != '*' && banned.charAt(i) != user.charAt(i)) return false;
    }
    return true;
}

public void dfs(int idx, int mask) {
    if (idx == m) {
        combinations.add(mask);
        return;
    }
    for (int j = 0; j < n; j++) {
        if ((mask & (1 << j)) != 0 || !matched[idx][j]) continue;
        dfs(idx + 1, mask | (1 << j));
    }
}
```
