## 문제

> 링크: [프로그래머스 250135](https://school.programmers.co.kr/learn/courses/30/lessons/250135)

시침, 분침, 초침이 있는 아날로그시계에서 초침이 시침 또는 분침과 겹칠 때 알람이 울린다. h1시m1분s1초부터 h2시m2분s2초까지(양 끝 포함) 알람이 울리는 횟수를 구한다.

## 접근

### 겹침은 정수초 단위로 일어나지 않는다

먼저 매 초마다 세 바늘의 각도를 비교하는 완전탐색을 떠올릴 수 있다. 하지만 예제 중 `11:58:59 ~ 11:59:00` 구간(정답 1)을 확인해보면, 두 정수초 지점 어디에서도 바늘이 정확히 겹치지 않는다. 실제 겹침은 약 43139.92초처럼 두 정수초 사이의 소수점 시각에서 일어난다. 정수초만 훑는 방식으로는 이 케이스를 놓친다.

### 겹침 주기를 이용한 공식화

겹침은 두 바늘의 상대각속도로 정해지는 일정한 주기로 반복된다.

- 초침과 분침: 상대각속도 5.9도/초 → 겹침 주기 3600/59초. t = 3600k/59 (k=0,1,2,...)마다 겹친다.
- 초침과 시침: 상대각속도 719/120도/초 → 겹침 주기 43200/719초. t = 43200k/719마다 겹친다.

두 겹침이 동시에 일어나는 경우(세 바늘이 한 번에 겹치는 순간)는 719가 소수이기 때문에 정확히 43200의 배수(00:00:00, 12:00:00, ...)에서만 발생한다. 이때는 알람이 한 번만 울리므로 중복을 빼줘야 한다.

구간 `[t1, t2]` 안에서 각 수열의 항 개수는 정수 나눗셈으로 구할 수 있다. `t1 <= num*k/den <= t2` 를 만족하는 정수 k의 개수는 `floor(den*t2/num) - ceil(den*t1/num) + 1` 이고, ceil은 부동소수점 없이 `(a + b - 1) / b` 형태로 계산한다.

최종 답은 (초-분 겹침 횟수) + (초-시 겹침 횟수) - (셋 다 겹치는 횟수) 이다.

## 풀이

```java
public int solution(int h1, int m1, int s1, int h2, int m2, int s2) {
    long t1 = h1 * 3600L + m1 * 60L + s1;
    long t2 = h2 * 3600L + m2 * 60L + s2;
    long ms = cntCoincide(t1, t2, 3600, 59);
    long hs = cntCoincide(t1, t2, 43200, 719);
    long both = cntCoincide(t1, t2, 43200, 1);
    return (int) (ms + hs - both);
}

public long cntCoincide(long t1, long t2, long num, long den) {
    long lo = (den * t1 + num - 1) / num;
    long hi = (den * t2) / num;
    long cnt = hi - lo + 1;
    return cnt > 0 ? cnt : 0;
}
```
