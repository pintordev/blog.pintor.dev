## 문제

> 링크: [프로그래머스 12941](https://school.programmers.co.kr/learn/courses/30/lessons/12941)

길이가 같은 두 배열 A, B에서 각각 하나씩 꺼내 곱한 값의 합이 최소가 되도록 한다.

## 접근

### 그리디 — 큰 수 × 작은 수

곱의 합을 최소로 만들려면, A의 가장 작은 값과 B의 가장 큰 값을 짝짓는 것이 최적이다.

A를 오름차순, B를 오름차순으로 정렬한 뒤, A[i]와 B[n-1-i]를 곱해 합산한다.

## 풀이

{% raw %}
```java
package programmers.greedy.p12941;

import java.util.Arrays;

public class Solution {

    public static void main(String[] args) {
        Solution s = new Solution();

        int[][] As = {{1, 4, 2}, {1, 2}};
        int[][] Bs = {{5, 4, 4}, {3, 4}};
        int[] answers = {29, 10};

        for (int i = 0; i < As.length; i++) {
            System.out.println(s.solution(As[i], Bs[i]) == answers[i]);
        }
    }

    public int solution(int[] A, int[] B) {
        Arrays.sort(A);
        Arrays.sort(B);
        int sum = 0;
        for (int i = 0, len = A.length; i < len; i++) {
            sum += A[i] * B[len - i - 1];
        }
        return sum;
    }
}
```
