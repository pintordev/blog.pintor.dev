## 문제

> 링크: [프로그래머스 42584](https://school.programmers.co.kr/learn/courses/30/lessons/42584)

초 단위 주식가격 배열이 주어질 때, 각 시점에서 가격이 떨어지지 않은 기간(초)을 반환한다.

## 접근

### 단조 스택(Monotonic Stack)

스택에 인덱스를 순서대로 쌓는다. 현재 가격(`prices[i]`)이 스택 top에 저장된 인덱스의 가격보다 낮아지는 순간, 그 인덱스를 pop하면서 기간을 계산한다.

- pop 시: `res[stack[top]] = i - stack[top]`
- 루프 종료 후 스택에 남은 인덱스는 끝까지 가격이 떨어지지 않은 것 → `res[stack[top]] = n - 1 - stack[top]`

주의할 점은 잔여 처리에서 스택 포인터(`top`)가 아닌 스택에 저장된 실제 인덱스(`stack[top]`)를 사용해야 한다는 것이다. pop 과정 중 스택 원소가 연속적이지 않을 수 있기 때문이다.

## 풀이

```java
public int[] solution(int[] prices) {
    int n = prices.length;
    int[] res = new int[n];
    int[] stack = new int[n];
    int top = -1;
    for (int i = 0; i < n; i++) {
        while (top >= 0 && prices[stack[top]] > prices[i]) {
            res[stack[top]] = i - stack[top--];
        }
        stack[++top] = i;
    }
    while (top >= 0) {
        res[stack[top]] = n - stack[top--] - 1;
    }
    return res;
}
```
