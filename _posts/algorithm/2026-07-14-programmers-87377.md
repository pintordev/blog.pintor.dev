## 문제

> 링크: [프로그래머스 87377](https://school.programmers.co.kr/learn/courses/30/lessons/87377)

Ax + By + C = 0 형태로 주어진 n개의 직선들에 대해, 모든 직선 쌍의 교점 중 정수 좌표를 갖는 곳에만 별을 찍어 문자열 격자로 반환하는 문제다.

## 접근

### 모든 직선 쌍의 교점을 크래머 공식으로 계산

직선이 최대 1,000개이므로 모든 쌍을 검사해도 최대 약 50만 쌍 수준이라 O(n²) 브루트포스로 충분하다.

두 직선 A₁x + B₁y + C₁ = 0, A₂x + B₂y + C₂ = 0에 대해 `det = A₁B₂ - A₂B₁`을 구하고, `det`가 0이면 평행이므로 건너뛴다. 그렇지 않으면 크래머 공식으로 `xNum`, `yNum`을 구해 두 값이 모두 `det`로 나누어떨어질 때만 정수 교점으로 채택한다. 계수가 최대 100,000이라 곱셈 결과가 int 범위를 넘을 수 있어 전부 `long`으로 계산했다.

같은 좌표에 여러 직선 쌍이 동시에 교차할 수 있으므로 `Point` 클래스에 `equals`/`hashCode`를 오버라이드해 `Set`으로 중복을 제거했다. 이후 모은 교점들의 최소/최대 x, y로 바운딩 박스를 구해 그리드 크기를 정하고, y값이 클수록 위쪽 행에 오도록 행 인덱스를 반전해 별을 찍었다.

## 풀이

```java
import java.util.Arrays;
import java.util.HashSet;
import java.util.Objects;
import java.util.Set;

public String[] solution(int[][] line) {
    Set<Point> points = new HashSet<>();
    long minX = Long.MAX_VALUE, maxX = Long.MIN_VALUE;
    long minY = Long.MAX_VALUE, maxY = Long.MIN_VALUE;
    for (int i = 0, n = line.length; i < n; i++) {
        long a1 = line[i][0], b1 = line[i][1], c1 = line[i][2];
        for (int j = i + 1; j < n; j++) {
            long a2 = line[j][0], b2 = line[j][1], c2 = line[j][2];
            long det = a1 * b2 - a2 * b1;
            if (det == 0) continue;
            long xNum = b1 * c2 - b2 * c1;
            long yNum = a2 * c1 - a1 * c2;
            if (xNum % det != 0 || yNum % det != 0) continue;
            long x = xNum / det;
            long y = yNum / det;
            if (!points.add(new Point(x, y))) continue;
            minX = Math.min(minX, x);
            maxX = Math.max(maxX, x);
            minY = Math.min(minY, y);
            maxY = Math.max(maxY, y);
        }
    }
    int w = (int) (maxX - minX + 1);
    int h = (int) (maxY - minY + 1);
    char[][] grid = new char[h][w];
    for (char[] row : grid) {
        Arrays.fill(row, '.');
    }
    for (Point p : points) {
        int row = (int) (maxY - p.y);
        int col = (int) (p.x - minX);
        grid[row][col] = '*';
    }
    String[] res = new String[h];
    for (int i = 0; i < h; i++) {
        res[i] = new String(grid[i]);
    }
    return res;
}

class Point {
    long x, y;

    Point(long x, long y) {
        this.x = x;
        this.y = y;
    }

    @Override
    public boolean equals(Object o) {
        if (!(o instanceof Point p)) return false;
        return x == p.x && y == p.y;
    }

    @Override
    public int hashCode() {
        return Objects.hash(x, y);
    }
}
```

## 회고

처음에는 교점을 `Set<long[]>`에 모아 중복을 제거하려 했는데, `long[]`는 `equals`/`hashCode`를 오버라이드하지 않아 참조 동일성으로 비교된다는 점을 놓쳤다. 그래서 값이 같은 좌표라도 서로 다른 배열 인스턴스면 별개로 취급돼 실제로는 중복 제거가 되지 않았다. 다만 그리드에 별을 여러 번 찍어도 결과는 달라지지 않는 멱등 연산이라 출력 자체는 우연히 맞았을 뿐이었다. `Point` 클래스를 만들어 `equals`/`hashCode`를 값 기준으로 정의하고 나서야 의도한 대로 중복 제거가 되는 것을 확인했다.
