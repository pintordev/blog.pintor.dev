## 문제

> 링크: [프로그래머스 132265](https://school.programmers.co.kr/learn/courses/30/lessons/132265)

토핑 배열을 두 조각으로 나눌 때, 양쪽의 토핑 종류 수가 같은 경우의 수를 구하는 문제.

## 접근

### 배열 2개 + 유니크 카운트 변수

토핑 값의 범위가 1~10,000으로 고정되어 있으므로 HashMap/HashSet 대신 배열 2개로 각 파트의 토핑 개수를 관리한다.

유니크 종류 수는 `lu`(왼쪽), `ru`(오른쪽) 변수로 추적한다. `right[t]`가 0이 되면 오른쪽에서 해당 토핑이 사라지므로 `ru--`, `left[t]`가 처음 등장하면 `lu++`.

2번 순회로 O(n) 처리.

## 풀이

```java
public int solution(int[] topping) {
    int[] right = new int[10001];
    int[] left = new int[10001];
    int ru = 0, lu = 0;
    for (int t : topping) {
        if (right[t]++ == 0) ru++;
    }

    int cnt = 0;
    for (int t : topping) {
        if (left[t]++ == 0) lu++;
        if (--right[t] == 0) ru--;
        if (lu == ru) cnt++;
    }
    return cnt;
}
```

## 회고

HashMap + HashSet으로 먼저 접근했는데, 토핑 값 범위(1~10,000)가 고정되어 있어서 배열 2개로 대체할 수 있었다. HashSet 없이 유니크 카운트를 변수 하나로 관리하는 방식이 깔끔하고 빠르다.
