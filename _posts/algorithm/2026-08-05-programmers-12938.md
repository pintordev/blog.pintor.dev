## 문제

> 링크: [프로그래머스 12938](https://school.programmers.co.kr/learn/courses/30/lessons/12938)

자연수 n개로 이루어진 집합 중 원소의 합이 s가 되면서 원소들의 곱이 최대가 되는 집합을 구하는 문제다.

## 접근

### 균등 분배 (AM-GM 부등식)

합이 고정된 여러 자연수의 곱을 최대화하려면 값들을 서로 최대한 균등하게 분배해야 한다. 이는 산술평균-기하평균 부등식(AM-GM)에 의해 성립하는데, 값이 극단적으로 치우칠수록 곱은 작아지고 균등할수록 곱은 커진다.

s를 n으로 나눈 몫과 나머지를 이용하면 균등 분배를 바로 구할 수 있다. 나머지만큼은 몫보다 1 큰 값으로, 나머지 개수는 몫 그대로 채우면 합은 s를 유지하면서 곱이 최대인 집합이 된다. 몫을 먼저 채우고 몫+1을 뒤에 채우면 오름차순 정렬 결과를 자연스럽게 얻을 수 있다.

s < n인 경우에는 자연수 n개(각 원소 최소 1)로는 합 s를 만들 수 없으므로 -1을 반환한다.

## 풀이

```java
public int[] solution(int n, int s) {
    if (s < n) return new int[]{-1};

    int q = s / n;
    int r = s % n;
    int[] set = new int[n];
    for (int i = 0; i < n - r; i++) {
        set[i] = q;
    }
    for (int i = n - r; i < n; i++) {
        set[i] = q + 1;
    }
    return set;
}
```
