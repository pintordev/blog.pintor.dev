## 문제

> 링크: [프로그래머스 42583](https://school.programmers.co.kr/learn/courses/30/lessons/42583)

일차선 다리를 정해진 순서대로 건너는 트럭들이 모두 통과하는 데 걸리는 최소 시간을 구한다.

## 접근

### 큐 시뮬레이션

다리를 크기 `bridge_length`인 원형 배열로 모델링한다. 빈 자리는 0으로 채운다.

매 초마다 다음 순서로 처리한다.

1. 다리 앞 칸(`bridge[time % bridge_length]`)의 트럭을 꺼내 무게 합에서 차감한다.
2. 해당 칸을 0으로 초기화한다.
3. 다음 트럭을 올릴 수 있으면(현재 무게 + 다음 트럭 ≤ weight) 해당 칸에 트럭을 태우고 무게를 더한다.
4. 모든 트럭이 출발하고 다리 위 무게가 0이 되면 종료한다.

`LinkedList` 대신 원형 배열을 사용해 불필요한 객체 생성 없이 O(1)로 슬롯을 재사용한다.

## 풀이

```java
public int solution(int bridge_length, int weight, int[] truck_weights) {
    int[] bridge = new int[bridge_length];
    int time = 0, bridgeWeight = 0, idx = 0;
    while (idx < truck_weights.length || bridgeWeight > 0) {
        bridgeWeight -= bridge[time % bridge_length];
        bridge[time % bridge_length] = 0;
        if (idx < truck_weights.length && bridgeWeight + truck_weights[idx] <= weight) {
            bridge[time % bridge_length] = truck_weights[idx++];
            bridgeWeight += bridge[time % bridge_length];
        }
        time++;
    }
    return time;
}
```
