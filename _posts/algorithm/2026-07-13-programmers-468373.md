## 문제

> 링크: [프로그래머스 468373](https://school.programmers.co.kr/learn/courses/30/lessons/468373)

n개의 배양체가 A, B, C 3종류의 파이프로 연결된 트리 구조에서, 파이프 종류를 최대 k번 선택해 여닫으며 감염 배양체 수를 최대화하는 문제다.

## 접근

### 타입 시퀀스 완전탐색 + 비트마스크 상태 전달

한 번의 동작은 파이프 종류 하나를 선택해 여는 것이고, 열려 있는 동안 감염은 그 종류의 간선만으로 이루어진 서브그래프를 따라 전파된다. 같은 종류의 간선이 여러 개 이어져 있으면 한 번의 동작 안에서도 체인처럼 다단계로 퍼질 수 있다.

k ≤ 10, 파이프 종류가 3가지뿐이라 선택 가능한 시퀀스는 최악의 경우도 3^k 수준이라 완전탐색으로 충분하다. 직전에 고른 타입을 다시 고르면 이미 그 타입으로 도달 가능한 노드는 전부 감염된 상태라 추가로 얻는 게 없으므로, 직전과 같은 타입을 다시 선택하는 분기는 가지치기한다.

감염 상태는 n ≤ 100이라 long 하나(64비트)로는 부족해 `long[2]`(최대 128비트) 비트마스크로 표현한다. 재귀마다 이 배열을 복제해서 값으로 넘기고 별도로 되돌리지 않는 방식을 썼다. 감염 수는 경로를 따라 단조 증가하므로, 매 단계마다 최댓값을 갱신할 필요 없이 리프(깊이 == k)에서 한 번만 `Long.bitCount`로 세어도 전체 최댓값과 동일하다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

int n, max;
List<Node>[] graph;

public int solution(int n, int infection, int[][] edges, int k) {
    this.n = n;
    graph = new List[n + 1];
    for (int i = 1; i <= n; i++) {
        graph[i] = new ArrayList<>();
    }
    for (int[] edge : edges) {
        int x = edge[0], y = edge[1], no = edge[2];
        graph[x].add(new Node(y, no));
        graph[y].add(new Node(x, no));
    }
    long[] mask = new long[2];
    visit(mask, infection);
    dfs(0, k, 0, mask);
    return max;
}

public void dfs(int d, int k, int prev, long[] mask) {
    if (d == k) {
        max = Math.max(max, Long.bitCount(mask[0]) + Long.bitCount(mask[1]));
        return;
    }
    for (int no = 1; no <= 3; no++) {
        if (no == prev) continue;
        dfs(d + 1, k, no, spread(mask, no));
    }
}

public long[] spread(long[] mask, int no) {
    long[] next = mask.clone();
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 1; i <= n; i++) {
        if (isVisited(mask, i)) queue.add(i);
    }
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        for (Node nd : graph[cur]) {
            if (nd.no != no || isVisited(next, nd.to)) continue;
            visit(next, nd.to);
            queue.add(nd.to);
        }
    }
    return next;
}

public boolean isVisited(long[] mask, int i) {
    return (mask[(i - 1) >> 6] & (1L << ((i - 1) & 63))) != 0;
}

public void visit(long[] mask, int i) {
    mask[(i - 1) >> 6] |= 1L << ((i - 1) & 63);
}

class Node {
    int to, no;

    Node(int to, int no) {
        this.to = to;
        this.no = no;
    }
}
```
