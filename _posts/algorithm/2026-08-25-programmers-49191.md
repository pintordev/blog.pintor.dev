## 문제

> 링크: [프로그래머스 49191](https://school.programmers.co.kr/learn/courses/30/lessons/49191)

n명의 선수가 벌인 일부 경기 결과가 주어질 때, 승패 관계가 완전히 확정되는(=정확한 순위를 매길 수 있는) 선수의 수를 구한다.

## 접근

### 승패 관계 전이 (플로이드-워셜)

승패는 이행성을 가진다. A가 B를 이기고 B가 C를 이기면, 직접 경기하지 않았어도 A는 C를 이긴 것으로 확정된다. 즉 주어진 직접 결과만으로는 부족하고, 이 관계를 끝까지 전개해야 각 선수의 순위 확정 여부를 판단할 수 있다.

n이 100 이하로 작으므로 플로이드-워셜로 `win[i][j]`(i가 j를 이겼는가) 관계를 O(n³)에 전이시킨다. 전이가 끝나면, 선수 i의 순위가 확정되려면 자신을 제외한 n-1명 전원과 `win[i][j]` 또는 `win[j][i]` 중 하나가 참이어야 한다.

## 풀이

```java
public int solution(int n, int[][] results) {
    boolean[][] win = new boolean[n + 1][n + 1];
    for (int[] r : results) {
        win[r[0]][r[1]] = true;
    }
    for (int k = 1; k <= n; k++) {
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                if (win[i][k] && win[k][j]) win[i][j] = true;
            }
        }
    }
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        boolean confirmed = true;
        for (int j = 1; j <= n; j++) {
            if (i == j) continue;
            if (!win[i][j] && !win[j][i]) {
                confirmed = false;
                break;
            }
        }
        if (confirmed) cnt++;
    }
    return cnt;
}
```

## 회고

거리(경로 길이)를 계산하는 방식으로도 같은 결과를 낼 수 있지만, 이 문제에서 필요한 건 "몇 단계 만에 이겼는가"가 아니라 "이겼는지 여부"뿐이라 boolean 기반 전이가 더 문제 의도에 맞는다.

또한 순위 확정 여부를 셀 때 처음에는 상대 전원을 끝까지 세어 n-1과 비교했는데, 관계를 모르는 상대를 하나라도 찾으면 그 선수는 이미 확정 불가로 판정 나므로 그 즉시 반복을 끊는 편이 낫다. 확정되는 선수는 어차피 끝까지 봐야 하니 worst-case는 동일하지만, 확정 안 되는 선수의 경우 불필요한 순회를 줄일 수 있다.
