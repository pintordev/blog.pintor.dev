## 문제

> 링크: [프로그래머스 17687](https://school.programmers.co.kr/learn/courses/30/lessons/17687)

0부터 시작하는 숫자를 n진수로 변환한 문자열을 이어붙여, m명이 순서대로 한 글자씩 말할 때 p번째 사람이 말해야 할 t개의 글자를 반환한다.

## 접근

### 수열 미리 생성 후 인덱스 추출

전체에서 필요한 글자 수는 `m * t`개다. 0부터 n진수로 변환한 문자열을 이어붙여 길이가 `m * t` 이상이 될 때까지 수열을 생성한 뒤, p번째 사람의 차례에 해당하는 인덱스(`j * m + p - 1`)의 문자만 t개 추출한다.

## 풀이

```java
public String solution(int n, int t, int m, int p) {
    StringBuilder sb = new StringBuilder();
    int i = 0;
    while (sb.length() < m * t) {
        sb.append(Integer.toString(i++, n).toUpperCase());
    }
    char[] res = new char[t];
    for (int j = 0; j < t; j++) {
        res[j] = sb.charAt(j * m + p - 1);
    }
    return new String(res);
}
```
