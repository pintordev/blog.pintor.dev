## 문제

> 링크: [프로그래머스 12951](https://school.programmers.co.kr/learn/courses/30/lessons/12951)

주어진 문자열을 JadenCase(각 단어의 첫 글자는 대문자, 나머지는 소문자)로 변환한다. 단어의 첫 글자가 알파벳이 아니면 이후 알파벳은 소문자로 처리한다.

## 접근

### 이전 문자가 공백인지 확인

단어의 시작을 별도로 추적하는 대신, 현재 인덱스 `i`의 이전 문자 `s.charAt(i - 1)`이 공백이면 단어의 첫 글자로 간주해 대문자로 변환하고, 아니면 소문자로 변환한다.

첫 번째 문자는 루프 바깥에서 별도로 `toUpperCase`를 적용한다.

## 풀이

```java
public String solution(String s) {
    StringBuilder sb = new StringBuilder();
    sb.append(Character.toUpperCase(s.charAt(0)));
    for (int i = 1, len = s.length(); i < len; i++) {
        if (s.charAt(i - 1) == ' ') sb.append(Character.toUpperCase(s.charAt(i)));
        else sb.append(Character.toLowerCase(s.charAt(i)));
    }
    return sb.toString();
}
```
