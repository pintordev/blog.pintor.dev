## 문제

> 링크: [프로그래머스 49995](https://school.programmers.co.kr/learn/courses/30/lessons/49995)

일렬로 놓인 바구니에서 인접한 두 구간의 과자 수 합이 같도록 나눌 때, 한 명이 받을 수 있는 과자 수의 최댓값을 구하는 문제. 불가능하면 0을 반환한다.

## 접근

### 경계 고정 + 투 포인터

두 구간이 맞닿아 있으므로 경계 `m`을 하나 고정하면 왼쪽 구간 `[l, m]`과 오른쪽 구간 `[m+1, r]`의 끝점이 정해진다. 이후에는 각 구간을 바깥쪽으로만 늘려 가며 합을 맞추면 된다.

- 처음에는 `l = m`, `r = m + 1`로 각 구간에 바구니를 하나씩만 담는다.
- 왼쪽 합이 오른쪽 합 이하이면 `l`을 왼쪽으로 늘리고, 더 크면 `r`을 오른쪽으로 늘린다.
- 두 합이 같으면 답을 갱신하고, 이어서 구간을 계속 늘린다. 더 큰 합이 나올 수 있기 때문이다.
- 더 늘릴 수 없는 쪽에 도달하면 해당 `m`의 탐색을 끝낸다.

모든 원소가 양수이므로 구간을 늘리면 합이 단조 증가한다. 따라서 한 `m`에서 `l`과 `r`은 각각 한 방향으로만 움직이고, `m`당 O(N)이다. 전체 시간복잡도는 O(N²), 공간복잡도는 O(1)이다. N이 최대 2,000이므로 충분하다.

## 풀이

```java
    public int solution(int[] cookie) {
        int n = cookie.length, res = 0;
        for (int m = 0; m < n - 1; m++) {
            int l = m, r = m + 1, lsum = cookie[l], rsum = cookie[r];
            while (true) {
                if (lsum == rsum && res < lsum) res = lsum;
                else if (lsum <= rsum && l > 0) lsum += cookie[--l];
                else if (lsum > rsum && r < n - 1) rsum += cookie[++r];
                else break;
            }
        }
        return res;
    }
```
