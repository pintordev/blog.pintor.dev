## 문제

> 링크: [프로그래머스 118668](https://school.programmers.co.kr/learn/courses/30/lessons/118668)

알고력과 코딩력 두 능력치를 훈련하거나 문제를 풀어 올리면서, 모든 문제를 풀 수 있는 상태에 도달하는 최단 시간을 구하는 문제.

## 접근

### 상태 그래프로 모델링

(알고력, 코딩력) 쌍을 상태로 보고, 세 종류의 간선으로 상태 그래프를 만든다. 알고력 +1(비용 1), 코딩력 +1(비용 1), 조건을 만족하는 문제 풀이(비용 cost, 보상만큼 능력치 증가)다. 이 그래프에서 시작 상태부터 모든 문제를 풀 수 있는 상태까지의 최단 비용을 구하면 된다.

### 상태 범위 제한

alp_req, cop_req가 모두 150 이하이므로 능력치를 그 이상으로 올릴 필요가 없다. 초기값과 모든 문제의 요구치 중 최댓값(maxAlp, maxCop)까지만 상태를 고려하면 상태 수가 유한하게 줄어든다.

### 다익스트라 대신 그리드 DP

모든 간선이 (i, j) → (i', j')에서 i' ≥ i && j' ≥ j를 만족한다. 훈련은 한 축만 증가시키고, 문제 보상은 항상 비음수이기 때문이다. 따라서 이 그래프는 (i, j) 좌표 기준으로 사이클이 없는 DAG이고, i와 j를 오름차순으로 순회하는 이중 for문 자체가 위상정렬 순서와 일치한다. 우선순위 큐 없이 한 번의 순회로 relax하면 정확한 최단시간이 나온다.

## 풀이

```java
import java.util.Arrays;

int[][] problems;
int maxAlp;
int maxCop;
int[][] dist;

public int solution(int alp, int cop, int[][] problems) {
    this.problems = problems;
    maxAlp = alp;
    maxCop = cop;
    for (int[] p : problems) {
        maxAlp = Math.max(maxAlp, p[0]);
        maxCop = Math.max(maxCop, p[1]);
    }
    return gridDp(alp, cop);
}

public int gridDp(int alp, int cop) {
    dist = new int[maxAlp + 1][maxCop + 1];
    for (int[] row : dist) {
        Arrays.fill(row, Integer.MAX_VALUE);
    }
    dist[alp][cop] = 0;
    for (int i = alp; i <= maxAlp; i++) {
        for (int j = cop; j <= maxCop; j++) {
            if (i + 1 <= maxAlp && dist[i][j] + 1 < dist[i + 1][j]) dist[i + 1][j] = dist[i][j] + 1;
            if (j + 1 <= maxCop && dist[i][j] + 1 < dist[i][j + 1]) dist[i][j + 1] = dist[i][j] + 1;
            for (int[] p : problems) {
                if (i < p[0] || j < p[1]) continue;
                int na = Math.min(maxAlp, i + p[2]);
                int nc = Math.min(maxCop, j + p[3]);
                if (dist[i][j] + p[4] < dist[na][nc]) dist[na][nc] = dist[i][j] + p[4];
            }
        }
    }
    return dist[maxAlp][maxCop];
}
```
