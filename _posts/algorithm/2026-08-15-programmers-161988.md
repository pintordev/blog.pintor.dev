## 문제

> 링크: [프로그래머스 161988](https://school.programmers.co.kr/learn/courses/30/lessons/161988)

정수 수열의 연속 부분수열에 `[1, -1, 1, ...]` 또는 `[-1, 1, -1, ...]` 형태의 펄스 수열을 원소별로 곱했을 때 얻을 수 있는 합의 최댓값을 구하는 문제다.

## 접근

### 부호를 전역으로 고정하고 카데인 알고리즘 적용

펄스는 `1`로 시작하거나 `-1`로 시작하는 두 가지뿐이다. 부분수열의 시작 인덱스가 짝수인지 홀수인지에 따라 실제 곱해지는 부호 패턴이 정해지므로, 원소 인덱스 `i`를 기준으로 `sequence[i] * (i가 짝수면 1, 홀수면 -1)`로 전역 변환한 값을 만들면, 임의의 연속 부분수열에 대해 얻을 수 있는 두 가지 펄스 합은 이 변환된 배열의 부분합 `T`와 `-T` 둘 중 하나가 된다.

따라서 문제는 변환된 배열에서 연속 부분합의 최댓값과 최솟값을 구한 뒤 `max(최댓값, -최솟값)`을 답으로 내는 것으로 바뀐다. 최솟값을 별도로 추적하는 대신, 부호를 뒤집은 값에 대해 최댓값을 추적하면 `Math.min` 없이 `Math.max`만으로 두 값을 동시에 갱신할 수 있다. 한 번의 순회로 처리 가능하므로 시간복잡도는 O(N), 추가 공간은 O(1)이다.

## 풀이

```java
public long solution(int[] sequence) {
    long max = 0, dp0 = 0, dp1 = 0;
    int f = 1;
    for (int cur : sequence) {
        cur *= f;
        dp0 = Math.max(dp0 + cur, cur);
        dp1 = Math.max(dp1 - cur, -cur);
        max = Math.max(max, Math.max(dp0, dp1));
        f *= -1;
    }
    return max;
}
```
