## 문제

> 링크: [프로그래머스 12923](https://school.programmers.co.kr/learn/courses/30/lessons/12923)

begin~end 구간 각 위치에 최종적으로 설치된 숫자 블록 번호를 반환한다.

## 접근

### 최소 소인수 탐색

블록 n은 n×2, n×3, ... 위치에 순서대로 설치되고 나중에 온 블록이 덮어쓴다. 따라서 위치 p에 남는 블록 번호는 **p의 진약수(p보다 작은 약수) 중 ≤ 10,000,000인 것들 중 최댓값**이다.

p의 가장 큰 진약수는 p를 최소 소인수로 나눈 값이다. 2부터 √p까지 순회하면서 p의 약수 i를 찾되, p/i ≤ 10,000,000이면 즉시 반환한다. p/i > 10,000,000인 경우 i 자체는 유효한 진약수이므로 r에 저장해 두고, 루프 종료 후 r을 반환한다.

- 시간복잡도: O((end - begin + 1) × √end) = O(5,001 × 31,623) ≈ 1.58×10⁸ (조기 종료 빈번)
- 공간복잡도: O(end - begin + 1)

## 풀이

```java
public int[] solution(long begin, long end) {
    int[] res = new int[(int)(end - begin + 1)];
    for (long p = begin; p <= end; p++) {
        res[(int)(p - begin)] = block(p);
    }
    return res;
}

public int block(long p) {
    if (p == 1) return 0;
    long r = 1;
    for (long i = 2; i * i <= p; i++) {
        if (p % i == 0) {
            if (p / i <= 10_000_000) return (int)(p / i);
            r = i;
        }
    }
    return (int) r;
}
```
