## 문제

> 링크: [프로그래머스 214288](https://school.programmers.co.kr/learn/courses/30/lessons/214288)

k개 상담 유형에 멘토 n명을 유형별 최소 1명씩 배정할 때, 참가자들의 대기 시간 합을 최소로 만드는 값을 구하는 문제.

## 접근

### 유형별 대기 시간을 먼저 구한다

멘토는 한 유형만 담당하므로 유형이 다르면 서로 영향을 주지 않는다. 한 유형의 대기 시간은 그 유형의 요청과 배정된 멘토 수만으로 결정된다. 그래서 `waiting[i][m]`을 "유형 i에 멘토 m명을 둘 때의 총 대기 시간"으로 정의하고 미리 계산해 둔다.

- 각 유형에는 최소 1명이 필요하고 나머지 유형이 최소 1명씩 가져가야 하므로, 한 유형이 가질 수 있는 멘토 수는 1명부터 `n - k + 1`명까지다.
- 계산은 우선순위 큐 시뮬레이션으로 한다. 큐에는 멘토별 상담 종료 시각을 넣고 처음에는 모두 0으로 채운다.
- 요청이 시각 순으로 들어오므로 앞에서부터 처리한다. 가장 빨리 비는 멘토의 종료 시각 `end`를 꺼내면 상담 시작 시각은 `max(end, 요청 시각)`이다. 대기 시간은 `max(0, end - 요청 시각)`이다.
- 상담이 끝나는 시각 `시작 + 상담 시간`을 큐에 다시 넣는다. 어느 멘토가 받는지는 결과에 영향이 없으므로 종료 시각만 관리하면 된다.
- 요청이 하나도 없는 유형은 반복문이 돌지 않아 대기 시간이 0이다.

### 멘토 배분은 DP로 구한다

`waiting` 표가 있으면 문제는 "유형 1..k에 멘토를 합이 n이 되도록 나누고 `waiting` 합을 최소화"하는 형태로 바뀐다. 유형 하나의 선택이 다음 유형에 남는 멘토 수만 바꾸므로 DP로 풀 수 있다.

**상태**

`dp[i][j]` = 앞의 i개 유형에 멘토 j명을 배정했을 때 대기 시간 합의 최솟값.

**점화식**

i번째 유형에 m명을 주면 앞의 i-1개 유형이 j-m명을 가져간다.

```
dp[i][j] = min(dp[i-1][j-m] + waiting[i][m])
```

**범위**

- `m ≥ 1`: 모든 유형은 최소 1명이 필요하다.
- `m ≤ n - k + 1`: `waiting` 표에서 계산해 둔 범위다.
- `m ≤ j - i + 1`: 앞의 i-1개 유형이 최소 1명씩 가져가야 하므로 i번째 유형이 쓸 수 있는 인원은 `j - (i - 1)` 이하다.
- `j ≥ i`: i개 유형에 최소 i명이 있어야 한다.

**초기값과 불가능한 상태**

- `dp[0][0] = 0`에서 시작하고 나머지는 `Integer.MAX_VALUE`로 채운다. 이 값은 "도달할 수 없는 상태"를 뜻한다.
- 전이에서 `dp[i-1][j-m]`이 `MAX_VALUE`면 건너뛴다. 그대로 더하면 오버플로가 난다.

**답**

모든 유형에 멘토 n명을 전부 배정한 `dp[k][n]`이다.

**예시 흐름**

k=2, n=3에서 모든 요청이 유형 2인 경우를 보면 다음과 같다.

- 유형 1은 요청이 없어 `waiting[1][m]`이 전부 0이다.
- `dp[1][1] = 0`, `dp[1][2] = 0`이다.
- `dp[2][3]`은 유형 2에 m=1명을 주면 `dp[1][2] + waiting[2][1]`, m=2명을 주면 `dp[1][1] + waiting[2][2]`로 계산한다.
- 둘 중 작은 값이 답이며 예시의 정답은 90이다.

### 복잡도

- 시뮬레이션: 유형마다 m = 1..n-k+1에 대해 요청 수 × log n이므로 전체 O(R · n · log n).
- DP: O(k · n²).
- R ≤ 300, n ≤ 20, k ≤ 5라 여유롭다.

## 풀이

```java
import java.util.*;

List<int[]>[] types;

public int solution(int k, int n, int[][] reqs) {
    types = new List[k + 1];
    for (int i = 1; i <= k; i++) {
        types[i] = new ArrayList<>();
    }
    for (int[] req : reqs) {
        types[req[2]].add(req);
    }
    int[][] waiting = new int[k + 1][n - k + 2];
    for (int i = 1; i <= k; i++) {
        for (int j = 1; j <= n - k + 1; j++) {
            waiting[i][j] = simulate(i, j);
        }
    }
    int[][] dp = new int[k + 1][n + 1];
    for (int[] row : dp) {
        Arrays.fill(row, Integer.MAX_VALUE);
    }
    dp[0][0] = 0;
    for (int i = 1; i <= k; i++) {
        for (int j = i; j <= n; j++) {
            for (int m = 1; m <= n - k + 1 && m <= j - i + 1; m++) {
                if (dp[i - 1][j - m] == Integer.MAX_VALUE) continue;
                dp[i][j] = Math.min(dp[i][j], dp[i - 1][j - m] + waiting[i][m]);
            }
        }
    }
    return dp[k][n];
}

public int simulate(int type, int mentors) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    for (int i = 0; i < mentors; i++) {
        pq.add(0);
    }
    int res = 0;
    for (int[] req : types[type]) {
        int end = pq.poll();
        res += Math.max(0, end - req[0]);
        pq.add(Math.max(end, req[0]) + req[1]);
    }
    return res;
}
```
