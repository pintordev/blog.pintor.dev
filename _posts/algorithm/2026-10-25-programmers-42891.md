## 문제

> 링크: [프로그래머스 42891](https://school.programmers.co.kr/learn/courses/30/lessons/42891)

회전판 위 음식을 1초에 하나씩 번호순으로 돌아가며 먹을 때, K초 후 방송이 중단되면 복구 후 먹어야 할 음식 번호를 구하는 문제. 남은 음식이 없으면 -1을 반환한다.

## 접근

### 정렬 + 라운드 단위 건너뛰기

k가 최대 2×10¹³이라 초 단위로 시뮬레이션할 수 없다. 대신 먹는 시간이 짧은 음식부터 한꺼번에 제거한다.

남은 음식이 m개이고 가장 적게 남은 시간이 t라면, 모든 음식이 한 바퀴씩 돌며 t만큼 줄어드는 데 `m × t`초가 걸린다. 이때 가장 적게 남은 음식은 정확히 다 먹혀 사라진다. 이미 줄어든 시간을 `prev`로 두면, 시간이 `cur`인 음식까지 제거하는 비용은 `(cur - prev) × m`이다.

1. (시간, 번호) 쌍을 시간 오름차순으로 정렬한다.
2. 앞에서부터 비용을 계산해 k 이상이면 k에서 빼고 해당 음식을 제거한다. 시간이 같은 음식은 `cur - prev = 0`이라 비용 0으로 자연스럽게 제거된다.
3. 비용이 k보다 크면 멈춘다. 모든 음식을 제거했다면 -1이다.
4. 남은 음식을 번호순으로 다시 정렬하면, 답은 `k % (남은 음식 수)`번째 음식이다.

비용 계산에서 오버플로가 나지 않도록 `prev`를 `long`으로 둔다.

- 시간복잡도: O(N log N)
- 공간복잡도: O(N)

## 풀이

```java
import java.util.Arrays;

public int solution(int[] food_times, long k) {
    int n = food_times.length;
    int[][] foods = new int[n][];
    for (int i = 0; i < n; i++) {
        foods[i] = new int[]{food_times[i], i + 1};
    }
    Arrays.sort(foods, (a, b) -> Integer.compare(a[0], b[0]));
    long prev = 0;
    int i = 0;
    while (i < n) {
        long cost = (foods[i][0] - prev) * (n - i);
        if (k < cost) break;
        k -= cost;
        prev = foods[i][0];
        i++;
    }
    if (i == n) return -1;
    Arrays.sort(foods, i, n, (a, b) -> Integer.compare(a[1], b[1]));
    return foods[i + (int) (k % (n - i))][1];
}
```
