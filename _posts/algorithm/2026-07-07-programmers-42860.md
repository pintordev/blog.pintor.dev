## 문제

> 링크: [프로그래머스 42860](https://school.programmers.co.kr/learn/courses/30/lessons/42860)

조이스틱으로 알파벳 이름을 완성하는 데 필요한 최솟값 이동 횟수를 구하는 문제

## 접근

### 상하 이동과 좌우 이동 분리

이동 횟수는 두 가지로 분리해서 계산한다.

**알파벳 변경(상하):** 각 위치의 문자를 만들기 위한 최솟값은 위로 올리는 횟수(`c - 'A'`)와 아래로 내리는 횟수(`'Z' - c + 1`) 중 작은 값이다. 이를 모든 위치에 대해 합산한다.

**커서 이동(좌우):** 핵심은 연속된 A 구간을 건너뛰는 것이다. A는 초기값이므로 방문할 필요가 없다. 오른쪽으로만 끝까지 이동하는 비용(`len - 1`)을 기준으로, 각 위치 `i`에서 `i+1`부터 시작하는 연속 A 구간의 끝 `e`를 찾아 다음 비용과 비교한다.

- 오른쪽으로 `i`까지 갔다가 되돌아와 왼쪽 방향으로 `e`부터 처리: `2i + (len - e)`
- 왼쪽 방향으로 `e`부터 처리하고 되돌아와 오른쪽으로 `i`까지: `2(len - e) + i`

두 전략의 최솟값은 `i + (len - e) + min(i, len - e)`로 표현된다.

## 풀이

```java
public int solution(String name) {
    int len = name.length();
    int ud = 0, lr = len - 1;
    for (int i = 0; i < len; i++) {
        char c = name.charAt(i);
        ud += Math.min(c - 'A', 'Z' - c + 1);
        int e = i + 1;
        while (e < len && name.charAt(e) == 'A') e++;
        lr = Math.min(lr, i + len - e + Math.min(i, len - e));
    }
    return ud + lr;
}
```
