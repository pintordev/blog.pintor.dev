## 문제

> 링크: [프로그래머스 42885](https://school.programmers.co.kr/learn/courses/30/lessons/42885)

최대 2명, 무게 제한이 있는 구명보트로 전원을 구출하는 데 필요한 최소 보트 수를 구하는 문제.

## 접근

### 투 포인터 (양 끝에서 좁히기)

정렬 후 가장 가벼운 사람(i)과 가장 무거운 사람(j)을 함께 태울 수 있으면 같이, 못 태우면 무거운 사람 혼자 탑승시킨다.

- `people[i] + people[j] <= limit` → 둘 다 탑승, `i++`, `j--`
- 초과 → 무거운 사람 혼자 탑승, `j--`

루프 종료 후 정답은 `people.length - i`.

`i`는 짝을 찾은 가벼운 사람 수다. 루프가 끝나면:
- j가 거쳐간 사람(무거운 쪽) 중 `i`명은 가벼운 사람과 동승 → 2인 보트 `i`개
- 나머지 `people.length - 2i`명은 혼자 탑승 → 1인 보트 `people.length - 2i`개
- 합계: `i + (people.length - 2i)` = **`people.length - i`**

## 풀이

```java
import java.util.Arrays;

public int solution(int[] people, int limit) {
    Arrays.sort(people);
    int i = 0;
    int j = people.length - 1;
    while (i < j) {
        if (people[i] + people[j] <= limit) i++;
        j--;
    }
    return people.length - i;
}
```
