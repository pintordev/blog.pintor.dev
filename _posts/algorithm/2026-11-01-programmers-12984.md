## 문제

> 링크: [프로그래머스 12984](https://school.programmers.co.kr/learn/courses/30/lessons/12984)

N×N 격자의 모든 칸 높이를 같게 맞추되, 블록 추가 비용 P와 제거 비용 Q의 합이 최소가 되는 값을 구하는 문제.

## 접근

### 정렬 + 누적합

목표 높이를 h라 하면 총 비용은 h보다 낮은 칸을 채우는 비용(P)과 h보다 높은 칸을 깎는 비용(Q)의 합이다. 칸마다 비용이 |높이 − h|에 비례하는 구간 선형 함수이므로 합도 꺾이는 지점이 칸의 높이 값에서만 생긴다. 따라서 최적의 h는 주어진 높이 중 하나다.

모든 높이를 1차원으로 펴서 정렬하고 누적합을 구하면, i번째 높이를 목표로 삼았을 때의 비용을 O(1)에 계산할 수 있다.

- 채워야 할 블록 수: `h * (i + 1) - 앞쪽 합`
- 깎아야 할 블록 수: `(전체 합 - 앞쪽 합) - h * (뒤쪽 칸 수)`

모든 후보에 대해 `채울 수 * P + 깎을 수 * Q`를 계산해 최솟값을 구한다. 시간복잡도는 정렬이 지배하는 O(N² log N²)이다.

비용은 최대 약 9×10¹⁵까지 커질 수 있어 곱셈 전에 `long`으로 변환해야 한다.

## 풀이

```java
import java.util.Arrays;

public long solution(int[][] land, int P, int Q) {
    int n = land.length;
    int[] heights = new int[n * n];
    long total = 0;
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < n; c++) {
            heights[r * n + c] = land[r][c];
            total += land[r][c];
        }
    }
    Arrays.sort(heights);
    long res = Long.MAX_VALUE;
    long sum = 0;
    for (int i = 0; i < heights.length; i++) {
        sum += heights[i];
        long add = (long) heights[i] * (i + 1) - sum;
        long del = total - sum - (long) heights[i] * (heights.length - i - 1);
        res = Math.min(res, add * P + del * Q);
    }
    return res;
}
```
