## 문제

> 링크: [프로그래머스 154538](https://school.programmers.co.kr/learn/courses/30/lessons/154538)

자연수 x에 +n, ×2, ×3 연산을 반복해 y로 만드는 최소 연산 횟수를 구한다.

## 접근

### DP로 각 값까지의 최소 연산 횟수 누적

세 연산 모두 값을 증가시키므로, 작은 값에서 큰 값으로만 전이가 일어난다. 따라서 `dp[i]` = x에서 i까지 도달하는 최소 연산 횟수로 정의하고, x부터 y-1까지 순서대로 처리하면 각 전이가 항상 이미 확정된 값에서 출발함을 보장할 수 있다.

- 초기값: `dp[x] = 0`, 나머지 = `Integer.MAX_VALUE`
- 전이: `dp[i]`가 도달 가능한 경우에만 +n, ×2, ×3 세 연산으로 다음 값 갱신
- 결과: `dp[y]`가 여전히 MAX_VALUE면 -1, 아니면 그 값

## 풀이

```java
import java.util.Arrays;

public int solution(int x, int y, int n) {
    int[] dp = new int[y + 1];
    Arrays.fill(dp, Integer.MAX_VALUE);
    dp[x] = 0;

    for (int i = x; i < y; i++) {
        if (dp[i] == Integer.MAX_VALUE) continue;
        if (i + n <= y) dp[i + n] = Math.min(dp[i + n], dp[i] + 1);
        if (i * 2 <= y) dp[i * 2] = Math.min(dp[i * 2], dp[i] + 1);
        if (i * 3 <= y) dp[i * 3] = Math.min(dp[i * 3], dp[i] + 1);
    }

    return dp[y] == Integer.MAX_VALUE ? -1 : dp[y];
}
```
