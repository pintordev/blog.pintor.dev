## 문제

> 링크: [프로그래머스 42626](https://school.programmers.co.kr/learn/courses/30/lessons/42626)

스코빌 지수가 모두 K 이상이 되도록, 가장 맵지 않은 두 음식을 섞는 최소 횟수를 구한다.

## 접근

### MinHeap (PriorityQueue)

매 단계마다 가장 작은 값 두 개를 꺼내야 하므로, `PriorityQueue`(MinHeap)를 사용한다.

- 모든 원소를 PriorityQueue에 삽입
- `peek() < K`이고 원소가 2개 이상인 동안, 최솟값 두 개를 꺼내 `a + b * 2`로 섞어 재삽입
- 루프 종료 후 `peek() < K`이면 불가능하므로 -1 반환

`pq.size() > 1` 조건이 중요하다. 원소가 1개 남은 상태에서 섞으려 하면 두 번째 `poll()`이 `null`을 반환해 NPE가 발생한다.

## 풀이

```java
import java.util.PriorityQueue;

public int solution(int[] scoville, int K) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    for (int s : scoville) pq.add(s);
    int cnt = 0;
    while (pq.size() > 1 && pq.peek() < K) {
        int a = pq.poll();
        int b = pq.poll();
        pq.add(a + (b << 1));
        cnt++;
    }
    return pq.peek() < K ? -1 : cnt;
}
```
