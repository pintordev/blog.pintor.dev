## 문제

> 링크: [프로그래머스 148653](https://school.programmers.co.kr/learn/courses/30/lessons/148653)

현재 층 `storey`에서 0층까지 내려갈 때, ±10^c 버튼을 최소한으로 눌러 소모하는 마법의 돌 개수를 구한다.

## 접근

### 그리디 — 자릿수별 올림/내림 선택

낮은 자리부터 자릿수 `d`를 하나씩 제거한다. 각 자리에서 두 가지 선택이 있다.

- **내림**: `-10^c`를 `d`번 → 비용 `d`
- **올림**: `+10^c`를 `10 - d`번 → 비용 `10 - d`, 윗 자리에 1 올림

`d < 5`이면 내림, `d > 5`이면 올림이 항상 유리하다.  
`d == 5`일 때는 비용이 같으므로, 다음 자릿수가 5 이상이면 올림(연쇄적으로 윗 자리 비용도 줄어듦), 미만이면 내림을 선택한다.

## 풀이

```java
public int solution(int storey) {
    int cost = 0;
    while (storey > 0) {
        int d = storey % 10;
        if (d < 5) cost += d;
        else if (d > 5) {
            cost += 10 - d;
            storey += 10 - d;
        }
        else {
            if (storey / 10 % 10 >= 5) {
                cost += 5;
                storey += 5;
            }
            else cost += 5;
        }
        storey /= 10;
    }
    return cost;
}
```

## 회고

`d == 5`일 때 단순히 둘 중 하나를 고정하면 틀린다. 예를 들어 `storey = 2554`에서 백의 자리 5를 처리할 때, 다음 자리(천의 자리)가 2이므로 내림을 선택해야 총 비용이 최소가 된다. 다음 자릿수를 함께 보는 것이 핵심이었다.
