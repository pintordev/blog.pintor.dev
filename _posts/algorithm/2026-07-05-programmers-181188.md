## 문제

> 링크: [프로그래머스 181188](https://school.programmers.co.kr/learn/courses/30/lessons/181188)

개구간 (s, e)로 표현되는 폭격 미사일을 모두 요격하기 위한 최소 요격 미사일 수를 구하는 문제.

## 접근

### 끝점 기준 정렬 + 그리디

개구간이므로 요격 위치 x는 s < x < e를 만족해야 한다. 가장 일찍 끝나는 구간을 기준으로 요격 위치를 최대한 오른쪽(끝점 직전)에 배치하면, 이후 구간을 최대한 함께 커버할 수 있다.

끝점 e 기준으로 오름차순 정렬한 뒤, 다음 구간의 시작점이 현재 요격 기준 끝점 이상이면(s >= le) 새 요격 미사일을 발사하고 le를 갱신한다.

## 풀이

```java
import java.util.Arrays;
import java.util.Comparator;

public int solution(int[][] targets) {
    Arrays.sort(targets, Comparator.comparingInt(o -> o[1]));
    int cnt = 1;
    int le = targets[0][1];
    for (int i = 1; i < targets.length; i++) {
        if (targets[i][0] < le) continue;
        cnt++;
        le = targets[i][1];
    }
    return cnt;
}
```
