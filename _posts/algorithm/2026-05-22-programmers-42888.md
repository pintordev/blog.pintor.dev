## 문제

> 링크: [프로그래머스 42888](https://school.programmers.co.kr/learn/courses/30/lessons/42888)

오픈채팅방의 입장/퇴장/닉네임 변경 레코드를 처리해 최종 닉네임 기준으로 메시지 목록을 반환한다.

## 접근

### uid → 최종 닉네임 맵 + 2차 순회

닉네임은 언제든 변경될 수 있으므로, 출력 시점의 닉네임은 전체 레코드를 한 번 훑은 뒤에야 확정된다.

1. **1차 순회**: `Enter`/`Change` 레코드로 `id2Name` 맵을 갱신해 uid별 최종 닉네임을 구한다. `Leave`는 닉네임 정보가 없으므로 건너뛴다.
2. **2차 순회**: `Enter`/`Leave` 이벤트에 대해 `id2Name`에서 닉네임을 조회해 메시지를 생성한다. `Change`는 결과에 포함하지 않는다.

`split` 중복 호출을 줄이기 위해 1차 순회에서 파싱한 결과를 `commands` 리스트에 캐싱한다.

## 풀이

```java
import java.util.*;

public String[] solution(String[] record) {
    Map<String, String> id2Name = new HashMap<>();
    List<String[]> commands = new ArrayList<>();
    for (String r : record) {
        String[] bits = r.split(" ");
        commands.add(bits);
        if (bits[0].equals("Leave")) continue;
        id2Name.put(bits[1], bits[2]);
    }
    List<String> resList = new ArrayList<>();
    for (String[] bits : commands) {
        if (bits[0].equals("Change")) continue;
        if (bits[0].equals("Enter")) resList.add(id2Name.get(bits[1]) + "님이 들어왔습니다.");
        else resList.add(id2Name.get(bits[1]) + "님이 나갔습니다.");
    }
    return resList.toArray(new String[0]);
}
```
