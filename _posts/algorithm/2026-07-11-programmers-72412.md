## 문제

> 링크: [프로그래머스 72412](https://school.programmers.co.kr/learn/courses/30/lessons/72412)

지원자의 개발언어, 직군, 경력, 소울푸드 조건과 점수가 주어질 때, 조회 조건을 만족하면서 점수가 X 이상인 지원자 수를 구하는 문제다. 조회 조건 중 일부는 `-`로 표시되어 해당 항목을 무시할 수 있다.

## 접근

### 조건 조합별 해시맵 + 이분탐색

info와 query의 크기가 각각 최대 50,000, 100,000이라 매 query마다 전체 info를 순회하는 완전탐색은 시간초과가 발생한다.

지원자 조건은 4개 항목이고 각 항목은 실제 값 또는 `-`(무시) 두 가지로 취급될 수 있으므로, 조건 조합의 경우의 수는 2⁴=16가지로 고정된다. info 각 항목마다 16가지 조합의 키를 모두 만들어 `키 → 점수 리스트` 형태의 해시맵에 점수를 저장하고, 각 리스트를 정렬해둔다.

query는 이미 조건 4개가 "값 또는 -" 형태로 주어지므로 그대로 키를 만들어 해시맵에서 점수 리스트를 찾고, 이분탐색으로 X 이상인 개수를 구한다.

## 풀이

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public int[] solution(String[] info, String[] query) {
    Map<String, List<Integer>> map = new HashMap<>();
    for (String line : info) {
        String[] tokens = line.split(" ");
        String[] fields = {tokens[0], tokens[1], tokens[2], tokens[3]};
        int score = Integer.parseInt(tokens[4]);
        for (int mask = 0; mask < 16; mask++) {
            map.computeIfAbsent(genKey(fields, mask), k -> new ArrayList<>()).add(score);
        }
    }
    for (List<Integer> scores : map.values()) {
        Collections.sort(scores);
    }
    int[] answer = new int[query.length];
    for (int i = 0; i < query.length; i++) {
        String[] tokens = query[i].split(" ");
        String key = tokens[0] + "/" + tokens[2] + "/" + tokens[4] + "/" + tokens[6] + "/";
        int x = Integer.parseInt(tokens[7]);
        List<Integer> scores = map.get(key);
        answer[i] = scores == null ? 0 : scores.size() - bs(scores, x);
    }
    return answer;
}

public String genKey(String[] fields, int mask) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < 4; i++) {
        sb.append((mask & (1 << i)) != 0 ? "-" : fields[i]);
        sb.append("/");
    }
    return sb.toString();
}

public int bs(List<Integer> scores, int x) {
    int lo = 0, hi = scores.size() - 1;
    while (lo < hi + 1) {
        int mid = (lo + hi) >> 1;
        if (scores.get(mid) < x) lo = mid + 1;
        else hi = mid - 1;
    }
    return lo;
}
```
