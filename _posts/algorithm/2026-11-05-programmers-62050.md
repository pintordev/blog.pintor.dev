## 문제

> 링크: [프로그래머스 62050](https://school.programmers.co.kr/learn/courses/30/lessons/62050)

N×N 격자의 모든 칸을 방문하기 위해, 높이 차가 `height`를 넘는 인접 칸 사이에 설치하는 사다리 비용(높이 차)의 최솟값을 구하는 문제.

## 접근

### 크루스칼 (Union-Find)

각 칸을 정점으로, 상하좌우로 인접한 두 칸을 간선으로 보면 모든 칸을 연결하는 최소 비용을 구하는 최소 신장 트리 문제가 된다.

- 칸 번호는 `r * n + c`로 매긴다.
- 간선 비용은 높이 차가 `height` 이하면 0, 초과하면 높이 차 그대로다. 비용이 0인 간선이 사다리 없이 이동 가능한 구역을 먼저 묶어 준다.
- 중복 없이 모든 인접 쌍을 덮으려면 아래쪽과 오른쪽 이웃만 간선으로 만들면 된다.
- 간선을 비용 오름차순으로 정렬한 뒤, 두 칸의 집합이 다를 때만 union하고 비용을 더한다.

정점은 최대 90,000개, 간선은 약 180,000개라 정렬 비용이 O(N² log N)으로 충분하다.

## 풀이

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

int n;
int[][] land;
int height;
int[] parent;
int[] dr = {1, 0};
int[] dc = {0, 1};

public int solution(int[][] land, int height) {
    this.land = land;
    this.height = height;
    n = land.length;
    parent = new int[n * n];
    for (int i = 0; i < n * n; i++) {
        parent[i] = i;
    }
    List<Edge> edges = new ArrayList<>();
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < n; c++) {
            for (int d = 0; d < 2; d++) {
                int nr = r + dr[d];
                int nc = c + dc[d];
                if (!isAvailable(nr, nc)) continue;
                int diff = Math.abs(land[r][c] - land[nr][nc]);
                edges.add(new Edge(r * n + c, nr * n + nc, diff <= height ? 0 : diff));
            }
        }
    }
    Collections.sort(edges);
    int res = 0;
    for (Edge e : edges) {
        if (find(e.a) == find(e.b)) continue;
        union(e.a, e.b);
        res += e.cost;
    }
    return res;
}

public boolean isAvailable(int r, int c) {
    if (r >= n || c >= n) return false;
    return true;
}

public int find(int x) {
    if (parent[x] == x) return x;
    return parent[x] = find(parent[x]);
}

public void union(int a, int b) {
    parent[find(a)] = find(b);
}

class Edge implements Comparable<Edge> {
    int a;
    int b;
    int cost;

    Edge(int a, int b, int cost) {
        this.a = a;
        this.b = b;
        this.cost = cost;
    }

    @Override
    public int compareTo(Edge o) {
        return cost - o.cost;
    }
}
```
