## 문제

> 링크: [프로그래머스 87946](https://school.programmers.co.kr/learn/courses/30/lessons/87946)

현재 피로도 k로 던전을 최대한 많이 탐험하는 문제. 각 던전마다 최소 필요 피로도와 소모 피로도가 있다.

## 접근

### 비트마스크 DFS 완전탐색

던전이 최대 8개이므로 모든 탐험 순서를 완전탐색(8! = 40,320)해도 충분하다.

방문 상태를 boolean 배열 대신 int 비트마스크로 관리하면 백트래킹이 필요 없다. `visited | (1 << i)`는 원본을 바꾸지 않으므로 재귀 호출 후 복원 코드 없이 파라미터로 그대로 넘기면 된다.

## 풀이

```java
public int solution(int k, int[][] dungeons) {
    return dfs(k, dungeons, 0);
}

public int dfs(int k, int[][] dungeons, int visited) {
    int max = 0;
    for (int i = 0; i < dungeons.length; i++) {
        if ((visited & (1 << i)) != 0 || k < dungeons[i][0]) continue;
        max = Math.max(max, 1 + dfs(k - dungeons[i][1], dungeons, visited | (1 << i)));
    }
    return max;
}
```

## 회고

boolean 배열로 풀면 방문 표시 후 재귀, 복원의 3단계가 필요하다. 비트마스크를 파라미터로 넘기면 `|` 연산이 새로운 상태를 만들 뿐 원본을 건드리지 않아 복원 단계가 사라진다.
