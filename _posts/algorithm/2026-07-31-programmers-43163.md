## 문제

> 링크: [프로그래머스 43163](https://school.programmers.co.kr/learn/courses/30/lessons/43163)

begin에서 target으로, words에 있는 단어만 거쳐서 한 번에 한 글자씩 바꾸며 변환할 때 최소 몇 단계가 필요한지 구하는 문제다.

## 접근

### BFS로 최단 경로 탐색

단어 하나하나를 그래프의 노드로, 알파벳이 정확히 한 글자만 다른 두 단어를 간선으로 연결된 관계로 본다. 그러면 begin에서 target까지의 최소 변환 횟수는 가중치 없는 그래프에서의 최단 경로 문제가 된다.

큐에 begin을 넣고 시작해서, 매 단계(레벨)마다 큐에 있는 단어들을 모두 꺼내 words와 비교한다. 정확히 한 글자만 다른 단어가 있으면 다음 단계 후보로 큐에 넣고 방문 처리한다. 꺼낸 단어가 target이면 그 시점의 step이 곧 최단 변환 횟수다. 큐가 비었는데도 target을 찾지 못했다면 변환이 불가능한 경우이므로 0을 반환한다.

한 글자 차이인지는 두 단어의 같은 위치 문자를 하나씩 비교해서 다른 문자의 개수를 세고, 그 개수가 정확히 1인지로 판별한다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Queue;

String[] words;
boolean[] visited;

public int solution(String begin, String target, String[] words) {
    this.words = words;
    visited = new boolean[words.length];
    Queue<String> queue = new ArrayDeque<>();
    queue.add(begin);
    int step = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            String cur = queue.poll();
            if (cur.equals(target)) return step;
            for (int j = 0; j < words.length; j++) {
                if (!isAvailable(cur, j)) continue;
                visited[j] = true;
                queue.add(words[j]);
            }
        }
        step++;
    }
    return 0;
}

public boolean isAvailable(String a, int j) {
    if (visited[j]) return false;
    String b = words[j];
    int cnt = 0;
    for (int i = 0; i < a.length(); i++) {
        if (a.charAt(i) != b.charAt(i)) cnt++;
    }
    return cnt == 1;
}
```
