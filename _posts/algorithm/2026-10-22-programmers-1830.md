## 문제

> 링크: [프로그래머스 1830](https://school.programmers.co.kr/learn/courses/30/lessons/1830)

광고 문구에 두 가지 규칙(글자 사이 기호 삽입, 단어 앞뒤 기호 삽입)과 공백 제거가 적용된 문자열이 주어질 때, 규칙 적용 전 원래 문구를 복원하는 문제. 규칙으로 만들 수 없는 문자열이면 `"invalid"`를 반환한다.

## 접근

### 기호 등장 횟수로 구조를 검증하는 위치 기준 DP

한 번 쓰인 기호는 다시 쓰일 수 없으므로, 소문자 하나의 모든 등장 위치는 정확히 하나의 구조(규칙 1 또는 규칙 2)에 속한다. 따라서 구조를 하나 확정할 때 전체 문자열에서의 기호 등장 횟수와 그 구조 안에서의 등장 횟수가 같은지만 확인하면 기호 중복 사용 금지가 자동으로 보장된다. 등장 횟수는 미리 세어 둔다.

단어의 종류는 세 가지다.

- **일반 글자**: 기호가 붙지 않은 대문자 한 글자.
- **규칙 1 단어**: `대문자 c 대문자 c … 대문자` 형태. 기호 c가 k번 나오면 길이는 `2k + 1`로 정해진다.
- **규칙 2 단어**: 기호 c가 정확히 2번 나오고, 그 사이가 비어 있지 않은 하나의 단어. 사이 내용은 대문자뿐이거나, 구간 전체가 규칙 1 단어 하나여야 한다. 후자가 두 규칙이 한 단어에 모두 적용된 경우다.

기호가 없는 대문자 구간은 어디서든 끊을 수 있고, `XcYcZ`처럼 규칙 1과 규칙 2 두 가지로 해석되는 경우도 있어 그리디로는 모호성이 생긴다. 그래서 `ok[i]`를 "i번째부터 끝까지 올바르게 분해할 수 있는가"로 두고 뒤에서부터 채운다. 각 위치에서 규칙 1, 규칙 2, 일반 글자 순으로 후보를 시도하고, 후보의 끝 위치가 `ok`이면 현재 위치도 `ok`로 표시하며 끝 위치를 `nxt`에 저장한다.

`ok[0]`이 거짓이면 `"invalid"`를 반환한다. 참이면 `nxt`를 따라가며 대문자만 모아 단어를 만들고 공백으로 잇는다. 연속된 일반 글자는 한 단어로 합친다.

시간복잡도는 최악 O(n²)이지만 실제로는 O(n)에 가깝고, 공간복잡도는 O(n)이다. n ≤ 1,000이라 충분하다.

## 풀이

```java
String s;
int n;
int[] cnt;

public String solution(String sentence) {
    s = sentence;
    n = s.length();
    cnt = new int[26];
    for (int i = 0; i < n; i++) {
        if (Character.isLowerCase(s.charAt(i))) {
            cnt[s.charAt(i) - 'a']++;
        }
    }

    boolean[] ok = new boolean[n + 1];
    int[] nxt = new int[n + 1];
    ok[n] = true;
    for (int i = n - 1; i >= 0; i--) {
        int e = rule1(i);
        if (e == -1 || !ok[e]) e = rule2(i);
        if (e == -1 || !ok[e]) e = Character.isUpperCase(s.charAt(i)) ? i + 1 : -1;
        if (e == -1 || !ok[e]) continue;
        ok[i] = true;
        nxt[i] = e;
    }
    if (!ok[0]) return "invalid";

    StringBuilder sb = new StringBuilder();
    boolean prevPlain = false;
    for (int i = 0; i < n; i = nxt[i]) {
        boolean plain = nxt[i] - i == 1;
        if (sb.length() > 0 && !(plain && prevPlain)) sb.append(' ');
        for (int k = i; k < nxt[i]; k++) {
            if (Character.isUpperCase(s.charAt(k))) sb.append(s.charAt(k));
        }
        prevPlain = plain;
    }
    return sb.toString();
}

public int rule1(int i) {
    if (i + 1 >= n || !Character.isUpperCase(s.charAt(i)) || !Character.isLowerCase(s.charAt(i + 1))) return -1;
    char c = s.charAt(i + 1);
    int end = i + 2 * cnt[c - 'a'] + 1;
    if (end > n) return -1;
    for (int k = i; k < end; k++) {
        boolean ok = (k - i) % 2 == 0 ? Character.isUpperCase(s.charAt(k)) : s.charAt(k) == c;
        if (!ok) return -1;
    }
    return end;
}

public int rule2(int i) {
    char c = s.charAt(i);
    if (!Character.isLowerCase(c) || cnt[c - 'a'] != 2) return -1;
    int j = s.indexOf(c, i + 1);
    if (j == i + 1) return -1;
    for (int k = i + 1; k < j; k++) {
        if (Character.isLowerCase(s.charAt(k))) return rule1(i + 1) == j ? j + 1 : -1;
    }
    return j + 1;
}
```
