## 문제

> 링크: [프로그래머스 76502](https://school.programmers.co.kr/learn/courses/30/lessons/76502)

문자열 s를 왼쪽으로 x칸 회전했을 때 올바른 괄호 문자열이 되는 x의 개수 반환

## 접근

### 회전 × 스택 유효성 검사 (O(n²))

각 회전 x마다 스택으로 유효성을 검사한다. 원형 접근은 `(x + i) % n` 인덱스로 처리한다.

핵심 트릭: 여는 괄호를 push할 때 **대응하는 닫는 괄호**를 저장하면, 닫는 괄호가 왔을 때 `stack.pop() != c` 한 줄로 매칭 여부를 판단할 수 있다. `isRight` 같은 별도 헬퍼가 필요 없다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Deque;

public int solution(String s) {
    int cnt = 0;
    for (int i = 0, len = s.length(); i < len; i++) {
        if (isValid(s, i)) cnt++;
    }
    return cnt;
}

public boolean isValid(String s, int bias) {
    Deque<Character> stack = new ArrayDeque<>();
    for (int i = 0, len = s.length(); i < len; i++) {
        char c = s.charAt((i + bias) % len);
        if (c == '(') stack.push(')');
        else if (c == '[') stack.push(']');
        else if (c == '{') stack.push('}');
        else if (stack.isEmpty() || stack.pop() != c) return false;
    }
    return stack.isEmpty();
}
```

## 회고

처음에 원본 문자열을 한 번 스캔하면서 인접 쌍을 제거하고, 남은 스택의 head-tail로 회전 케이스를 처리하려 했다. 하지만 head-tail 매칭이 유효한 회전과 1:1 대응이 아니라 반례(`"())("`에서 2를 반환)가 생겼다. 결국 각 회전을 독립적으로 검사하는 O(n²)이 정석이었다. n ≤ 1000이라 충분하다.
