## 문제

> 링크: [프로그래머스 12946](https://school.programmers.co.kr/learn/courses/30/lessons/12946)

n개의 원판을 1번 기둥에서 3번 기둥으로 최소 횟수로 옮기는 각 이동 단계를 반환한다.

## 접근

### Bottom-up DP (분할정복)

`dp[i]`를 i개의 원판을 1번 → 3번으로 옮기는 이동 목록이라 할 때, 다음 점화식이 성립한다.

```
dp[i] = swap(2↔3, dp[i-1])  // n-1개를 1→2로
       + [[1, 3]]             // 가장 큰 원판을 1→3으로
       + swap(1↔2, dp[i-1])  // n-1개를 2→3으로
```

- `swap(2↔3, dp[i-1])`: 목적지를 2번으로 바꾸기 위해 기존 이동의 2·3번 기둥 번호를 교환
- `swap(1↔2, dp[i-1])`: 출발지를 2번으로 바꾸기 위해 기존 이동의 1·2번 기둥 번호를 교환

이동 횟수는 2^n - 1이므로, `dp` 배열 크기를 `(1 << i) - 1`로 미리 계산해 할당한다.

- 시간: O(2^n)
- 공간: O(2^n)

## 풀이

```java
public int[][] solution(int n) {
    int[][] dp = {{1, 3}};
    for (int i = 2; i <= n; i++) {
        int[][] next = new int[(1 << i) - 1][2];
        for (int j = 0; j < dp.length; j++) {
            next[j][0] = swap(dp[j][0], 2, 3);
            next[j][1] = swap(dp[j][1], 2, 3);
        }
        next[dp.length] = new int[]{1, 3};
        for (int j = 0; j < dp.length; j++) {
            next[dp.length + 1 + j][0] = swap(dp[j][0], 1, 2);
            next[dp.length + 1 + j][1] = swap(dp[j][1], 1, 2);
        }
        dp = next;
    }
    return dp;
}

public int swap(int peg, int a, int b) {
    if (peg == a) return b;
    if (peg == b) return a;
    return peg;
}
```
