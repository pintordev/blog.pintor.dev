## 문제

> 링크: [프로그래머스 468375](https://school.programmers.co.kr/learn/courses/30/lessons/468375)

엘리베이터로 층을 오갈 수 있는 h층 격자에서, 1번 패널 위치에서 출발해 안전 순서 쌍을 지키며 모든 패널을 활성화하는 최소 시간을 구하는 문제.

## 접근

### 패널 간 거리 + 비트마스크 DP

문제는 두 단계로 나뉜다. 패널 사이의 최단 이동 시간을 구하는 단계와, 선행 조건을 지키며 패널을 방문하는 순서를 정하는 단계다.

패널 수 k가 15 이하이므로 방문 순서를 순열로 완전탐색할 수는 없지만, 비트마스크 DP는 가능하다.

**1. 거리 행렬**

각 패널에서 `(층, 행, 열)` 3차원 BFS를 한 번씩 수행해 `dist[i][j]`를 만든다. 상하좌우 이동은 비용 1이고, `@` 칸에서만 `층±1` 이동이 비용 1로 추가된다. 노드 수는 최대 10×40×40 = 16,000개이고 BFS는 k번만 돌리므로 부담이 없다.

**2. 비트마스크 DP**

`dp[mask][last]`를 "mask에 해당하는 패널을 활성화했고 마지막이 last일 때의 최소 시간"으로 정의한다.

- 선행 조건 `[a, b]`는 `pre[b]`에 a의 비트를 켜서 저장한다.
- 다음 패널 `next`는 `(pre[next] & mask) == pre[next]`일 때만 활성화할 수 있다.
- 시작은 1번 패널의 위치이고, 1번 패널의 활성화도 다른 패널처럼 선행 조건을 따른다. 그래서 선행 조건이 없는 패널 i에 대해 `dp[1 << i][i] = dist[0][i]`로 초기화한다.
- 답은 모든 패널을 활성화한 `dp[(1 << k) - 1][*]`의 최솟값이다.

시간 복잡도는 BFS가 `O(k · h·n·m)`, DP가 `O(2^k · k^2)`이다. k = 15일 때 DP는 약 740만 번의 연산이다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Queue;

int h;
int n;
int m;
String[] grid;
int[] dr = {1, -1, 0, 0};
int[] dc = {0, 0, 1, -1};

public int solution(int h, String[] grid, int[][] panels, int[][] seqs) {
    this.h = h;
    this.grid = grid;
    n = grid.length;
    m = grid[0].length();
    int k = panels.length;
    int[][] dist = new int[k][k];
    for (int i = 0; i < k; i++) {
        int[][][] d = bfs(panels[i]);
        for (int j = 0; j < k; j++) {
            dist[i][j] = d[panels[j][0] - 1][panels[j][1] - 1][panels[j][2] - 1];
        }
    }
    int[] pre = new int[k];
    for (int[] seq : seqs) {
        pre[seq[1] - 1] |= 1 << (seq[0] - 1);
    }
    int[][] dp = new int[1 << k][k];
    for (int[] row : dp) {
        Arrays.fill(row, Integer.MAX_VALUE);
    }
    for (int i = 0; i < k; i++) {
        if (pre[i] != 0) continue;
        dp[1 << i][i] = dist[0][i];
    }
    for (int mask = 1; mask < (1 << k); mask++) {
        for (int last = 0; last < k; last++) {
            if (dp[mask][last] == Integer.MAX_VALUE) continue;
            for (int next = 0; next < k; next++) {
                if ((mask & (1 << next)) != 0 || (pre[next] & mask) != pre[next]) continue;
                int nmask = mask | (1 << next);
                dp[nmask][next] = Math.min(dp[nmask][next], dp[mask][last] + dist[last][next]);
            }
        }
    }
    int res = Integer.MAX_VALUE;
    for (int last = 0; last < k; last++) {
        res = Math.min(res, dp[(1 << k) - 1][last]);
    }
    return res;
}

public int[][][] bfs(int[] start) {
    int[][][] d = new int[h][n][m];
    for (int[][] floor : d) {
        for (int[] row : floor) {
            Arrays.fill(row, Integer.MAX_VALUE);
        }
    }
    Queue<Node> q = new ArrayDeque<>();
    q.add(new Node(start[0] - 1, start[1] - 1, start[2] - 1));
    d[start[0] - 1][start[1] - 1][start[2] - 1] = 0;
    while (!q.isEmpty()) {
        Node cur = q.poll();
        for (int i = 0; i < 4; i++) {
            int nr = cur.r + dr[i];
            int nc = cur.c + dc[i];
            if (!isAvailable(nr, nc) || d[cur.f][nr][nc] != Integer.MAX_VALUE) continue;
            d[cur.f][nr][nc] = d[cur.f][cur.r][cur.c] + 1;
            q.add(new Node(cur.f, nr, nc));
        }
        if (grid[cur.r].charAt(cur.c) != '@') continue;
        for (int nf = cur.f - 1; nf <= cur.f + 1; nf += 2) {
            if (nf < 0 || nf >= h || d[nf][cur.r][cur.c] != Integer.MAX_VALUE) continue;
            d[nf][cur.r][cur.c] = d[cur.f][cur.r][cur.c] + 1;
            q.add(new Node(nf, cur.r, cur.c));
        }
    }
    return d;
}

public boolean isAvailable(int nr, int nc) {
    if (nr < 0 || nr >= n || nc < 0 || nc >= m) return false;
    if (grid[nr].charAt(nc) == '#') return false;
    return true;
}

class Node {
    int f;
    int r;
    int c;

    Node(int f, int r, int c) {
        this.f = f;
        this.r = r;
        this.c = c;
    }
}
```
