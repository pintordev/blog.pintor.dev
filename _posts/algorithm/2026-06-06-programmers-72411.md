## 문제

> 링크: [프로그래머스 72411](https://school.programmers.co.kr/learn/courses/30/lessons/72411)

각 손님의 주문 이력에서 가장 많이 함께 주문된 메뉴 조합을 course 크기별로 찾아 코스요리 메뉴를 구성한다.

## 접근

### 비트마스크 완전탐색 + HashMap 빈도 카운트

각 손님의 주문 문자열을 알파벳 순으로 정렬한 뒤, course에 명시된 크기 k마다 비트마스크로 크기 k인 모든 조합을 생성한다. 각 조합의 등장 횟수를 HashMap에 누적하고, course 크기별로 최다 빈도(≥ 2)를 가진 조합만 결과에 포함한다.

비트마스크에서 1인 비트의 위치가 선택된 메뉴의 인덱스에 해당하며, `Integer.bitCount`로 크기 k인 마스크만 걸러낸다. 주문 문자열을 미리 정렬해두었으므로 낮은 비트부터 순서대로 담으면 알파벳 순 조합 문자열이 자동으로 만들어진다.

## 풀이

```java
import java.util.*;

Map<String, Integer> map;
int[] course;

public String[] solution(String[] orders, int[] course) {
    map = new HashMap<>();
    this.course = course;
    extractCourse(orders);
    String[] res = getRenewalMenu().toArray(new String[0]);
    Arrays.sort(res);
    return res;
}

public void extractCourse(String[] orders) {
    for (String order : orders) {
        char[] c = order.toCharArray();
        Arrays.sort(c);
        for (int k : course) {
            if (c.length < k) continue;
            comb(c, k);
        }
    }
}

public void comb(char[] c, int k) {
    for (int mask = 0; mask < (1 << c.length); mask++) {
        if (Integer.bitCount(mask) != k) continue;
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < c.length; i++) if ((mask >> i & 1) == 1) sb.append(c[i]);
        String key = sb.toString();
        map.put(key, map.getOrDefault(key, 0) + 1);
    }
}

public List<String> getRenewalMenu() {
    List<String> menu = new ArrayList<>();
    for (int k : course) {
        List<String> sub = new ArrayList<>();
        int max = 2;
        for (Map.Entry<String, Integer> entry : map.entrySet()) {
            if (entry.getKey().length() != k) continue;
            int cnt = entry.getValue();
            if (cnt < max) continue;
            if (cnt > max) { sub.clear(); max = cnt; }
            sub.add(entry.getKey());
        }
        menu.addAll(sub);
    }
    return menu;
}
```

## 회고

처음에는 `Map<Character, Integer>`로 단일 메뉴 아이템의 등장 빈도를 세는 방향으로 접근했는데, 이 문제는 조합 자체의 빈도를 세야 한다는 점을 놓쳤다. `Map<String, Integer>`로 구조를 전면 변경했다.

course 크기별 최댓값 필터링 로직에서도 버그가 있었다. max를 갱신할 때 `sub.clear(); max = cnt;`만 하고 해당 entry를 sub에 추가하지 않아, 최다 빈도 조합이 결과에서 빠지는 문제가 발생했다. `cnt > max`일 때 초기화 후 곧바로 아래 `sub.add`로 떨어지도록 분기를 정리해 해결했다.
