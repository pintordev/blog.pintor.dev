## 문제

> 링크: [프로그래머스 72414](https://school.programmers.co.kr/learn/courses/30/lessons/72414)

시청자들의 재생 구간 로그가 주어질 때, 길이가 정해진 공익광고를 넣어 광고 구간과 겹치는 누적 시청 시간이 최대가 되는 가장 빠른 시작 시각을 구한다.

## 접근

### 누적합(imos) + 슬라이딩 윈도우

모든 시각을 초 단위로 바꾸면 동영상 길이는 최대 `99:59:59` = 359,999초다. 광고를 `[t, t + advSec)`에 넣었을 때의 누적 시청 시간은 "각 로그 구간과 광고 구간의 교집합 길이 총합"인데, `t`마다 로그를 전부 훑으면 `O(P·N)`이라 30만 × 36만으로 터진다.

대신 초 단위 그리드에서 "각 1초를 몇 명이 보고 있는지"를 먼저 구한다.

1. **차분 배열** `watch`: 로그마다 `watch[start]++`, `watch[end]--`.
2. **1차 누적합**: `watch[i]` = `i`초 구간 `[i, i+1)`을 시청 중인 사람 수.
3. **윈도우 합**: 광고를 `t`에 넣었을 때 누적 시청 시간 = `watch[t] + ... + watch[t + advSec - 1]`. 크기 `advSec`짜리 구간 합이다.
4. `t`를 1씩 옮길 때 `windowView += watch[t + advSec - 1] - watch[t - 1]`로 `O(1)` 갱신.

최댓값 갱신을 `>` (등호 없음)로만 하면, `t`를 증가 방향으로 훑기 때문에 동점일 때 더 이른 `t`가 그대로 남는다. "누적 시청 시간이 최대인 곳이 여러 곳이면 가장 빠른 시작 시각" 조건이 자연히 처리된다.

`advSec == playSec`이면 슬라이드 루프가 아예 돌지 않고 `maxStart = 0`이 반환된다.

### 오버플로 주의

누적 시청 시간 합계는 최대 300,000개 로그 × 약 360,000초 ≈ `1.1e11`로 `int`(약 21억)를 넘는다. `windowView`, `maxView`는 `long`이어야 한다. 반면 `watch[i]` 자체는 최대 300,000이라 `int[]`로 충분하다.

시간 복잡도는 `O(N + P)`, 공간 복잡도는 `O(P)`.

## 풀이

```java
public String solution(String play_time, String adv_time, String[] logs) {
    int playSec = timeToSec(play_time);
    int advSec = timeToSec(adv_time);
    int[] watch = new int[playSec + 1];
    for (String log : logs) {
        watch[timeToSec(log.substring(0, 8))]++;
        watch[timeToSec(log.substring(9))]--;
    }
    for (int i = 1; i < playSec; i++) {
        watch[i] += watch[i - 1];
    }
    long windowView = 0;
    for (int i = 0; i < advSec; i++) {
        windowView += watch[i];
    }
    long maxView = windowView;
    int maxStart = 0;
    for (int t = 1; t <= playSec - advSec; t++) {
        windowView += watch[t + advSec - 1] - watch[t - 1];
        if (windowView > maxView) {
            maxView = windowView;
            maxStart = t;
        }
    }
    return secToTime(maxStart);
}

public int timeToSec(String time) {
    int hour = Integer.parseInt(time.substring(0, 2));
    int min = Integer.parseInt(time.substring(3, 5));
    int sec = Integer.parseInt(time.substring(6, 8));
    return hour * 3600 + min * 60 + sec;
}

public String secToTime(int total) {
    int hour = total / 3600;
    int min = total % 3600 / 60;
    int sec = total % 60;
    return String.format("%02d:%02d:%02d", hour, min, sec);
}
```

## 회고

`watch`를 한 번 더 누적합해서 `[0, x)` 구간 합 배열을 만들고 `acc[t + advSec] - acc[t]`로 빼는 방법도 있다. 코드는 조금 더 짧지만, 그 배열은 값이 `int`를 넘어 배열 전체를 `long[]`으로 잡아야 한다. 슬라이딩 윈도우는 초당 시청자 수 배열(`int[]`)만 두고 윈도우 합만 `long`으로 들면 되어 메모리가 절반이고, 순회 경계도 `1 <= t <= playSec - advSec`로 깔끔하게 떨어진다.
