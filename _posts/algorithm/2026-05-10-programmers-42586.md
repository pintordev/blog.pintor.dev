## 문제

> 링크: [프로그래머스 42586](https://school.programmers.co.kr/learn/courses/30/lessons/42586)

각 기능의 진도와 속도가 주어질 때, 배포마다 몇 개의 기능이 함께 배포되는지 반환한다.

## 접근

### day를 단조 증가 포인터로 활용

각 작업의 완료일을 독립적으로 계산하는 대신, `day`를 이전 작업에서 이어받는 단조 증가 포인터로 유지한다.

앞 작업의 완료일에서 `day`를 이어받으면, 뒤 작업이 더 일찍 끝나더라도 `day`가 앞으로 되돌아가지 않는다. 이 덕분에 배포 기준을 별도로 계산하지 않아도 자연스럽게 앞 작업의 배포일에 묶인다.

`deploy[day]`에 해당 날짜에 완료되는 작업 수를 누적하고, 새 배포일이 등장할 때마다 `cnt`를 증가시킨다.

## 풀이

```java
public int[] solution(int[] progresses, int[] speeds) {
    int[] deploy = new int[100];
    int day = -1, cnt = 0;
    for (int i = 0; i < progresses.length; i++) {
        while (progresses[i] + speeds[i] * day < 100) day++;
        if (deploy[day]++ == 0) cnt++;
    }

    int[] log = new int[cnt];
    for (int d = 0, l = 0; d < 100; d++) {
        if (deploy[d] == 0) continue;
        log[l++] = deploy[d];
    }
    return log;
}
```

## 회고

스택/큐로 접근하는 대신 `deploy[day]` 배열로 날짜별 배포 수를 직접 누적해 로직을 단순화했다.

`if (deploy[day]++ == 0) cnt++` 한 줄로 새 배포일 감지와 카운트를 동시에 처리한 것이 핵심이다.
