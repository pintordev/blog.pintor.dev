## 문제

> 링크: [프로그래머스 12899](https://school.programmers.co.kr/learn/courses/30/lessons/12899)

10진수 자연수 n을 1, 2, 4만 사용하는 124 나라의 표기법으로 변환한다.

## 접근

### 3진법 변형

124 나라의 수 체계는 0이 없는 3진법이다. 일반 3진법에서 나머지 0, 1, 2가 나오는 반면, 여기서는 나머지 0을 4로 대응시켜야 한다.

`(n - 1) % 3`을 사용하면 나머지 0, 1, 2를 각각 인덱스 0, 1, 2로 매핑할 수 있고, map 배열 `{'1', '2', '4'}`에서 해당 문자를 꺼낸다. 다음 n은 `(n - 1) / 3`으로 구하며, n이 0이 될 때까지 반복한 뒤 역순으로 뒤집으면 된다.

## 풀이

```java
public String solution(int n) {
    char[] map = {'1', '2', '4'};
    StringBuilder sb = new StringBuilder();
    while (n > 0) {
        sb.append(map[(n - 1) % 3]);
        n = (n - 1) / 3;
    }
    return sb.reverse().toString();
}
```
