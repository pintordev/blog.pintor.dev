## 문제

> 링크: [프로그래머스 340212](https://school.programmers.co.kr/learn/courses/30/lessons/340212)

퍼즐을 순서대로 풀 때, 제한 시간 내에 모두 완료할 수 있는 최소 숙련도를 구하는 문제.

## 접근

### 이분 탐색

숙련도가 높을수록 소요 시간이 줄어드는 단조 감소 구조이므로 이분 탐색을 적용한다.

특정 숙련도 `level`로 퍼즐 `i`를 풀 때 소요 시간은 다음과 같다.

- `diffs[i] <= level`: `times[i]`
- `diffs[i] > level`: 난이도 차이만큼 틀리므로, 재시도마다 현재 퍼즐과 이전 퍼즐 시간을 소모한다.
  → `(diffs[i] - level) * (times[i] + times[i-1]) + times[i]`

이분 탐색은 열린 경계로 구성한다.

- `lo = 0`: 숙련도 0은 항상 시간 초과 (항상 false)
- `hi = 100001`: 최대 난이도(100000) 초과이므로 항상 통과 (항상 true)
- 불변식: `canSolve(lo) == false`, `canSolve(hi) == true`
- 종료 시 `lo + 1 == hi`이므로 `hi`를 반환

## 풀이

```java
public int solution(int[] diffs, int[] times, long limit) {
    int lo = 0, hi = 100001;
    while (lo + 1 < hi) {
        int mid = (lo + hi) >> 1;
        if (canSolve(diffs, times, limit, mid)) hi = mid;
        else lo = mid;
    }
    return hi;
}

public boolean canSolve(int[] diffs, int[] times, long limit, int level) {
    long total = 0;
    for (int i = 0; i < diffs.length; i++) {
        if (diffs[i] <= level) total += times[i];
        else total += (long) (diffs[i] - level) * (times[i] + times[i - 1]) + times[i];
        if (total > limit) return false;
    }
    return true;
}
```
