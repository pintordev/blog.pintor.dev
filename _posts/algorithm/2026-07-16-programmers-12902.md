## 문제

> 링크: [프로그래머스 12902](https://school.programmers.co.kr/learn/courses/30/lessons/12902)

세로 길이 3, 가로 길이 n인 바닥을 2×1 타일로 채우는 경우의 수를 1,000,000,007로 나눈 나머지로 구한다.

## 접근

### 점화식 기반 DP

n이 홀수면 넓이(3n)가 홀수가 되어 2×1 타일로 완전히 채울 수 없으므로 경우의 수는 0이다.

n이 짝수일 때 세로 3×가로 n을 채우는 경우의 수를 f(n)이라 하면 f(0)=1, f(2)=3이고, f(n) = 4·f(n-2) - f(n-4) (n≥4) 점화식이 성립한다. 직전 두 값만 유지하며 순회하면 O(n) 시간, O(1) 공간으로 계산할 수 있다.

뺄셈 과정에서 음수가 나올 수 있으므로 MOD를 더한 뒤 다시 나머지 연산을 적용한다.

## 풀이

```java
public int solution(int n) {
    int MOD = 1_000_000_007;
    if (n % 2 != 0) return 0;
    long a = 1; // f(0)
    long b = 3; // f(2)
    for (int i = 4; i <= n; i += 2) {
        long tmp = (4 * b - a + MOD) % MOD;
        a = b;
        b = tmp;
    }
    return (int) b;
}
```
