## 문제

> 링크: [프로그래머스 49189](https://school.programmers.co.kr/learn/courses/30/lessons/49189)

n개의 노드로 이루어진 그래프에서 1번 노드로부터 최단경로 간선 개수가 가장 많은 노드의 개수를 구하는 문제다.

## 접근

### BFS로 거리 배열 채우기

가중치 없는 그래프의 최단거리 문제이므로 BFS가 적합하다. 인접 리스트로 그래프를 구성한 뒤 1번 노드에서 BFS를 돌며 각 노드까지의 거리를 채우고, 거리 배열에서 최댓값과 같은 값을 가진 노드의 개수를 세면 된다.

## 풀이

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

public int solution(int n, int[][] edge) {
    List<Integer>[] graph = new List[n + 1];
    for (int i = 1; i <= n; i++) {
        graph[i] = new ArrayList<>();
    }
    for (int[] e : edge) {
        int a = e[0];
        int b = e[1];
        graph[a].add(b);
        graph[b].add(a);
    }

    int[] dist = new int[n + 1];
    for (int i = 2; i <= n; i++) {
        dist[i] = -1;
    }
    Queue<Integer> queue = new LinkedList<>();
    queue.add(1);
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        for (int next : graph[cur]) {
            if (dist[next] != -1) continue;
            dist[next] = dist[cur] + 1;
            queue.add(next);
        }
    }

    int max = 0;
    for (int i = 2; i <= n; i++) {
        max = Math.max(max, dist[i]);
    }
    int cnt = 0;
    for (int i = 2; i <= n; i++) {
        if (dist[i] == max) cnt++;
    }
    return cnt;
}
```
