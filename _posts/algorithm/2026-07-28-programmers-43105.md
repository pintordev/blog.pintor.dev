## 문제

> 링크: [프로그래머스 43105](https://school.programmers.co.kr/learn/courses/30/lessons/43105)

삼각형 꼭대기에서 바닥까지 대각선 방향(왼쪽 또는 오른쪽)으로만 이동하면서, 거쳐간 숫자의 합이 최대가 되는 경로를 찾는다.

## 접근

### 상향식(bottom-up) DP

삼각형 높이가 최대 500이라 완전탐색은 시간초과가 확실하다. 대신 아래 행에서 위 행으로 올라가며 각 칸에 "그 칸부터 바닥까지 도달할 수 있는 최대 합"을 누적하는 DP로 접근한다.

맨 아래에서 두 번째 행부터 시작해서, 각 칸의 값에 바로 아래 두 자식 칸 중 큰 값을 더해준다. 이 과정을 맨 위 행까지 반복하면 `triangle[0][0]`에 최종 정답이 남는다. 상향식으로 풀면 매 칸마다 아래 두 칸이 항상 존재하므로, 하향식(top-down)과 달리 배열 경계를 따로 처리할 필요가 없다.

## 풀이

```java
public int solution(int[][] triangle) {
    for (int i = triangle.length - 2; i >= 0; i--) {
        for (int j = 0; j < triangle[i].length; j++) {
            triangle[i][j] += Math.max(triangle[i + 1][j], triangle[i + 1][j + 1]);
        }
    }
    return triangle[0][0];
}
```
