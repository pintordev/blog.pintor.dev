## 문제

> 링크: [프로그래머스 131702](https://school.programmers.co.kr/learn/courses/30/lessons/131702)

시계 하나를 돌리면 상하좌우 인접 시계도 함께 90° 돌아갈 때, 모든 시계 바늘을 12시로 맞추는 최소 조작 횟수를 구하는 문제.

## 접근

### 첫 행 완전탐색 + 아래 행 확정

한 시계를 4번 돌리면 원상복구되므로 칸마다 회전 횟수는 0~3번만 고려하면 된다. 모든 칸의 조합은 4^(N²)가지라 N=8에서는 불가능하다.

(r, c)를 돌리면 (r-1, c), (r, c-1), (r, c), (r, c+1), (r+1, c)가 변한다. 이때 (r-1, c)를 0으로 만들 수 있는 칸은 (r, c)뿐이다. 이후 행의 조작은 (r-1, c)에 영향을 주지 못한다. 따라서 첫 행의 회전 횟수만 정하면 나머지 행의 회전 횟수는 유일하게 결정된다.

1. 첫 행 N칸의 회전 횟수를 4진수 마스크로 열거한다. 최대 4^8 = 65,536가지다.
2. 조합마다 격자를 복사해 첫 행 조작을 적용한다.
3. 1행부터 순서대로 윗칸을 0으로 만드는 `(4 - 윗칸) % 4`번만큼 회전한다.
4. 마지막 행이 전부 0이면 유효한 해이므로 누적 횟수로 최솟값을 갱신한다.

시간복잡도는 O(4^N · N²), 공간복잡도는 O(N²)이다.

## 풀이

```java
int n;
int[][] board;
int[] dr = {0, -1, 1, 0, 0};
int[] dc = {0, 0, 0, -1, 1};

public int solution(int[][] clockHands) {
    n = clockHands.length;
    int res = Integer.MAX_VALUE;
    for (int mask = 0; mask < (1 << (2 * n)); mask++) {
        board = new int[n][];
        for (int r = 0; r < n; r++) {
            board[r] = clockHands[r].clone();
        }
        int cnt = 0;
        for (int c = 0; c < n; c++) {
            int rot = (mask >> (2 * c)) & 3;
            rotate(0, c, rot);
            cnt += rot;
        }
        for (int r = 1; r < n; r++) {
            for (int c = 0; c < n; c++) {
                int rot = (4 - board[r - 1][c]) % 4;
                rotate(r, c, rot);
                cnt += rot;
            }
        }
        if (!isAligned()) continue;
        res = Math.min(res, cnt);
    }
    return res;
}

public void rotate(int r, int c, int rot) {
    for (int d = 0; d < 5; d++) {
        int nr = r + dr[d];
        int nc = c + dc[d];
        if (!isAvailable(nr, nc)) continue;
        board[nr][nc] = (board[nr][nc] + rot) % 4;
    }
}

public boolean isAvailable(int r, int c) {
    if (r < 0 || r >= n) return false;
    if (c < 0 || c >= n) return false;
    return true;
}

public boolean isAligned() {
    for (int c = 0; c < n; c++) {
        if (board[n - 1][c] != 0) return false;
    }
    return true;
}
```
