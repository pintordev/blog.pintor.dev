## 문제

> 링크: [프로그래머스 169199](https://school.programmers.co.kr/learn/courses/30/lessons/169199)

격자 보드에서 로봇이 장애물 또는 가장자리에 부딪힐 때까지 미끄러지는 방식으로 이동할 때, 시작 위치에서 목표 위치까지 도달하는 최소 이동 횟수를 구한다.

## 접근

### BFS + 슬라이딩

상태를 `(행, 열, 이동 횟수, 방향)`으로 정의하고 BFS를 수행한다.

시작 위치 R에서 4방향을 초기 상태로 큐에 넣는다. 꺼낼 때마다 해당 방향으로 장애물(`D`) 또는 가장자리 직전까지 슬라이딩하고, 착지 위치가 G이면 이동 횟수를 반환한다.

착지 위치가 미방문이면 방문 표시 후 같은 방향을 제외한 3방향을 큐에 추가한다. 같은 방향은 착지를 멈추게 한 벽이 그대로이므로 다시 시도해도 이동이 없어 생략 가능하다.

BFS 특성상 처음 착지한 위치가 최소 이동 횟수이므로 위치 기준 visited만으로 충분하다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Queue;

String[] board;
int n, m;
int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};
boolean[][] visited;

public int solution(String[] board) {
    this.board = board;
    n = board.length;
    m = board[0].length();
    Queue<State> q = new ArrayDeque<>();
    visited = new boolean[n][m];
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (board[i].charAt(j) != 'R') continue;
            visited[i][j] = true;
            for (int dir = 0; dir < 4; dir++) {
                q.add(new State(i, j, 0, dir));
            }
        }
    }
    while (!q.isEmpty()) {
        State cur = q.poll();
        int nr = cur.r, nc = cur.c;
        while (isAvailable(nr + dr[cur.dir], nc + dc[cur.dir])) {
            nr += dr[cur.dir];
            nc += dc[cur.dir];
        }
        if (board[nr].charAt(nc) == 'G') return cur.d + 1;
        if (visited[nr][nc]) continue;
        visited[nr][nc] = true;
        for (int dir = 0; dir < 4; dir++) {
            if (dir == cur.dir) continue;
            q.add(new State(nr, nc, cur.d + 1, dir));
        }
    }
    return -1;
}

boolean isAvailable(int r, int c) {
    if (r < 0 || r >= n || c < 0 || c >= m) return false;
    if (board[r].charAt(c) == 'D') return false;
    return true;
}

class State {
    int r, c, d, dir;

    State(int r, int c, int d, int dir) {
        this.r = r;
        this.c = c;
        this.d = d;
        this.dir = dir;
    }
}
```
