## 문제

> 링크: [프로그래머스 17679](https://school.programmers.co.kr/learn/courses/30/lessons/17679)

같은 문자가 2×2로 모이면 동시에 제거되고 위 블록이 낙하하는 과정을 반복해, 총 제거된 블록 수를 반환한다.

## 접근

### 시뮬레이션

매 라운드마다 두 단계를 반복한다.

**1단계 — 2×2 탐지**

좌상단 `(i, j)` 기준으로 `i ∈ [0, m-2]`, `j ∈ [0, n-2]` 범위를 순회한다. 4칸이 동일 문자이면 `toRemove` 배열에 표시한다. 탐지와 제거를 분리해야 동시 제거가 보장된다.

**2단계 — 제거 + 낙하 (열 단위)**

각 열을 아래에서 위로 순회하면서 `toRemove`가 true인 셀은 카운트만 하고, false인 셀은 `bottom` 포인터 위치에 덮어쓴다. 순회가 끝난 뒤 `bottom` 위의 빈 자리는 공백으로 채운다. 별도의 마킹 패스 없이 제거와 낙하를 한 번에 처리할 수 있다.

제거된 셀이 0개면 종료하고 누적값을 반환한다.

## 풀이

```java
public int solution(int m, int n, String[] board) {
    char[][] grid = new char[m][n];
    for (int i = 0; i < m; i++) grid[i] = board[i].toCharArray();
    int total = 0;
    while (true) {
        boolean[][] toRemove = new boolean[m][n];
        for (int i = 0; i < m - 1; i++) {
            for (int j = 0; j < n - 1; j++) {
                char c = grid[i][j];
                if (c != ' ' && c == grid[i][j + 1] && c == grid[i + 1][j] && c == grid[i + 1][j + 1]) {
                    toRemove[i][j] = toRemove[i][j + 1] = toRemove[i + 1][j] = toRemove[i + 1][j + 1] = true;
                }
            }
        }
        int cnt = 0;
        for (int j = 0; j < n; j++) {
            int bottom = m - 1;
            for (int i = m - 1; i >= 0; i--) {
                if (toRemove[i][j]) cnt++;
                else grid[bottom--][j] = grid[i][j];
            }
            while (bottom >= 0) grid[bottom--][j] = ' ';
        }
        if (cnt == 0) break;
        total += cnt;
    }
    return total;
}
```
