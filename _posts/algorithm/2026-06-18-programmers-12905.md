## 문제

> 링크: [프로그래머스 12905](https://school.programmers.co.kr/learn/courses/30/lessons/12905)

0과 1로 이루어진 2차원 배열에서 1로만 구성된 가장 큰 정사각형의 넓이를 구하는 문제다.

## 접근

### DP — board 자체를 dp 테이블로 활용

`dp[i][j]`를 `(i, j)`를 우하단 꼭짓점으로 하는 정사각형의 최대 변 길이로 정의한다.

- `board[i][j] == 0` → 그대로 0
- `board[i][j] == 1` → `min(위, 왼쪽, 왼쪽 위) + 1`

세 이웃이 모두 변 길이 k 이상인 정사각형을 만들 수 있을 때만, 현재 칸을 우하단으로 하는 변 길이 k+1 정사각형이 성립한다는 직관에서 도출된다.

0행·0열은 이웃이 없으므로 초기값 그대로 유지하고, (1,1)부터 점화식을 적용한다. board 자체를 덮어쓰므로 추가 공간은 O(1)이다.

- 시간복잡도: O(N × M)
- 공간복잡도: O(1) 추가 공간

## 풀이

```java
public int solution(int[][] board) {
    int max = 0;
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            if (i > 0 && j > 0 && board[i][j] == 1) {
                board[i][j] = Math.min(board[i-1][j], Math.min(board[i][j-1], board[i-1][j-1])) + 1;
            }
            max = Math.max(max, board[i][j]);
        }
    }
    return max * max;
}
```
