## 문제

> 링크: [프로그래머스 468377](https://school.programmers.co.kr/learn/courses/30/lessons/468377)

n개의 스테이지를 순서대로 클리어해야 하며, 각 스테이지에서는(마지막 제외) 힌트 번들을 최대 1개 구매할 수 있다. 구매한 번들은 이후 스테이지에서 쓸 힌트권을 제공하고, 힌트권을 많이 보유한 채로 스테이지에 도달할수록 클리어 비용이 줄어든다. 모든 스테이지를 클리어하는 데 드는 총비용(번들 구매 비용 + 스테이지 클리어 비용)의 최솟값을 구해야 한다.

## 접근

### 구매 여부 부분집합 완전탐색

i번 힌트권은 오직 i번 스테이지에서만 쓸 수 있고, `cost[i][j]`는 사용 개수 j에 대해 단조감소하도록 주어진다. 따라서 스테이지에 도달했을 때 보유한 힌트권은 아껴둘 이유가 없이 항상 전부 사용하는 게 최적이며, 실제 사용 개수는 별도의 선택지가 아니라 보유 개수로 자동 결정된다.

남는 의사결정은 각 스테이지(최대 n-1개)에서 판매하는 번들을 살지 말지뿐이다. n ≤ 16이라 번들 구매 대상은 최대 15개이고, 가능한 구매 조합은 2^(n-1) ≤ 32768가지이므로 전체 조합을 완전탐색한다.

각 조합에 대해 구매한 번들들의 힌트권을 모아 스테이지별 보유 개수를 집계하고, (구매한 번들 가격의 합) + (각 스테이지에서 `min(보유 개수, n-1)`개 사용했을 때의 클리어 비용 합)을 계산해 최솟값을 갱신한다.

## 풀이

```java
public int solution(int[][] cost, int[][] hint) {
    int n = cost.length;
    int bundleCount = n - 1;
    int min = Integer.MAX_VALUE;
    for (int mask = 0; mask < (1 << bundleCount); mask++) {
        int[] cnt = new int[n + 1];
        int price = 0;
        for (int k = 0; k < bundleCount; k++) {
            if ((mask & (1 << k)) == 0) continue;
            price += hint[k][0];
            for (int j = 1; j < hint[k].length; j++) {
                cnt[hint[k][j]]++;
            }
        }
        int total = price;
        for (int i = 1; i <= n; i++) {
            int used = Math.min(cnt[i], n - 1);
            total += cost[i - 1][used];
        }
        min = Math.min(min, total);
    }
    return min;
}
```
