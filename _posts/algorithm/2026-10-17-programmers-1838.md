## 문제

> 링크: [프로그래머스 1838](https://school.programmers.co.kr/learn/courses/30/lessons/1838)

n×n 락커에서 이용 시간이 겹치는 손님들이 서로 최대한 멀리 떨어지도록 배정할 때, 할당된 락커 간 최소 거리의 최댓값을 구하는 문제.

## 접근

### 최대 동시 이용 인원으로 축소

거리 제약은 이용 시간이 겹치는 손님끼리만 걸린다. 구간 그래프는 필요한 색 수가 최대 클리크 크기와 같으므로, 동시에 이용하는 최대 인원을 k라 하면 서로 d 이상 떨어진 락커 k개만 찾을 수 있을 때 모든 손님을 그 k개 중 하나에 배정할 수 있다. 문제는 n×n 격자에 k개의 점을 놓았을 때 최소 쌍 거리를 최대화하는 문제로 줄어든다.

k는 차이 배열로 구한다. 입실 시각에 +1, 퇴실 시각 + 1에 -1을 기록하고 누적합의 최댓값을 취한다. 예제 3처럼 퇴실과 입실이 같은 시각이면 겹치는 것으로 보므로 퇴실 시각까지 포함한다. 시각 범위가 600~1320이라 배열 크기는 722면 충분하다. k가 1 이하면 겹치는 쌍이 없으므로 0을 반환한다.

### 거리 d를 내려가며 행 우선 탐욕 배치

거리는 상하좌우가 1, 대각선이 2이므로 맨해튼 거리 `|dr| + |dc|`와 같다. 가능한 최대 거리 `2(n - 1)`부터 1까지 d를 줄여 가며, 거리 d 이상으로 k개 이상 놓을 수 있는 첫 d가 답이다.

d가 주어지면 0행의 시작 열을 바꿔 가며 행 우선으로 순회하고, 이미 놓은 점들과 거리가 모두 d 이상인 칸에 점을 놓는다. 놓은 점이 k개 이상이면 d가 가능하다. 실제로 놓을 수 있는 배치를 찾은 것이므로 가능하다는 판정은 항상 옳다.

시간 복잡도는 d의 개수 O(n), 시작 열 O(n), 순회 O(n²), 거리 확인 O(k)를 곱한 O(n⁴k) 수준이고 n ≤ 10이라 충분하다.

## 풀이

```java
import java.util.ArrayList;
import java.util.List;

int n;
int d;
List<Node> nodes;

public int solution(int n, int m, int[][] timetable) {
    this.n = n;
    int max = calMax(timetable);
    if (max == 1) return 0;
    return calDist(max);
}

public int calMax(int[][] timetable) {
    int[] cumulative = new int[722];
    for (int[] time : timetable) {
        cumulative[time[0] - 600]++;
        cumulative[time[1] - 600 + 1]--;
    }
    int max = 1;
    for (int i = 1; i < 722; i++) {
        cumulative[i] += cumulative[i - 1];
        max = Math.max(max, cumulative[i]);
    }
    return max;
}

public int calDist(int max) {
    for (d = 2 * (n - 1); d > 0; d--) {
        for (int sc = 0; sc < n; sc++) {
            if (calCnt(sc) >= max) return d;
        }
    }
    return 0;
}

public int calCnt(int sc) {
    nodes = new ArrayList<>();
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < n; c++) {
            if (r == 0 && c < sc) continue;
            if (!isAvailable(r, c)) continue;
            nodes.add(new Node(r, c));
        }
    }
    return nodes.size();
}

public boolean isAvailable(int r, int c) {
    for (Node node : nodes) {
        if (Math.abs(node.r - r) + Math.abs(node.c - c) < d) return false;
    }
    return true;
}

class Node {
    int r;
    int c;

    Node(int r, int c) {
        this.r = r;
        this.c = c;
    }
}
```
