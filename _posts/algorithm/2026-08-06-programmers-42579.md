## 문제

> 링크: [프로그래머스 42579](https://school.programmers.co.kr/learn/courses/30/lessons/42579)

장르별로 많이 재생된 순서대로, 장르 안에서도 많이 재생된 곡 순으로 최대 2곡씩 모아 베스트 앨범에 수록할 곡 번호를 구하는 문제다.

## 접근

### 장르 총재생 횟수를 그룹 키로 활용

문제 제약에서 모든 장르는 총 재생 횟수가 서로 다르다는 게 보장된다. 이 값을 그대로 그룹 식별자로 쓸 수 있다는 뜻이다.

먼저 장르별 총 재생 횟수를 구해두고, 각 곡마다 `{장르 총재생, 곡 인덱스, 곡 개별재생}` 형태의 튜플을 만든다. 이 튜플 배열 하나를 정렬 기준 세 가지(장르 총재생 내림차순 → 개별재생 내림차순 → 인덱스 오름차순)에 맞춰 한 번에 정렬하면, 장르별로 묶어 따로 정렬할 필요 없이 전체가 원하는 순서로 늘어선다.

정렬된 배열을 순회하면서 장르 값(총재생)이 바뀔 때마다 카운트를 리셋하고, 카운트가 2 이하인 곡만 결과에 채택하면 장르당 최대 2곡 제한이 자연스럽게 처리된다.

## 풀이

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

public int[] solution(String[] genres, int[] plays) {
    Map<String, Integer> genMap = new HashMap<>();
    for (int i = 0; i < genres.length; i++) {
        genMap.put(genres[i], genMap.getOrDefault(genres[i], 0) + plays[i]);
    }

    int[][] info = new int[genres.length][3];
    for (int i = 0; i < genres.length; i++) {
        info[i] = new int[] {genMap.get(genres[i]), i, plays[i]};
    }

    Arrays.sort(info, (a, b) -> {
        if (a[0] == b[0] && a[2] == b[2]) return a[1] - b[1];
        if (a[0] == b[0]) return b[2] - a[2];
        return b[0] - a[0];
    });

    int[] res = new int[genres.length];
    int idx = 0, now = 0, cnt = 0;
    for (int[] song : info) {
        cnt++;
        if (song[0] != now) {
            now = song[0];
            cnt = 1;
        }
        if (cnt <= 2) res[idx++] = song[1];
    }
    return Arrays.copyOf(res, idx);
}
```
