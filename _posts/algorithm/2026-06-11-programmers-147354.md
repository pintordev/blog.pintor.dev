## 문제

> 링크: [프로그래머스 147354](https://school.programmers.co.kr/learn/courses/30/lessons/147354)

테이블을 지정된 컬럼 기준으로 정렬한 뒤, 각 행의 나머지 합을 XOR 연산하여 해시값을 반환한다.

## 접근

### 정렬 조건 정의 후 나머지 합 XOR

정렬 기준이 두 가지다. `col` 기준 오름차순이 1순위이고, 값이 같으면 첫 번째 컬럼 기준 내림차순이 2순위다. `Comparator`로 두 조건을 순서대로 처리한다.

정렬 후 행 번호 `i`는 1-indexed다. `row_begin`부터 `row_end`까지 각 행 `i`에서 모든 컬럼 값을 `i`로 나눈 나머지의 합 `S_i`를 구하고, 이를 누적 XOR하면 된다.

## 풀이

```java
import java.util.Arrays;

public int solution(int[][] data, int col, int row_begin, int row_end) {
    Arrays.sort(data, (o1, o2) -> {
        if (o1[col - 1] == o2[col - 1]) return o2[0] - o1[0];
        return o1[col - 1] - o2[col - 1];
    });
    int res = 0;
    for (int i = row_begin; i <= row_end; i++) {
        int si = 0;
        for (int d : data[i - 1]) si += d % i;
        res ^= si;
    }
    return res;
}
```
