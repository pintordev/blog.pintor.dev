## 문제

> 링크: [프로그래머스 388352](https://school.programmers.co.kr/learn/courses/30/lessons/388352)

1~n 중 5개의 정수로 이루어진 비밀 코드를 m번의 시도 결과를 바탕으로 가능한 후보 조합의 수를 구하는 문제.

## 접근

### 완전탐색 + 비트마스크

n ≤ 30이므로 C(30, 5) = 142,506개의 조합을 모두 탐색할 수 있다. 각 쿼리 `q[i]`와 후보 조합을 비트마스크로 표현하면, 교집합 크기를 `Integer.bitCount(mask & qBits[i])`로 한 번에 구할 수 있다. DFS로 조합을 생성하면서 5개가 채워지는 시점에 모든 쿼리 조건을 검증한다.

## 풀이

```java
int[] qBits;
int[] ans;
int cnt;

public int solution(int n, int[][] q, int[] ans) {
    qBits = new int[q.length];
    for (int i = 0; i < q.length; i++) {
        for (int num : q[i]) {
            qBits[i] |= (1 << (num - 1));
        }
    }
    this.ans = ans;
    cnt = 0;
    dfs(1, n, 0, 0);
    return cnt;
}

public void dfs(int s, int n, int d, int mask) {
    if (d == 5) {
        for (int i = 0; i < qBits.length; i++) {
            if (Integer.bitCount(mask & qBits[i]) != ans[i]) return;
        }
        cnt++;
        return;
    }
    for (int i = s; i <= n; i++) {
        dfs(i + 1, n, d + 1, mask | (1 << (i - 1)));
    }
}
```
