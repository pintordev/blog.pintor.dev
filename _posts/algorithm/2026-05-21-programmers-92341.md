## 문제

> 링크: [프로그래머스 92341](https://school.programmers.co.kr/learn/courses/30/lessons/92341)

입출차 기록을 바탕으로 차량별 주차 요금을 계산하는 문제.

## 접근

### 음수 누적으로 주차 시간 계산

TreeMap에 차량번호를 키로, 시각 누적값을 값으로 관리한다. IN 시 현재 시각을 빼고, OUT 시 현재 시각을 더하면 자연스럽게 체류 시간이 누적된다. 이 방식은 다회 입출차도 별도 처리 없이 동작한다.

모든 기록 처리 후 값이 0 이하인 차량은 아직 주차 중이므로, 23:59(1439분)를 더해 체류 시간을 구한다.

## 풀이

```java
import java.util.*;

public int[] solution(int[] fees, String[] records) {
    Map<String, Integer> map = new TreeMap<>();
    for (String rec : records) {
        String[] bits = rec.split(" ");
        int t = toMin(bits[0]);
        String key = bits[1];
        int val = map.getOrDefault(key, 0);
        if (bits[2].equals("IN")) map.put(key, val - t);
        else map.put(key, val + t);
    }
    int[] res = new int[map.size()];
    int idx = 0;
    for (String key : map.keySet()) {
        int t = map.get(key);
        if (t <= 0) t += 1439; // 23:59
        res[idx++] = calFee(t, fees);
    }
    return res;
}

public int toMin(String bit) {
    return Integer.parseInt(bit.substring(0, 2)) * 60 + Integer.parseInt(bit.substring(3));
}

public int calFee(int t, int[] fees) {
    return fees[1] + (int) Math.ceil((double) Math.max(0, (t - fees[0])) / fees[2]) * fees[3];
}
```
