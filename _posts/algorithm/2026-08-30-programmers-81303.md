## 문제

> 링크: [프로그래머스 81303](https://school.programmers.co.kr/learn/courses/30/lessons/81303)

`n`개의 행과 현재 선택된 행이 주어질 때, `U X`(X칸 위로)·`D X`(X칸 아래로)·`C`(현재 행 삭제)·`Z`(가장 최근 삭제 행 복구) 명령을 순서대로 처리한 뒤, 각 행의 삭제 여부를 `O`/`X` 문자열로 반환한다.

## 접근

### 양방향 연결 리스트 + 삭제 스택

`n`은 최대 100만이지만 `U`/`D`에 등장하는 모든 `X`의 합이 100만 이하로 제한된다. 이동을 한 칸씩 처리해도 전체 이동 횟수가 100만을 넘지 않으므로, 선택 행 이동은 단순 반복으로 충분하다.

핵심은 삭제와 복구다. 특정 행이 O(1)에 리스트에서 빠지고 다시 끼워져야 하므로 양방향 연결 리스트를 쓴다. 노드를 객체로 만들면 100만 개 할당과 GC 부담이 생기므로, `prev[i]` / `next[i]` 정수 배열로 인접 관계만 관리한다.

- `prev[i]`, `next[i]`: 행 `i`의 이전·다음 행 인덱스. 리스트 양 끝은 `prev[0] == -1`, `next[n - 1] == n` 으로 경계를 표시한다.
- `deleted[i]`: 최종 출력용 삭제 플래그.
- `deletedStack`: 삭제된 행 인덱스를 쌓아 두고 `Z`에서 최근 것부터 꺼낸다.

명령별 처리:

- `U X` / `D X`: `cur`를 `prev` / `next`로 `X`번 이동.
- `C`: `cur`를 스택에 넣고 `deleted` 표시. `prev`/`next` 연결을 끊어 리스트에서 분리한 뒤, 아래 행(`next`)이 있으면 그쪽을, 없으면(마지막 행이었으면) 위 행(`prev`)을 선택한다.
- `Z`: 스택에서 행 하나를 꺼내 `deleted`를 해제하고 다시 연결한다.

`Z`에서 재연결이 성립하는 이유는, 삭제 시점에 그 행의 `prev`/`next` 값을 **덮어쓰지 않고 그대로 두기** 때문이다. 스택이 LIFO이므로 어떤 행을 복구하는 시점에는 그 뒤에 삭제된 행들이 모두 이미 복구된 상태다. 따라서 저장돼 있던 `prev`/`next`가 여전히 유효한 인접 행을 가리키고, 그대로 이어 붙이면 된다.

시간 복잡도는 초기화·출력 `O(n)`, 이동 `O(ΣX)`, 명령 처리 `O(cmd.length)`로 제약 안에서 넉넉히 통과한다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Deque;

public String solution(int n, int k, String[] cmd) {
    int[] prev = new int[n];
    int[] next = new int[n];
    boolean[] deleted = new boolean[n];
    for (int i = 0; i < n; i++) {
        prev[i] = i - 1;
        next[i] = i + 1;
    }
    Deque<Integer> deletedStack = new ArrayDeque<>();
    int cur = k;
    for (String c : cmd) {
        char op = c.charAt(0);
        switch (op) {
            case 'U': {
                int x = Integer.parseInt(c.substring(2));
                for (int i = 0; i < x; i++) cur = prev[cur];
                break;
            }
            case 'D': {
                int x = Integer.parseInt(c.substring(2));
                for (int i = 0; i < x; i++) cur = next[cur];
                break;
            }
            case 'C': {
                deletedStack.push(cur);
                deleted[cur] = true;
                int p = prev[cur];
                int nx = next[cur];
                if (p != -1) next[p] = nx;
                if (nx != n) prev[nx] = p;
                cur = (nx != n) ? nx : p;
                break;
            }
            case 'Z': {
                int r = deletedStack.pop();
                deleted[r] = false;
                int p = prev[r];
                int nx = next[r];
                if (p != -1) next[p] = r;
                if (nx != n) prev[nx] = r;
                break;
            }
        }
    }
    StringBuilder sb = new StringBuilder(n);
    for (int i = 0; i < n; i++) sb.append(deleted[i] ? 'X' : 'O');
    return sb.toString();
}
```
