## 문제

> 링크: [프로그래머스 12920](https://school.programmers.co.kr/learn/courses/30/lessons/12920)

동일한 작업 n개를 처리 시간이 서로 다른 코어들에 순서대로 배정할 때, n번째 작업이 몇 번째 코어에서 처리되는지 구하는 문제.

## 접근

### 이진탐색으로 완료 시각 찾기

최초에 코어 개수(m)만큼 작업이 각 코어에 순서대로 배정되므로, n이 m 이하면 n번째 작업은 그대로 n번 코어가 처리한다.

n이 m보다 크면, 이후 배정은 코어가 작업을 끝낼 때마다(완료 이벤트) 순서대로 일어난다. 즉 n번째 작업은 `target = n - m`번째 완료 이벤트가 일어나는 시점에 배정된다.

시각 T까지 전체 코어가 처리 완료한 작업 수는 `count(T) = Σ (T / cores[i])`로 구할 수 있고, T가 커질수록 단조증가하므로 `count(T) >= target`을 만족하는 최소 T를 이진탐색으로 찾는다.

이 T가 target번째 완료가 일어나는 시각이며, 여러 코어가 동시에 완료될 수 있다. `T-1` 시점까지의 완료 수(`done`)를 구해 `target - done`으로 T 시점에 몇 번째 완료가 target인지 계산한 뒤, 코어를 앞에서부터 순회하며 `T % cores[i] == 0`인 코어를 셀 때마다 감소시켜 0이 되는 코어의 인덱스를 반환한다.

## 풀이

```java
public int solution(int n, int[] cores) {
    if (n <= cores.length) return n;
    long target = n - cores.length;
    int maxCore = 0;
    for (int core : cores) {
        maxCore = Math.max(maxCore, core);
    }
    long lo = 0, hi = target * maxCore;
    while (lo + 1 < hi) {
        long mid = (lo + hi) >> 1;
        long cnt = 0;
        for (int core : cores) cnt += mid / core;
        if (cnt < target) lo = mid;
        else hi = mid;
    }
    long done = 0;
    for (int core : cores) {
        done += (hi - 1) / core;
    }
    long remain = target - done;
    for (int i = 0; i < cores.length; i++) {
        if (hi % cores[i] != 0) continue;
        remain--;
        if (remain == 0) return i + 1;
    }
    return -1;
}
```
