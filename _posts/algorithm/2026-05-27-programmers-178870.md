## 문제

> 링크: [프로그래머스 178870](https://school.programmers.co.kr/learn/courses/30/lessons/178870)

비내림차순 수열에서 합이 `k`인 연속 부분 수열 중 가장 짧은 것의 시작·끝 인덱스를 반환하는 문제다.

## 접근

### 투 포인터 (슬라이딩 윈도우)

비내림차순 정렬이 보장되므로 구간 합이 단조적으로 변한다. 왼쪽·오른쪽 포인터를 이동하면서 구간 합을 유지한다.

- `sum < k`: 오른쪽 포인터를 늘려 구간 확장
- `sum > k`: 왼쪽 포인터를 늘려 구간 축소
- `sum == k`: 현재 구간 길이가 더 짧으면 정답 갱신 후, 왼쪽 포인터를 늘려 탐색 계속

## 풀이

```java
public int[] solution(int[] sequence, int k) {
    int l = 0, r = 0, sum = sequence[0], al = 0, ar = sequence.length - 1;
    while (r < sequence.length) {
        if (sum < k && ++r < sequence.length) sum += sequence[r];
        else if (sum > k) sum -= sequence[l++];
        else if (sum == k) {
            if (r - l < ar - al) {
                al = l;
                ar = r;
            }
            sum -= sequence[l++];
        }
    }
    return new int[]{al, ar};
}
```
