## 문제

> 링크: [프로그래머스 150364](https://school.programmers.co.kr/learn/courses/30/lessons/150364)

루트에 1, 2, 3을 떨어트릴 때마다 각 노드의 길이 다음 자식으로 순환하는 트리에서, 리프에 쌓인 합을 target과 같게 만드는 가장 짧고 사전 순으로 가장 빠른 수열을 구하는 문제.

## 접근

### 도착 순서 시뮬레이션 + 리프별 그리디 분배

숫자가 어느 리프에 도착하는지는 떨어트린 숫자와 무관하고 길 상태로만 결정된다. 따라서 "몇 번 떨어트릴지"와 "무엇을 떨어트릴지"를 분리할 수 있다.

**1단계: 떨어트릴 개수 결정**

각 노드의 방문 횟수 `cnt`를 하나의 배열로 관리한다. 내부 노드는 `(cnt - 1) % 자식 수`번째 자식으로 내려가므로 `cnt`가 곧 길 위치가 되고, 리프에서는 도착 횟수가 된다.

리프에 `cnt`번 도착하면 만들 수 있는 합의 범위는 `cnt` 이상 `3 * cnt` 이하다. 따라서

- `cnt > target`이 되는 순간 이후로는 절대 맞출 수 없으므로 `[-1]`을 반환한다.
- `cnt >= ⌈target / 3⌉`이 처음 되는 순간 그 리프는 충족된다. `made` 플래그로 한 번만 센다.
- target이 0인 리프는 처음부터 충족 대상에서 제외한다. 이 리프에 숫자가 떨어지면 `cnt > target`으로 자연스럽게 `[-1]`이 된다.

모든 리프가 충족되는 첫 시점이 최소 개수다.

**2단계: 사전 순 최소 수열 구성**

리프끼리는 서로 영향을 주지 않으므로 리프마다 자기 몫의 수열을 사전 순 최소로 만들면 전체도 사전 순 최소가 된다. 큰 수를 최대한 뒤로 보내야 하므로 도착 순서를 뒤에서부터 보면서, 남은 칸을 모두 1로 채울 수 있는 한도 안에서 3, 2, 1 순으로 가장 큰 수를 고른다.

시간 복잡도는 떨어트리는 횟수가 최대 target 합 정도이고 한 번에 트리 깊이 D만큼 내려가므로 O(Σtarget · D)다.

## 풀이

```java
import java.util.*;

int n;
List<Integer>[] children;
int[] cnt;

public int[] solution(int[][] edges, int[] target) {
    n = target.length;
    children = new List[n + 1];
    cnt = new int[n + 1];
    int[] min = new int[n + 1];
    boolean[] made = new boolean[n + 1];
    for (int i = 1; i <= n; i++) {
        children[i] = new ArrayList<>();
        min[i] = (target[i - 1] + 2) / 3;
    }
    for (int[] edge : edges) {
        children[edge[0]].add(edge[1]);
    }
    int leafCnt = 0;
    for (int i = 1; i <= n; i++) {
        Collections.sort(children[i]);
        if (children[i].isEmpty() && target[i - 1] > 0) leafCnt++;
    }
    List<Integer> order = new ArrayList<>();
    while (leafCnt > 0) {
        int leaf = drop();
        if (cnt[leaf] > target[leaf - 1]) return new int[]{-1};
        if (!made[leaf] && cnt[leaf] >= min[leaf]) {
            made[leaf] = true;
            leafCnt--;
        }
        order.add(leaf);
    }
    int[] res = new int[order.size()];
    for (int i = res.length - 1; i >= 0; i--) {
        int leaf = order.get(i);
        for (int j = 3; j >= 1; j--) {
            if (target[leaf - 1] - j < cnt[leaf] - 1) continue;
            target[leaf - 1] -= j;
            cnt[leaf]--;
            res[i] = j;
            break;
        }
    }
    return res;
}

public int drop() {
    int u = 1;
    cnt[u]++;
    while (!children[u].isEmpty()) {
        u = children[u].get((cnt[u] - 1) % children[u].size());
        cnt[u]++;
    }
    return u;
}
```
