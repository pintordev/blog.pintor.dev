## 문제

> 링크: [프로그래머스 155651](https://school.programmers.co.kr/learn/courses/30/lessons/155651)

대실 예약 목록과 퇴실 후 10분의 청소 시간을 고려하여 필요한 최소 객실 수를 구하는 문제.

## 접근

### 정렬 + 우선순위 큐

예약을 시작 시각 기준으로 정렬한 뒤, 퇴실+청소 종료 시각을 기준으로 하는 minHeap으로 현재 사용 중인 방을 관리한다.

새 예약을 처리할 때, 힙에서 종료 시각이 현재 시작 시각 이하인 방을 모두 제거하면 힙에 남은 원소가 현재 시점에 동시 사용 중인 방의 집합이 된다. 여기에 현재 예약을 추가한 후 힙 크기의 최댓값을 갱신하면 필요한 최소 객실 수를 구할 수 있다.

시각은 "HH:MM" 문자열을 분 단위 정수로 변환하여 비교한다.

## 풀이

```java
import java.util.Arrays;
import java.util.PriorityQueue;

public int solution(String[][] book_time) {
    int[][] bt = new int[book_time.length][];
    for (int i = 0; i < book_time.length; i++) {
        bt[i] = parse(book_time[i]);
    }
    Arrays.sort(bt, (o1, o2) -> o1[0] - o2[0]);
    PriorityQueue<int[]> pq = new PriorityQueue<>((o1, o2) -> o1[1] - o2[1]);
    int max = 0;
    for (int[] cur : bt) {
        while (!pq.isEmpty() && pq.peek()[1] <= cur[0]) {
            pq.poll();
        }
        pq.add(cur);
        max = Math.max(pq.size(), max);
    }
    return max;
}

public int[] parse(String[] bts) {
    return new int[]{parseTime(bts[0]), parseTime(bts[1]) + 10};
}

public int parseTime(String bt) {
    return Integer.parseInt(bt.substring(0, 2)) * 60 + Integer.parseInt(bt.substring(3));
}
```

## 회고

방 재사용 가능 여부를 판단하는 조건에서 `pq.peek()[1] <= cur[0]`이어야 할 것을 `cur[1]`(현재 예약의 종료 시각)로 잘못 작성하는 실수를 했다. 두 종료 시각끼리 비교하게 되어 아직 사용 중인 방도 힙에서 제거되었고, 결과가 실제보다 작게 나왔다. 기준이 되는 인덱스를 헷갈리지 않도록 주의가 필요하다.
