## 문제

> 링크: [프로그래머스 1843](https://school.programmers.co.kr/learn/courses/30/lessons/1843)

숫자와 `+`, `-`가 번갈아 나오는 식에서 괄호를 어떻게 묶느냐에 따라 달라지는 결과 중 최댓값을 구하는 문제.

## 접근

### 구간 DP (최댓값·최솟값 동시 저장)

뺄셈은 결합법칙이 성립하지 않아 괄호 위치에 따라 결과가 달라진다. 숫자가 최대 101개라 모든 구간을 나누어 보는 O(n³)으로 충분하다.

숫자 i부터 j까지를 묶었을 때 만들 수 있는 최댓값과 최솟값을 함께 저장한다. 최댓값만 저장하면 안 되는 이유는 `-` 뒤쪽 구간이 작을수록 결과가 커지기 때문이다.

구간 `[s, e]`를 연산자 위치 `i`에서 `[s, i]`와 `[i + 1, e]`로 나누면 점화식은 다음과 같다.

- `+`: 최댓값 = 왼쪽 최댓값 + 오른쪽 최댓값, 최솟값 = 왼쪽 최솟값 + 오른쪽 최솟값
- `-`: 최댓값 = 왼쪽 최댓값 - 오른쪽 최솟값, 최솟값 = 왼쪽 최솟값 - 오른쪽 최댓값

구간 길이를 1부터 늘려가며 모든 `i`에 대해 최댓값은 최대로, 최솟값은 최소로 갱신하고, 전체 구간 `[0, n - 1]`의 최댓값이 답이다.

시간복잡도는 O(n³), 공간복잡도는 O(n²)이다.

## 풀이

```java
int[][][] dp;
boolean[] plus;

public int solution(String[] arr) {
    int n = (arr.length >> 1) + 1;
    int[] nums = new int[n];
    plus = new boolean[n - 1];
    for (int i = 0; i < n; i++) {
        nums[i] = Integer.parseInt(arr[i << 1]);
        if (i < n - 1) plus[i] = arr[(i << 1) + 1].equals("+");
    }
    dp = new int[n][n][2];
    for (int i = 0; i < n; i++) {
        dp[i][i][0] = nums[i];
        dp[i][i][1] = nums[i];
    }
    for (int len = 1; len < n; len++) {
        for (int s = 0; s + len < n; s++) {
            cal(s, s + len);
        }
    }
    return dp[0][n - 1][1];
}

public void cal(int s, int e) {
    int min = Integer.MAX_VALUE;
    int max = Integer.MIN_VALUE;
    for (int i = s; i < e; i++) {
        if (plus[i]) {
            min = Math.min(min, dp[s][i][0] + dp[i + 1][e][0]);
            max = Math.max(max, dp[s][i][1] + dp[i + 1][e][1]);
        } else {
            min = Math.min(min, dp[s][i][0] - dp[i + 1][e][1]);
            max = Math.max(max, dp[s][i][1] - dp[i + 1][e][0]);
        }
    }
    dp[s][e][0] = min;
    dp[s][e][1] = max;
}
```
