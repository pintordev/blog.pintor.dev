## 문제

> 링크: [프로그래머스 12914](https://school.programmers.co.kr/learn/courses/30/lessons/12914)

한 번에 1칸 또는 2칸씩 뛰어 n칸에 도달하는 방법의 수를 1234567로 나눈 나머지를 구하는 문제.

## 접근

### DP (피보나치)

n번째 칸에 도달하는 방법은 `(n-1)칸에서 1칸 뛰기` + `(n-2)칸에서 2칸 뛰기`이므로 점화식은 피보나치와 동일하다.

- `dp[i] = (dp[i-1] + dp[i-2]) % 1234567`
- 베이스 케이스: `dp[1] = 1`, `dp[2] = 2`
- 매 단계 mod를 적용해 오버플로우 방지

## 풀이

```java
public long solution(int n) {
    if (n == 1) return 1;
    long[] dp = new long[n + 1];
    dp[1] = 1;
    dp[2] = 2;
    for (int i = 3; i <= n; i++) {
        dp[i] = (dp[i - 1] + dp[i - 2]) % 1234567;
    }
    return dp[n];
}
```
