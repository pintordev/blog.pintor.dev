## 문제

> 링크: [프로그래머스 17683](https://school.programmers.co.kr/learn/courses/30/lessons/17683)

라디오에서 들은 멜로디와 음악 정보 목록이 주어질 때, 해당 멜로디가 포함된 곡의 제목을 반환한다.

## 접근

### `#` 음표를 단일 문자로 치환

음표는 A~G 단일 문자와 `C#`, `D#`, `F#`, `G#`, `A#` 처럼 두 글자짜리 샵 음표로 구성된다. 멜로디 포함 여부를 `contains`로 판단하려면 샵 음표를 단일 문자로 통일해야 한다. A~G와 겹치지 않는 대문자(V, W, X, Y, Z)로 치환해 처리한다.

### 재생 시퀀스 생성 후 포함 여부 확인

악보가 재생 시간보다 짧으면 반복 재생된다. 따라서 재생 시간(분)만큼의 실제 재생 시퀀스를 생성한 뒤, 멜로디가 그 안에 포함되는지 확인한다. 재생 시퀀스는 악보를 충분히 반복한 뒤 앞에서 재생 시간만큼 잘라 만든다.

여러 곡이 매칭될 경우 재생 시간이 가장 긴 곡을 반환하며, 동일하면 먼저 입력된 곡을 반환한다.

## 풀이

```java
public String solution(String m, String[] musicinfos) {
    String title = "(None)";
    int maxTime = 0;
    m = convert(m);
    for (String musicinfo : musicinfos) {
        String[] music = musicinfo.split(",");
        int playTime = toTime(music[1]) - toTime(music[0]);
        if (!toNotes(convert(music[3]), playTime).contains(m) || playTime <= maxTime) continue;
        title = music[2];
        maxTime = playTime;
    }
    return title;
}

public String convert(String s) {
    return s
        .replace("C#", "V")
        .replace("D#", "W")
        .replace("F#", "X")
        .replace("G#", "Y")
        .replace("A#", "Z");
}

public int toTime(String time) {
    String[] t = time.split(":");
    return Integer.parseInt(t[0]) * 60 + Integer.parseInt(t[1]);
}

public String toNotes(String notes, int playTime) {
    return (notes.repeat(playTime / notes.length()) + notes)
        .substring(0, playTime);
}
```
