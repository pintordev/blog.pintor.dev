## 문제

> 링크: [프로그래머스 49993](https://school.programmers.co.kr/learn/courses/30/lessons/49993)

주어진 선행 스킬 순서를 지키면서 배울 수 있는 스킬트리의 수를 반환한다.

## 접근

### 포인터로 선행 순서 검증

스킬트리를 순회하면서 선행 스킬(`skill`)에 포함된 문자를 만날 때마다 순서가 맞는지 확인한다.

`skill` 문자열의 인덱스를 포인터 `p`로 관리하여, 현재 배워야 할 스킬(`skill.charAt(p)`)과 일치하면 포인터를 올리고, 다른 선행 스킬이 먼저 등장하면 즉시 `false`를 반환한다. 선행 스킬에 없는 문자는 언제든 배울 수 있으므로 건너뛴다.

## 풀이

```java
public int solution(String skill, String[] skill_trees) {
    int cnt = 0;
    for (String skill_tree : skill_trees) {
        if (isValid(skill, skill_tree)) cnt++;
    }
    return cnt;
}

public boolean isValid(String skill, String skillTree) {
    for (int i = 0, p = 0; i < skillTree.length(); i++) {
        char c = skillTree.charAt(i);
        if (skill.indexOf(c) == -1) continue;
        if (skill.charAt(p) == c) p++;
        else return false;
    }
    return true;
}
```
