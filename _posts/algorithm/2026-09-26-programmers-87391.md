## 문제

> 링크: [프로그래머스 87391](https://school.programmers.co.kr/learn/courses/30/lessons/87391)

n×m 격자에서 여러 쿼리로 공을 이동시켰을 때, 모든 시작점 중 최종적으로 (x, y)에 도착하는 시작점의 개수를 구하는 문제.

## 접근

### 축 분리

행 이동(command 2, 3)과 열 이동(command 0, 1)은 서로 영향을 주지 않는다. 따라서 문제를 크기 n인 행 축과 크기 m인 열 축, 두 개의 1차원 문제로 나눠서 풀 수 있다. 최종 답은 두 축에서 각각 구한 시작 위치 개수의 곱이다.

### 역순 구간 추적

한 축에서 "이동 후 clamp"는 `p -> clamp(p ± dist, 0, size - 1)` 형태이고, 이 함수는 단조 비감소(monotonic non-decreasing)다. 단조 함수의 합성도 단조이므로, 쿼리를 모두 적용한 최종 위치 함수도 단조 비감소가 된다.

이 성질을 이용해 목표 위치 (x, y)에서 출발해 쿼리를 역순으로 훑으며, 그 위치로 도달할 수 있는 시작 위치의 범위 `[r1, r2]`(행), `[c1, c2]`(열)를 직접 갱신한다.

한 스텝의 역연산은 다음과 같이 나뉜다.
- 경계에 clamp된 값이 아니면, 범위를 그대로 `dist`만큼 반대 방향으로 평행이동한다.
- 경계(0 또는 size - 1)에 걸친 값이면, 그 경계로 clamp될 수 있는 모든 시작 위치가 후보이므로 범위가 경계 쪽으로 넓어진다.

각 스텝마다 범위가 비어버리면(`lo > hi`) 그 순간 해당 위치로 도달하는 시작점이 없다는 뜻이므로 0을 반환하고 종료한다. 전체 쿼리를 훑고 남은 두 범위의 길이를 곱하면 답이 된다.

## 풀이

```java
public long solution(int n, int m, int x, int y, int[][] queries) {
    long r1 = x;
    long r2 = x;
    long c1 = y;
    long c2 = y;
    for (int i = queries.length - 1; i >= 0; i--) {
        int dir = queries[i][0];
        int dist = queries[i][1];
        switch (dir) {
            case 0:
                if (c1 != 0) c1 += dist;
                c2 = Math.min(m - 1, c2 + dist);
                break;
            case 1:
                if (c2 != m - 1) c2 -= dist;
                c1 = Math.max(0, c1 - dist);
                break;
            case 2:
                if (r1 != 0) r1 += dist;
                r2 = Math.min(n - 1, r2 + dist);
                break;
            case 3:
                if (r2 != n - 1) r2 -= dist;
                r1 = Math.max(0, r1 - dist);
                break;
        }
        if (r1 > r2 || c1 > c2) return 0;
    }
    return (r2 - r1 + 1) * (c2 - c1 + 1);
}
```
