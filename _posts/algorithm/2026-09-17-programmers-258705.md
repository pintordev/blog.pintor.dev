## 문제

> 링크: [프로그래머스 258705](https://school.programmers.co.kr/learn/courses/30/lessons/258705)

사다리꼴 모양의 도형을 정삼각형 또는 마름모 타일로 완전히 채우는 경우의 수를 10007로 나눈 나머지로 구하는 문제.

## 접근

### 도형 구조와 상태 정의

사다리꼴 한 줄은 `U1 D1 U2 D2 ... Dn Un+1` 형태로 위쪽 삼각형(U, n+1개)과 아래쪽 삼각형(D, n개)이 번갈아 배치된 구조다. `tops[i]=1`이면 `Di` 위에 돌출 삼각형 `Ti`가 붙는데, `Ti`는 `Di`하고만 맞닿아 있어 이웃한 돌출 삼각형끼리는 서로 영향을 주지 않는다.

각 `Di`는 단독 타일이 되거나, 왼쪽 `Ui` 또는 오른쪽 `Ui+1`과 묶여 마름모가 되거나, `tops[i]=1`인 경우 `Ti`와 묶여 마름모가 될 수 있다. `Uj`는 단독이거나 왼쪽 `Dj-1` 또는 오른쪽 `Dj` 중 하나에게만 선점될 수 있으므로, 이 선점 여부를 상태로 삼아 왼쪽에서 오른쪽으로 진행하는 DP를 세울 수 있다.

`dp0`은 다음 `U`가 아직 선점되지 않은 경우의 수, `dp1`은 이미 선점된 경우의 수를 의미한다. `Di` 처리 시 `x = tops[i]`라 하면 전이는 다음과 같다.

- 이전 상태가 `dp1`(현재 `U`가 이미 선점됨)이면: 단독 또는 돌출과 결합(`1+x`가지)으로 다음 `dp0`에 기여하고, 오른쪽 `U`를 선점(1가지)하면 다음 `dp1`에 기여한다.
- 이전 상태가 `dp0`(현재 `U`가 자유로움)이면: 단독/왼쪽 결합/돌출과 결합(`2+x`가지)으로 다음 `dp0`에 기여하고, 오른쪽 `U`를 선점(1가지)하면 다음 `dp1`에 기여한다.

n번 반복 후 `(dp0 + dp1) % 10007`이 답이다.

## 풀이

```java
public int solution(int n, int[] tops) {
    int MOD = 10007;
    int dp0 = 1;
    int dp1 = 0;
    for (int i = 0; i < n; i++) {
        int x = tops[i];
        int nextDp0 = (dp1 * (1 + x) + dp0 * (2 + x)) % MOD;
        int nextDp1 = (dp0 + dp1) % MOD;
        dp0 = nextDp0;
        dp1 = nextDp1;
    }
    return (dp0 + dp1) % MOD;
}
```
