## 문제

> 링크: [프로그래머스 150367](https://school.programmers.co.kr/learn/courses/30/lessons/150367)

정수를 이진 문자열로 바꿔 포화 이진트리의 중위 순회로 해석했을 때, 더미 노드 아래에 실제 노드가 없는 유효한 트리인지 판별한다.

## 접근

### 이진 문자열을 포화 이진트리로 보고 분할 정복

수를 표현하는 규칙을 거꾸로 밟으면 된다. 십진수를 `Long.toBinaryString`으로 이진 문자열로 바꾸면, 이 문자열은 어떤 포화 이진트리를 왼쪽부터 오른쪽 순서(= 중위 순회)로 훑은 결과다.

포화 이진트리의 노드 수는 항상 `2^k - 1`이므로, 문자열 길이가 `2^k - 1`이 되도록 앞에 `0`을 채운다. 앞에 붙는 `0`은 십진수 값을 바꾸지 않고, 트리 왼쪽 깊은 곳에 더미 노드를 추가하는 것에 대응한다.

패딩 크기는 `2^k - 1 ≥ 이진 문자열 길이`를 만족하는 **가장 작은 `k`** 하나만 확인하면 충분하다. 한 레벨 더 키우면 새로 생기는 루트가 더미 노드(`0`)인데 기존 트리 전체가 그 왼쪽 서브트리로 들어가 실제 노드를 포함하게 되어, 아래에서 볼 규칙에 의해 항상 무효가 되기 때문이다.

중위 순회 문자열에서 가운데 문자가 루트이고, 좌·우 절반이 각각 좌·우 서브트리의 중위 순회다. 이를 재귀로 검사한다.

- 루트가 `1`이면 좌·우 서브트리를 각각 재귀 검사한다.
- 루트가 `0`(더미 노드)이면 부모 없는 자식이 존재할 수 없으므로, 그 구간 전체가 `0`이어야 한다. `1`이 하나라도 있으면 무효다.

원소 값이 최대 `10^15`라 이진 문자열 길이는 최대 50, 패딩 후에도 63이다. 원소당 `O(L)`, 전체 `O(N·L)`로 여유롭게 통과한다.

## 풀이

```java
import java.util.Arrays;

public int[] solution(long[] numbers) {
    int[] res = new int[numbers.length];
    for (int i = 0; i < numbers.length; i++) {
        res[i] = isRepresentable(numbers[i]) ? 1 : 0;
    }
    return res;
}

public boolean isRepresentable(long number) {
    String binary = Long.toBinaryString(number);
    int size = 1;
    while (size < binary.length()) {
        size = (size << 1) + 1;
    }
    char[] tree = new char[size];
    Arrays.fill(tree, '0');
    for (int i = 0; i < binary.length(); i++) {
        tree[size - binary.length() + i] = binary.charAt(i);
    }
    return isValid(tree, 0, size - 1);
}

public boolean isValid(char[] tree, int lo, int hi) {
    if (lo > hi) return true;
    int mid = (lo + hi) >> 1;
    if (tree[mid] == '1') return isValid(tree, lo, mid - 1) && isValid(tree, mid + 1, hi);
    for (int i = lo; i <= hi; i++) {
        if (tree[i] == '1') return false;
    }
    return true;
}
```
