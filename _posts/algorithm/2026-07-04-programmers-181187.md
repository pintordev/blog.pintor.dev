## 문제

> 링크: [프로그래머스 181187](https://school.programmers.co.kr/learn/courses/30/lessons/181187)

원점 중심의 두 원(반지름 r1, r2) 사이 공간에 놓인 정수 좌표 점의 개수를 구한다. (경계 포함)

## 접근

### x 대칭을 이용한 1사분면 순회 × 4

x를 1부터 r2까지 순회하면서, 각 x에서 유효한 y의 개수를 구한 뒤 4를 곱해 4사분면 전체를 커버한다.

각 x에서 유효한 y의 범위:
- 상한: floor(√(r2² - x²)) — 바깥 원 안쪽
- 하한: x < r1이면 ceil(√(r1² - x²)), 아니면 0 — 안쪽 원 바깥쪽

유효한 y 개수 = 상한 - 하한 + 1

루프가 x=1부터 시작하므로 x=0은 계산되지 않지만, x ∈ [r1, r2] 구간에서 y=0을 포함해 ×4로 과산정하는 양이 x=0의 누락분(2×(r2-r1+1))과 정확히 일치해 상쇄된다.

## 풀이

```java
public long solution(int r1, int r2) {
    long r1sq = (long) r1 * r1;
    long r2sq = (long) r2 * r2;
    long cnt = 0;
    for (long i = 1; i <= r2; i++) {
        long iSq = i * i;
        cnt += (long) Math.sqrt(r2sq - iSq)
                - (i < r1 ? (long) Math.ceil(Math.sqrt(r1sq - iSq)) : 0)
                + 1;
    }
    return cnt * 4;
}
```
