## 문제

> 링크: [프로그래머스 42883](https://school.programmers.co.kr/learn/courses/30/lessons/42883)

숫자 문자열 `number`에서 `k`개를 제거해 만들 수 있는 가장 큰 수를 반환한다.

## 접근

### 그리디 + 스택

더 앞 자리의 숫자가 클수록 전체 수가 커진다. 따라서 왼쪽부터 스캔하면서 현재 숫자가 스택 맨 위보다 크면, 스택 맨 위를 제거(k 감소)하는 것이 항상 최선이다.

순회 후 `k`가 남아 있으면 스택 끝에서 `k`개를 잘라낸다. 이는 순회 중 제거가 일어나지 않은 경우(단조 감소 등)에 해당하며, 스택 뒤쪽이 가장 작으므로 뒤에서 자르는 것이 최선이다.

`char[]`를 스택으로 직접 사용해 불필요한 객체 생성을 줄였다.

- 시간복잡도: O(n) — 각 문자는 push/pop 최대 1회
- 공간복잡도: O(n)

## 풀이

```java
public String solution(String number, int k) {
    char[] stack = new char[number.length()];
    int top = 0;
    for (char c : number.toCharArray()) {
        while (k > 0 && top > 0 && stack[top - 1] < c) {
            top--;
            k--;
        }
        stack[top++] = c;
    }
    return new String(stack, 0, top - k);
}
```
