## 문제

> 링크: [프로그래머스 1829](https://school.programmers.co.kr/learn/courses/30/lessons/1829)

m×n 크기의 2차원 배열 picture가 주어질 때, 상하좌우로 연결된 같은 색상의 영역이 몇 개인지와 그중 가장 넓은 영역의 크기를 구하는 문제다.

## 접근

### BFS 기반 Flood Fill

그림 전체를 순회하다가 아직 방문하지 않았고 색이 칠해진(0이 아닌) 칸을 만나면, 그 칸을 시작점으로 BFS를 돌려 같은 색으로 연결된 영역을 한 번에 방문 처리한다.

BFS 한 번이 끝날 때마다 영역 하나를 찾은 것이므로 영역 개수를 1 늘리고, 이번에 방문한 칸 수와 지금까지의 최댓값을 비교해 갱신한다. 모든 칸을 순회하고 나면 영역 개수와 최대 넓이를 담아 반환한다.

시간복잡도는 각 칸을 최대 한 번씩만 큐에 넣고 처리하므로 O(m×n)이다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Queue;

public int[] dr = {-1, 1, 0, 0};
public int[] dc = {0, 0, -1, 1};
public int m, n;
public int[][] picture;
public boolean[][] visited;

public int[] solution(int m, int n, int[][] picture) {
    this.m = m;
    this.n = n;
    this.picture = picture;
    visited = new boolean[m][n];
    int area = 0;
    int max = 0;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (picture[i][j] == 0 || visited[i][j]) continue;
            area++;
            max = Math.max(max, bfs(i, j));
        }
    }
    return new int[]{area, max};
}

public int bfs(int r, int c) {
    int color = picture[r][c];
    int size = 0;
    Queue<Node> q = new ArrayDeque<>();
    q.add(new Node(r, c));
    visited[r][c] = true;
    while (!q.isEmpty()) {
        Node cur = q.poll();
        size++;
        for (int d = 0; d < 4; d++) {
            int nr = cur.r + dr[d];
            int nc = cur.c + dc[d];
            if (!isAvailable(nr, nc, color)) continue;
            visited[nr][nc] = true;
            q.add(new Node(nr, nc));
        }
    }
    return size;
}

public boolean isAvailable(int r, int c, int color) {
    if (r < 0 || r >= m || c < 0 || c >= n) return false;
    if (visited[r][c]) return false;
    return picture[r][c] == color;
}

class Node {
    int r, c;

    Node(int r, int c) {
        this.r = r;
        this.c = c;
    }
}
```
