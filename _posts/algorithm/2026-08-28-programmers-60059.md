## 문제

> 링크: [프로그래머스 60059](https://school.programmers.co.kr/learn/courses/30/lessons/60059)

N x N 크기의 자물쇠와 M x M 크기의 열쇠가 주어질 때, 열쇠를 회전·이동시켜 자물쇠의 모든 홈을 정확히 채울 수 있는지 판별한다.

## 접근

### 완전탐색 + 홈 개수 카운팅

M, N이 모두 20 이하로 작기 때문에 완전탐색으로 충분하다. 열쇠를 0°, 90°, 180°, 270° 회전시킨 뒤, 자물쇠 위에서 가능한 모든 위치로 슬라이딩시키며 딱 맞는 경우가 있는지 확인한다.

열쇠가 자물쇠 밖으로 튀어나오며 이동할 수도 있으므로, 좌표 계산은 자물쇠 기준으로 한다. 열쇠의 각 칸 `(i, j)`를 후보 위치 `(r, c)`에 놓았을 때 자물쇠 좌표는 `(r + i - offset, c + j - offset)`이 되는데(`offset = M - 1`), 이 좌표가 자물쇠 범위를 벗어나면 그냥 건너뛴다. 자물쇠 범위 안에서는 두 가지만 확인하면 된다.

- 자물쇠의 돌기(1)와 열쇠의 돌기(1)가 겹치면 그 자리에서 바로 실패
- 자물쇠의 홈(0)을 열쇠의 돌기(1)가 채우면 카운트 증가

자물쇠 전체의 홈 개수를 미리 세어두고, 이번 후보 위치에서 채운 홈 개수가 그 값과 정확히 같으면 열린다. 홈이 열쇠의 발자국 밖에 남아 있으면 카운트가 모자라 자동으로 걸러지기 때문에, 발자국 밖 홈을 따로 검사할 필요가 없다.

이 방식은 자물쇠 크기만큼의 배열을 새로 만들어 열쇠 값을 더했다 빼는 방식과 비교하면, 후보 위치마다 열쇠 크기(M x M)만큼만 순회하면 되고 별도의 복구 단계도 필요 없다.

## 풀이

```java
int[][] lock;
int[][] key;
int n;
int m;
int offset;
int hole;

public boolean solution(int[][] key, int[][] lock) {
    this.lock = lock;
    this.key = key;
    n = lock.length;
    m = key.length;
    offset = m - 1;
    hole = 0;
    for (int[] row : lock) {
        for (int val : row) {
            if (val == 0) hole++;
        }
    }
    int size = n + 2 * offset;
    for (int rot = 0; rot < 4; rot++) {
        for (int r = 0; r <= size - m; r++) {
            for (int c = 0; c <= size - m; c++) {
                if (canUnlock(r, c)) return true;
            }
        }
        rotate();
    }
    return false;
}

public boolean canUnlock(int r, int c) {
    int filled = 0;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < m; j++) {
            int lr = r + i - offset;
            int lc = c + j - offset;
            if (lr < 0 || lr >= n || lc < 0 || lc >= n) continue;
            if (lock[lr][lc] == 1 && key[i][j] == 1) return false;
            if (lock[lr][lc] == 0 && key[i][j] == 1) filled++;
        }
    }
    return filled == hole;
}

public void rotate() {
    int[][] rotated = new int[m][m];
    for (int r = 0; r < m; r++) {
        for (int c = 0; c < m; c++) {
            rotated[c][m - 1 - r] = key[r][c];
        }
    }
    key = rotated;
}
```
