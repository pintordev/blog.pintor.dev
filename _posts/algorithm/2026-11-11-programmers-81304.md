## 문제

> 링크: [프로그래머스 81304](https://school.programmers.co.kr/learn/courses/30/lessons/81304)

함정 방에 들어갈 때마다 그 방에 연결된 길의 방향이 뒤집히는 단방향 그래프에서, 출발 방부터 도착 방까지의 최단 시간을 구하는 문제.

## 접근

### 함정 상태 비트마스크 + 다익스트라

길의 방향이 함정의 발동 여부에 따라 달라지므로, 현재 방 번호만으로는 상태를 표현할 수 없다. 함정은 최대 10개이고 같은 함정을 다시 밟으면 원래대로 돌아오므로, 각 함정의 발동 여부를 비트마스크로 나타내면 상태는 `(방, 마스크)` 최대 1,000 × 1,024개가 된다.

원래 `u → v`인 길은 양 끝 방 중 하나만 발동 상태일 때 뒤집힌다. 둘 다 발동했거나 둘 다 발동하지 않았다면 원래 방향 그대로다. 그래서 길 하나를 정방향 간선과 역방향 간선으로 함께 저장해 두고, 현재 마스크에서 양 끝 방의 발동 여부가 같으면 정방향 간선만, 다르면 역방향 간선만 사용한다. 함정이 아닌 방은 항상 미발동으로 본다.

이동한 방이 함정이면 해당 비트를 XOR로 토글한 마스크로 다음 상태를 만든다. 간선 비용이 모두 양수이므로 `dist[방][마스크]`에 대해 다익스트라를 돌리고, 도착 방이 처음 꺼내지는 순간의 시간이 답이다.

시간복잡도는 `O((V + E) · 2^T · log(V · 2^T))`이다.

## 풀이

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.PriorityQueue;

int n;
List<Edge>[] graph;
int[] trap;

public int solution(int n, int start, int end, int[][] roads, int[] traps) {
    this.n = n;
    graph = new List[n + 1];
    for (int i = 1; i <= n; i++) {
        graph[i] = new ArrayList<>();
    }
    for (int[] road : roads) {
        graph[road[0]].add(new Edge(road[1], road[2], false));
        graph[road[1]].add(new Edge(road[0], road[2], true));
    }
    trap = new int[n + 1];
    Arrays.fill(trap, -1);
    for (int i = 0; i < traps.length; i++) {
        trap[traps[i]] = i;
    }
    return dijkstra(start, end, traps.length);
}

public int dijkstra(int start, int end, int k) {
    int[][] dist = new int[n + 1][1 << k];
    for (int i = 1; i <= n; i++) {
        Arrays.fill(dist[i], Integer.MAX_VALUE);
    }
    PriorityQueue<Node> pq = new PriorityQueue<>();
    dist[start][0] = 0;
    pq.add(new Node(start, 0, 0));
    while (!pq.isEmpty()) {
        Node cur = pq.poll();
        if (cur.time > dist[cur.to][cur.mask]) continue;
        if (cur.to == end) return cur.time;
        for (Edge next : graph[cur.to]) {
            boolean same = isActive(cur.to, cur.mask) == isActive(next.to, cur.mask);
            if (same == next.reversed) continue;
            int nm = trap[next.to] == -1 ? cur.mask : cur.mask ^ (1 << trap[next.to]);
            int nd = cur.time + next.time;
            if (dist[next.to][nm] <= nd) continue;
            dist[next.to][nm] = nd;
            pq.add(new Node(next.to, nm, nd));
        }
    }
    return -1;
}

public boolean isActive(int v, int mask) {
    if (trap[v] == -1) return false;
    return (mask >> trap[v] & 1) == 1;
}

class Edge {
    int to;
    int time;
    boolean reversed;

    public Edge(int to, int time, boolean reversed) {
        this.to = to;
        this.time = time;
        this.reversed = reversed;
    }
}

class Node implements Comparable<Node> {
    int to;
    int mask;
    int time;

    public Node(int to, int mask, int time) {
        this.to = to;
        this.mask = mask;
        this.time = time;
    }

    @Override
    public int compareTo(Node o) {
        return this.time - o.time;
    }
}
```
