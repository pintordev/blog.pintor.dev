## 문제

> 링크: [프로그래머스 86971](https://school.programmers.co.kr/learn/courses/30/lessons/86971)

트리 형태의 전력망에서 전선 하나를 끊어 두 전력망으로 나눌 때, 송전탑 수의 차이 최솟값을 구한다.

## 접근

### 트리 루팅 후 서브트리 크기 DFS

간선을 하나씩 끊고 BFS/DFS로 크기를 세는 O(n²) 대신, 트리를 루팅해 한 번의 DFS로 모든 경우를 처리한다.

루트(1번)에서 DFS를 수행해 각 노드의 서브트리 크기를 계산한다. 루트를 제외한 모든 노드 v는 부모와의 간선 하나에 대응하며, 그 간선을 끊으면 한쪽 크기는 `subtree[v]`, 반대쪽은 `n - subtree[v]`가 된다. 루트의 경우 서브트리 크기가 n이므로 차이가 n으로 다른 경우보다 항상 크거나 같아 결과에 영향을 주지 않는다.

## 풀이

```java
import java.util.ArrayList;
import java.util.List;

int n, min;
List<Integer>[] graph;

public int solution(int n, int[][] wires) {
    this.n = n;
    this.min = Integer.MAX_VALUE;
    graph = new List[n + 1];
    for (int i = 1; i <= n; i++) {
        graph[i] = new ArrayList<>();
    }
    for (int[] wire : wires) {
        graph[wire[0]].add(wire[1]);
        graph[wire[1]].add(wire[0]);
    }
    dfs(1, 1);
    return min;
}

public int dfs(int v, int p) {
    int children = 1;
    for (int u : graph[v]) {
        if (u != p) children += dfs(u, v);
    }
    min = Math.min(min, Math.abs(children - (n - children)));
    return children;
}
```
