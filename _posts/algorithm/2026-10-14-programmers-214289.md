## 문제

> 링크: [프로그래머스 214289](https://school.programmers.co.kr/learn/courses/30/lessons/214289)

승객이 탑승한 시간 동안 실내온도를 t1 이상 t2 이하로 유지하면서 에어컨의 최소 소비전력을 구하는 문제.

## 접근

### 시간 × 실내온도 DP

희망온도는 매분 바꿀 수 있지만, 결국 중요한 것은 매분 실내온도가 어떻게 변하느냐다. 따라서 희망온도를 상태로 두지 않고 `dp[시간][실내온도]`만 관리한다.

- 에어컨을 끄면 실내온도는 외부온도 방향으로 1도 이동하고(같으면 유지) 비용은 0이다.
- 에어컨을 켜고 실내온도를 1도 올리거나 내리면 비용은 `a`이다.
- 에어컨을 켜고 희망온도를 실내온도와 같게 두면 온도는 유지되고 비용은 `b`이다.
- 승객이 탑승한 시각에는 실내온도가 t1 이상 t2 이하인 상태만 허용한다.

시작 온도는 외부온도이고, 정답은 마지막 분의 `dp` 중 최솟값이다.

### 온도 범위 압축

`temperature`, `t1`, `t2`를 모두 감싸는 구간 밖의 온도는 쓸 이유가 없다. 최솟값을 0으로 맞춰 그 구간만 상태로 쓰면 배열 크기가 줄어든다. 이전 분의 `dp`만 필요하므로 두 배열을 번갈아 쓴다.

- 시간복잡도: O(N × T) (N: `onboard` 길이, T: 압축한 온도 범위, 최대 51)
- 공간복잡도: O(T)

## 풀이

```java
import java.util.Arrays;

int INF = Integer.MAX_VALUE;

public int solution(int temperature, int t1, int t2, int a, int b, int[] onboard) {
    int n = onboard.length;
    int min = Math.min(temperature, Math.min(t1, t2));
    int max = Math.max(temperature, Math.max(t1, t2)) - min;
    temperature -= min;
    t1 -= min;
    t2 -= min;
    int[] dp = new int[max + 1];
    Arrays.fill(dp, INF);
    dp[temperature] = 0;
    for (int i = 1; i < n; i++) {
        int[] next = new int[max + 1];
        Arrays.fill(next, INF);
        for (int t = 0; t <= max; t++) {
            if (dp[t] == INF) continue;
            int[] dts = {Integer.compare(temperature, t), -1, 1, 0};
            int[] costs = {0, a, a, b};
            for (int k = 0; k < 4; k++) {
                int nt = t + dts[k];
                if (nt < 0 || nt > max) continue;
                if (onboard[i] == 1 && (nt < t1 || nt > t2)) continue;
                next[nt] = Math.min(next[nt], dp[t] + costs[k]);
            }
        }
        dp = next;
    }
    int res = INF;
    for (int cost : dp) {
        res = Math.min(res, cost);
    }
    return res;
}
```
