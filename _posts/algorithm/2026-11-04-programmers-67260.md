## 문제

> 링크: [프로그래머스 67260](https://school.programmers.co.kr/learn/courses/30/lessons/67260)

0번 방이 입구인 트리 모양의 동굴에서, 방문 순서 규칙(`A`를 `B`보다 먼저)을 지키며 모든 방을 탐험할 수 있는지 판별하는 문제.

## 접근

### 보류(defer) 방식 BFS

`order`는 제한사항 때문에 서로 독립된 `A → B` 쌍들의 모음이다. 한 방의 선행 방과 후행 방은 각각 최대 1개이므로 `before[B] = A`, `after[A] = B` 배열 두 개로 저장한다. 순환은 `order` 끼리가 아니라 트리의 진행 방향(0번에서 바깥쪽)과 `order`가 합쳐질 때만 생긴다.

0번 방에서 BFS를 시작한다. 이웃 방에 닿았을 때 그 방의 선행 방이 아직 방문 전이면 들어가지 않고 `held`로 보류한다. 이후 선행 방을 꺼내는 시점에 `after`가 보류 상태이면 그 방을 큐에 넣어 이어서 탐색한다. 트리이므로 보류된 방은 다른 경로로 다시 닿지 않으며, 선행 방을 방문하는 순간에만 풀린다.

꺼낸 방의 수가 n이면 모든 방을 탐험할 수 있다. 순환이 있으면 순환에 속한 방들이 보류된 채로 남아 방문 수가 모자라다. 0번 방이 후행 방인 경우는 입구부터 막히므로 바로 `false`로 처리한다.

선행 방이 없는 경우를 `0`으로 표현해도 문제가 없다. 0번 방은 항상 먼저 방문되므로 `visited[0]`이 참이고, 0번이 선행 방인 경우도 같은 방식으로 통과한다. 같은 이유로 `after`가 없는 경우의 `held[0]`은 항상 거짓이다.

시간복잡도와 공간복잡도는 O(n)이다. n이 최대 200,000이라 재귀 DFS 대신 큐 기반 BFS를 사용한다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

List<Integer>[] graph;
int[] before;
int[] after;
boolean[] visited;
boolean[] held;

public boolean solution(int n, int[][] path, int[][] order) {
    graph = new List[n];
    for (int i = 0; i < n; i++) {
        graph[i] = new ArrayList<>();
    }
    for (int[] p : path) {
        graph[p[0]].add(p[1]);
        graph[p[1]].add(p[0]);
    }
    before = new int[n];
    after = new int[n];
    for (int[] o : order) {
        after[o[0]] = o[1];
        before[o[1]] = o[0];
    }
    if (before[0] != 0) return false;
    visited = new boolean[n];
    held = new boolean[n];
    Queue<Integer> q = new ArrayDeque<>();
    q.add(0);
    visited[0] = true;
    int cnt = 0;
    while (!q.isEmpty()) {
        int cur = q.poll();
        cnt++;
        for (int next : graph[cur]) {
            if (visited[next]) continue;
            if (!visited[before[next]]) {
                held[next] = true;
                continue;
            }
            q.add(next);
            visited[next] = true;
        }
        if (held[after[cur]]) {
            q.add(after[cur]);
            visited[after[cur]] = true;
        }
    }
    return cnt == n;
}
```
