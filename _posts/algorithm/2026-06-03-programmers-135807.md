## 문제

> 링크: [프로그래머스 135807](https://school.programmers.co.kr/learn/courses/30/lessons/135807)

두 정수 배열 arrayA, arrayB가 주어질 때, 한쪽 배열의 모든 원소를 나눌 수 있고 다른 쪽 배열의 어떤 원소도 나눌 수 없는 가장 큰 양의 정수를 구한다.

## 접근

### GCD를 후보로 사용

a가 arrayA의 모든 원소를 나누려면 a는 GCD(arrayA)의 약수여야 한다.

핵심 관찰은 GCD(arrayA)가 arrayB의 어떤 원소를 나눈다면, GCD의 모든 약수도 그 원소를 나눈다는 점이다. 따라서 arrayB에 GCD(arrayA)로 나누어지는 원소가 하나라도 있으면 arrayA 쪽에서 유효한 a는 존재하지 않는다.

반대로 GCD(arrayA)가 arrayB의 어떤 원소도 나누지 않는다면, GCD(arrayA)가 arrayA 쪽에서 구할 수 있는 가장 큰 a이다.

양쪽 방향(arrayA→arrayB, arrayB→arrayA)으로 각각 검사한 후 최댓값을 반환한다.

## 풀이

```java
public int solution(int[] arrayA, int[] arrayB) {
    return Math.max(findOrZero(arrayA, arrayB), findOrZero(arrayB, arrayA));
}

public int findOrZero(int[] arrayA, int[] arrayB) {
    int gcd = arrayA[0];
    for (int a : arrayA) gcd = gcd(gcd, a);
    for (int b : arrayB) if (b % gcd == 0) return 0;
    return gcd;
}

public int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
```
