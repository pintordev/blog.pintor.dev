## 문제

> 링크: [프로그래머스 68645](https://school.programmers.co.kr/learn/courses/30/lessons/68645)

높이 n인 삼각형을 꼭짓점부터 반시계 방향으로 1씩 채운 뒤, 행 순으로 이어붙인 배열을 반환한다.

## 접근

### 방향 사이클과 2D 배열 시뮬레이션

삼각형을 n×n 2D 배열로 모델링하고, 반시계 방향 3단계(↓ 아래, → 오른쪽, ↖ 대각선)를 순서대로 반복한다.

외부 루프 인덱스 i를 3으로 나눈 나머지로 방향을 결정하고, 내부 루프는 j=i부터 j<n까지 돌아 자연스럽게 (n-i)번 반복된다.

n=4 트레이싱:

| i | i%3 | 방향 | 단계 | 배정 |
|---|-----|------|------|------|
| 0 | 0 | ↓ 아래 | 4 | mat[0][0]=1, mat[1][0]=2, mat[2][0]=3, mat[3][0]=4 |
| 1 | 1 | → 오른쪽 | 3 | mat[3][1]=5, mat[3][2]=6, mat[3][3]=7 |
| 2 | 2 | ↖ 대각선 | 2 | mat[2][2]=8, mat[1][1]=9 |
| 3 | 0 | ↓ 아래 | 1 | mat[2][1]=10 |

채워진 행렬:

```
[1,  -,  -,  -]
[2,  9,  -,  -]
[3, 10,  8,  -]
[4,  5,  6,  7]
```

행 순으로 읽으면 `[1, 2, 9, 3, 10, 8, 4, 5, 6, 7]` ✓

## 풀이

```java
public int[] solution(int n) {
    int[] flat = new int[(n * (n + 1)) >> 1];
    int[][] mat = new int[n][n];
    int r = -1, c = 0, num = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i; j < n; j++) {
            if (i % 3 == 0) ++r;
            else if (i % 3 == 1) ++c;
            else {--r; --c;}
            mat[r][c] = ++num;
        }
    }
    int idx = 0;
    for (int[] m : mat) {
        for (int a : m) {
            if (a == 0) break;
            flat[idx++] = a;
        }
    }
    return flat;
}
```
