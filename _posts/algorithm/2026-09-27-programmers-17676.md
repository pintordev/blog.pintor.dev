## 문제

> 링크: [프로그래머스 17676](https://school.programmers.co.kr/learn/courses/30/lessons/17676)

응답이 완료된 요청들의 로그가 주어질 때, 임의의 연속된 1초 구간에서 동시에 처리 중인 요청 수의 최댓값을 구하는 문제.

## 접근

### 요청을 시간 구간으로 변환

각 로그의 응답완료시간 S와 처리시간 T로 요청이 처리된 구간 `[start, end]`를 구한다. 처리시간은 시작과 끝을 포함하므로 `end = S`, `start = end - T + 1`(밀리초 단위)이 된다.

### 구간 스위핑으로 최대 겹침 개수 계산

윈도우 `[c, c+999]`가 요청 구간 `[start, end]`와 겹치는 조건은 `start - 999 ≤ c ≤ end`이다. 각 요청을 `[start-999, end]`로 바꾸면, 문제는 "이 구간들 중 한 지점 c를 가장 많이 덮는 구간 개수"를 구하는 문제로 바뀐다.

바뀐 구간의 시작값들과 끝값들을 각각 정렬한 뒤 투 포인터로 병합하면서, 시작값을 만나면 카운트를 늘리고 끝값을 만나면 카운트를 줄이는 방식으로 최댓값을 구한다. 정렬 비용이 지배적이라 시간복잡도는 O(N log N)이다.

## 풀이

```java
import java.util.Arrays;

int start;
int end;

public int solution(String[] lines) {
    int n = lines.length;
    int[] starts = new int[n];
    int[] ends = new int[n];
    for (int i = 0; i < n; i++) {
        parseInterval(lines[i]);
        starts[i] = start - 999;
        ends[i] = end;
    }
    Arrays.sort(starts);
    Arrays.sort(ends);
    int cnt = 0;
    int max = 0;
    int i = 0;
    int j = 0;
    while (i < n) {
        if (starts[i] <= ends[j]) {
            cnt++;
            max = Math.max(max, cnt);
            i++;
        } else {
            cnt--;
            j++;
        }
    }
    return max;
}

public void parseInterval(String line) {
    int hour = Integer.parseInt(line.substring(11, 13));
    int minute = Integer.parseInt(line.substring(14, 16));
    int second = Integer.parseInt(line.substring(17, 19));
    int millis = Integer.parseInt(line.substring(20, 23));
    int duration = (int) (Double.parseDouble(line.substring(24, line.length() - 1)) * 1000);
    end = ((hour * 60 + minute) * 60 + second) * 1000 + millis;
    start = end - duration + 1;
}
```
