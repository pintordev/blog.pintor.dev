## 문제

> 링크: [프로그래머스 42628](https://school.programmers.co.kr/learn/courses/30/lessons/42628)

삽입, 최댓값 삭제, 최솟값 삭제를 모두 지원하는 이중 우선순위 큐를 구현하는 문제다.

## 접근

### TreeMap<값, 개수>

값 자체를 key로, 등장 횟수를 value로 가지는 TreeMap을 사용한다. 삽입은 값의 개수를 1 증가시키고, 삭제는 `firstKey`/`lastKey`로 최솟값/최댓값을 바로 조회해 개수를 감소시킨 뒤 0이 되면 제거한다. 최대힙과 최소힙을 따로 관리하며 지연 삭제를 동기화하는 방식과 달리, 정렬된 트리 구조 하나로 최댓값과 최솟값을 동시에 O(log n)에 조회·삭제할 수 있다.

## 풀이

```java
import java.util.TreeMap;

public int[] solution(String[] operations) {
    TreeMap<Integer, Integer> map = new TreeMap<>();

    for (String op : operations) {
        String[] tokens = op.split(" ");
        String cmd = tokens[0];
        int num = Integer.parseInt(tokens[1]);

        if (cmd.equals("I")) {
            map.merge(num, 1, Integer::sum);
            continue;
        }

        if (map.isEmpty()) continue;

        int key = num == 1 ? map.lastKey() : map.firstKey();
        int cnt = map.get(key) - 1;
        map.put(key, cnt);
        if (cnt == 0) {
            map.remove(key);
        }
    }

    if (map.isEmpty()) return new int[]{0, 0};
    return new int[]{map.lastKey(), map.firstKey()};
}
```
