## 문제

> 링크: [프로그래머스 131703](https://school.programmers.co.kr/learn/courses/30/lessons/131703)

행 또는 열 단위로만 뒤집을 수 있는 동전판을 최소 횟수로 목표 상태까지 뒤집는 문제.

## 접근

### 행 마스크 완전탐색

같은 행이나 열을 두 번 뒤집으면 원상태로 돌아오므로, 최종 상태는 각 행을 뒤집었는지 여부(`r_i`)와 각 열을 뒤집었는지 여부(`c_j`)만으로 결정된다.

`diff[i][j] = beginning[i][j] XOR target[i][j]`로 두면, 만족해야 할 조건은 모든 `i, j`에 대해 `r_i XOR c_j == diff[i][j]`이다.

`N ≤ 10`이므로 행 마스크(`0 ~ 2^N - 1`)를 전부 완전탐색한다. 각 마스크에 대해 0번 행을 기준으로 `c_j = diff[0][j] XOR r_0`를 역산한 뒤, 나머지 모든 행에서 `r_i XOR c_j == diff[i][j]`가 성립하는지 검증한다. 하나라도 어긋나면 해당 마스크는 무효 처리한다.

유효한 마스크마다 뒤집은 행 개수와 열 개수의 합을 구해 최솟값을 갱신하고, 끝까지 유효한 마스크가 하나도 없으면 `-1`을 반환한다.

시간복잡도는 `O(2^N × N × M)`으로 제약 조건 안에서 충분히 통과한다.

## 풀이

```java
int n;
int m;
int[][] diff;

public int solution(int[][] beginning, int[][] target) {
    n = beginning.length;
    m = beginning[0].length;
    diff = new int[n][m];
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < m; c++) {
            diff[r][c] = beginning[r][c] ^ target[r][c];
        }
    }
    int res = -1;
    for (int mask = 0; mask < (1 << n); mask++) {
        int[] cols = columns(mask);
        if (cols == null) continue;
        int flips = Integer.bitCount(mask);
        for (int col : cols) {
            flips += col;
        }
        if (res == -1 || flips < res) res = flips;
    }
    return res;
}

public int[] columns(int mask) {
    int[] cols = new int[m];
    for (int c = 0; c < m; c++) {
        cols[c] = diff[0][c] ^ (mask & 1);
    }
    for (int r = 0; r < n; r++) {
        int rowFlip = (mask >> r) & 1;
        for (int c = 0; c < m; c++) {
            if ((rowFlip ^ cols[c]) != diff[r][c]) return null;
        }
    }
    return cols;
}
```
