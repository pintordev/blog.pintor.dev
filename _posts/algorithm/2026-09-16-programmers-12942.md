## 문제

> 링크: [프로그래머스 12942](https://school.programmers.co.kr/learn/courses/30/lessons/12942)

행렬의 크기 목록이 주어질 때, 모든 행렬을 순서대로 곱하기 위한 최소 곱셈 연산 횟수를 구하는 문제. 행렬 곱셈은 결합법칙이 성립하므로 어떤 순서로 괄호를 묶어 곱하느냐에 따라 총 연산 횟수가 달라진다.

## 접근

### 구간 DP (Matrix Chain Multiplication)

행렬이 3개 이상일 때 완전탐색으로 모든 괄호 조합을 시도하면 카탈란 수만큼의 경우의 수가 발생해 지수 시간이 걸린다. 행렬 개수가 최대 200개인 제약상 이 방식은 사용할 수 없다.

대신 구간 DP로 접근한다. 행렬 개수를 n이라 하고, 각 행렬의 행/열 크기로부터 차원 배열 `dims[0..n]`을 구성한다 (`dims[i]`는 i번째 행렬의 행 크기, `dims[i+1]`은 i번째 행렬의 열 크기와 같다).

`dp[i][j]`를 i번째부터 j번째까지의 행렬을 모두 곱하는 데 필요한 최소 곱셈 횟수로 정의하면 다음 점화식이 성립한다.

- `dp[i][i] = 0`
- `dp[i][j] = min( dp[i][k] + dp[k+1][j] + dims[i] * dims[k+1] * dims[j+1] )`, (i ≤ k < j)

구간 길이를 2부터 n까지 늘려가며 모든 구간에 대해 위 점화식을 채우면, 각 구간을 계산할 때 참조하는 더 짧은 구간의 값이 이미 계산되어 있음이 보장된다. 시간복잡도는 O(n³)으로, n ≤ 200 제약에서 충분히 통과 가능하다.

## 풀이

```java
public int solution(int[][] matrixSizes) {
    int n = matrixSizes.length;
    int[] dims = new int[n + 1];
    dims[0] = matrixSizes[0][0];
    for (int i = 0; i < n; i++) {
        dims[i + 1] = matrixSizes[i][1];
    }
    int[][] dp = new int[n][n];
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            dp[i][j] = Integer.MAX_VALUE;
            for (int k = i; k < j; k++) {
                int cost = dp[i][k] + dp[k + 1][j] + dims[i] * dims[k + 1] * dims[j + 1];
                dp[i][j] = Math.min(dp[i][j], cost);
            }
        }
    }
    return dp[0][n - 1];
}
```
