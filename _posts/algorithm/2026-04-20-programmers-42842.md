## 문제

> 링크: [프로그래머스 42842](https://school.programmers.co.kr/learn/courses/30/lessons/42842)

갈색 격자와 노란색 격자의 수가 주어질 때, 카펫의 가로·세로 크기를 구하는 문제.
카펫은 가장자리가 갈색, 안쪽이 노란색으로 채워진 직사각형이다.

## 접근

### 수학 (2차 방정식)

카펫의 가로를 w, 세로를 h (w ≥ h)라 하면 아래 두 조건이 성립한다.

```
w * h = brown + yellow       ... (1) 전체 넓이
(w - 2) * (h - 2) = yellow  ... (2) 안쪽 넓이
```

(2)를 전개하면 `wh - 2(w + h) + 4 = yellow`, (1)을 대입하면:

```
w + h = (brown + 4) / 2
```

w + h와 w * h를 알면 w, h는 2차 방정식의 두 근이다.

```
x² - (w+h)x + wh = 0
판별식 d = (w+h)² - 4*wh
w = ((w+h) + √d) / 2
h = ((w+h) - √d) / 2
```

## 풀이

```java
public int[] solution(int brown, int yellow) {
    // b + y == wh;
    // (w - 2)(h - 2) == y;
    // (b + 4) >> 1 == w + h;
    // sum & times -> 2nd order equation
    int t = brown + yellow;
    int s = (brown + 4) >> 1;
    int d = (int) Math.sqrt(s * s - 4 * t);
    return new int[]{(s + d) >> 1, (s - d) >> 1};
}
```
