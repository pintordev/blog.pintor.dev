## 문제

> 링크: [프로그래머스 17678](https://school.programmers.co.kr/learn/courses/30/lessons/17678)

셔틀은 09:00부터 n회, t분 간격으로 도착하며 한 번에 최대 m명이 탈 수 있다. 대기열에 선 크루들의 도착 시각이 주어질 때, 콘이 대기열 순서에서 밀리지 않고 셔틀을 탈 수 있는 가장 늦은 도착 시각을 구하는 문제다.

## 접근

### 정렬 + 그리디 역추적

크루들의 도착 시각을 분 단위 정수로 변환해 정렬한다. 이후 n번째 버스까지 순서대로 도착한 크루를 앞에서부터 최대 m명씩 배정한다.

마지막 버스를 배정할 때 두 경우로 나뉜다.

- 자리가 남는 경우: 콘은 마지막 버스 시각에 맞춰 도착해도 탈 수 있다.
- 정원이 꽉 찬 경우: 콘은 마지막으로 탑승한 크루보다 먼저 대기열에 서야 하므로, 그 크루의 도착 시각에서 1분을 뺀 시각이 답이 된다.

## 풀이

```java
import java.util.Arrays;

public String solution(int n, int t, int m, String[] timetable) {
    int[] arrivals = new int[timetable.length];
    for (int i = 0; i < timetable.length; i++) {
        arrivals[i] = toMinutes(timetable[i]);
    }
    Arrays.sort(arrivals);
    int idx = 0;
    int busTime = 9 * 60;
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        busTime = 9 * 60 + i * t;
        cnt = 0;
        while (idx < arrivals.length && arrivals[idx] <= busTime && cnt < m) {
            idx++;
            cnt++;
        }
    }
    int res;
    if (cnt < m) res = busTime;
    else res = arrivals[idx - 1] - 1;
    return toTimeString(res);
}

public int toMinutes(String time) {
    int hour = Integer.parseInt(time.substring(0, 2));
    int min = Integer.parseInt(time.substring(3, 5));
    return hour * 60 + min;
}

public String toTimeString(int min) {
    return String.format("%02d:%02d", min / 60, min % 60);
}
```
