## 문제

> 링크: [프로그래머스 12979](https://school.programmers.co.kr/learn/courses/30/lessons/12979)

일렬로 늘어선 N개의 아파트 중 일부 위치에 전파 도달 거리 W인 기지국이 이미 설치되어 있을 때, 모든 아파트에 전파가 닿도록 추가로 설치해야 하는 최소 기지국 개수를 구한다.

## 접근

### 빈 구간 그리디 커버링

N은 최대 2억이라 아파트 하나하나를 순회하는 방식은 시간 초과가 나기 쉽다. 대신 이미 설치된 stations 배열(최대 1만 개)만 순회하면서, 기존 기지국들 사이에 전파가 닿지 않는 빈 구간을 찾아 그 길이만큼 몇 개의 기지국이 더 필요한지 계산한다.

기지국 하나는 `2W+1`칸을 커버할 수 있으므로, 빈 구간의 길이를 `2W+1`로 나눈 올림값이 그 구간에 필요한 기지국 수가 된다. `covered` 변수로 지금까지 커버된 마지막 위치를 추적하면서, 각 station의 커버 시작 위치와 비교해 빈 구간이 있는지 판단하고, 배열을 다 순회한 뒤에는 마지막 station 이후 N까지 남은 구간도 같은 방식으로 처리한다.

## 풀이

```java
public int solution(int n, int[] stations, int w) {
    int res = 0;
    int covered = 0;
    int range = 2 * w + 1;
    for (int station : stations) {
        int start = station - w;
        if (start > covered + 1) res += (start - covered - 2) / range + 1;
        covered = station + w;
    }
    if (n > covered) res += (n - covered - 1) / range + 1;
    return res;
}
```
