## 문제

> 링크: [프로그래머스 42627](https://school.programmers.co.kr/learn/courses/30/lessons/42627)

디스크 컨트롤러가 대기 중인 작업 중 소요시간이 가장 짧은 작업부터 처리할 때, 각 작업의 (완료 시각 - 요청 시각) 평균을 구한다.

## 접근

### 우선순위 큐 기반 SJF 시뮬레이션

작업을 요청시각 기준으로 정렬해두고, 현재 시각까지 요청이 들어온 작업들을 소요시간 기준 최소 힙에 담는다. 매 스텝마다 힙에서 소요시간이 가장 짧은 작업을 꺼내 처리하면, 처리 시각까지 요청된 작업들 중 항상 최단 작업을 선택하는 SJF(Shortest Job First) 스케줄링이 된다.

힙이 비어 있다면(현재 시각까지 요청된 작업이 없다면) 다음으로 요청될 작업의 시각으로 현재 시각을 점프시킨다.

## 풀이

```java
import java.util.Arrays;
import java.util.PriorityQueue;

public int solution(int[][] jobs) {
    int n = jobs.length;
    Arrays.sort(jobs, (a, b) -> a[0] - b[0]);
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] != b[1] ? a[1] - b[1] : a[0] - b[0]);

    int idx = 0;
    int time = 0;
    int total = 0;
    int done = 0;
    while (done < n) {
        while (idx < n && jobs[idx][0] <= time) {
            pq.add(jobs[idx]);
            idx++;
        }
        if (pq.isEmpty()) {
            time = jobs[idx][0];
            continue;
        }
        int[] job = pq.poll();
        time += job[1];
        total += time - job[0];
        done++;
    }
    return total / n;
}
```
