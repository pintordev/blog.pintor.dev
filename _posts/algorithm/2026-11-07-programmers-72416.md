## 문제

> 링크: [프로그래머스 72416](https://school.programmers.co.kr/learn/courses/30/lessons/72416)

CEO를 루트로 하는 조직도 트리에서 팀장과 직속 팀원으로 이루어진 모든 팀이 최소 1명씩 워크숍에 참석하도록 할 때, 참석자 매출액 합의 최솟값을 구하는 문제.

## 접근

### 참석 / 불참 2상태 트리 DP

`dp[v][1]`은 `v`가 참석할 때, `dp[v][0]`은 `v`가 불참할 때 `v`의 서브트리 안 모든 팀을 만족시키는 최소 매출액 합이다.

- 리프는 팀장이 아니므로 자기 팀 제약이 없다. `dp[v][1] = sales[v]`, `dp[v][0] = 0`이다.
- 팀장 노드는 자식마다 더 싼 쪽을 골라 더한 값을 `base`로 둔다.
  - `v`가 참석하면 팀 조건이 이미 충족되므로 `dp[v][1] = sales[v] + base`이다.
  - `v`가 불참하면 자식 중 최소 1명은 참석해야 한다. 이미 참석을 고른 자식이 있으면 추가 비용이 없고, 없으면 `dp[c][1] - dp[c][0]`이 가장 작은 자식 하나를 참석으로 바꾼다. 즉 `dp[v][0] = base + max(0, min(dp[c][1] - dp[c][0]))`이다.
- 정답은 `min(dp[1][0], dp[1][1])`이다.

### 재귀 없이 순회

직원이 최대 30만 명이고 일자형 트리도 가능하므로 재귀 DFS는 스택 오버플로 위험이 있다. 루트에서 BFS로 방문 순서를 기록한 뒤 역순으로 DP를 채우면 자식이 항상 부모보다 먼저 계산된다. 시간·공간 모두 O(n)이다.

각 노드의 최솟값은 전체 정답 이하이고, 참석과 불참의 차이는 많아야 `sales[v]`(최대 10,000)이므로 dp 값은 `int` 범위를 넘지 않는다.

## 풀이

```java
import java.util.*;

int n;
int[] sales;
List<Integer>[] children;
int[][] dp;

public int solution(int[] sales, int[][] links) {
    n = sales.length;
    this.sales = sales;
    children = new List[n + 1];
    dp = new int[n + 1][2];
    for (int i = 1; i <= n; i++) {
        children[i] = new ArrayList<>();
    }
    for (int[] link : links) {
        children[link[0]].add(link[1]);
    }
    int[] order = bfs();
    for (int i = n - 1; i >= 0; i--) {
        calc(order[i]);
    }
    return Math.min(dp[1][0], dp[1][1]);
}

public int[] bfs() {
    int[] order = new int[n];
    int idx = 0;
    Queue<Integer> q = new ArrayDeque<>();
    q.add(1);
    while (!q.isEmpty()) {
        int u = q.poll();
        order[idx++] = u;
        for (int v : children[u]) {
            q.add(v);
        }
    }
    return order;
}

public void calc(int v) {
    dp[v][1] = sales[v - 1];
    if (children[v].isEmpty()) return;
    int base = 0;
    int extra = Integer.MAX_VALUE;
    for (int c : children[v]) {
        base += Math.min(dp[c][0], dp[c][1]);
        extra = Math.min(extra, dp[c][1] - dp[c][0]);
    }
    dp[v][1] += base;
    dp[v][0] = base + Math.max(0, extra);
}
```
