## 문제

> 링크: [프로그래머스 42587](https://school.programmers.co.kr/learn/courses/30/lessons/42587)

우선순위 큐 방식으로 프로세스를 실행할 때, 특정 프로세스가 몇 번째로 실행되는지 구하는 문제.

## 접근

### 큐 + 우선순위 큐 분리

큐(`ArrayDeque`)로 프로세스 순서를 유지하고, 별도의 `PriorityQueue`(내림차순)로 현재 최대 우선순위를 추적한다.

큐 맨 앞 프로세스의 우선순위가 현재 최대값과 같으면 실행하고, 아니면 큐 뒤로 다시 넣는다. 실행할 때마다 `pq`에서도 해당 우선순위를 제거하여 최대값을 갱신한다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Comparator;
import java.util.PriorityQueue;
import java.util.Queue;

public int solution(int[] priorities, int location) {
    Queue<Process> q = new ArrayDeque<>();
    PriorityQueue<Integer> pq = new PriorityQueue<>(Comparator.reverseOrder());
    for (int i = 0; i < priorities.length; i++) {
        q.add(new Process(i, priorities[i]));
        pq.add(priorities[i]);
    }

    int order = 0;
    while (!q.isEmpty()) {
        Process curr = q.poll();
        if (pq.peek() != curr.priority) q.add(curr);
        else {
            pq.poll();
            order++;
            if (curr.location == location) return order;
        }
    }
    return order;
}

class Process {
    int location;
    int priority;

    public Process(int location, int priority) {
        this.location = location;
        this.priority = priority;
    }
}
```
