## 문제

> 링크: [프로그래머스 92345](https://school.programmers.co.kr/learn/courses/30/lessons/92345)

발판이 있는 칸으로만 번갈아 이동하고 떠난 발판은 사라지는 게임에서, 두 플레이어가 최적으로 플레이할 때의 총 이동 횟수를 구하는 문제.

## 접근

### Minimax DFS + 백트래킹

보드가 최대 5×5이고 이동할 때마다 발판이 하나씩 사라지므로 게임은 최대 25수를 넘지 못한다. 상태 공간이 작아 메모이제이션 없이 완전탐색으로 풀 수 있다.

`dfs(ar, ac, br, bc)`는 현재 턴 플레이어가 (ar, ac), 상대가 (br, bc)에 있을 때 앞으로 진행될 이동 횟수를 반환한다. 재귀 호출마다 두 플레이어의 좌표를 바꿔 넘겨 항상 현재 턴 플레이어 기준으로 계산한다.

- 이동할 수 있는 칸이 없으면 패배이며 이동 횟수는 0이다.
- 두 캐릭터가 같은 발판에 있고 이동할 칸이 있으면, 이동하는 순간 상대의 발판이 사라지므로 즉시 승리이며 이동 횟수는 1이다.
- 그 외에는 현재 칸을 0으로 만들고 네 방향으로 재귀 호출한 뒤 복구한다. 반환값에 1을 더해 현재 플레이어의 이동 횟수로 환산한다.

승패는 반환값의 홀짝으로 판정한다. 현재 턴 플레이어가 이기면 마지막 수를 자신이 두므로 총 이동 횟수가 홀수이고, 지면 상대가 마지막 수를 두므로 짝수이다. 별도의 승패 값 없이 정수 하나로 승패와 횟수를 함께 표현할 수 있다.

최적 플레이는 다음과 같이 선택한다.

- 이길 수 있는 이동이 하나라도 있으면 승리이며, 그중 이동 횟수가 최소인 것을 고른다.
- 모든 이동이 패배로 이어지면 패배이며, 그중 이동 횟수가 최대인 것을 고른다.

시간복잡도는 상한 기준 약 O(3^25)이지만, 발판이 사라지는 구조라 실제 탐색량은 훨씬 적다. 공간복잡도는 재귀 깊이 기준 O(25)이다.

## 풀이

```java
int[][] board;
int n;
int m;
int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};

public int solution(int[][] board, int[] aloc, int[] bloc) {
    this.board = board;
    n = board.length;
    m = board[0].length;
    return dfs(aloc[0], aloc[1], bloc[0], bloc[1]);
}

public int dfs(int ar, int ac, int br, int bc) {
    int win = Integer.MAX_VALUE;
    int lose = 0;
    for (int d = 0; d < 4; d++) {
        int nr = ar + dr[d];
        int nc = ac + dc[d];
        if (nr < 0 || nr >= n || nc < 0 || nc >= m || board[nr][nc] == 0) continue;
        if (ar == br && ac == bc) return 1;
        board[ar][ac] = 0;
        int res = dfs(br, bc, nr, nc) + 1;
        board[ar][ac] = 1;
        if (res % 2 == 1) win = Math.min(win, res);
        else lose = Math.max(lose, res);
    }
    return win == Integer.MAX_VALUE ? lose : win;
}
```
