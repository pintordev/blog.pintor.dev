## 문제

> 링크: [프로그래머스 258709](https://school.programmers.co.kr/learn/courses/30/lessons/258709)

n개의 주사위를 A와 B가 절반씩 나눠 가진 뒤 각자 굴려 나온 눈의 합으로 승부를 겨룰 때, A의 승리 확률이 가장 높아지는 주사위 조합을 구하는 문제.

## 접근

### 조합 완전탐색 + 합 분포 비교

n ≤ 10이라 A가 고를 수 있는 조합은 최대 nC(n/2) = 252가지뿐이고, 조합 하나당 주사위 개수(m = n/2)도 최대 5개라 각 조합이 만들 수 있는 합의 가짓수도 최대 6^5 = 7776개로 작다. 승리 확률을 직접 계산하지 않아도 A와 B 모두 항상 같은 경우의 수(6^m × 6^m)를 갖기 때문에 분모가 동일해서, 승리 확률 대신 "A가 이기는 경우의 수"만 비교하면 충분하다.

각 조합마다 A 그룹과 B 그룹이 만들 수 있는 합을 전부 나열하고, B 그룹의 합을 값별 빈도 배열로 만든 뒤 누적합을 구해두면 A의 각 합에 대해 "B보다 작은 경우의 수"를 O(1)에 조회할 수 있다. 이렇게 구한 승수가 가장 큰 조합을 선택한다.

## 풀이

```java
import java.util.ArrayList;
import java.util.List;

int[][] dice;

public int[] solution(int[][] dice) {
    this.dice = dice;
    int n = dice.length;
    int m = n >> 1;
    int bestMask = 0;
    int bestWins = -1;
    for (int mask = 0; mask < (1 << n); mask++) {
        if (Integer.bitCount(mask) != m) continue;
        List<Integer> indicesA = new ArrayList<>();
        List<Integer> indicesB = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) indicesA.add(i);
            else indicesB.add(i);
        }
        int wins = countWins(possibleSums(indicesA), possibleSums(indicesB));
        if (wins > bestWins) {
            bestWins = wins;
            bestMask = mask;
        }
    }
    List<Integer> result = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        if ((bestMask & (1 << i)) != 0) result.add(i + 1);
    }
    int[] res = new int[result.size()];
    for (int i = 0; i < res.length; i++) {
        res[i] = result.get(i);
    }
    return res;
}

public List<Integer> possibleSums(List<Integer> indices) {
    List<Integer> sums = new ArrayList<>();
    collectSums(indices, 0, 0, sums);
    return sums;
}

public void collectSums(List<Integer> indices, int depth, int sum, List<Integer> sums) {
    if (depth == indices.size()) {
        sums.add(sum);
        return;
    }
    int die = indices.get(depth);
    for (int face : dice[die]) {
        collectSums(indices, depth + 1, sum + face, sums);
    }
}

public int countWins(List<Integer> sumsA, List<Integer> sumsB) {
    int maxSum = 500;
    int[] freqB = new int[maxSum + 2];
    for (int sum : sumsB) {
        freqB[sum]++;
    }
    int[] cumulative = new int[maxSum + 2];
    for (int v = 1; v <= maxSum + 1; v++) {
        cumulative[v] = cumulative[v - 1] + freqB[v - 1];
    }
    int wins = 0;
    for (int sum : sumsA) {
        wins += cumulative[sum];
    }
    return wins;
}
```
