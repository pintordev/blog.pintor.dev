## 문제

> 링크: [프로그래머스 468381](https://school.programmers.co.kr/learn/courses/30/lessons/468381)

격자의 빈칸에 선로를 놓아, (1, 1)에서 오른쪽으로 출발한 기차가 (n, m)에 도착하면서 이미 놓인 모든 선로를 지나가고 3번 선로는 상하좌우가 모두 연결되도록 만드는 방법의 수를 구하는 문제.

## 접근

### 기차가 가는 대로 선로를 놓는 백트래킹

선로는 7종류이고 각각 연결되는 방향이 정해져 있다. 1번은 좌우, 2번은 상하, 3번은 상하좌우, 4~7번은 두 방향이 이어지는 곡선이다. 기차는 (1, 1)에서 오른쪽으로 출발하며, 칸의 선로와 진입 방향이 정해지면 나가는 방향도 하나로 정해진다. 그래서 격자 전체를 채워 보는 대신 기차가 움직이는 대로 빈칸에 놓을 선로를 하나씩 고르는 DFS로 경로를 만든다. 지나간 빈칸에만 선로가 놓이고 나머지는 비워 두므로, 경로 하나가 곧 배치 하나이고 경로의 수가 답이다.

- 방향은 비트로 표현한다. 상 1, 우 2, 하 4, 좌 8로 두고 선로마다 연결 방향의 비트합을 `conn`에 저장한다. 진입 방향 `d`로 들어오면 반대 방향 `(d + 2) % 4`가 선로에 연결되어 있어야 하고, 나가는 방향은 나머지 연결 방향이다.
- 선로 이동은 되돌릴 수 있는 규칙이라, 일반 선로를 두 번 지나는 경로는 되돌아가는 경로뿐이고 이 경로는 도착하지 못한다. 따라서 일반 칸은 한 번만 방문하면 된다.
- 3번 선로만 가로와 세로로 한 번씩 총 두 번 지날 수 있다. 방문 상태 `seen`에 가로 1, 세로 2 비트를 두고, 같은 축으로 다시 들어오면 가지치기한다.
- 도착 칸은 1번 또는 2번이고 이 칸에서 나가면 격자 밖이므로, 도착 칸에 정상 진입했다면 그 자리에서 종료 조건을 판정한다. 다른 칸에서 격자 밖으로 나가거나 장애물을 만나면 실패다.
- 종료 조건은 모든 선로를 지났는지다. 아직 지나야 하는 횟수를 `need`로 센다. 미리 놓인 선로는 칸마다 1로 세고, 빈칸에 3번을 새로 놓으면 반대 축을 한 번 더 지나야 하므로 1을 더한다. 도착했을 때 `need`가 0이면 1을 센다.

빈칸마다 선택지가 많아야 4가지이고 자기 회피 경로만 탐색하므로, n × m ≤ 20 제한에서 충분히 빠르다. 공간은 방문 배열과 재귀 깊이로 O(n × m)이다.

## 풀이

```java
int[] dr = {-1, 0, 1, 0};
int[] dc = {0, 1, 0, -1};
int[] conn = {0, 10, 5, 15, 9, 3, 6, 12};
int[][] grid;
int[][] seen;
int n;
int m;
int need;

public int solution(int[][] grid) {
    this.grid = grid;
    n = grid.length;
    m = grid[0].length;
    seen = new int[n][m];
    need = 0;
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < m; c++) {
            if (grid[r][c] > 0) need++;
        }
    }
    return go(0, 0, 1);
}

public int go(int r, int c, int d) {
    if (r < 0 || r >= n || c < 0 || c >= m || grid[r][c] < 0) return 0;
    if (grid[r][c] > 0) return step(r, c, d, grid[r][c]);
    int res = 0;
    need++;
    for (int k = 1; k <= 7; k++) {
        grid[r][c] = k;
        res += step(r, c, d, k);
    }
    grid[r][c] = 0;
    need--;
    return res;
}

public int step(int r, int c, int d, int t) {
    if ((conn[t] >> (d + 2) % 4 & 1) == 0) return 0;
    int prior = seen[r][c];
    int axis = t == 3 && d % 2 == 0 ? 2 : 1;
    if ((prior & axis) != 0) return 0;
    int e = t == 3 ? d : Integer.numberOfTrailingZeros(conn[t] & ~(1 << (d + 2) % 4));
    int delta = t == 3 && prior == 0 ? 0 : 1;
    seen[r][c] = prior | axis;
    need -= delta;
    int res = r == n - 1 && c == m - 1 ? (need == 0 ? 1 : 0) : go(r + dr[e], c + dc[e], e);
    need += delta;
    seen[r][c] = prior;
    return res;
}
```
