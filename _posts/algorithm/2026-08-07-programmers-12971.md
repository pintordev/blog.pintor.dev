## 문제

> 링크: [프로그래머스 12971](https://school.programmers.co.kr/learn/courses/30/lessons/12971)

N개의 스티커가 원형으로 연결되어 있고, 스티커 한 장을 뜯으면 양쪽으로 인접한 스티커는 사용할 수 없을 때, 뜯어낸 스티커 숫자 합의 최댓값을 구하는 문제다.

## 접근

### 원형 배열 분할 + 선형 DP (House Robber 변형)

인접한 원소를 동시에 고를 수 없다는 조건은 전형적인 "집 도둑" DP 패턴이다. `dp[i] = max(dp[i-1], dp[i-2] + a[i])` 형태로 인접하지 않게 선택했을 때의 최댓값을 구할 수 있다. 다만 이 문제는 배열이 원형이라 `sticker[0]`과 `sticker[N-1]`을 동시에 선택할 수 없다는 제약이 하나 더 붙는다.

이를 해결하기 위해 원형 제약을 두 개의 선형 부분 문제로 나눈다.

- `sticker[0]`을 포함할 수 있되 `sticker[N-1]`은 제외하는 경우 → 구간 `[0, N-2]`에서 선형 DP
- `sticker[0]`을 제외하되 `sticker[N-1]`은 포함할 수 있는 경우 → 구간 `[1, N-1]`에서 선형 DP

두 경우 각각 선형 DP를 돌리고 더 큰 값을 최종 답으로 취한다. dp 배열 전체를 저장하지 않고 직전 두 값만 변수로 유지하면 O(1) 공간에 계산할 수 있다.

`N = 1`인 경우는 구간을 나누면 한쪽이 비므로 별도로 처리한다.

## 풀이

```java
public int solution(int[] sticker) {
    int n = sticker.length;
    if (n == 1) return sticker[0];
    return Math.max(maxSum(sticker, 0, n - 2), maxSum(sticker, 1, n - 1));
}

private int maxSum(int[] sticker, int start, int end) {
    int prev2 = 0, prev1 = 0;
    for (int i = start; i <= end; i++) {
        int cur = Math.max(prev1, prev2 + sticker[i]);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

## 회고

처음에는 `N = 1`, `N = 2`를 모두 별도 분기로 처리했는데, `maxSum` 헬퍼가 단일 원소 구간(`start == end`)도 자연스럽게 처리한다는 걸 뒤늦게 확인하고 `N = 2` 분기를 제거했다. 헬퍼 함수가 처리 가능한 범위를 미리 점검하면 불필요한 분기를 줄일 수 있다는 걸 다시 느꼈다.
