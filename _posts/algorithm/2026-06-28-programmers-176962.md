## 문제

> 링크: [프로그래머스 176962](https://school.programmers.co.kr/learn/courses/30/lessons/176962)

시작 시각이 정해진 과제들을 규칙에 따라 진행할 때, 완료되는 순서를 반환하는 문제.

## 접근

### 스택 시뮬레이션

`plans`를 시작 시각 기준으로 정렬한 뒤 순서대로 순회한다. 각 이터레이션에서 이전 과제 시작 시각과의 차이(`remain`)를 계산하고, 스택에 쌓인 중단된 과제들을 `remain`만큼 소진한다. 현재 과제는 항상 스택에 push하고, 모든 순회가 끝나면 스택에 남은 과제를 차례로 꺼내 결과에 추가한다.

스택 항목은 `int[] {sortedIndex, remainingPlaytime}`으로 관리한다. 인덱스로 `plans[i][0]`(이름)을 참조하고, 남은 시간은 소진 과정에서 직접 수정한다.

## 풀이

```java
import java.util.Arrays;
import java.util.ArrayDeque;
import java.util.Comparator;
import java.util.Deque;

public String[] solution(String[][] plans) {
    Arrays.sort(plans, Comparator.comparing(o -> o[1]));
    Deque<int[]> stack = new ArrayDeque<>();
    String[] res = new String[plans.length];
    int min = toMin(plans[0][1]), idx = 0, rdx = 0;
    for (String[] plan : plans) {
        int temp = toMin(plan[1]);
        int remain = temp - min;
        min = temp;
        while (!stack.isEmpty()) {
            int[] now = stack.pop();
            if (remain >= now[1]) {
                remain -= now[1];
                res[rdx++] = plans[now[0]][0];
            } else {
                now[1] -= remain;
                stack.push(now);
                break;
            }
        }
        stack.push(new int[]{idx++, Integer.parseInt(plan[2])});
    }
    while (!stack.isEmpty()) {
        res[rdx++] = plans[stack.pop()[0]][0];
    }
    return res;
}

public int toMin(String s) {
    String[] t = s.split(":");
    return Integer.parseInt(t[0]) * 60 + Integer.parseInt(t[1]);
}
```
