## 문제

> 링크: [프로그래머스 68936](https://school.programmers.co.kr/learn/courses/30/lessons/68936)

0과 1로 이루어진 2^n × 2^n 배열을 쿼드트리 방식으로 압축한 뒤, 남아 있는 0과 1의 개수를 반환한다.

## 접근

### 재귀 분할정복

현재 영역의 모든 값이 동일하면 해당 값 1개로 압축하고, 다르면 4등분하여 재귀적으로 압축한다.

`compress(row, col, size)`에서 영역을 순회하다 불일치 값이 발견되면 즉시 4분할 재귀로 전환하고 `return`한다. 끝까지 불일치가 없으면 `counts[val]++`로 해당 값을 카운트한다.

인스턴스 필드로 `arr`와 `counts`를 공유해 `compress` 시그니처를 `(row, col, size)` 3개로 유지했다.

## 풀이

```java
int[][] arr;
int[] counts;

public int[] solution(int[][] arr) {
    this.arr = arr;
    counts = new int[2];
    compress(0, 0, arr.length);
    return counts;
}

public void compress(int row, int col, int size) {
    int val = arr[row][col];
    for (int r = row; r < row + size; r++) {
        for (int c = col; c < col + size; c++) {
            if (arr[r][c] == val) continue;
            int half = size >> 1;
            compress(row, col, half);
            compress(row, col + half, half);
            compress(row + half, col, half);
            compress(row + half, col + half, half);
            return;
        }
    }
    counts[val]++;
}
```
