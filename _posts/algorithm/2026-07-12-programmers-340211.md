## 문제

> 링크: [프로그래머스 340211](https://school.programmers.co.kr/learn/courses/30/lessons/340211)

n개의 포인트가 있는 물류 센터에서 여러 로봇이 정해진 경로를 따라 동시에 출발해 이동할 때, 같은 시각에 같은 좌표에 2대 이상의 로봇이 모이는 "위험 상황"이 몇 번 발생하는지 구하는 문제다.

## 접근

### 시각별 좌표를 키로 묶어 위험 상황 세기

로봇은 다음 포인트로 이동할 때 r좌표를 먼저 목표 값까지 전부 옮기고, 그다음 c좌표를 옮긴다는 규칙이 주어진다. 이 규칙을 그대로 시뮬레이션하면 각 로봇이 매 초(t)마다 어떤 좌표에 있는지 순서대로 얻을 수 있다.

모든 로봇의 이동을 시각별 좌표로 펼친 뒤, `(시각, r, c)`를 하나의 정수로 인코딩해 맵에 등장 횟수를 누적한다. r, c는 최대 100이라 8비트(0~255) 안에 들어가고, t는 최대 약 19,602라 16비트 이상 시프트해도 겹치지 않으므로 `(t << 16) | (r << 8) | c` 형태로 충돌 없이 패킹할 수 있다.

로봇이 마지막 포인트에 도착하면 그 시점 이후로는 좌표를 더 기록하지 않는다. 센터를 벗어난 로봇이기 때문이다. 모든 로봇의 기록이 끝나면, 값이 2 이상인 키의 개수가 곧 위험 상황의 총 횟수다. 몇 대가 겹치든 같은 시각·좌표 조합은 1회로만 센다.

## 풀이

```java
import java.util.HashMap;
import java.util.Map;

Map<Integer, Integer> cnts;

public int solution(int[][] points, int[][] routes) {
    cnts = new HashMap<>();
    for (int[] route : routes) {
        int[] p = points[route[0] - 1].clone();
        int t = 0;
        mark(t, p[0], p[1]);
        for (int i = 1; i < route.length; i++) {
            int[] to = points[route[i] - 1];
            t = move(t, p, 0, to[0]);
            t = move(t, p, 1, to[1]);
        }
    }
    int risk = 0;
    for (int cnt : cnts.values()) {
        if (cnt >= 2) risk++;
    }
    return risk;
}

public int move(int t, int[] p, int d, int to) {
    int ds = Integer.compare(to, p[d]);
    while (p[d] != to) {
        p[d] += ds;
        t++;
        mark(t, p[0], p[1]);
    }
    return t;
}

public void mark(int t, int r, int c) {
    int key = (t << 16) | (r << 8) | c;
    cnts.merge(key, 1, Integer::sum);
}
```
