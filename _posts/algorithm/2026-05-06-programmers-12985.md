## 문제

> 링크: [프로그래머스 12985](https://school.programmers.co.kr/learn/courses/30/lessons/12985)

N명이 참가하는 토너먼트에서 A번과 B번 참가자가 처음 만나는 라운드를 반환하라.

## 접근

토너먼트 대진표는 이진 트리 구조다. 두 선수가 만나는 라운드 = 두 인덱스가 처음으로 같은 부모 노드를 갖는 레벨이다.

### 시뮬레이션

처음에만 0-indexed로 변환(`-1`)하고, 이후엔 `>> 1`만 반복한다.

```java
int count = 0;
a--; b--;
while (a != b) {
    a >>= 1;
    b >>= 1;
    count++;
}
return count;
```

**예시** `A=4, B=7` → `a=3(011), b=6(110)`

| 라운드 | a | b |
|--------|---|---|
| 1 | 1 (01) | 3 (11) |
| 2 | 0 (0) | 1 (1) |
| 3 | 0 | 0 → 동일 |

### 이진 트리 구조 + 비트 연산

두 값의 XOR은 서로 다른 비트만 1로 표시한다. XOR의 최상위 비트 위치가 두 선수가 처음 갈라지는 트리 레벨이므로, 이진수 길이가 곧 만나는 라운드가 된다.

**예시** `a-1=3(011), b-1=6(110)` → XOR = `101` → 이진수 길이 **3**

## 풀이

```java
public int solution(int n, int a, int b) {
    return Integer.toBinaryString((a - 1) ^ (b - 1)).length();
}
```

## 회고

토너먼트 구조를 이진 트리로 보면 두 선수가 만나는 라운드 = 0-indexed XOR의 최상위 비트 위치. `Integer.toBinaryString().length()`가 그 값을 바로 반환하므로 루프 없이 한 줄로 끝난다. 이진 트리 + 비트 연산의 연결고리를 기억해두자.
