## 문제

> 링크: [프로그래머스 43164](https://school.programmers.co.kr/learn/courses/30/lessons/43164)

ICN에서 출발해 주어진 항공권을 모두 사용하면서 알파벳 순으로 가장 앞서는 여행 경로를 구한다.

## 접근

### Hierholzer's Algorithm

모든 간선을 정확히 한 번씩 사용해서 경로를 완성해야 하므로 오일러 경로(Eulerian path) 문제다. 단순히 사전순으로 가장 앞선 목적지를 그리디하게 골라 DFS를 진행하면, 나중에 반드시 방문해야 할 간선을 앞에서 먼저 소비해버려 막다른 길에 도달할 수 있다.

Hierholzer's algorithm은 이 문제를 스택 기반으로 해결한다. 현재 정점에서 아직 사용하지 않은 간선이 있으면 그 간선을 따라 계속 진행하고, 더 이상 나갈 간선이 없을 때 비로소 해당 정점을 결과 경로에 추가한다. 이렇게 하면 막다른 길에 몰렸던 정점도 뒤늦게 다른 경로를 통해 마저 방문한 뒤에 결과에 들어가므로, 백트래킹 없이도 모든 간선을 사용한 경로가 완성된다.

출발지별 목적지를 `PriorityQueue`로 관리해 사전순으로 먼저 꺼내도록 하면, 완성된 경로 역시 자동으로 사전순으로 가장 앞서는 경로가 된다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;
import java.util.PriorityQueue;

public String[] solution(String[][] tickets) {
    Map<String, PriorityQueue<String>> graph = new HashMap<>();
    for (String[] ticket : tickets) {
        PriorityQueue<String> destinations = graph.get(ticket[0]);
        if (destinations == null) {
            destinations = new PriorityQueue<>();
            graph.put(ticket[0], destinations);
        }
        destinations.add(ticket[1]);
    }

    Deque<String> stack = new ArrayDeque<>();
    Deque<String> route = new ArrayDeque<>();
    stack.push("ICN");
    while (!stack.isEmpty()) {
        String airport = stack.peek();
        PriorityQueue<String> destinations = graph.get(airport);
        if (destinations == null || destinations.isEmpty()) route.push(stack.pop());
        else stack.push(destinations.poll());
    }
    return route.toArray(new String[0]);
}
```

간선이 남아있는 동안은 스택에 계속 push하고, 더 갈 곳이 없어진 정점만 `route`에 push한다. `route`는 push(=addFirst)로 쌓기 때문에 별도로 뒤집는 과정 없이 `toArray()` 결과가 그대로 최종 경로 순서가 된다.
