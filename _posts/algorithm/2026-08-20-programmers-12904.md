## 문제

> 링크: [프로그래머스 12904](https://school.programmers.co.kr/learn/courses/30/lessons/12904)

문자열 s가 주어질 때, s의 부분문자열 중 가장 긴 팰린드롬의 길이를 구한다.

## 접근

### 중심 확장 (Expand Around Center)

모든 부분문자열을 하나씩 팰린드롬인지 검사하는 방식은 O(n³)이라 문자열 길이가 최대 2,500인 조건에서는 시간 초과 위험이 크다.

팰린드롬은 항상 어떤 중심을 기준으로 좌우 대칭이라는 성질을 이용한다. 문자 하나를 중심으로 하는 홀수 길이 팰린드롬과, 문자 사이를 중심으로 하는 짝수 길이 팰린드롬 두 경우를 모두 고려해 각 위치에서 좌우로 확장하며 일치 여부를 검사한다. 문자열의 모든 위치를 중심 후보로 순회하므로 O(n²)에 해결할 수 있고, 별도의 테이블이 필요 없어 공간복잡도도 O(1)로 유지된다.

## 풀이

```java
public int solution(String s) {
    int res = 1;
    for (int c = 0; c < s.length(); c++) {
        res = Math.max(res, expand(s, c, c));
        res = Math.max(res, expand(s, c, c + 1));
    }
    return res;
}

public int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        l--;
        r++;
    }
    return r - l - 1;
}
```
