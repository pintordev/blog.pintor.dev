## 문제

> 링크: [백준 1149](https://www.acmicpc.net/problem/1149)

N개의 집을 빨강, 초록, 파랑 중 하나로 칠한다. 인접한 집은 같은 색을 사용할 수 없을 때, 전체 비용의 최솟값을 구한다.

## 접근

### DP

`dp[i][c]`를 i번째 집을 색 c로 칠했을 때의 최소 누적 비용으로 정의한다.

- 인접한 집은 다른 색이어야 하므로 i번째 집의 비용은 i-1번째 집에서 **다른 두 색의 최솟값**을 더한 값이다.

```
dp[i][0] = cost[i][0] + min(dp[i-1][1], dp[i-1][2])
dp[i][1] = cost[i][1] + min(dp[i-1][0], dp[i-1][2])
dp[i][2] = cost[i][2] + min(dp[i-1][0], dp[i-1][1])
```

이전 행만 참조하므로 배열 전체를 유지할 필요 없이 이전 행만 갱신하면 된다.

## 풀이

```java
import java.io.IOException;

public class Solution {
    public static void main(String[] args) throws IOException {
        int n = read();
        int[][] dp = new int[n][3];
        for (int i = 0; i < 3; i++) {
            dp[0][i] = read();
        }

        for (int i = 1; i < n; i++) {
            dp[i][0] = read() + Math.min(dp[i - 1][1], dp[i - 1][2]);
            dp[i][1] = read() + Math.min(dp[i - 1][0], dp[i - 1][2]);
            dp[i][2] = read() + Math.min(dp[i - 1][0], dp[i - 1][1]);
        }

        System.out.println(Math.min(dp[n - 1][0], Math.min(dp[n - 1][1], dp[n - 1][2])));
    }

    private static int read() throws IOException {
        int c, n = System.in.read() & 15;
        boolean negative = n == 13;
        if (negative) n = System.in.read() & 15;
        while ((c = System.in.read()) > 32) {
            n = (n << 3) + (n << 1) + (c & 15);
        }
        return negative ? ~n + 1 : n;
    }
}
```
