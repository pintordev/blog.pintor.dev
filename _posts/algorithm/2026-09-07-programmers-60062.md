## 문제

> 링크: [프로그래머스 60062](https://school.programmers.co.kr/learn/courses/30/lessons/60062)

둘레가 `n`인 원형 외벽의 취약 지점 `weak`을 모두 점검하기 위해, 이동 거리 `dist`가 제각각인 친구들 중 최소 몇 명을 투입해야 하는지 구한다. 전원 투입해도 전부 점검할 수 없으면 `-1`.

## 접근

### 원형 → 선형 전개 + 순열 완전탐색

제한이 작다. `weak`의 길이는 최대 15, `dist`의 길이는 최대 8이다. 친구를 어떤 순서로 배치하느냐가 결과를 좌우하므로 `dist`의 모든 순열(최대 8! = 40320)을 완전탐색해도 충분하다.

원형을 다루기 까다로우니 선형으로 편다. `weak`을 두 배로 이어 붙여 뒤쪽 절반에 `+n`을 더한 `extended` 배열을 만든다. 그러면 "어떤 취약 지점에서 출발해 시계 방향으로 훑는다"를 연속 구간으로 표현할 수 있다.

- 첫 친구의 출발점은 취약 지점으로 한정해도 된다. 취약 지점이 아닌 곳에서 출발하면 이동 거리만 낭비된다. 후보는 `weak.length`개.
- 반시계 방향은 "다른 취약 지점에서 출발하는 시계 방향"과 대칭이므로, 모든 출발점을 훑으면 시계 방향만 봐도 된다.

각 (순열, 출발점) 조합마다 친구를 순서대로 투입한다. 현재 친구가 커버하는 오른쪽 끝을 `covered`로 두고, 그 범위를 벗어나는 취약 지점을 만나면 다음 친구를 새로 투입해 `covered`를 갱신한다. 친구를 다 썼는데도 남는 취약 지점이 있으면 실패로 처리한다. 모든 조합에서 나온 투입 인원의 최솟값이 답이고, 끝까지 실패면 `-1`.

시간복잡도는 `O(weak.length · dist.length! · weak.length)`로 약 `15 × 8! × 15 ≈ 9.1 × 10^6`. 여유롭게 통과한다.

## 풀이

```java
int[] weak;
int[] dist;
int[] extended;
int minFriends;

public int solution(int n, int[] weak, int[] dist) {
    this.weak = weak;
    this.dist = dist;
    extended = new int[weak.length * 2];
    for (int i = 0; i < weak.length; i++) {
        extended[i] = weak[i];
        extended[i + weak.length] = weak[i] + n;
    }
    minFriends = dist.length + 1;
    permute(0);
    return minFriends > dist.length ? -1 : minFriends;
}

public void permute(int depth) {
    if (depth == dist.length) {
        for (int start = 0; start < weak.length; start++) {
            minFriends = Math.min(minFriends, countFrom(start));
        }
        return;
    }
    for (int i = depth; i < dist.length; i++) {
        swap(depth, i);
        permute(depth + 1);
        swap(depth, i);
    }
}

public int countFrom(int start) {
    int used = 1;
    int covered = extended[start] + dist[0];
    for (int i = start + 1; i < start + weak.length; i++) {
        if (extended[i] <= covered) continue;
        if (used == dist.length) return dist.length + 1;
        covered = extended[i] + dist[used];
        used++;
    }
    return used;
}

public void swap(int a, int b) {
    int tmp = dist[a];
    dist[a] = dist[b];
    dist[b] = tmp;
}
```
