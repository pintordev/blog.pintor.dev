## 문제

> 링크: [백준 1167](https://www.acmicpc.net/problem/1167)

트리의 지름, 즉 트리에서 임의의 두 점 사이의 거리 중 가장 긴 것을 구한다.

## 접근

### DFS 두 번

트리의 지름은 아래 성질을 이용해 DFS 두 번으로 구할 수 있다.

1. 임의의 노드에서 DFS → 가장 먼 노드 `u` 탐색
2. `u`에서 DFS → 가장 먼 노드까지의 거리 = 트리의 지름

재귀 대신 스택을 이용한 반복 DFS로 구현했다. 부모 노드를 `Node`에 함께 저장해 역방향 탐색을 방지한다.

## 풀이

```java
import java.io.IOException;
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

public class Solution {
    public static List<Edge>[] graph;

    public static void main(String[] args) throws IOException {
        init();
        System.out.println(dfs(dfs(1)[0])[1]);
    }

    private static void init() throws IOException {
        int v = read();

        graph = new ArrayList[v + 1];
        while (v-- > 0) {
            int i = read();
            graph[i] = new ArrayList<>();
            int r;
            while ((r = read()) != -1) {
                graph[i].add(new Edge(r, read()));
            }
        }
    }

    // 반환: [가장 먼 노드, 최대 거리]
    private static int[] dfs(int start) {
        Deque<Node> stack = new ArrayDeque<>();
        stack.push(new Node(start, -1, 0));

        int farest = start;
        int maxDist = 0;
        while (!stack.isEmpty()) {
            Node cur = stack.pop();

            if (cur.dist > maxDist) {
                maxDist = cur.dist;
                farest = cur.me;
            }

            for (Edge edge : graph[cur.me]) {
                if (edge.to == cur.parent) continue;
                stack.push(new Node(edge.to, cur.me, cur.dist + edge.cost));
            }
        }

        return new int[]{farest, maxDist};
    }

    private static int read() throws IOException {
        int c, n = System.in.read() & 15;
        boolean negative = n == 13;
        if (negative) n = System.in.read() & 15;
        while ((c = System.in.read()) > 32) {
            n = (n << 3) + (n << 1) + (c & 15);
        }
        return negative ? ~n + 1 : n;
    }
}

class Edge {
    int to, cost;
    Edge(int to, int cost) { this.to = to; this.cost = cost; }
}

class Node {
    int me, parent, dist;
    Node(int me, int parent, int dist) {
        this.me = me; this.parent = parent; this.dist = dist;
    }
}
```
