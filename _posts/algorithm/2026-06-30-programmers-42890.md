## 문제

> 링크: [프로그래머스 42890](https://school.programmers.co.kr/learn/courses/30/lessons/42890)

릴레이션에서 유일성과 최소성을 동시에 만족하는 후보키의 개수를 구한다.

## 접근

### 비트마스크 브루트포스

컬럼 수가 최대 8이므로 모든 컬럼 부분집합을 비트마스크(1~2^C-1)로 열거하고, 각 부분집합에 대해 유일성과 최소성을 순서대로 검사한다.

**유일성**: 비트마스크의 켜진 비트에 해당하는 컬럼 값을 이어 붙인 문자열을 Set에 삽입하여, Set 크기가 전체 로우 수와 같으면 통과.

**최소성**: 이미 확정된 후보키 목록을 순회하며, 기존 후보키 비트마스크가 현재 비트마스크의 부분집합(`(mask & k) == k`)이면 탈락. 즉, 더 작은 후보키가 이미 존재하면 현재 집합은 최소가 아니다.

유일성을 먼저 걸러낸 뒤 최소성을 검사하면, 비트마스크를 오름차순으로 순회하는 특성상 작은 집합이 항상 먼저 처리되어 최소성 판정이 자연스럽게 성립한다.

## 풀이

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

int m;
String[][] relation;
List<Integer> candidates;

public int solution(String[][] relation) {
    m = relation[0].length;
    this.relation = relation;
    candidates = new ArrayList<>();
    for (int mask = 1; mask < (1 << m); mask++) {
        if (!isUnique(mask)) continue;
        if (!isMinimal(mask)) continue;
        candidates.add(mask);
    }
    return candidates.size();
}

public boolean isUnique(int mask) {
    Set<String> set = new HashSet<>();
    for (String[] row : relation) {
        StringBuilder sb = new StringBuilder();
        for (int c = 0; c < m; c++) {
            if ((mask & (1 << c)) != 0) sb.append(row[c]).append("|");
        }
        if (!set.add(sb.toString())) return false;
    }
    return true;
}

public boolean isMinimal(int mask) {
    for (int k : candidates) {
        if ((mask & k) == k) return false;
    }
    return true;
}
```
