## 문제

> 링크: [프로그래머스 42747](https://school.programmers.co.kr/learn/courses/30/lessons/42747)

n편의 논문 중 h번 이상 인용된 논문이 h편 이상인 h의 최댓값(H-Index)을 구하는 문제.

## 접근

### 정렬 후 뒤에서부터 카운트

인용 수를 오름차순 정렬하면, 뒤에서부터 순회할 때 인용 수가 높은 논문 순으로 확인할 수 있다.

변수 h를 0으로 초기화하고, 현재 논문의 인용 수가 h보다 크면 h를 1 증가시킨다. 이 방식은 다음 불변식을 유지한다.

> **순회 중 h = "지금까지 citations[i] > h 조건을 만족한 논문 수"**

즉, h번 이상 인용된 논문이 정확히 h편 존재함을 보장하므로, 순회가 끝난 h가 곧 H-Index다.

## 풀이

```java
import java.util.Arrays;

public int solution(int[] citations) {
    Arrays.sort(citations);
    int h = 0;
    for (int i = citations.length - 1; i >= 0; i--) {
        if (citations[i] > h) h++;
    }
    return h;
}
```

## 회고

`citations[i] > h`일 때만 h를 증가시키는 것이 핵심이다. 정렬된 배열에서 뒤에서 순회하면 h는 항상 "h번 초과 인용된 논문 수"를 의미하고, 새 논문의 인용 수가 h를 초과하면 그 논문도 h+1편 조건에 포함된다. 이분탐색 없이 O(n log n)에 처리된다.
