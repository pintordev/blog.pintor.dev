## 문제

> 링크: [프로그래머스 86053](https://school.programmers.co.kr/learn/courses/30/lessons/86053)

각 도시의 트럭으로 금 a kg과 은 b kg을 새 도시에 전달하는 데 걸리는 최소 시간을 구하는 문제.

## 접근

### 시간에 대한 이분 탐색

T시간 안에 전달이 가능하면 T보다 긴 시간에도 항상 가능하므로 답에 대해 이분 탐색을 할 수 있다. `can(T)`로 가능 여부를 판별하고 가능한 최소 시간을 찾는다.

도시 i의 트럭은 편도 t[i]시간이 걸리고 마지막 운반은 돌아올 필요가 없으므로, T시간 안에 `(T + t[i]) / (2 * t[i])`번 운반할 수 있다. 여기에 w[i]를 곱한 값이 도시 i가 나를 수 있는 최대 무게 cap이다. 금과 은은 한 트럭에 섞어 실을 수 있어서 cap은 둘이 공유한다.

도시마다 다음 세 값을 누적한다.

- 금: `min(g[i], cap)`
- 은: `min(s[i], cap)`
- 합계: `min(g[i] + s[i], cap)`

금의 합이 a 이상, 은의 합이 b 이상, 합계가 a + b 이상이면 가능하다. 합계 조건은 같은 cap을 금과 은에 중복해서 쓰는 경우를 막는다.

탐색 범위는 `lo = 0`(a + b > 0이면 불가능), `hi = (a + b) * 2 * 10^5`(도시 하나가 w = 1, t = 10^5로 전부 나르는 최악의 경우에도 가능)로 잡는다. 시간 복잡도는 O(N log(a + b))이다.

## 풀이

```java
int a;
int b;
int[] g;
int[] s;
int[] w;
int[] t;

public long solution(int a, int b, int[] g, int[] s, int[] w, int[] t) {
    this.a = a;
    this.b = b;
    this.g = g;
    this.s = s;
    this.w = w;
    this.t = t;
    long lo = 0;
    long hi = (a + b) * 2L * 100_000;
    while (lo + 1 < hi) {
        long mid = (lo + hi) >> 1;
        if (can(mid)) hi = mid;
        else lo = mid;
    }
    return hi;
}

public boolean can(long time) {
    long gold = 0;
    long silver = 0;
    long total = 0;
    for (int i = 0; i < g.length; i++) {
        long cap = (time + t[i]) / (2L * t[i]) * w[i];
        gold += Math.min(g[i], cap);
        silver += Math.min(s[i], cap);
        total += Math.min((long) g[i] + s[i], cap);
    }
    return gold >= a && silver >= b && total >= (long) a + b;
}
```
