## 문제

> 링크: [프로그래머스 42577](https://school.programmers.co.kr/learn/courses/30/lessons/42577)

한 번호가 다른 번호의 접두어인 경우가 있는지 확인하는 문제. 접두어 관계가 있으면 `false`, 없으면 `true`를 반환한다.

## 접근

### 정렬 + startsWith

정렬하면 접두어 관계인 번호들이 **반드시 인접하게** 위치한다.

```
["12", "123", "1235", "567", "88"]
→ 정렬 후: ["12", "123", "1235", "567", "88"]
→ 인접한 쌍만 비교: "12"가 "123"의 접두어 → false
```

전체 쌍을 비교할 필요 없이 인접한 쌍만 `startsWith`로 확인하면 O(N log N)으로 해결된다.

HashSet으로 부분 문자열을 잘라 조회하거나 Trie를 쓰는 방법도 있지만, N=1,000,000, L=20 조건에서 O(N×L)과 연산량이 비슷하면서 구현이 훨씬 단순하다.

## 풀이

```java
import java.util.Arrays;

public boolean solution(String[] phone_book) {
    Arrays.sort(phone_book);
    for (int i = 1; i < phone_book.length; i++) {
        if (phone_book[i].startsWith(phone_book[i - 1])) return false;
    }
    return true;
}
```

## 회고

정렬하면 접두어 관계인 번호가 인접하게 붙는다는 성질을 활용하면 인접 쌍만 비교하면 된다. O(N log N)이지만 이 문제의 최악 조건(N=1,000,000, L=20)에서 O(N×L)과 연산량이 엇비슷하게 수렴하고, 구현은 훨씬 단순하다.
