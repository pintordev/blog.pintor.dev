## 문제

> 링크: [백준 1074](https://www.acmicpc.net/problem/1074)

2^N × 2^N 배열을 Z자 순서로 재귀적으로 탐색할 때, (r, c)가 몇 번째로 방문되는지 출력한다.

## 접근

### 분할정복

격자를 4등분해서 (r, c)가 어느 사분면에 속하는지 판단하고, 해당 사분면의 오프셋을 누적하며 재귀한다.

```
┌─────────┬─────────┐
│  0번째  │  1번째  │
│ 사분면  │ 사분면  │
├─────────┼─────────┤
│  2번째  │  3번째  │
│ 사분면  │ 사분면  │
└─────────┴─────────┘
```

각 사분면의 크기는 `half × half` (= 4^(n-1))이므로, 재귀마다 해당 사분면 번호 × 사분면 크기를 더하면 된다. 재귀 깊이가 N이므로 시간복잡도는 O(N).

### 비트 연산

분할정복의 각 단계를 비트 연산으로 표현할 수 있다. 사분면 번호는 `(r_bit << 1) | c_bit`이고, 사분면 크기는 `4^i = 2^(2i)`이므로:

```
result += quadrant_number << (2 * i)
```

이는 r과 c의 비트를 상위 비트부터 교차 결합하는 것과 동일하다. ([Z-order curve / Morton code](https://en.wikipedia.org/wiki/Z-order_curve))

예시: n=2, r=3(11₂), c=1(01₂)
```
r[1] c[1] r[0] c[0]
 1    0    1    1   = 1011₂ = 11₁₀
```

## 풀이

```java
import java.io.IOException;

public class Solution {
    public static void main(String[] args) throws IOException {
        int n = read();
        int r = read();
        int c = read();

        System.out.println(solve(n, r, c));
    }

    // Divide and conquer: split the grid into 4 quadrants recursively.
    // Determine which quadrant (r, c) belongs to, add the quadrant offset, and recurse with adjusted coordinates.
    private static long solve(int n, int r, int c) {
        if (n == 0) return 0;
        int half = 1 << (n - 1);
        long subSquared = (long) half * half;
        if (r < half && c < half) return solve(n - 1, r, c);
        if (r < half) return subSquared + solve(n - 1, r, c - half);
        if (c < half) return 2 * subSquared + solve(n - 1, r - half, c);
        return 3 * subSquared + solve(n - 1, r - half, c - half);
    }

    // Bit manipulation: at each bit level i, the quadrant number is (r_bit << 1) | c_bit,
    // contributing quadrant_number * 4^i to the result. This is equivalent to interleaving bits of r and c.
    private static long solve(int n, int r, int c) {
        long result = 0;
        for (int i = n - 1; i >= 0; i--) {
            int rb = (r >> i) & 1;
            int cb = (c >> i) & 1;
            result += (long)(rb * 2 + cb) << (2 * i);
        }
        return result;
    }

    private static int read() throws IOException {
        int c, n = System.in.read() & 15;
        boolean negative = n == 13;
        if (negative) n = System.in.read() & 15;
        while ((c = System.in.read()) > 32) {
            n = (n << 3) + (n << 1) + (c & 15);
        }
        return negative ? ~n + 1 : n;
    }
}
```
