## 문제

> 링크: [프로그래머스 12927](https://school.programmers.co.kr/learn/courses/30/lessons/12927)

퇴근까지 남은 n시간과 각 일의 작업량 works가 주어질 때, n시간 동안 작업량을 1씩 줄여서 남은 작업량 제곱의 합(야근 지수)을 최소화한 값을 구한다.

## 접근

### 그리디 + 최대 힙

매 시간 가장 큰 작업량을 1씩 줄이는 것이 제곱합을 최소화하는 최적의 선택이다. 두 값 a, b(a > b)가 있을 때 큰 쪽을 줄이면 제곱합이 (a-1)² + b², 작은 쪽을 줄이면 a² + (b-1)²이 되는데, 전개해보면 항상 큰 쪽을 줄이는 쪽의 값이 더 작거나 같다.

이 최댓값을 매번 빠르게 찾고 갱신하기 위해 최대 힙(우선순위 큐)을 사용한다. n번 반복하며 힙에서 최댓값을 꺼내 1 줄인 뒤 다시 넣되, 최댓값이 이미 0이면 더 줄일 게 없으므로 즉시 멈춘다. 마지막으로 힙에 남은 값들의 제곱합을 구한다.

- 시간복잡도: O(min(n, sum(works)) log m) (m = works.length)
- 공간복잡도: O(m)

## 풀이

```java
import java.util.PriorityQueue;

public long solution(int n, int[] works) {
    PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> b - a);
    for (int w : works) pq.add(w);
    while (n-- > 0 && pq.peek() > 0) pq.add(pq.poll() - 1);
    long fatigue = 0;
    while (!pq.isEmpty()) fatigue += (long) pq.peek() * pq.poll();
    return fatigue;
}
```
