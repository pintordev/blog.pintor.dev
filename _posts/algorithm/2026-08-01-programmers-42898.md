## 문제

> 링크: [프로그래머스 42898](https://school.programmers.co.kr/learn/courses/30/lessons/42898)

m x n 격자에서 오른쪽과 아래쪽으로만 움직여 집(1,1)에서 학교(m,n)까지 가는 최단경로의 개수를 구한다. 물에 잠긴 좌표(puddles)는 지나갈 수 없고, 결과는 1,000,000,007로 나눈 나머지를 반환한다.

## 접근

### DP로 경로 개수 누적하기

`map[i][j]`를 (1,1)에서 (i,j)까지 오는 경로의 개수로 정의한다. 각 칸은 왼쪽 칸과 위쪽 칸에서만 넘어올 수 있으므로 `map[i][j] = map[i-1][j] + map[i][j-1]`이 성립한다.

물웅덩이는 별도 배열 대신 `map` 배열 안에 `-1`로 표시한다. 웅덩이 칸은 지나갈 수 없으니 값 갱신 없이 continue하고, 인접 칸을 더할 때도 `-1`이면 0으로 취급해서 더한다.

시작 칸 `map[1][1] = 1`은 대입이 아니라 `+=`로 누적하기 때문에, 반복문이 (1,1)을 다시 지나가도 0으로 덮어쓰이지 않고 값이 그대로 유지된다. 덕분에 시작 칸을 위한 별도의 예외 처리가 필요 없다.

시간복잡도는 O(m x n), 공간복잡도도 O(m x n)이다. m, n이 100 이하로 작아 별도 최적화는 필요 없다.

## 풀이

```java
public int solution(int m, int n, int[][] puddles) {
    int[][] map = new int[m + 1][n + 1];
    for (int[] puddle : puddles) map[puddle[0]][puddle[1]] = -1;

    map[1][1] = 1;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (map[i][j] == -1) continue;
            map[i][j] += map[i - 1][j] != -1 ? map[i - 1][j] : 0;
            map[i][j] += map[i][j - 1] != -1 ? map[i][j - 1] : 0;
            map[i][j] %= 1000000007;
        }
    }

    return map[m][n];
}
```
