## 문제

> 링크: [프로그래머스 136797](https://school.programmers.co.kr/learn/courses/30/lessons/136797)

왼손 엄지는 4, 오른손 엄지는 6에서 시작해 숫자 자판을 두 엄지로 눌러 numbers 문자열을 입력할 때, 최소 비용의 합을 구하는 문제.

## 접근

### 이동 비용을 O(1) 공식으로 계산

키패드는 장애물 없는 평면 이동이라 두 숫자 사이 최소 비용은 좌표 차이만으로 바로 계산할 수 있다. 같은 칸이면 비용 1, 그 외에는 대각선 이동(비용 3)을 최대한 활용하는 경로가 상하좌우 이동(비용 2)만 쓰는 경로보다 항상 저렴하므로, `dr = |r1-r2|`, `dc = |c1-c2|`일 때 `3 * min(dr, dc) + 2 * |dr - dc|`로 계산한다.

### idle 엄지 위치만 상태로 갖는 DP

한 자리를 입력하고 나면 방금 누른 엄지는 항상 그 숫자 위에 있으므로, 상태로 들고 다녀야 하는 정보는 나머지(idle) 엄지의 위치 하나, 즉 0~9 중 하나뿐이다.

매 자리마다 두 전이만 고려한다.

- idle 엄지로 현재 숫자를 누르는 경우: 새 idle 위치는 직전에 누른 자리가 된다.
- 직전과 같은(active) 엄지로 다시 누르는 경우: idle 위치는 그대로 유지된다.

두 엄지가 같은 버튼 위에 동시에 있을 수 없다는 제약 때문에, idle 위치가 현재 숫자와 같으면 active 엄지로 누르는 전이를 배제하고, 직전 active 위치가 현재 숫자와 같으면 idle 엄지로 누르는 전이를 배제한다.

## 풀이

```java
import java.util.Arrays;

int[] r = {3, 0, 0, 0, 1, 1, 1, 2, 2, 2};
int[] c = {1, 0, 1, 2, 0, 1, 2, 0, 1, 2};

public int solution(String numbers) {
    int inf = Integer.MAX_VALUE >> 1;
    int[] dp = new int[10];
    Arrays.fill(dp, inf);
    int first = numbers.charAt(0) - '0';
    dp[6] = dist(4, first);
    dp[4] = dist(6, first);
    int prevActive = first;
    for (int i = 1; i < numbers.length(); i++) {
        int digit = numbers.charAt(i) - '0';
        int[] next = new int[10];
        Arrays.fill(next, inf);
        for (int p = 0; p < 10; p++) {
            if (dp[p] == inf) continue;
            if (p != digit) {
                int moved = dp[p] + dist(prevActive, digit);
                if (moved < next[p]) next[p] = moved;
            }
            if (prevActive != digit) {
                int moved = dp[p] + dist(p, digit);
                if (moved < next[prevActive]) next[prevActive] = moved;
            }
        }
        dp = next;
        prevActive = digit;
    }
    int min = Integer.MAX_VALUE;
    for (int cost : dp) {
        if (cost < min) min = cost;
    }
    return min;
}

public int dist(int a, int b) {
    if (a == b) return 1;
    int dr = Math.abs(r[a] - r[b]);
    int dc = Math.abs(c[a] - c[b]);
    return 3 * Math.min(dr, dc) + 2 * Math.abs(dr - dc);
}
```
