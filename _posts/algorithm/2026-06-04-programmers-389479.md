## 문제

> 링크: [프로그래머스 389479](https://school.programmers.co.kr/learn/courses/30/lessons/389479)

시간대별 이용자 수, 서버당 수용 인원 m, 운영 시간 k가 주어질 때, 하루 동안 필요한 최소 서버 증설 횟수를 구하는 문제.

## 접근

### 차분 배열로 운영 중인 서버 수 추적

매 시간마다 현재 운영 중인 서버 수(`cur`)와 필요한 서버 수(`players[i] / m`)를 비교한다.
부족하면 그 차이만큼 증설하고, 횟수를 누적한다.
증설한 서버는 k시간 후 반납되므로, `expansion[i + k]`에 감산값을 기록해두고 해당 시간에 `cur`에 반영한다.

## 풀이

```java
public int solution(int[] players, int m, int k) {
    int[] expansion = new int[24 + k];
    int total = 0;
    for (int i = 0, cur = 0; i < players.length; i++) {
        cur += expansion[i];
        int required = players[i] / m;
        if (cur >= required) continue;
        int needed = required - cur;
        cur += needed;
        total += needed;
        expansion[i + k] -= needed;
    }
    return total;
}
```
