## 문제

> 링크: [프로그래머스 42578](https://school.programmers.co.kr/learn/courses/30/lessons/42578)

의상 종류별로 최대 1가지만 착용 가능할 때, 가능한 조합의 수를 반환. (최소 1개 착용)

## 접근

### 경우의 수 곱셈 원리

각 의상 종류는 서로 독립적이다. 예를 들어 headgear 2가지, eyewear 1가지가 있다면:

- headgear: yellow_hat / green_turban / **안 입음** → 3가지 선택
- eyewear: blue_sunglasses / **안 입음** → 2가지 선택

두 종류의 선택은 독립적이므로 전체 경우의 수는 `3 × 2 = 6`가지.

그런데 이 중 **모든 종류를 안 입는 경우(1가지)**는 문제 조건상 불가능하므로 빼면 `6 - 1 = 5`가지가 된다.

정리하면, 종류별 의상 수를 `n`이라 할 때:

```
정답 = ∏(n + 1) - 1
```

`+1`은 해당 종류를 안 입는 선택지, `-1`은 아무것도 안 입는 경우 제외.

### 구현

종류별 의상 수를 HashMap으로 집계한 뒤, values를 순회하며 `(count + 1)`을 곱해나간다.

## 풀이

```java
import java.util.HashMap;
import java.util.Map;

public int solution(String[][] clothes) {
    Map<String, Integer> map = new HashMap<>();
    for (String[] clothe : clothes) {
        map.put(clothe[1], map.getOrDefault(clothe[1], 0) + 1);
    }

    int comb = 1;
    for (var value : map.values()) {
        comb *= (1 + value);
    }
    return comb - 1;
}
```
