## 문제

> 링크: [프로그래머스 43236](https://school.programmers.co.kr/learn/courses/30/lessons/43236)

출발지점과 도착지점 사이의 바위 중 `n`개를 제거했을 때, 인접한 지점 사이 거리의 최솟값이 가장 클 때의 값을 구하는 문제.

## 접근

### 답에 대한 이분 탐색

"최솟값의 최댓값"을 구하는 문제라서 최소 거리 `d`를 정해 놓고 가능한지 판별하는 이분 탐색으로 푼다. 최소 거리를 `d` 이상으로 만들기 위해 제거해야 하는 바위의 수는 `d`가 커질수록 늘어나기만 하므로 단조성이 성립한다.

먼저 `rocks`를 정렬한다. 판별은 앞에서부터 한 번 순회하며 이루어진다. 마지막으로 남긴 위치 `prev`(처음에는 출발지점 0)에서 현재 바위까지의 거리가 `d`보다 작으면 그 바위를 제거하고, 아니면 `prev`를 그 바위로 갱신한다. 순회가 끝난 뒤 `distance - prev`가 `d`보다 작으면 도착지점은 제거할 수 없으므로 직전에 남긴 바위를 제거하는 것으로 센다. 제거 횟수가 `n` 이하이면 `d`는 가능하다.

탐색 범위는 `lo = 0`(항상 가능), `hi = distance + 1`(항상 불가능)로 두고 `lo + 1 < hi`인 동안 반복한다. 가능하면 `lo = mid`, 불가능하면 `hi = mid`로 옮기고 `lo`를 반환한다.

- 시간복잡도: `O(R log R + R log distance)` (`R`은 바위 개수)
- 공간복잡도: 정렬 외 추가 공간 `O(1)`

## 풀이

```java
import java.util.Arrays;

public int solution(int distance, int[] rocks, int n) {
    Arrays.sort(rocks);
    int lo = 0, hi = distance + 1;
    while (lo + 1 < hi) {
        int mid = (lo + hi) >>> 1;
        int cnt = 0, prev = 0;
        for (int rock : rocks) {
            if (rock - prev < mid) cnt++;
            else prev = rock;
        }
        if (distance - prev < mid) cnt++;
        if (cnt <= n) lo = mid;
        else hi = mid;
    }
    return lo;
}
```
