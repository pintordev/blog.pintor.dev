## 문제

> 링크: [프로그래머스 118670](https://school.programmers.co.kr/learn/courses/30/lessons/118670)

행렬에 ShiftRow(행을 한 칸씩 아래로 밀기)와 Rotate(바깥 테두리를 시계 방향으로 한 칸 회전)를 순서대로 적용한 결과 행렬을 구하는 문제.

## 접근

### 왼쪽 열 · 가운데 · 오른쪽 열 덱 분리

행렬 크기는 최대 10만, 연산 수도 최대 10만이다. 연산마다 행렬을 직접 옮기면 Rotate 한 번에 O(n + m)이 들어 시간 초과가 난다.

두 연산이 실제로 건드리는 부분은 행의 순서와 테두리뿐이다. 그래서 행렬을 세 덱으로 나눈다.

- `left`: 0번 열
- `center`: 각 행의 가운데 부분(1 ~ m−2번 열)을 원소로 갖는 덱의 덱
- `right`: m−1번 열

ShiftRow는 세 덱 모두 마지막 원소를 맨 앞으로 옮기면 된다.

Rotate는 네 모서리에서 원소 4개만 옮기면 된다.

1. `left`의 첫 원소 → `center` 첫 행의 맨 앞
2. `center` 첫 행의 마지막 원소 → `right`의 맨 앞
3. `right`의 마지막 원소 → `center` 마지막 행의 맨 뒤
4. `center` 마지막 행의 첫 원소 → `left`의 맨 뒤

이 순서를 지키면 열이 2개라 가운데 행이 비어 있어도, 1에서 넣은 값을 2에서 그대로 꺼내고 3에서 넣은 값을 4에서 그대로 꺼내므로 별도 처리 없이 동작한다.

연산이 모두 O(1)이라 전체 시간복잡도는 O(nm + K)다. 마지막에 행마다 `left`, `center`, `right`에서 차례로 꺼내 결과 행렬을 복원한다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Deque;

public int[][] solution(int[][] rc, String[] operations) {
    int n = rc.length;
    int m = rc[0].length;
    Deque<Integer> left = new ArrayDeque<>();
    Deque<Deque<Integer>> center = new ArrayDeque<>();
    Deque<Integer> right = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        left.add(rc[i][0]);
        Deque<Integer> row = new ArrayDeque<>();
        for (int j = 1; j < m - 1; j++) {
            row.add(rc[i][j]);
        }
        center.add(row);
        right.add(rc[i][m - 1]);
    }

    for (String op : operations) {
        if (op.equals("ShiftRow")) {
            left.addFirst(left.pollLast());
            center.addFirst(center.pollLast());
            right.addFirst(right.pollLast());
            continue;
        }
        center.peekFirst().addFirst(left.pollFirst());
        right.addFirst(center.peekFirst().pollLast());
        center.peekLast().addLast(right.pollLast());
        left.addLast(center.peekLast().pollFirst());
    }

    int[][] res = new int[n][m];
    for (int i = 0; i < n; i++) {
        res[i][0] = left.poll();
        Deque<Integer> row = center.poll();
        for (int j = 1; j < m - 1; j++) {
            res[i][j] = row.poll();
        }
        res[i][m - 1] = right.poll();
    }
    return res;
}
```
