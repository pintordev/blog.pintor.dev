## 문제

> 링크: [프로그래머스 134239](https://school.programmers.co.kr/learn/courses/30/lessons/134239)

k에서 시작하는 우박수열을 꺾은선 그래프로 나타냈을 때, 주어진 구간들의 정적분값을 구하는 문제.

## 접근

### 누적합 (Prefix Sum)

인접한 두 수열 값 사이의 넓이는 사다리꼴 공식 `(a + b) / 2`로 구할 수 있다.

나눗셈을 매 단계마다 하면 부동소수점 오차가 누적되므로, `a + b`를 정수로 누적해 두고 쿼리 시점에 한 번만 `/2.0` 한다.

1. 우박수열을 생성하면서 `cumArea[i] = cumArea[i-1] + a + b`를 기록한다.
2. range `[s, e]`의 실제 끝 인덱스는 `n + e` (e는 0 이하).
3. 끝 인덱스 < 시작 인덱스이면 -1, 그 외엔 `(cumArea[end] - cumArea[start]) / 2.0`.

## 풀이

```java
import java.util.ArrayList;
import java.util.List;

public double[] solution(int k, int[][] ranges) {
    List<Long> cumArea = new ArrayList<>();
    cumArea.add(0L);
    long a = k, b;
    while (a > 1) {
        if ((a & 1) == 0) b = a >> 1;
        else b = 3 * a + 1;
        cumArea.add(cumArea.get(cumArea.size() - 1) + a + b);
        a = b;
    }
    double[] res = new double[ranges.length];
    for (int i = 0, n = cumArea.size() - 1; i < res.length; i++) {
        if (n + ranges[i][1] < ranges[i][0]) res[i] = -1.0;
        else res[i] = (cumArea.get(n + ranges[i][1]) - cumArea.get(ranges[i][0])) / 2.0;
    }
    return res;
}
```
