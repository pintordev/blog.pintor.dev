## 문제

> 링크: [프로그래머스 12987](https://school.programmers.co.kr/learn/courses/30/lessons/12987)

A팀이 출전 순서를 먼저 공개하면 B팀은 이를 보고 최적의 순서로 대응해 최대 승점을 얻어야 한다.

## 접근

### 정렬 + 투 포인터 그리디

A팀이 어떤 순서로 출전 순서를 공개하든, B팀이 얻을 수 있는 최대 승점은 두 배열의 순서와 무관하게 값의 집합에만 의존한다. 두 배열을 오름차순 정렬한 뒤 B의 값을 작은 것부터 순회하면서, 아직 이기지 못한 A의 최솟값보다 크면 승리로 매칭하고 그렇지 않으면 그 B값은 버린다. 작은 B값을 이길 수 없는 A값에 낭비시켜서 큰 B값을 더 큰 A값과 매칭할 기회로 아껴두는 방식이다.

## 풀이

```java
import java.util.Arrays;

public int solution(int[] A, int[] B) {
    Arrays.sort(A);
    Arrays.sort(B);
    int score = 0;
    int i = 0;
    for (int b : B) {
        if (b > A[i]) {
            score++;
            i++;
        }
    }
    return score;
}
```
