## 문제

> 링크: [프로그래머스 17677](https://school.programmers.co.kr/learn/courses/30/lessons/17677)

두 문자열에서 바이그램 다중집합을 만들어 자카드 유사도를 구하고, 65536을 곱한 정수값을 반환한다.

## 접근

### 바이그램 다중집합 + 자카드 유사도

두 문자열 각각에서 연속된 두 알파벳 문자 쌍(바이그램)을 추출해 다중집합을 만든다. 대소문자는 구분하지 않으며, 알파벳이 아닌 문자가 포함된 쌍은 제외한다.

두 다중집합의 교집합은 각 원소의 min, 합집합은 max로 계산한다. 합집합이 0이면 유사도는 1.0으로 처리한다.

바이그램 빈도는 `HashMap` 대신 크기 676짜리 `int[]`로 관리한다. 가능한 바이그램이 26×26=676가지로 유한하므로, `(c1-'a')*26 + (c2-'a')`로 인덱스를 직접 계산해 해시 연산 없이 O(1) 접근이 가능하다.

## 풀이

```java
public int solution(String str1, String str2) {
    int[] freq1 = bigrams(str1);
    int[] freq2 = bigrams(str2);
    int intersect = 0, union = 0;
    for (int i = 0; i < freq1.length; i++) {
        intersect += Math.min(freq1[i], freq2[i]);
        union += Math.max(freq1[i], freq2[i]);
    }
    if (union == 0) return 65536;
    return 65536 * intersect / union;
}

public int[] bigrams(String s) {
    s = s.toLowerCase();
    int[] freq = new int[676];
    for (int i = 1; i < s.length(); i++) {
        char c1 = s.charAt(i - 1);
        char c2 = s.charAt(i);
        if (!Character.isAlphabetic(c1) || !Character.isAlphabetic(c2)) continue;
        freq[(c1 - 'a') * 26 + (c2 - 'a')]++;
    }
    return freq;
}
```

## 회고

`65536 * intersect / union` 순서가 중요하다. `intersect / union`을 먼저 계산하면 정수 나눗셈으로 0이 나올 수 있으므로, 곱셈을 먼저 해 정밀도를 확보한 뒤 나눈다. Java 정수 나눗셈은 자동으로 floor 효과를 내므로 별도 처리가 필요 없다.
