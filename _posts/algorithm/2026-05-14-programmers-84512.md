## 문제

> 링크: [프로그래머스 84512](https://school.programmers.co.kr/learn/courses/30/lessons/84512)

모음 `A`, `E`, `I`, `O`, `U` 로 만든 길이 1~5의 모든 단어를 사전 순으로 나열했을 때, 주어진 단어가 몇 번째인지 반환하는 문제.

## 접근

### 위치별 가중치 계산

각 위치 i(0-indexed)에서 모음 인덱스 v(A=0, E=1, I=2, O=3, U=4)가 기여하는 순서값은 `v × (해당 위치 이하에서 가능한 단어 수)` 다.

위치 i에서 가능한 하위 단어 수는 `1 + 5 + 5² + ... + 5^(4-i)` 이고, 이를 미리 계산하면:

| 위치 | 가중치 |
|------|--------|
| 0 | 781 |
| 1 | 156 |
| 2 | 31 |
| 3 | 6 |
| 4 | 1 |

각 문자마다 `v * f[i] + 1` 을 더하면 (`+1` 은 해당 깊이까지 내려온 것을 카운트), 최종 합이 단어의 사전 순서가 된다.

## 풀이

```java
public int solution(String word) {
    int[] f = {781, 156, 31, 6, 1};
    String vowels = "AEIOU";
    int order = 0;
    for (int i = 0; i < word.length(); i++) {
        order += vowels.indexOf(word.charAt(i)) * f[i] + 1;
    }
    return order;
}
```

## 회고

사전 순서를 직접 세는 대신, 각 위치의 모음 인덱스에 위치별 가중치를 곱하는 수학적 접근으로 O(n) 풀이가 가능하다.
