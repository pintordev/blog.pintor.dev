## 문제

> 링크: [프로그래머스 12953](https://school.programmers.co.kr/learn/courses/30/lessons/12953)

N개의 수가 담긴 배열이 주어질 때, 모든 수의 최소공배수(LCM)를 반환하라.

## 접근

### LCM 누적 적용

두 수의 LCM은 `lcm(a, b) = a / gcd(a, b) * b`로 구할 수 있다. 이를 배열 전체에 순차적으로 적용하면 N개의 수의 LCM을 구할 수 있다.

GCD는 유클리드 호제법(`gcd(a, b) = gcd(b, a % b)`)으로 재귀 계산한다.

오버플로우 방지를 위해 `a * b / gcd` 대신 `a / gcd * b` 순서로 계산한다.

## 풀이

```java
public int solution(int[] arr) {
    int lcm = 1;
    for (int num : arr) {
        lcm = lcm(lcm, num);
    }
    return lcm;
}

public int lcm(int a, int b) {
    return a / gcd(a, b) * b;
}

public int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
```

## 회고

`a * b / gcd(a, b)` 순서로 작성하면 중간 곱셈에서 오버플로우가 발생할 수 있다. `a / gcd(a, b) * b`처럼 나눗셈을 먼저 하는 습관을 들이자.
