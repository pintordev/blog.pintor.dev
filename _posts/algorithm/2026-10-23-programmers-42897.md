## 문제

> 링크: [프로그래머스 42897](https://school.programmers.co.kr/learn/courses/30/lessons/42897)

원형으로 배치된 집들 중 인접한 두 집을 동시에 털 수 없을 때, 훔칠 수 있는 돈의 최댓값을 구하는 문제.

## 접근

### 원형을 두 개의 일렬로 분리하는 DP

일렬 배치라면 `dp[i] = max(dp[i-1], dp[i-2] + money[i])`로 풀린다. 원형에서는 첫 집과 마지막 집이 인접하므로 이 둘을 함께 터는 경우만 막으면 된다.

- 첫 집을 털 수 있는 경우: 마지막 집을 제외한 `0 ~ n-2` 범위에 DP를 적용한다.
- 마지막 집을 털 수 있는 경우: 첫 집을 제외한 `1 ~ n-1` 범위에 DP를 적용한다.

두 결과 중 큰 값이 답이다. 점화식은 직전 두 값만 사용하므로 변수 두 개로 계산할 수 있다. 시간복잡도는 O(n), 공간복잡도는 O(1)이다.

## 풀이

```java
int[] money;

public int solution(int[] money) {
    this.money = money;
    int n = money.length;
    return Math.max(rob(0, n - 2), rob(1, n - 1));
}

public int rob(int from, int to) {
    int prev = 0;
    int cur = 0;
    for (int i = from; i <= to; i++) {
        int next = Math.max(cur, prev + money[i]);
        prev = cur;
        cur = next;
    }
    return cur;
}
```
