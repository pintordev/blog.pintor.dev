## 문제

> 링크: [프로그래머스 42839](https://school.programmers.co.kr/learn/courses/30/lessons/42839)

숫자 종이 조각을 일부 또는 전부 조합해 만들 수 있는 소수의 개수를 구하는 문제.

## 접근

### 완전탐색 + 비트마스킹 + 소수 판별

만들 수 있는 모든 수를 나열한 뒤 소수 판별을 수행한다.

`numbers`의 길이가 최대 7이므로 완전탐색이 가능하다. 재귀 백트래킹으로 길이 1 ~ N의 모든 순열을 생성하고, `HashSet`에 정수로 저장해 중복을 제거한다.

사용 여부 추적은 `boolean[]` 대신 `int` 비트마스크를 사용했다. `int`는 값 전달(pass by value)이므로 재귀 후 복원 코드(`used[i] = false`)가 불필요하고, 필드로 꺼낸 `visited` 하나만으로 시그니처가 단순해진다.

소수 판별은 `2 ~ √n` 범위 시험 나눗셈을 사용한다. 최대 수가 9,876,543이므로 `i * i` 오버플로우가 발생하지 않아 `(long)` 캐스트도 필요 없다.

## 풀이

```java
char[] chars;
Set<Integer> candidates;
StringBuilder sb;

public int solution(String numbers) {
    chars = numbers.toCharArray();
    candidates = new HashSet<>();
    sb = new StringBuilder();
    permute(0);
    int cnt = 0;
    for (int n : candidates) {
        if (isPrime(n)) cnt++;
    }
    return cnt;
}

public void permute(int visited) {
    if (sb.length() > 0) candidates.add(Integer.parseInt(sb.toString()));
    for (int i = 0; i < chars.length; i++) {
        if ((visited & (1 << i)) != 0) continue;
        sb.append(chars[i]);
        permute(visited | (1 << i));
        sb.deleteCharAt(sb.length() - 1);
    }
}

public boolean isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}
```
