## 문제

> 링크: [프로그래머스 64062](https://school.programmers.co.kr/learn/courses/30/lessons/64062)

디딤돌을 밟으면 숫자가 1씩 줄고, 0이 된 디딤돌은 가장 가까운 다음 디딤돌로 최대 k칸까지 건너뛸 수 있을 때, 몇 명까지 징검다리를 건널 수 있는지 구하는 문제다.

## 접근

### 이분탐색(파라메트릭 서치)

건널 수 있는 인원 수는 단조성을 가진다. n명이 건널 수 있다면 n-1명도 항상 건널 수 있다. 이 성질을 이용해 정답 자체를 이분탐색으로 좁혀갈 수 있다.

n번째 사람이 건너기 직전의 디딤돌 상태는 n-1명이 먼저 건넌 뒤의 상태와 같다. 디딤돌 값이 n보다 작으면 n-1명이 지나가는 동안 이미 0으로 소진됐다는 뜻이므로, `stones[i] < n`인 구간이 곧 "이미 사라진 디딤돌"의 연속 구간이다. 이 구간의 길이가 k 이상이면 다음 디딤돌까지 한 번에 건너뛸 수 없으므로 n명은 건널 수 없다.

이 판별 함수(`canCross`)로 건널 수 있는 최대 인원을 이분탐색으로 탐색한다.

## 풀이

```java
public int solution(int[] stones, int k) {
    int lo = 1, hi = 0;
    for (int stone : stones) hi = Math.max(hi, stone);
    while (lo < hi + 1) {
        int mid = (lo + hi) / 2;
        if (canCross(stones, k, mid)) lo = mid + 1;
        else hi = mid - 1;
    }
    return hi;
}

public boolean canCross(int[] stones, int k, int people) {
    int cnt = 0;
    for (int stone : stones) {
        if (stone < people) cnt++;
        else cnt = 0;
        if (cnt >= k) return false;
    }
    return true;
}
```
