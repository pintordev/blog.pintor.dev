## 문제

> 링크: [프로그래머스 468374](https://school.programmers.co.kr/learn/courses/30/lessons/468374)

격자 위 정사각형 앱들을 명령대로 한 칸씩 밀고, 밀린 앱이 다른 앱을 연쇄로 밀거나 격자 반대편으로 넘어가는 규칙을 적용한 최종 배치를 구하는 문제.

## 접근

### 한 칸씩 이동하는 큐 시뮬레이션

앱마다 좌상단 좌표와 한 변의 길이를 저장해 두고, 명령이 들어오면 큐로 연쇄 이동을 처리한다.

큐에서 앱을 하나 꺼낼 때마다 정확히 한 칸만 움직인다.

1. 이동 방향의 반대쪽 가장자리 한 줄을 비운다. 단, 그 칸이 이미 다른 앱으로 덮여 있으면 건드리지 않는다.
2. 이동 방향 쪽 가장자리 바로 앞 한 줄로 들어간다. 그 칸에 다른 앱이 있으면 그 앱도 한 칸 밀려야 하므로 큐에 넣는다. 이미 큐에서 대기 중인 앱은 중복으로 넣지 않는다.
3. 좌표를 한 칸 옮긴다.

격자 밖으로 나가는 처리는 칸 단위 모듈러 연산으로 한다. 2x2 이상인 앱이 경계에 걸치면 일부 칸은 오른쪽 끝, 일부 칸은 왼쪽 끝에 놓인 상태가 된다. 이 상태면 앱을 다시 큐에 넣어 격자 안에 완전히 들어올 때까지 계속 민다. 결과적으로 앱은 반대편 끝에 통째로 붙고, 넘어가는 동안 한 줄씩 새로 들어가는 칸의 앱만 밀기 때문에 연쇄도 자연스럽게 처리된다.

이동 중에는 칸을 마지막으로 덮은 앱이 그 칸의 주인이 되므로, 별도의 겹침 판정 없이 `board` 하나로 상태를 관리할 수 있다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Queue;

int n, m;
int[][] board;
App[] apps;
int[] dr = {0, 1, 0, -1};
int[] dc = {1, 0, -1, 0};

public int[][] solution(int[][] board, int[][] commands) {
    n = board.length;
    m = board[0].length;
    this.board = board;
    apps = new App[101];
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < m; c++) {
            int id = board[r][c];
            if (id == 0) continue;
            if (apps[id] == null) apps[id] = new App(r, c);
            if (apps[id].r == r) apps[id].size++;
        }
    }
    for (int[] cmd : commands) {
        push(cmd[0], cmd[1] - 1);
    }
    return board;
}

public void push(int id, int d) {
    Queue<Integer> q = new ArrayDeque<>();
    boolean[] queued = new boolean[apps.length];
    q.add(id);
    queued[id] = true;
    while (!q.isEmpty()) {
        int cur = q.poll();
        queued[cur] = false;
        App app = apps[cur];
        int pr = Math.abs(dc[d]);
        int pc = Math.abs(dr[d]);
        int sr = app.r + (d == 3 ? app.size - 1 : 0);
        int sc = app.c + (d == 2 ? app.size - 1 : 0);
        for (int i = 0; i < app.size; i++) {
            int r = (sr + i * pr) % n;
            int c = (sc + i * pc) % m;
            if (board[r][c] == cur) board[r][c] = 0;
        }
        for (int i = 0; i < app.size; i++) {
            int nr = (sr + dr[d] * app.size + i * pr + n) % n;
            int nc = (sc + dc[d] * app.size + i * pc + m) % m;
            int next = board[nr][nc];
            if (next != 0 && !queued[next]) {
                q.add(next);
                queued[next] = true;
            }
            board[nr][nc] = cur;
        }
        app.r = (app.r + dr[d] + n) % n;
        app.c = (app.c + dc[d] + m) % m;
        if (app.r + app.size > n || app.c + app.size > m) {
            q.add(cur);
            queued[cur] = true;
        }
    }
}

class App {
    int r;
    int c;
    int size;

    App(int r, int c) {
        this.r = r;
        this.c = c;
    }
}
```
