## 문제

> 링크: [프로그래머스 72413](https://school.programmers.co.kr/learn/courses/30/lessons/72413)

n개의 지점에서 A와 B가 같은 출발지 s에서 각자 다른 도착지 a, b로 이동할 때, 일정 지점까지 합승하는 경우까지 포함해 최소 택시 요금을 구하는 문제다.

## 접근

### 플로이드-워셜 + 분기점 탐색

지점 개수 n이 최대 200으로 작아 플로이드-워셜로 모든 지점 쌍의 최단거리를 미리 구해둔다. 이후 1부터 n까지 모든 지점 k를 "합승 분기점" 후보로 놓고 `dist[s][k] + dist[k][a] + dist[k][b]`의 최솟값을 찾는다. k가 s 자신인 경우 `dist[s][s] = 0`이 되어 "합승하지 않고 각자 이동"하는 경우도 자동으로 포함되므로 별도 분기 처리가 필요 없다.

## 풀이

```java
import java.util.Arrays;

public int solution(int n, int s, int a, int b, int[][] fares) {
    int INF = Integer.MAX_VALUE >> 2;
    int[][] dist = new int[n + 1][n + 1];
    for (int i = 1; i <= n; i++) {
        Arrays.fill(dist[i], INF);
        dist[i][i] = 0;
    }
    for (int[] fare : fares) {
        int from = fare[0], to = fare[1], cost = fare[2];
        dist[from][to] = cost;
        dist[to][from] = cost;
    }
    for (int k = 1; k <= n; k++) {
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                if (dist[i][k] + dist[k][j] >= dist[i][j]) continue;
                dist[i][j] = dist[i][k] + dist[k][j];
            }
        }
    }
    int min = INF;
    for (int k = 1; k <= n; k++) {
        int cost = dist[s][k] + dist[k][a] + dist[k][b];
        if (cost < min) min = cost;
    }
    return min;
}
```
