## 문제

> 링크: [프로그래머스 160585](https://school.programmers.co.kr/learn/courses/30/lessons/160585)

주어진 3×3 틱택토 게임판이 규칙에 맞게 진행된 유효한 상황인지 판단한다.

## 접근

### 유효성 조건 분기

O가 선공이므로 O 수는 항상 X 수와 같거나 하나 더 많아야 한다. 이 조건이 깨지면 턴 순서 위반이다.

또한 게임이 끝난 후에도 계속 진행한 경우를 차단해야 한다.

- O가 이겼을 때: O가 마지막 수를 놓은 것이므로 O 수 = X 수 + 1이어야 한다.
- X가 이겼을 때: X가 마지막 수를 놓은 것이므로 O 수 = X 수이어야 한다.

O·X 동시 승리는 위 두 카운트 조건이 서로 배타적이므로 별도 처리 없이 자동으로 차단된다.

## 풀이

```java
String[] board;
int cntO, cntX;

public int solution(String[] board) {
    this.board = board;
    cnt();
    if (cntO != cntX && cntO != cntX + 1) return 0;
    if (isWin('O') && cntO != cntX + 1) return 0;
    if (isWin('X') && cntO != cntX) return 0;
    return 1;
}

public void cnt() {
    this.cntO = 0;
    this.cntX = 0;
    for (String r : board) {
        for (int i = 0; i < r.length(); i++) {
            if (r.charAt(i) == 'O') cntO++;
            else if (r.charAt(i) == 'X') cntX++;
        }
    }
}

public boolean isWin(char c) {
    boolean dtlbr = true, dtrbl = true;
    for (int i = 0; i < board.length; i++) {
        if (board[i].charAt(i) != c) dtlbr = false;
        if (board[i].charAt(2 - i) != c) dtrbl = false;
        boolean ri = true, cj = true;
        for (int j = 0; j < board[i].length(); j++) {
            if (board[i].charAt(j) != c) ri = false;
            if (board[j].charAt(i) != c) cj = false;
        }
        if (ri || cj) return true;
    }
    return dtlbr || dtrbl;
}
```
