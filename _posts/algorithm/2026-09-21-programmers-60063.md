## 문제

> 링크: [프로그래머스 60063](https://school.programmers.co.kr/learn/courses/30/lessons/60063)

2×1 크기 로봇이 벽이 있는 N×N 보드에서 상하좌우 이동과 90도 회전을 반복해 (N, N)까지 도달하는 최단 시간을 구하는 문제.

## 접근

### 상태를 기준점 + 방향으로 정의한 BFS

로봇이 차지하는 두 칸을 하나의 상태로 보고, 기준점이 되는 칸(왼쪽/위쪽 칸)과 방향(가로 0, 세로 1)으로 상태를 정의한다. 각 상태에서 가능한 전이는 상하좌우 평행이동 4가지와 90도 회전 4가지다. 평행이동은 두 칸이 같은 방향으로 한 칸씩 옮겨가는 경우이고, 회전은 축이 되는 칸의 대각선 위치에 벽이 없어야 가능하다.

방문 배열은 `visited[r][c][dir]`로 관리해서 같은 위치라도 방향이 다르면 다른 상태로 취급한다. 큐에 담기는 노드가 `time`을 직접 들고 있어서, 레벨 단위로 큐 크기를 스냅샷하지 않고도 BFS가 진행된다.

회전 시 새 기준점 좌표와 회전 유효성 판단에 필요한 대각선 오프셋은 방향(`dir`)별로 다르므로, 이를 각각 `rotateR`/`rotateC`, `checkR`/`checkC` 배열에 인덱싱해서 가로/세로 분기를 나누지 않고 하나의 루프로 처리한다. `isAvailable`은 좌표가 큐에 들어갈 수 있는지(범위, 벽, 두 번째 칸, 방문 여부)를 한 번에 판단하고, 회전 전용 오버로드는 여기에 대각선 체크까지 더해 회전 가능 여부까지 한 번의 호출로 판단한다.

## 풀이

{% raw %}
```java
import java.util.ArrayDeque;
import java.util.Queue;

public int[][] board;
public int n;
public boolean[][][] visited;
public int[] dr = {-1, 1, 0, 0};
public int[] dc = {0, 0, -1, 1};
public int[][] rotateR = {{-1, 0, -1, 0}, {0, 0, 1, 1}};
public int[][] rotateC = {{0, 0, 1, 1}, {-1, 0, -1, 0}};
public int[][] checkR = {{0, 1, 0, 1}, {1, 1, -1, -1}};
public int[][] checkC = {{1, 1, -1, -1}, {0, 1, 0, 1}};

public int solution(int[][] board) {
    this.board = board;
    n = board.length;
    visited = new boolean[n][n][2];
    Queue<Node> q = new ArrayDeque<>();
    q.add(new Node(0, 0, 0, 0));
    visited[0][0][0] = true;
    while (!q.isEmpty()) {
        Node cur = q.poll();
        if (isArrived(cur)) return cur.time;
        for (int i = 0; i < 4; i++) {
            int nr = cur.r + dr[i];
            int nc = cur.c + dc[i];
            if (!isAvailable(nr, nc, cur.dir)) continue;
            visited[nr][nc][cur.dir] = true;
            q.add(new Node(nr, nc, cur.dir, cur.time + 1));
        }
        for (int i = 0; i < 4; i++) {
            int nr = cur.r + rotateR[cur.dir][i];
            int nc = cur.c + rotateC[cur.dir][i];
            int ndir = 1 - cur.dir;
            if (!isAvailable(nr, nc, ndir, cur.dir, i)) continue;
            visited[nr][nc][ndir] = true;
            q.add(new Node(nr, nc, ndir, cur.time + 1));
        }
    }
    return -1;
}

public boolean isArrived(Node cur) {
    if (cur.dir == 0 && cur.r == n - 1 && cur.c + 1 == n - 1) return true;
    if (cur.dir == 1 && cur.r + 1 == n - 1 && cur.c == n - 1) return true;
    return false;
}

public boolean isAvailable(int nr, int nc, int dir) {
    if (nr < 0 || nr >= n || nc < 0 || nc >= n) return false;
    if (board[nr][nc] == 1) return false;
    if (dir == 0 && (nc + 1 >= n || board[nr][nc + 1] == 1)) return false;
    if (dir == 1 && (nr + 1 >= n || board[nr + 1][nc] == 1)) return false;
    if (visited[nr][nc][dir]) return false;
    return true;
}

public boolean isAvailable(int nr, int nc, int dir, int fromDir, int i) {
    if (!isAvailable(nr, nc, dir)) return false;
    return board[nr + checkR[fromDir][i]][nc + checkC[fromDir][i]] == 0;
}

class Node {
    int r;
    int c;
    int dir;
    int time;

    Node(int r, int c, int dir, int time) {
        this.r = r;
        this.c = c;
        this.dir = dir;
        this.time = time;
    }
}
```
