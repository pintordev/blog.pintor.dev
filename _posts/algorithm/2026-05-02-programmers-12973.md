## 문제

> 링크: [프로그래머스 12973](https://school.programmers.co.kr/learn/courses/30/lessons/12973)

문자열에서 인접한 같은 문자 쌍을 반복 제거해 빈 문자열이 되면 1, 아니면 0을 반환하라.

## 접근

### char 배열 스택

`Stack<Character>` 대신 char 배열을 직접 스택으로 사용한다. 포인터 `t`가 스택의 top 역할을 하며, 현재 문자가 top과 같으면 pop(t--), 다르면 push(c[t++])한다.

## 풀이

```java
public int solution(String s) {
    int n = s.length();
    char[] c = new char[n];
    int t = 0;
    for (int i = 0; i < n; i++) {
        if (t > 0 && c[t - 1] == s.charAt(i)) t--;
        else c[t++] = s.charAt(i);
    }
    return t == 0 ? 1 : 0;
}
```
