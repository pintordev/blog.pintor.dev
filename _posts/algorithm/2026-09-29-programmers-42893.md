## 문제

> 링크: [프로그래머스 42893](https://school.programmers.co.kr/learn/courses/30/lessons/42893)

검색어와 웹페이지 HTML 목록이 주어졌을 때, 기본점수와 링크점수를 합산한 매칭점수가 가장 높은 웹페이지의 index를 구하는 문제.

## 접근

### 정규식 파싱 + URL 매핑으로 역방향 링크 집계

각 페이지의 `<meta property="og:url" content="...">`에서 자신의 URL을, `<a href="...">`에서 외부 링크를 정규식으로 추출한다.

기본점수는 검색어와 완전히 일치하는 단어의 개수다. 자바 정규식의 `\b`는 숫자를 단어 문자로 취급해 `muzI92apeach`처럼 숫자가 낀 문자열에서 경계를 제대로 못 잡으므로, 숫자를 공백으로 치환한 뒤 `\b(?i)word\b`로 매칭한다.

URL을 key, 페이지 index를 value로 하는 맵을 만든 다음, 각 페이지의 외부 링크(같은 대상으로 중복 링크가 걸린 경우는 한 번만)를 순회하며 연결된 대상 페이지에 `기본점수 ÷ 외부 링크 수`를 누적해 링크점수를 구한다. 마지막으로 기본점수와 링크점수의 합이 가장 큰 페이지(동점이면 index가 가장 작은 페이지)를 반환한다.

## 풀이

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

static Pattern urlPattern = Pattern.compile("<meta property=\"og:url\" content=\"https://(\\S*)\"/>");
static Pattern hrefPattern = Pattern.compile("<a href=\"https://(\\S*)\"");
Pattern wordPattern;

public int solution(String word, String[] pages) {
    wordPattern = Pattern.compile("\\b(?i)" + word + "\\b");
    int n = pages.length;
    int[] baseScores = new int[n];
    int[] outDegrees = new int[n];
    List<String>[] links = new List[n];
    Map<String, Integer> urlIndex = new HashMap<>();
    for (int i = 0; i < n; i++) {
        urlIndex.put(extractUrl(pages[i]), i);
        baseScores[i] = countWord(pages[i]);
        links[i] = extractLinks(pages[i]);
        outDegrees[i] = links[i].size();
    }
    double[] linkScores = new double[n];
    for (int i = 0; i < n; i++) {
        for (String link : new HashSet<>(links[i])) {
            Integer target = urlIndex.get(link);
            if (target != null) linkScores[target] += (double) baseScores[i] / outDegrees[i];
        }
    }
    int res = 0;
    double maxScore = -1;
    for (int i = 0; i < n; i++) {
        double score = baseScores[i] + linkScores[i];
        if (score > maxScore) {
            maxScore = score;
            res = i;
        }
    }
    return res;
}

public String extractUrl(String page) {
    Matcher m = urlPattern.matcher(page);
    if (m.find()) return m.group(1);
    return null;
}

public List<String> extractLinks(String page) {
    List<String> links = new ArrayList<>();
    Matcher m = hrefPattern.matcher(page);
    while (m.find()) {
        links.add(m.group(1));
    }
    return links;
}

public int countWord(String page) {
    Matcher m = wordPattern.matcher(page.replaceAll("[0-9]", " "));
    int cnt = 0;
    while (m.find()) {
        cnt++;
    }
    return cnt;
}
```
