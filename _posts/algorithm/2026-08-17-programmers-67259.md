## 문제

> 링크: [프로그래머스 67259](https://school.programmers.co.kr/learn/courses/30/lessons/67259)

N x N 격자에서 (0,0)에서 (N-1,N-1)까지 경주로를 건설할 때, 직선 도로는 100원, 코너는 500원이 추가로 드는 최소 비용을 구하는 문제다.

## 접근

### (row, col, direction) 상태 확장 다익스트라

같은 칸에 도달해도 직전 이동 방향에 따라 다음 이동이 직선인지 코너인지가 달라지므로, 칸만 상태로 잡는 단순 BFS로는 코너 비용을 반영할 수 없다. 그래서 상태를 `(row, col, direction)`으로 확장해서 다익스트라를 돌렸다.

`dist[r][c][d]`는 `d` 방향으로 진입해서 `(r, c)`에 도달했을 때의 최소 누적 비용이다. 시작점은 직전 방향이 없으므로 `dir = -1`로 표시하고, 이 경우 첫 이동은 코너 판정 없이 100원만 부과한다. 이후 이동은 직전 방향과 같으면 100원, 다르면 코너가 발생해 600원(100 + 500)이 든다.

우선순위 큐로 비용이 작은 상태부터 꺼내면서 인접한 4방향으로 전이하고, 더 나은 비용일 때만 갱신 후 큐에 넣는 표준적인 다익스트라 방식이다. 도착점 `(N-1, N-1)`의 4방향 `dist` 중 최솟값이 답이다.

## 풀이

```java
import java.util.Arrays;
import java.util.PriorityQueue;

int n;
int[][] board;
int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};

public int solution(int[][] board) {
    n = board.length;
    this.board = board;
    int[][][] dist = new int[n][n][4];
    for (int[][] row : dist) {
        for (int[] cell : row) {
            Arrays.fill(cell, Integer.MAX_VALUE);
        }
    }
    PriorityQueue<Node> pq = new PriorityQueue<>();
    pq.add(new Node(0, 0, -1, 0));
    while (!pq.isEmpty()) {
        Node cur = pq.poll();
        if (cur.dir != -1 && cur.cost > dist[cur.r][cur.c][cur.dir]) continue;
        for (int d = 0; d < 4; d++) {
            int nr = cur.r + dr[d];
            int nc = cur.c + dc[d];
            if(!isAvailable(nr, nc)) continue;
            int newCost = cur.cost + ((cur.dir == -1 || cur.dir == d) ? 100 : 600);
            if (newCost >= dist[nr][nc][d]) continue;
            dist[nr][nc][d] = newCost;
            pq.add(new Node(nr, nc, d, newCost));
        }
    }
    int res = Integer.MAX_VALUE;
    for (int d = 0; d < 4; d++) {
        res = Math.min(res, dist[n - 1][n - 1][d]);
    }
    return res;
}

public boolean isAvailable(int r, int c) {
    if (r < 0 || r >= n || c < 0 || c >= n) return false;
    return board[r][c] != 1;
}

class Node implements Comparable<Node> {
    int r, c, dir, cost;

    public Node(int r, int c, int dir, int cost) {
        this.r = r;
        this.c = c;
        this.dir = dir;
        this.cost = cost;
    }

    @Override
    public int compareTo(Node o) {
        return this.cost - o.cost;
    }
}

```
