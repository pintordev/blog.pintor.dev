## 문제

> 링크: [프로그래머스 258707](https://school.programmers.co.kr/learn/courses/30/lessons/258707)

1~n 카드 중 처음 n/3장을 갖고 시작해서, 매 라운드 카드 두 장을 뽑아 동전을 써서 갖거나 버리고, 손에 든 카드 중 합이 n+1이 되는 두 장을 낼 수 있으면 다음 라운드로 진행하는 게임에서 최대 몇 라운드까지 도달할 수 있는지 구하는 문제.

## 접근

### 페어 단위로 문제를 재정의

카드 값은 1~n이 중복 없이 등장하고, 합이 n+1이 되는 짝은 (v, n+1-v) 하나뿐이다. 그래서 카드 값 자체보다 "어떤 페어가 완성됐는가"만 중요하다.

페어를 완성하는 데 드는 동전 비용은 그 페어의 두 카드 중 처음부터 손에 있던 카드가 아닌 것의 개수(0, 1, 2)로 고정되고, 완성 가능해지는 시점(ready round)은 두 카드가 모두 등장한 라운드(초기 카드는 0라운드) 중 늦은 쪽이다.

r라운드를 통과하려면 그 시점까지 활성화한 페어 수의 누적합이 r 이상이어야 한다. 페어들은 서로 값을 공유하지 않는 독립적인 자원이라 어떤 페어를 낼지는 상관없고 개수만 중요하다.

### 그리디: 매번 가장 싼 페어부터 활성화

각 페어가 준비되는 라운드에 맞춰 우선순위 큐(비용 기준 최소힙)에 넣어두고, 라운드마다 누적 활성화 수가 그 라운드 값에 도달할 때까지 가장 싼 페어부터 꺼내 코인을 소모한다. 힙이 비었거나 코인이 부족해 도달하지 못하면 그 라운드에서 종료다.

한 가지 놓치기 쉬운 조건은 "카드 뭉치에 남은 카드가 없으면 게임을 종료한다"는 부분이다. 모든 라운드를 성공해도 다음 라운드 시작 시 뽑을 카드가 없어 그 라운드에서 게임이 끝나므로, 전 라운드를 통과했을 때 반환값은 `n/3`이 아니라 `n/3 + 1`이다.

시간복잡도는 페어 개수(n/2개)에 대한 힙 연산으로 O(n log n)이다.

## 풀이

```java
import java.util.ArrayList;
import java.util.List;
import java.util.PriorityQueue;

int initialCount;

public int solution(int coin, int[] cards) {
    int n = cards.length;
    initialCount = n / 3;
    int rounds = n / 3;
    int[] pos = new int[n + 1];
    for (int i = 0; i < n; i++) {
        pos[cards[i]] = i;
    }
    List<Integer>[] bucket = new List[rounds + 1];
    for (int r = 0; r <= rounds; r++) {
        bucket[r] = new ArrayList<>();
    }
    for (int v = 1; v * 2 <= n; v++) {
        int partner = n + 1 - v;
        int cost = 0;
        if (pos[v] >= initialCount) cost++;
        if (pos[partner] >= initialCount) cost++;
        int readyRound = Math.max(roundOf(pos[v]), roundOf(pos[partner]));
        bucket[readyRound].add(cost);
    }
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    for (int cost : bucket[0]) {
        pq.add(cost);
    }
    int activated = 0;
    int remainingCoin = coin;
    for (int r = 1; r <= rounds; r++) {
        for (int cost : bucket[r]) {
            pq.add(cost);
        }
        while (activated < r) {
            if (pq.isEmpty()) return r;
            int cost = pq.peek();
            if (cost > remainingCoin) return r;
            pq.poll();
            remainingCoin -= cost;
            activated++;
        }
    }
    return rounds + 1;
}

public int roundOf(int idx) {
    if (idx < initialCount) return 0;
    return ((idx - initialCount) >> 1) + 1;
}
```
