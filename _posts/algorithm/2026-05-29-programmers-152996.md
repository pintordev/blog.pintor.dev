## 문제

> 링크: [프로그래머스 152996](https://school.programmers.co.kr/learn/courses/30/lessons/152996)

중심에서 2m, 3m, 4m 거리에 좌석이 있는 시소에서 두 사람이 균형을 이루는 쌍의 수를 구하는 문제.

## 접근

### 정렬 + 배열 빈도 카운트

두 사람의 무게 `w1`, `w2`가 각각 거리 `d1`, `d2`에 앉을 때 `w1 * d1 = w2 * d2`이면 시소 짝꿍이다. 가능한 거리 조합을 정리하면 유효한 무게 비율은 다음 네 가지뿐이다.

| 거리 비율 (d1:d2) | 무게 비율 (w1:w2) |
|-----------------|-----------------|
| 2:2, 3:3, 4:4   | 1:1             |
| 3:2             | 2:3             |
| 4:2             | 1:2             |
| 4:3             | 3:4             |

weights를 오름차순 정렬하면, 각 `w`를 처리할 때 이전에 등장한 무게는 항상 `w` 이하임이 보장된다. 따라서 현재 `w`를 더 큰 쪽으로 보고, 파트너가 될 수 있는 더 작거나 같은 무게를 배열에서 O(1)로 조회하면 된다.

- `ws[w]`: 동일 무게 (비율 1:1)
- `ws[w / 2]`: 파트너가 절반 무게 (비율 1:2)
- `ws[2 * w / 3]`: 파트너가 2/3 무게 (비율 2:3)
- `ws[3 * w / 4]`: 파트너가 3/4 무게 (비율 3:4)

조회 후 `ws[w]++`로 자신을 등록하면, 이후에 등장하는 더 큰 무게가 자신을 파트너로 찾을 수 있다. 쌍은 항상 한 방향으로만 집계되므로 중복 없이 정확히 한 번씩 카운트된다.

## 풀이

```java
import java.util.Arrays;

public long solution(int[] weights) {
    Arrays.sort(weights);
    int[] ws = new int[1001];
    long count = 0;
    for (int w : weights) {
        count += ws[w];
        if (w % 2 == 0) count += ws[w / 2];
        if (2 * w % 3 == 0) count += ws[2 * w / 3];
        if (3 * w % 4 == 0) count += ws[3 * w / 4];
        ws[w]++;
    }
    return count;
}
```
