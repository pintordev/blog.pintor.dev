## 문제

> 링크: [프로그래머스 1839](https://school.programmers.co.kr/learn/courses/30/lessons/1839)

격자의 (0, 0)에서 (m - 1, n - 1)까지 대화 시간 합이 s 이하인 경로 중 가장 짧은 경로를 찾고, 길이가 같으면 대화 시간 합이 최소인 경로의 길이와 합을 구하는 문제.

## 접근

### 이동 길이 단위 DP

일반 BFS로 칸마다 최단 거리 하나만 저장하면, 최단 경로가 대화 시간 합 s를 넘을 때 더 긴 우회 경로를 고려할 수 없다. 그래서 상태에 이동 길이를 포함시킨다.

`cost[r][c]`를 현재 길이로 (r, c)에 도착할 때의 최소 대화 시간 합으로 두고, 길이를 1씩 늘리며 상하좌우 이웃으로 값을 전파해 `next`를 만든다. 테이블(-1) 칸은 건너뛰고, 합이 s를 넘는 상태는 버린다. 도착점에 처음 값이 생기는 길이가 최단 길이이고, 그때의 값이 같은 길이 중 최소 대화 시간 합이다.

지나갈 수 있는 칸의 대화 시간은 0 이상이므로 같은 칸을 다시 지나는 경로는 고리를 잘라낸 더 짧은 경로보다 나을 수 없다. 따라서 답의 길이는 m·n - 1 이하이고, 전체 시간복잡도는 O((m·n)²)이다. 길이별 배열은 현재와 다음 두 개만 유지하면 되어 공간은 O(m·n)이다.

대화 시간이 최대 2³¹ - 1이라 합산 중 int 범위를 넘을 수 있으므로 합은 long으로 계산한다.

## 풀이

```java
import java.util.Arrays;

int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};

public int[] solution(int m, int n, int s, int[][] time_map) {
    long[][] cost = new long[m][n];
    for (int r = 0; r < m; r++) {
        Arrays.fill(cost[r], Long.MAX_VALUE);
    }
    cost[0][0] = 0;
    for (int len = 1; ; len++) {
        long[][] next = new long[m][n];
        for (int r = 0; r < m; r++) {
            Arrays.fill(next[r], Long.MAX_VALUE);
        }
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (cost[r][c] == Long.MAX_VALUE) continue;
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d];
                    int nc = c + dc[d];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                    if (time_map[nr][nc] == -1) continue;
                    long nt = cost[r][c] + time_map[nr][nc];
                    if (nt > s) continue;
                    next[nr][nc] = Math.min(next[nr][nc], nt);
                }
            }
        }
        if (next[m - 1][n - 1] != Long.MAX_VALUE) return new int[]{len, (int) next[m - 1][n - 1]};
        cost = next;
    }
}
```
