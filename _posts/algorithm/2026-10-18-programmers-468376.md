## 문제

> 링크: [프로그래머스 468376](https://school.programmers.co.kr/learn/courses/30/lessons/468376)

축에 평행한 도로 정중앙마다 단속 카메라가 있을 때, 1번 도시에서 일정한 속도로 각 도시까지 갈 수 있는 최고 속도를 구하는 문제.

## 접근

### 좌표 압축 격자

도시, 도로 끝점, 도로 중점(카메라 위치)의 x·y 좌표를 각각 압축하면 모든 관심 지점이 격자 칸이 된다. 도로를 압축된 인접 칸 단위로 이으면, 가로 도로와 세로 도로가 만나는 지점은 자연스럽게 같은 칸이 되므로 교차점을 따로 계산할 필요가 없다.

카메라는 칸에 붙는 제한값이다. 한 지점에 카메라가 여러 개면 최솟값을 쓰고, 카메라가 없는 칸은 제한이 없다(INF). 어느 도로로 지나가든 카메라 칸을 지나면 제한이 걸린다.

### 제한 속도 내림차순 유니온 파인드

경로의 속도는 경로 위 칸 제한의 최솟값이고, 이를 최대화하는 병목 경로 문제다. 인접한 두 칸을 잇는 간선의 가중치를 두 칸 제한의 최솟값으로 두면, 경로 위 모든 칸이 간선 끝점이 되므로 간선 기준 최솟값과 같아진다.

1. 양쪽 모두 카메라가 없는 간선은 바로 합친다. 이 시점에 1번 도시와 연결된 도시는 카메라 없이 갈 수 있으므로 0이다.
2. 카메라가 걸린 간선(카메라 수의 4배 이하)만 모아 제한 내림차순으로 정렬한다.
3. 하나씩 합치면서, 1번 도시와 처음 같은 집합이 되는 도시에 그 간선의 제한을 기록한다. 높은 제한부터 열었으므로 처음 연결되는 순간이 최고 속도다.

격자는 최대 약 440만 칸이지만 칸마다 `union` 한 번이고, 카메라 간선은 4,000개 이하라 충분히 빠르다.

## 풀이

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.TreeSet;

int INF = Integer.MAX_VALUE;
int[] parent;
int[] cell;
int[] res;

public int[] solution(int[][] city, int[][] road) {
    TreeSet<Integer>[] sets = new TreeSet[]{new TreeSet<>(), new TreeSet<>()};
    for (int[] ct : city) {
        sets[0].add(ct[0]);
        sets[1].add(ct[1]);
    }
    for (int[] rd : road) {
        for (int k = 0; k < 2; k++) {
            sets[k].add(rd[k]);
            sets[k].add(rd[k + 2]);
            sets[k].add((rd[k] + rd[k + 2]) / 2);
        }
    }
    int[] xs = sets[0].stream().mapToInt(Integer::intValue).toArray();
    int[] ys = sets[1].stream().mapToInt(Integer::intValue).toArray();
    int cols = ys.length;
    int[] limit = new int[xs.length * cols];
    Arrays.fill(limit, INF);
    for (int[] rd : road) {
        int mid = Arrays.binarySearch(xs, (rd[0] + rd[2]) / 2) * cols + Arrays.binarySearch(ys, (rd[1] + rd[3]) / 2);
        limit[mid] = Math.min(limit[mid], rd[4]);
    }
    parent = new int[limit.length];
    for (int i = 0; i < parent.length; i++) {
        parent[i] = i;
    }
    List<int[]> edges = new ArrayList<>();
    for (int[] rd : road) {
        int start = Arrays.binarySearch(xs, rd[0]) * cols + Arrays.binarySearch(ys, rd[1]);
        int end = Arrays.binarySearch(xs, rd[2]) * cols + Arrays.binarySearch(ys, rd[3]);
        int step = rd[0] == rd[2] ? 1 : cols;
        for (int a = start; a < end; a += step) {
            int w = Math.min(limit[a], limit[a + step]);
            if (w == INF) union(a + step, a);
            else edges.add(new int[]{a, a + step, w});
        }
    }
    cell = new int[city.length];
    for (int i = 0; i < city.length; i++) {
        cell[i] = Arrays.binarySearch(xs, city[i][0]) * cols + Arrays.binarySearch(ys, city[i][1]);
    }
    res = new int[city.length - 1];
    Arrays.fill(res, -1);
    check(0);
    edges.sort((a, b) -> b[2] - a[2]);
    for (int[] edge : edges) {
        union(edge[0], edge[1]);
        check(edge[2]);
    }
    return res;
}

public void check(int w) {
    for (int i = 1; i < cell.length; i++) {
        if (res[i - 1] != -1 || find(cell[i]) != find(cell[0])) continue;
        res[i - 1] = w;
    }
}

public int find(int x) {
    if (parent[x] == x) return x;
    return parent[x] = find(parent[x]);
}

public void union(int a, int b) {
    parent[find(a)] = find(b);
}
```
