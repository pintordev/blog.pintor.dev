## 문제

> 링크: [프로그래머스 12978](https://school.programmers.co.kr/learn/courses/30/lessons/12978)

1번 마을에서 출발해 K 시간 이하로 배달 가능한 마을의 수를 반환한다.

## 접근

### 다익스트라 (Dijkstra)

1번 마을에서 모든 마을까지의 최단 거리를 구한 뒤, 거리가 K 이하인 마을의 수를 센다.

도로가 양방향이고 같은 두 마을 사이에 여러 도로가 존재할 수 있으므로, 인접 리스트에 모든 간선을 그대로 추가하고 다익스트라로 최단 거리를 갱신한다.

## 풀이

```java
import java.util.ArrayList;
import java.util.List;
import java.util.PriorityQueue;

int n;
List<Node>[] graph;

public int solution(int N, int[][] road, int K) {
    n = N;
    graph = new List[n + 1];
    for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
    for (int[] r : road) {
        graph[r[0]].add(new Node(r[1], r[2]));
        graph[r[1]].add(new Node(r[0], r[2]));
    }
    return dijkstra(1, K);
}

public int dijkstra(int s, int k) {
    int[] dist = new int[n + 1];
    for (int i = 1; i <= n; i++) dist[i] = Integer.MAX_VALUE;
    dist[s] = 0;
    PriorityQueue<Node> pq = new PriorityQueue<>();
    pq.add(new Node(s, 0));
    while (!pq.isEmpty()) {
        Node cur = pq.poll();
        if (cur.d > dist[cur.t]) continue;
        for (Node next : graph[cur.t]) {
            int nd = dist[cur.t] + next.d;
            if (dist[next.t] <= nd) continue;
            dist[next.t] = nd;
            pq.add(new Node(next.t, nd));
        }
    }
    int cnt = 0;
    for (int i = 1; i <= n; i++) if (dist[i] <= k) cnt++;
    return cnt;
}
```
