## 문제

> 링크: [프로그래머스 68937](https://school.programmers.co.kr/learn/courses/30/lessons/68937)

트리에서 세 점을 골라 세 거리의 중간값을 만들 때, 그 중간값의 최댓값을 구하는 문제.

## 접근

### 지름 끝점에서 BFS

트리의 지름을 D라고 하면 어떤 두 점 사이의 거리도 D를 넘지 않으므로 답은 D 이하다. 또 지름 양 끝점 u, v와 v 바로 옆 정점을 고르면 거리가 (D, D-1, 1)이 되어 중간값 D-1을 항상 만들 수 있다. 따라서 답은 D 또는 D-1이다.

중간값이 D가 되려면 세 거리 중 두 개가 D여야 한다. 즉 지름 끝점에서 거리 D인 정점이 두 개 이상 있어야 한다.

1. 1번 정점에서 BFS를 돌려 가장 먼 정점 u를 찾는다.
2. u에서 BFS를 돌려 최대 거리 D와 거리 D인 정점 수를 구한다. 2개 이상이면 D가 답이다.
3. 아니면 반대쪽 끝점 v에서 다시 BFS를 돌린다. 거리 D인 정점이 2개 이상이면 D, 아니면 D-1이 답이다.

BFS는 깊이 단위로 진행하면서 마지막 깊이의 정점 수와 그중 한 정점을 함께 기록하므로, 탐색 한 번으로 최대 거리·가장 먼 정점·개수를 모두 얻는다. 정점이 최대 250,000개라 일직선 트리에서 재귀 DFS는 스택 오버플로우 위험이 있어 BFS를 쓴다. 시간복잡도는 O(n)이다.

## 풀이

```java
import java.util.*;

int n;
List<Integer>[] graph;
boolean[] visited;
int max;
int mdx;
int cnt;

public int solution(int n, int[][] edges) {
    this.n = n;
    graph = new List[n + 1];
    for (int i = 1; i <= n; i++) {
        graph[i] = new ArrayList<>();
    }
    for (int[] edge : edges) {
        graph[edge[0]].add(edge[1]);
        graph[edge[1]].add(edge[0]);
    }

    bfs(1);

    bfs(mdx);
    if (cnt > 1) return max;

    bfs(mdx);
    return cnt > 1 ? max : max - 1;
}

public void bfs(int s) {
    visited = new boolean[n + 1];
    visited[s] = true;
    Queue<Integer> q = new ArrayDeque<>();
    q.add(s);
    max = -1;
    while (!q.isEmpty()) {
        max++;
        cnt = q.size();
        mdx = q.peek();
        for (int i = 0; i < cnt; i++) {
            int cur = q.poll();
            for (int next : graph[cur]) {
                if (visited[next]) continue;
                visited[next] = true;
                q.add(next);
            }
        }
    }
}
```
