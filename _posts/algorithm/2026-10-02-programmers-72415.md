## 문제

> 링크: [프로그래머스 72415](https://school.programmers.co.kr/learn/courses/30/lessons/72415)

4x4 격자의 카드를 방향키, Ctrl+방향키, Enter 조작으로 모두 제거하는 최소 조작 횟수를 구하는 문제.

## 접근

### 제거 순서 순열 + BFS 이동 비용

카드 종류는 최대 6개이므로 제거 순서를 순열로 완전 탐색해도 6! = 720가지에 불과하다. 종류마다 두 장 중 어느 쪽을 먼저 뒤집을지도 2가지이므로, 탐색 공간은 최대 6! × 2^6이다. 틀린 짝을 뒤집어 보는 행동은 이득이 없어서 항상 한 쌍을 연달아 뒤집어 제거하는 경우만 본다.

커서 이동 비용은 BFS로 구한다. 한 칸에서 나가는 간선은 방향키 4개(1칸 이동)와 Ctrl+방향키 4개(가장 가까운 카드까지 이동, 카드가 없으면 격자 끝까지 이동)이고, 비용은 모두 1이다. 현재 board 상태에서 Ctrl 이동을 계산하므로 이미 제거한 카드는 빈 칸으로 취급된다.

한 쌍을 처리하는 비용은 `현재 위치 → 첫 번째 카드`, `첫 번째 카드 → 두 번째 카드` 두 번의 BFS 결과에 Enter 2회를 더한 값이다. 첫 번째 카드는 아직 제거되지 않았으므로 두 번째 카드로 가는 Ctrl 이동에서 장애물로 작동한다. 한 쌍을 제거하면 board의 두 칸을 0으로 바꾸고 다음 종류로 재귀하며, 돌아올 때 원래 값으로 복원한다.

모든 종류를 제거했을 때의 누적 비용 중 최솟값이 답이다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Queue;

int[][] board;
Node[][] cards;
boolean[] used;
int cardTypes;
int[] dr = {1, -1, 0, 0};
int[] dc = {0, 0, 1, -1};
int res;

public int solution(int[][] board, int r, int c) {
    this.board = board;
    cards = new Node[7][2];
    used = new boolean[7];
    cardTypes = 0;
    res = Integer.MAX_VALUE;
    saveCardInfo();
    dfs(r, c, 0, 0);
    return res;
}

public void saveCardInfo() {
    for (int i = 0; i < 4; i++) {
        for (int j = 0; j < 4; j++) {
            int v = board[i][j];
            if (v == 0) continue;
            if (cards[v][0] == null) {
                cards[v][0] = new Node(i, j);
                cardTypes++;
            } else {
                cards[v][1] = new Node(i, j);
            }
        }
    }
}

public void dfs(int r, int c, int cost, int depth) {
    if (depth == cardTypes) {
        res = Math.min(res, cost);
        return;
    }
    for (int v = 1; v <= 6; v++) {
        if (cards[v][0] == null || used[v]) continue;
        used[v] = true;
        for (int k = 0; k < 2; k++) {
            Node a = cards[v][k];
            Node b = cards[v][1 - k];
            int next = cost + bfs(r, c, a.r, a.c) + bfs(a.r, a.c, b.r, b.c) + 2;
            board[a.r][a.c] = 0;
            board[b.r][b.c] = 0;
            dfs(b.r, b.c, next, depth + 1);
            board[a.r][a.c] = v;
            board[b.r][b.c] = v;
        }
        used[v] = false;
    }
}

public int bfs(int sr, int sc, int er, int ec) {
    boolean[][] visited = new boolean[4][4];
    Queue<Node> q = new ArrayDeque<>();
    q.add(new Node(sr, sc, 0));
    visited[sr][sc] = true;
    while (!q.isEmpty()) {
        Node cur = q.poll();
        if (cur.r == er && cur.c == ec) return cur.mv;
        for (int i = 0; i < 4; i++) {
            int nr = cur.r + dr[i];
            int nc = cur.c + dc[i];
            if (!isAvailable(nr, nc) || visited[nr][nc]) continue;
            visited[nr][nc] = true;
            q.add(new Node(nr, nc, cur.mv + 1));
        }
        for (int i = 0; i < 4; i++) {
            int nr = cur.r + dr[i];
            int nc = cur.c + dc[i];
            if (!isAvailable(nr, nc)) continue;
            while (board[nr][nc] == 0 && isAvailable(nr + dr[i], nc + dc[i])) {
                nr += dr[i];
                nc += dc[i];
            }
            if (visited[nr][nc]) continue;
            visited[nr][nc] = true;
            q.add(new Node(nr, nc, cur.mv + 1));
        }
    }
    return -1;
}

public boolean isAvailable(int nr, int nc) {
    if (nr < 0 || nr >= 4 || nc < 0 || nc >= 4) return false;
    return true;
}

class Node {
    int r;
    int c;
    int mv;

    Node(int r, int c) {
        this.r = r;
        this.c = c;
    }

    Node(int r, int c, int mv) {
        this.r = r;
        this.c = c;
        this.mv = mv;
    }
}
```
