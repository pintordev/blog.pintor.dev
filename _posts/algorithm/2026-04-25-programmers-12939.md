## 문제

> 링크: [프로그래머스 12939](https://school.programmers.co.kr/learn/courses/30/lessons/12939)

공백으로 구분된 숫자 문자열 s가 주어질 때, 최솟값과 최댓값을 `"최솟값 최댓값"` 형태로 반환하는 문제.

## 접근

### 직접 파싱

`split(" ")`으로 토큰을 나누는 대신 문자열을 직접 순회하며 파싱했다.

- `-` 문자 감지 → `sign = -1`
- 이후 공백 전까지 `num = num * 10 + digit` 누적 (`* 10`은 `(num << 3) + (num << 1)`로 비트 연산)
- 파싱한 수를 min/max와 비교

## 풀이

```java
public String solution(String s) {
    int min = Integer.MAX_VALUE;
    int max = Integer.MIN_VALUE;
    int i = -1;
    int len = s.length();
    while (++i < len) {
        int sign = 1;
        if (s.charAt(i) == '-') {
            sign = -1;
            i++;
        }
        int num = 0;
        while (i < len && s.charAt(i) != ' ') {
            num = (num << 3) + (num << 1) + (s.charAt(i) - '0');
            i++;
        }
        num *= sign;
        min = Math.min(min, num);
        max = Math.max(max, num);
    }
    return new StringBuilder()
            .append(min)
            .append(' ')
            .append(max)
            .toString();
}
```
