## 문제

> 링크: [프로그래머스 49994](https://school.programmers.co.kr/learn/courses/30/lessons/49994)

게임 캐릭터가 (0,0)에서 출발해 UDRL 명령어로 이동할 때, 처음 지나간 간선의 수를 반환한다.

## 접근

### 간선 정규화 + 3D 배열 추적

점이 아닌 **간선**을 추적해야 한다. A→B와 B→A는 같은 간선이므로, 방향에 무관하게 동일한 셀에 기록해야 한다.

좌표 범위 (-5~5)를 0~10으로 오프셋하여 시작점을 (5, 5)로 잡는다.

`boolean[2][11][11]` 배열로 간선을 관리한다.
- 첫 번째 차원: `d >> 1`로 수직(U/D → 0) / 수평(R/L → 1) 타입 구분
- 두 번째/세 번째 차원: `Math.min(r, nr)`, `Math.min(c, nc)`로 정규화된 좌표

이 방식으로 A→B와 B→A가 항상 같은 셀에 저장된다.

## 풀이

```java
public int solution(String dirs) {
    int[] dr = {1, -1, 0, 0};
    int[] dc = {0, 0, 1, -1};
    boolean[][][] visited = new boolean[2][11][11];
    int r = 5, c = 5, cnt = 0;
    for (int i = 0; i < dirs.length(); i++) {
        int d = "UDRL".indexOf(dirs.charAt(i));
        int nr = r + dr[d];
        int nc = c + dc[d];
        if (!isAvailable(nr, nc)) continue;
        int minR = Math.min(r, nr), minC = Math.min(c, nc);
        r = nr;
        c = nc;
        if (visited[d >> 1][minR][minC]) continue;
        visited[d >> 1][minR][minC] = true;
        cnt++;
    }
    return cnt;
}

public boolean isAvailable(int r, int c) {
    return r >= 0 && r < 11 && c >= 0 && c < 11;
}
```

## 회고

`d >> 1` 비트 시프트로 방향 인덱스(U=0, D=1, R=2, L=3)를 타입(수직=0, 수평=1)으로 묶고, `Math.min`으로 좌표를 정규화하면 양방향 간선을 별도 처리 없이 같은 셀에 저장할 수 있다.

처음 시작 좌표를 (0,0)으로 잡아 경계 처리가 잘못되는 버그가 있었다. 범위 (-5~5)를 0~10으로 매핑할 때 중앙인 (5,5)에서 시작해야 한다.
