## 문제

> 링크: [프로그래머스 42895](https://school.programmers.co.kr/learn/courses/30/lessons/42895)

숫자 N과 사칙연산만으로 number를 표현할 때, N을 사용하는 최소 횟수를 구하는 문제.

## 접근

### dp[i] = N을 i번 사용해서 만들 수 있는 수의 집합

`dp[i]`를 "N을 정확히 i번 사용해서 만들 수 있는 모든 수의 집합"으로 정의한다.

- 기본값: N을 i번 이어붙인 수(5, 55, 555, ...)는 항상 `dp[i]`에 포함된다.
- 점화식: `j + (i - j) = i`가 되는 두 부분집합 `dp[j]`, `dp[i - j]`의 원소를 사칙연산으로 조합해 `dp[i]`를 채운다.
- `j`는 `1`부터 `i / 2`까지만 순회하고, 뺄셈·나눗셈은 `a - b`/`b - a`, `a / b`/`b / a` 양방향을 모두 채워서 `j`가 큰 쪽과 작은 쪽을 맞바꾼 조합까지 함께 커버한다.
- `i`를 1부터 8까지 늘려가며 `number`가 `dp[i]`에 처음 등장하는 `i`를 반환하고, 8번을 넘어가도 없으면 -1을 반환한다.

## 풀이

```java
import java.util.HashSet;
import java.util.Set;

Set<Integer>[] dp;

public int solution(int N, int number) {
    dp = new Set[9];
    int concat = 0;
    for (int cnt = 1; cnt <= 8; cnt++) {
        concat = concat * 10 + N;
        Set<Integer> cur = new HashSet<>();
        cur.add(concat);
        dp[cnt] = cur;
        for (int j = 1; j <= cnt >> 1; j++) {
            combine(cnt, j);
        }
        if (cur.contains(number)) return cnt;
    }
    return -1;
}

public void combine(int cnt, int j) {
    Set<Integer> cur = dp[cnt];
    for (int a : dp[j]) {
        for (int b : dp[cnt - j]) {
            cur.add(a + b);
            cur.add(a - b);
            cur.add(b - a);
            cur.add(a * b);
            if (b != 0) cur.add(a / b);
            if (a != 0) cur.add(b / a);
        }
    }
}
```
