## 문제

> 링크: [프로그래머스 62048](https://school.programmers.co.kr/learn/courses/30/lessons/62048)

가로 W, 세로 H인 직사각형을 대각선으로 자를 때, 온전히 남아있는 1×1 칸의 수를 구하는 문제.

## 접근

### 대각선이 지나는 칸 수 공식

대각선이 새 칸에 진입하는 경우는 수직 격자선(W-1번)과 수평 격자선(H-1번) 통과 두 가지다. 시작 칸을 포함하면 `1 + (W-1) + (H-1) = W + H - 1`이지만, 대각선이 격자점(정수 좌표)을 지날 때는 두 격자선을 동시에 통과하면서 칸은 하나만 진입한다. 내부 격자점의 수는 `GCD(W, H) - 1`이므로 이를 빼면:

```
잘리는 칸 수 = W + H - GCD(W, H)
멀쩡한 칸 수 = W * H - (W + H - GCD(W, H))
```

GCD는 유클리드 호제법으로 O(log n)에 구한다. W, H가 최대 1억이므로 반환값은 `long`이 필요하다.

## 풀이

```java
public long solution(int w, int h) {
    long g = gcd(w, h);
    return (long) w * h - (w + h - g);
}

public long gcd(long a, long b) {
    return b == 0 ? a : gcd(b, a % b);
}
```
