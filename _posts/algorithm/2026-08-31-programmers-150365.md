## 문제

> 링크: [프로그래머스 150365](https://school.programmers.co.kr/learn/courses/30/lessons/150365)

n × m 격자에서 (x, y)에서 출발해 정확히 k번 이동해 (r, c)에 도착하는 경로 중 사전 순으로 가장 빠른 문자열을 구한다.

## 접근

### 도달 가능성 판정 + 그리디

핵심은 "현재 위치에서 남은 이동 횟수 `remain`으로 목표에 **정확히** 도착할 수 있는가"를 판정하는 것이다.

현재 위치에서 목표까지 맨해튼 거리를 `need`라 하면, 다음 두 조건을 모두 만족해야 한다.

- `need <= remain` — 최소한 거리만큼은 움직여야 한다.
- `(remain - need) % 2 == 0` — 남는 횟수는 인접한 두 칸을 왕복(2칸)하며 소모해야 하므로 짝수여야 한다.

`n, m >= 2`이므로 어떤 칸에서도 왕복할 인접 칸이 항상 존재한다. 따라서 격자 경계 때문에 왕복이 막히는 경우는 없고, 위 판정식만으로 충분하다.

시작 시점에 `(x, y)`, `remain = k`로 판정식을 만족하지 않으면 곧바로 `"impossible"`이다.

가능하다면 그리디로 경로를 만든다. 매 스텝마다 방향을 사전 순(`d`, `l`, `r`, `u`)으로 시도하고, 그 방향으로 한 칸 간 뒤에도 남은 횟수로 도달 가능하면 즉시 확정한다. 항상 가장 이른 방향을 먼저 채택하므로 결과가 사전 순 최소임이 보장된다.

방향 배열을 `d(1, 0)`, `l(0, -1)`, `r(0, 1)`, `u(-1, 0)` 순서로 정렬해두면 첫 매칭이 곧 사전 순 최소가 된다.

스텝마다 반드시 한 방향이 선택된다. 직전 상태가 `remain + 1`로 도달 가능했다면, 목표 쪽으로 한 칸 이동한 위치는 `need - 1 <= remain`이고 홀짝도 그대로 유지되며(`remain - (need - 1) = (remain + 1) - need`), 목표가 격자 안이므로 그 방향도 격자 안이다. 따라서 경로 길이는 항상 `k`가 된다.

시간복잡도는 스텝 `k` × 방향 4 = `O(k)`, `k <= 2500`이라 여유롭게 통과한다.

## 풀이

```java
char[] dir = {'d', 'l', 'r', 'u'};
int[] dr = {1, 0, 0, -1};
int[] dc = {0, -1, 1, 0};
int n;
int m;

public String solution(int n, int m, int x, int y, int r, int c, int k) {
    this.n = n;
    this.m = m;
    if (!isAvailable(x, y, r, c, k)) return "impossible";
    StringBuilder sb = new StringBuilder();
    int cr = x;
    int cc = y;
    for (int step = 0; step < k; step++) {
        int remain = k - step - 1;
        for (int d = 0; d < 4; d++) {
            int nr = cr + dr[d];
            int nc = cc + dc[d];
            if (!isAvailable(nr, nc, r, c, remain)) continue;
            sb.append(dir[d]);
            cr = nr;
            cc = nc;
            break;
        }
    }
    return sb.toString();
}

public boolean isAvailable(int cr, int cc, int r, int c, int remain) {
    if (cr < 1 || cr > n || cc < 1 || cc > m) return false;
    int need = Math.abs(cr - r) + Math.abs(cc - c);
    return need <= remain && (remain - need) % 2 == 0;
}
```
