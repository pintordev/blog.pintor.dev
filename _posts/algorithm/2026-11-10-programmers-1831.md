## 문제

> 링크: [프로그래머스 1831](https://school.programmers.co.kr/learn/courses/30/lessons/1831)

3단 고음(`*++`)을 연달아 하거나 중간에 끼워 넣어 만든 올바른 문자열 중, 음높이 1에서 시작해 `*`는 3을 곱하고 `+`는 1을 더했을 때 최종 음높이가 n이 되는 문자열의 개수를 구하는 문제.

## 접근

### 역방향 DFS + 가지치기

올바른 문자열은 괄호 짝 맞추기와 같은 구조다. 앞에서부터 읽을 때 어느 지점에서든 `+`의 개수가 `*` 개수의 2배를 넘으면 안 되고, 끝에서는 정확히 2배여야 한다. 뒤에서부터 읽으면 조건이 뒤집혀, 어느 지점에서든 `+`의 개수가 `*` 개수의 2배 이상이어야 한다.

n이 최대 2^31-1이므로 1에서 n을 만들어 가는 대신 n에서 1로 되돌아가는 탐색을 한다. 상태는 현재 값 `cur`와 아직 짝이 맞지 않은 `+`의 개수 `plus`로 둔다.

- `+`를 되돌리면 `cur - 1`, `plus + 1`이 된다.
- `*`를 되돌리려면 `cur`가 3으로 나누어떨어지고 `plus`가 2 이상이어야 하며, `cur / 3`, `plus - 2`가 된다.
- `cur == 1`이고 `plus == 0`이면 올바른 문자열 하나를 찾은 것이다.

남은 `plus`를 모두 짝지으려면 `*`가 최소 `plus / 2`개 더 필요하므로, `cur`가 3^(plus/2)보다 작으면 더 볼 필요가 없다. 이 가지치기가 없으면 −1만 반복하는 경로가 n번 가까이 이어지지만, 가지치기로 `plus`가 2·log₃(cur) 정도로 묶여 탐색 공간이 작아진다.

## 풀이

```java
int cnt;

public int solution(int n) {
    cnt = 0;
    dfs(n, 0);
    return cnt;
}

public void dfs(int cur, int plus) {
    if (Math.pow(3, plus >> 1) > cur) return;
    if (cur == 1 && plus == 0) {
        cnt++;
        return;
    }
    if (cur % 3 == 0 && plus >= 2) dfs(cur / 3, plus - 2);
    dfs(cur - 1, plus + 1);
}
```
