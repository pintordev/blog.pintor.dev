## 문제

> 링크: [프로그래머스 1844](https://school.programmers.co.kr/learn/courses/30/lessons/1844)

RxC 격자 맵에서 `(0, 0)`→`(R-1, C-1)` 까지의 최단 거리를 구하는 문제. `1`은 이동 가능, `0`은 벽이며, 도달 불가능하면 `-1`을 반환한다.

## 접근

### BFS — 최단 거리

최단 거리를 구하는 문제이므로 BFS를 선택했다.

별도의 `visited` 배열을 두는 대신, 입력 배열 `maps` 자체에 거리를 덮어쓰는 방식을 사용했다. 미방문 셀은 항상 `1`이라는 점을 이용해 방문 여부와 거리를 동시에 관리할 수 있다.

- `map[0][0]++` → 출발점을 `2`로 설정 (거리 1을 의미)
- 인접 셀 방문 시: `map[nr][nc] += map[cur.r][cur.c]` = `1(미방문값) + 현재 거리` = 다음 거리
- `isAvailable`에서 `map[nr][nc] != 1` 조건 하나로 벽(`0`)과 이미 방문한 셀(`≥ 2`)을 동시에 필터링
- 목적지 도달 시 `map[er-1][ec-1] - 1` 반환

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Queue;

public int[][] map;
public int[] dr = {1, -1, 0, 0};
public int[] dc = {0, 0, 1, -1};
public int er;
public int ec;

public int solution(int[][] maps) {
    map = maps;
    er = maps.length;
    ec = maps[0].length;

    Queue<Node> q = new ArrayDeque<>();
    q.add(new Node(0, 0));
    map[0][0]++;
    while (!q.isEmpty()) {
        Node cur = q.poll();
        if (cur.r == er - 1 && cur.c == ec - 1) return map[cur.r][cur.c] - 1;
        for (int i = 0; i < 4; i++) {
            int nr = cur.r + dr[i];
            int nc = cur.c + dc[i];
            if (!isAvailable(nr, nc)) continue;
            q.add(new Node(nr, nc));
            map[nr][nc] += map[cur.r][cur.c];
        }
    }
    return -1;
}

public boolean isAvailable(int nr, int nc) {
    if (nr < 0 || nr >= er || nc < 0 || nc >= ec) return false;
    if (map[nr][nc] != 1) return false;
    return true;
}

class Node {
    int r;
    int c;

    Node(int r, int c) {
        this.r = r;
        this.c = c;
    }
}
```

## 회고

별도의 `visited` 배열 없이 입력 배열 자체를 재활용해 공간을 아끼는 방식이 인상적이었다. 미방문 셀이 항상 `1`이라는 점을 이용해 `map[nr][nc] += map[cur]` 한 줄로 거리 갱신과 방문 표시를 동시에 처리할 수 있었고, 조건 하나(`!= 1`)로 벽과 방문 셀을 동시에 필터링하는 부분도 깔끔하다.
