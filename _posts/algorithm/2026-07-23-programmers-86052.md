## 문제

> 링크: [프로그래머스 86052](https://school.programmers.co.kr/learn/courses/30/lessons/86052)

각 칸에 S(직진), L(좌회전), R(우회전)이 적힌 격자에서 빛을 쏘았을 때 만들어지는 이동 경로 사이클들의 길이를 구한다.

## 접근

### 상태를 (행, 열, 방향)으로 정의해 사이클 탐색

빛의 위치는 칸(row, col)만으로 정의되지 않는다. 같은 칸이라도 어느 방향으로 진입했는지에 따라 다음 이동이 달라지므로, 상태는 (row, col, direction)의 조합으로 잡아야 한다.

전체 상태는 N×M×4개이고, 각 상태는 그 칸에 적힌 문자(S/L/R)에 의해 다음 상태가 정확히 하나로 결정된다. 즉 모든 정점의 출차수가 1인 함수형 그래프이므로, 모든 상태는 반드시 하나의 사이클에 속하게 된다.

방문하지 않은 상태를 시작점으로 잡고 다음 상태로 계속 이동하면서 방문 처리하다가, 시작 상태로 돌아오면 사이클 하나가 완성된다. 이동 중 격자 경계를 넘으면 mod 연산으로 반대편으로 순환시킨다.

## 풀이

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public int[] solution(String[] grid) {
    int n = grid.length;
    int m = grid[0].length();
    int[] dr = {-1, 0, 1, 0};
    int[] dc = {0, 1, 0, -1};
    boolean[][][] visited = new boolean[n][m][4];
    List<Integer> cycles = new ArrayList<>();
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < m; c++) {
            for (int d = 0; d < 4; d++) {
                if (visited[r][c][d]) continue;
                int cr = r, cc = c, cd = d, len = 0;
                while (!visited[cr][cc][cd]) {
                    visited[cr][cc][cd] = true;
                    len++;
                    char dir = grid[cr].charAt(cc);
                    if (dir == 'L') cd = (cd + 3) % 4;
                    else if (dir == 'R') cd = (cd + 1) % 4;
                    cr = (cr + dr[cd] + n) % n;
                    cc = (cc + dc[cd] + m) % m;
                }
                cycles.add(len);
            }
        }
    }
    int[] res = new int[cycles.size()];
    for (int i = 0; i < res.length; i++) {
        res[i] = cycles.get(i);
    }
    Arrays.sort(res);
    return res;
}
```
