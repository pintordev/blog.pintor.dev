## 문제

> 링크: [프로그래머스 1833](https://school.programmers.co.kr/learn/courses/30/lessons/1833)

n개의 쐐기 중 두 개를 대각 꼭짓점으로 하는 동서남북 방향의 직사각형을 만들 때, 넓이가 0보다 크고 내부에 다른 쐐기가 없는 쌍의 수를 구하는 문제.

## 접근

### x 정렬 후 한 방향씩 세기

n이 최대 5,000이므로 모든 쌍을 확인하는 O(n²)까지는 가능하지만, 쌍마다 내부 쐐기를 O(n)으로 검사하면 O(n³)이라 시간 초과가 난다. 쌍당 내부 검사를 O(1)로 줄여야 한다.

쐐기를 x 오름차순, 같으면 y 오름차순으로 정렬한다. 각 쐐기 `i`를 직사각형의 왼쪽 점으로 고정하고 `j > i`를 순서대로 훑으면, 각 쌍이 한 번만 확인된다.

먼저 오른쪽 아래 방향(`y_j < y_i`)만 센다. `i`와 `j` 사이에 x가 끼어 있는 쐐기 중 `y_i`보다 낮은 쐐기의 y 최댓값을 `maxDown`으로 유지한다. `y_j >= maxDown`이면 직사각형 내부가 비어 있다. 경계 위의 쐐기는 허용되므로 등호를 포함한다.

- x가 같은 쌍은 정렬상 `y_j > y_i`라서 `y_j < y_i` 조건에서 걸러진다. y가 같은 쌍도 엄격한 부등호로 걸러진다. 둘 다 넓이가 0인 경우다.
- 같은 x 그룹은 y 오름차순으로 들어오므로, 앞선 점이 `maxDown`을 올려도 뒤따르는 점의 판정에 영향이 없다. 같은 x의 점은 서로의 경계 위에 있다는 조건이 별도의 그룹 처리 없이 맞아떨어진다.
- `maxDown`은 `y_j`의 갱신 여부와 상관없이 매번 갱신한다. 세어지지 않은 점도 이후 점의 내부에 들어올 수 있기 때문이다.

오른쪽 위 방향은 y를 `Integer.MAX_VALUE - y`로 뒤집어 같은 함수를 한 번 더 돌린다. y는 0 이상이므로 뒤집어도 음수나 오버플로가 생기지 않는다. 두 결과를 더하면 정답이다.

시간복잡도는 정렬 O(n log n)과 순회 O(n²)이고, 공간복잡도는 정렬에 필요한 O(n)이다.

## 풀이

```java
import java.util.Arrays;

public int solution(int n, int[][] data) {
    Arrays.sort(data, (a, b) -> a[0] != b[0] ? Integer.compare(a[0], b[0]) : Integer.compare(a[1], b[1]));
    int res = countDown(n, data);
    for (int[] d : data) {
        d[1] = Integer.MAX_VALUE - d[1];
    }
    Arrays.sort(data, (a, b) -> a[0] != b[0] ? Integer.compare(a[0], b[0]) : Integer.compare(a[1], b[1]));
    return res + countDown(n, data);
}

public int countDown(int n, int[][] data) {
    int res = 0;
    for (int i = 0; i < n; i++) {
        int maxDown = -1;
        for (int j = i + 1; j < n; j++) {
            int y = data[j][1];
            if (y >= data[i][1]) continue;
            if (y >= maxDown) res++;
            maxDown = Math.max(maxDown, y);
        }
    }
    return res;
}
```
