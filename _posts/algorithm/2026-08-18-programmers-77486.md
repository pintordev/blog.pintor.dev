## 문제

> 링크: [프로그래머스 77486](https://school.programmers.co.kr/learn/courses/30/lessons/77486)

다단계 판매 조직에서 판매원이 이익을 얻으면 그 중 10%를 자신의 추천인에게 계속 넘겨주는 방식으로, 최종적으로 각 판매원이 얻는 총 이익을 구하는 문제다.

## 접근

### 추천인 체인을 따라 10%씩 분배하기

`enroll`, `referral`로 이름 → 추천인 이름 매핑을 `HashMap`으로 구성한다. 이름별 누적 이익도 `HashMap`으로 따로 관리한다.

판매가 발생하면 판매자부터 시작해서 추천인 체인을 거슬러 올라가며 이익을 나눈다. 각 단계에서 `share = profit / 10`(원 단위 절사)을 계산해서, 현재 사람은 `profit - share`를 갖고 남은 `share`를 다음 추천인에게 넘긴다. `share`가 1원 미만이면 더 이상 분배하지 않고 전액 현재 사람이 갖고 멈춘다.

여기서 중요한 포인트는 `profit`이 매 단계 10%로 줄어들기 때문에, 추천인 체인이 아무리 길어도(최대 `enroll.length`인 10,000단계) 실제 반복 횟수는 1원 미만이 되는 시점에서 바로 끊긴다는 점이다. 이익 상한이 `100 * 100 = 10,000`원이므로 반복은 많아야 5단계 안팎이고, 판매 건수(최대 100,000건)를 곱해도 충분히 빠르게 통과한다.

## 풀이

```java
import java.util.HashMap;
import java.util.Map;

public int[] solution(String[] enroll, String[] referral, String[] seller, int[] amount) {
    Map<String, String> referrerOf = new HashMap<>();
    Map<String, Integer> profitOf = new HashMap<>();
    for (int i = 0; i < enroll.length; i++) {
        referrerOf.put(enroll[i], referral[i]);
        profitOf.put(enroll[i], 0);
    }
    for (int i = 0; i < seller.length; i++) {
        int profit = amount[i] * 100;
        String cur = seller[i];
        while (cur != null && !cur.equals("-")) {
            int share = profit / 10;
            if (share < 1) {
                profitOf.put(cur, profitOf.get(cur) + profit);
                break;
            }
            profitOf.put(cur, profitOf.get(cur) + profit - share);
            profit = share;
            cur = referrerOf.get(cur);
        }
    }
    int[] res = new int[enroll.length];
    for (int i = 0; i < enroll.length; i++) {
        res[i] = profitOf.get(enroll[i]);
    }
    return res;
}
```
