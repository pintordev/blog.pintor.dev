## 문제

> 링크: [프로그래머스 131701](https://school.programmers.co.kr/learn/courses/30/lessons/131701)

원형 수열에서 연속 부분 수열의 합으로 만들 수 있는 수의 개수를 구하라.

## 접근

### 누적합 + HashSet

길이 1 ~ N인 모든 부분 수열의 합을 HashSet에 넣어 중복을 제거한다.

`dp[i]`에 시작점 i의 합을 누적하면서, 길이를 늘릴 때마다 원형 인덱싱으로 다음 원소를 더하면 재계산 없이 O(n²)에 처리할 수 있다.

## 풀이

```java
import java.util.HashSet;
import java.util.Set;

public int solution(int[] elements) {
    Set<Integer> set = new HashSet<>();
    int n = elements.length;
    int[] dp = new int[n];
    for (int len = 1; len <= n; len++) {
        for (int i = 0; i < n; i++) {
            dp[i] += elements[(i + len - 1) % n];
            set.add(dp[i]);
        }
    }
    return set.size();
}
```
