## 문제

> 링크: [프로그래머스 12913](https://school.programmers.co.kr/learn/courses/30/lessons/12913)

N×4 크기의 땅에서 각 행마다 한 칸씩 밟되, 같은 열을 연속으로 밟을 수 없을 때 얻을 수 있는 최대 점수 반환

## 접근

### DP로 행마다 최대 누적값 갱신

각 칸에서 얻을 수 있는 최대 누적 점수를 이전 행 기준으로 계산한다. 현재 열 j에서는 이전 행의 j를 제외한 나머지 3열 중 최댓값을 더하면 된다.

## 풀이

```java
public int solution(int[][] land) {
    int n = land.length;
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < 4; j++) {
            int max = 0;
            for (int k = 0; k < 4; k++) {
                if (k != j) max = Math.max(max, land[i - 1][k]);
            }
            land[i][j] += max;
        }
    }
    return Math.max(Math.max(land[n - 1][0], land[n - 1][1]), Math.max(land[n - 1][2], land[n - 1][3]));
}
```
