## 문제

> 링크: [프로그래머스 451808](https://school.programmers.co.kr/learn/courses/30/lessons/451808)

`submit` 함수로 수를 제출해 "xS yB" 단서를 받으며, 1~9의 서로 다른 숫자 4개로 된 비밀번호를 n번(최소 6번) 이하의 제출로 알아내는 문제.

## 접근

### 후보 소거 + Minimax 질의 선택

가능한 비밀번호는 9 × 8 × 7 × 6 = 3024개다. 이 후보 집합을 유지하면서, 제출한 수에 대한 단서와 맞지 않는 후보를 매번 지운다. 후보가 1개 남으면 그 수가 비밀번호다. 정답은 return만 하면 되므로 마지막에 "4S 0B"를 받기 위한 제출은 필요 없다.

핵심은 무엇을 제출하느냐다. 1000~9999 전체 9000개를 질의 후보로 본다. 비밀번호에는 0이 없고 숫자도 중복되지 않지만, 제출하는 수에는 0과 중복 숫자가 들어가도 된다. 각 질의 q에 대해 현재 후보들을 단서별로 나누고, 가장 큰 그룹의 크기가 가장 작은 q를 고른다(minimax). 동점이면 그룹 크기의 제곱합, 즉 기대 잔여 후보 수가 작은 쪽을 고른다. 단서 (S, B)는 `S × 5 + B` 정수로 바꿔 크기 25 배열에 센다.

비밀번호가 제출마다 바뀌는 케이스도 있지만, 바뀐 비밀번호는 이전 단서와 모순되지 않는다. 질의 선택이 결정적이므로 상대가 고를 수 있는 것은 결정 트리의 경로 하나뿐이다. 따라서 3024개 비밀번호를 모두 시뮬레이션했을 때의 최대 제출 횟수가 곧 최악의 경우다. 이 방식으로 확인하면 최대 5번이라 n = 6 조건을 만족한다.

첫 단계는 후보 집합이 항상 같으므로 고르는 질의도 항상 `1123`이다. 이 단계가 9000 × 3024번의 비교로 가장 무겁기 때문에 상수로 고정한다. 이후 단계는 후보가 최대 720개 이하로 줄어 빠르게 끝난다.

## 풀이

```java
import java.util.ArrayList;
import java.util.List;
import java.util.function.Function;

public int solution(int n, Function<Integer, String> submit) {
    List<Integer> candidates = new ArrayList<>();
    for (int num = 1000; num <= 9999; num++) {
        if (valid(num)) candidates.add(num);
    }
    int q = 1123;
    while (true) {
        String clue = submit.apply(q);
        int code = (clue.charAt(0) - '0') * 5 + (clue.charAt(3) - '0');
        List<Integer> next = new ArrayList<>();
        for (int p : candidates) {
            if (score(p, q) == code) next.add(p);
        }
        candidates = next;
        if (candidates.size() == 1) return candidates.get(0);
        q = choose(candidates);
    }
}

public boolean valid(int num) {
    int mask = 0;
    for (int t = num; t > 0; t /= 10) {
        int d = t % 10;
        if (d == 0 || (mask >> d & 1) == 1) return false;
        mask |= 1 << d;
    }
    return true;
}

public int choose(List<Integer> candidates) {
    int res = 0;
    int minMax = Integer.MAX_VALUE;
    long minSum = Long.MAX_VALUE;
    for (int q = 1000; q <= 9999; q++) {
        int[] cnt = new int[25];
        for (int p : candidates) {
            cnt[score(p, q)]++;
        }
        int max = 0;
        long sum = 0;
        for (int c : cnt) {
            max = Math.max(max, c);
            sum += (long) c * c;
        }
        if (max > minMax || (max == minMax && sum >= minSum)) continue;
        minMax = max;
        minSum = sum;
        res = q;
    }
    return res;
}

public int score(int p, int q) {
    int mask = 0;
    for (int t = p; t > 0; t /= 10) {
        mask |= 1 << (t % 10);
    }
    int strike = 0;
    int ball = 0;
    for (int i = 0; i < 4; i++) {
        int pd = p % 10;
        int qd = q % 10;
        if (pd == qd) strike++;
        else if ((mask >> qd & 1) == 1) ball++;
        p /= 10;
        q /= 10;
    }
    return strike * 5 + ball;
}
```
