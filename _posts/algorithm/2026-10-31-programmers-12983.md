## 문제

> 링크: [프로그래머스 12983](https://school.programmers.co.kr/learn/courses/30/lessons/12983)

무한히 쓸 수 있는 단어 조각들로 문자열 `t`를 완성할 때, 필요한 조각 개수의 최솟값을 구하는 문제. 완성이 불가능하면 -1을 반환한다.

## 접근

### 1차원 DP + HashSet

`dp[i]`를 `t`의 앞 i글자를 만드는 데 필요한 최소 조각 수로 정의한다. `dp[0] = 0`, 나머지는 도달 불가를 뜻하는 `n + 1`로 초기화한다.

각 i에서 길이 len(1부터 조각의 최대 길이까지)의 마지막 구간 `t.substring(i - len, i)`가 조각 집합에 있고 `dp[i - len]`에 도달 가능하면 `dp[i] = min(dp[i], dp[i - len] + 1)`로 갱신한다. 도달 불가 값에 1을 더해 값이 섞이는 일을 막기 위해 도달 가능 여부를 먼저 확인한다.

조각 길이가 최대 5이므로 i마다 최대 5개의 구간만 확인하면 된다. 조각은 `HashSet`에 담아 조회한다. 시간복잡도는 O(|t| × L²)(L은 최대 조각 길이, 안쪽 L은 substring 생성과 해시 비용)이고, 공간복잡도는 O(|t| + 조각 총 길이)이다. 마지막에 `dp[n]`이 도달 불가 값이면 -1을 반환한다.

## 풀이

```java
import java.util.Arrays;
import java.util.HashSet;
import java.util.Set;

public int solution(String[] strs, String t) {
    Set<String> pieces = new HashSet<>();
    int maxLen = 0;
    for (String str : strs) {
        pieces.add(str);
        maxLen = Math.max(maxLen, str.length());
    }
    int n = t.length();
    int[] dp = new int[n + 1];
    Arrays.fill(dp, n + 1);
    dp[0] = 0;
    for (int i = 1; i <= n; i++) {
        for (int len = 1; len <= maxLen && len <= i; len++) {
            if (dp[i - len] > n || !pieces.contains(t.substring(i - len, i))) continue;
            dp[i] = Math.min(dp[i], dp[i - len] + 1);
        }
    }
    return dp[n] > n ? -1 : dp[n];
}
```
