## 문제

> 링크: [프로그래머스 67258](https://school.programmers.co.kr/learn/courses/30/lessons/67258)

진열대에 순서대로 놓인 보석들 중, 모든 종류의 보석을 하나 이상 포함하는 가장 짧은 구간을 찾는 문제다.

## 접근

### 투 포인터 + 해시맵

전체 보석 종류 수 `k`를 먼저 구한 뒤, `right` 포인터로 윈도우를 확장하며 등장하는 보석 종류 수(`distinct`)를 센다. `distinct`가 `k`와 같아지면, 즉 윈도우에 모든 종류가 포함되면 `left` 포인터를 최대한 오른쪽으로 옮기며 윈도우를 좁힌다. 좁히는 도중 어떤 보석의 개수가 0이 되면 그 순간 `distinct`가 줄어들어 더 이상 좁힐 수 없으므로 반복을 멈춘다.

윈도우가 조건을 만족하는 매 순간 길이를 기존 최솟값과 비교해서 갱신하는데, 엄격한 부등호(`<`)로만 갱신하기 때문에 동일한 길이의 구간이 여러 번 나와도 가장 먼저(=가장 작은 시작 번호) 발견된 구간이 유지된다.

카운트 증가·감소는 모두 `Map.merge(key, delta, Integer::sum)`로 처리했다. 오른쪽으로 확장할 때는 `+1`을 더해 반환값이 1이면(=이전엔 없던 보석이면) `distinct`를 늘리고, 왼쪽으로 좁힐 때는 `-1`을 더해 반환값이 0이면(=윈도우에서 해당 보석이 완전히 빠지면) `distinct`를 줄인다. 개수가 0이 된 키를 맵에서 굳이 지우지 않아도 다음에 같은 보석이 다시 들어올 때 `0 + 1 = 1`로 정상 동작한다.

`right`, `left` 포인터가 각각 배열을 한 번씩만 순회하므로 시간복잡도는 O(N)이다.

## 풀이

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;

public int[] solution(String[] gems) {
    int k = new HashSet<>(Arrays.asList(gems)).size();
    Map<String, Integer> window = new HashMap<>();
    int distinct = 0;
    int left = 0;
    int bestLen = Integer.MAX_VALUE;
    int bestStart = 0, bestEnd = 0;
    for (int right = 0; right < gems.length; right++) {
        if (window.merge(gems[right], 1, Integer::sum) == 1) distinct++;
        while (distinct == k) {
            int len = right - left + 1;
            if (len < bestLen) {
                bestLen = len;
                bestStart = left;
                bestEnd = right;
            }
            if (window.merge(gems[left], -1, Integer::sum) == 0) distinct--;
            left++;
        }
    }
    return new int[]{bestStart + 1, bestEnd + 1};
}
```
