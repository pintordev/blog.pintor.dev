## 문제

> 링크: [프로그래머스 17680](https://school.programmers.co.kr/learn/courses/30/lessons/17680)

LRU 캐시 알고리즘을 구현하여 도시 목록을 순서대로 조회할 때 총 실행시간을 구하는 문제. cache hit +1초, cache miss +5초.

## 접근

### LRU 캐시 구현

LRU(Least Recently Used)는 캐시가 꽉 찼을 때 가장 오래 전에 사용된 항목을 제거하는 알고리즘이다.

`ArrayDeque`를 큐처럼 사용해 순서를 유지한다.
- **hit:** 해당 도시를 제거하고 맨 뒤(최근)로 이동
- **miss + 여유:** 맨 뒤에 추가
- **miss + 꽉 참:** 맨 앞(가장 오래된 것)을 제거하고 맨 뒤에 추가

`cacheSize == 0`이면 캐시에 아무것도 저장할 수 없으므로 항상 miss → `5 * cities.length`를 바로 반환한다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Queue;

public int solution(int cacheSize, String[] cities) {
    if (cacheSize == 0) return 5 * cities.length;
    Queue<String> cache = new ArrayDeque<>();
    int runningTime = 0;
    for (String city : cities) {
        city = city.toLowerCase();
        if (cache.contains(city)) {
            cache.remove(city);
            runningTime++;
            cache.add(city);
        } else if (cache.size() < cacheSize) {
            runningTime += 5;
            cache.add(city);
        } else {
            cache.poll();
            runningTime += 5;
            cache.add(city);
        }
    }
    return runningTime;
}
```

## 회고

`cacheSize == 0`일 때 선처리 없이 그냥 두면, `contains`와 `size < cacheSize` 분기가 모두 false가 되어 `poll() + add()`를 반복하게 된다. 캐시 크기가 0이므로 `add`해도 바로 `poll`로 빠져 결과는 우연히 맞지만, 의도를 명확히 드러내기 위해 초반에 명시적으로 분기하는 것이 좋다.
