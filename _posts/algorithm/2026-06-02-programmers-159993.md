## 문제

> 링크: [프로그래머스 159993](https://school.programmers.co.kr/learn/courses/30/lessons/159993)

격자 미로에서 출발점(S)에서 레버(L)를 먼저 당긴 후 출구(E)로 이동하는 최소 시간을 구한다. 탈출이 불가능하면 -1을 반환한다.

## 접근

### BFS 두 번 수행 — 누적 거리 전달

S → L, L → E 경로를 각각 BFS로 탐색한다.

첫 번째 BFS는 S에서 출발해 L을 찾는다. 이때 찾은 State의 거리 `d`를 두 번째 BFS의 출발 거리로 그대로 넘긴다. 두 번째 BFS가 E에 도달했을 때의 `d`가 곧 S → L → E 전체 거리가 된다.

둘 중 하나라도 도달하지 못하면 -1을 반환한다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Queue;

int n, m;
String[] maps;
static final int[] dr = {-1, 0, 1, 0};
static final int[] dc = {0, 1, 0, -1};
boolean[][] visited;

public int solution(String[] maps) {
    n = maps.length;
    m = maps[0].length();
    this.maps = maps;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (maps[i].charAt(j) != 'S') continue;
            State lever = bfs(new State(i, j, 0), 'L');
            if (lever == null) return -1;
            State end = bfs(lever, 'E');
            if (end == null) return -1;
            return end.d;
        }
    }
    return -1;
}

public State bfs(State s, char e) {
    visited = new boolean[n][m];
    Queue<State> q = new ArrayDeque<>();
    q.add(s);
    visited[s.r][s.c] = true;
    while (!q.isEmpty()) {
        State cur = q.poll();
        if (maps[cur.r].charAt(cur.c) == e) return cur;
        for (int i = 0; i < dr.length; i++) {
            int nr = cur.r + dr[i];
            int nc = cur.c + dc[i];
            if (!isAvailable(nr, nc)) continue;
            q.add(new State(nr, nc, cur.d + 1));
            visited[nr][nc] = true;
        }
    }
    return null;
}

public boolean isAvailable(int r, int c) {
    if (r < 0 || r >= n || c < 0 || c >= m) return false;
    if (maps[r].charAt(c) == 'X') return false;
    if (visited[r][c]) return false;
    return true;
}

// State 클래스
class State {
    int r, c, d;
    public State(int r, int c, int d) {
        this.r = r; this.c = c; this.d = d;
    }
}
```
