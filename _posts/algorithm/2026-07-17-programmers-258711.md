## 문제

> 링크: [프로그래머스 258711](https://school.programmers.co.kr/learn/courses/30/lessons/258711)

도넛·막대·8자 모양 그래프 여러 개에 새 정점을 하나 만들어 각 그래프의 임의 정점으로 간선을 연결했을 때, 생성된 정점 번호와 도넛·막대·8자 그래프의 개수를 구하는 문제다.

## 접근

### in-degree / out-degree만으로 분류하기

각 정점의 in-degree, out-degree를 세어보면 그래프를 순회하지 않아도 모양을 구분할 수 있다.

- 생성된 정점: 자신은 어디서도 들어오는 간선이 없고(`in == 0`), 그래프 개수만큼 나가는 간선이 있다(`out >= 2`, 문제 조건상 그래프 총 개수는 2개 이상이므로 `out == 1`인 정점과 구분된다).
- 막대의 끝점: 원래 out-degree가 0인 리프 정점이고, 생성 정점의 간선은 in-degree만 늘릴 뿐 out-degree에는 영향을 주지 않으므로 `out == 0`인 정점 개수가 곧 막대 그래프 개수가 된다.
- 8자의 중심 정점: 원래 in=2, out=2인데, 생성 정점이 하필 이 중심을 가리키면 in만 3으로 늘어난다. 그래서 `out == 2`이면서 `in >= 2`인 정점을 세면 생성 정점이 중심을 가리키는 경우까지 8자 그래프로 정확히 잡힌다.
- 도넛 그래프 개수는 직접 세지 않고, 전체 그래프 개수(생성 정점의 out-degree)에서 막대·8자 개수를 뺀 값으로 구한다. 생성 정점이 도넛의 정점을 가리키면 in=2, out=1이 되는데, 이 패턴은 생성 정점이 8자의 중심이 아닌 정점을 가리켰을 때도 동일하게 나타나기 때문에 직접 카운트하면 8자 그래프와 겹쳐서 중복 계산된다.

정점 번호가 최대 100만이므로 in-degree/out-degree 배열을 크기 100만+1로 잡고 O(N+E)에 처리한다.

## 풀이

```java
public int[] solution(int[][] edges) {
    int[] in = new int[1000001];
    int[] out = new int[1000001];
    for (int[] edge : edges) {
        out[edge[0]]++;
        in[edge[1]]++;
    }
    int[] res = new int[4];
    for (int i = 0; i < in.length; i++) {
        if (in[i] == 0 && out[i] == 0) continue;
        if (in[i] == 0 && out[i] >= 2) res[0] = i;
        else if (out[i] == 0) res[2]++;
        else if (in[i] >= 2 && out[i] == 2) res[3]++;
    }
    res[1] = out[res[0]] - res[2] - res[3];
    return res;
}
```

## 회고

처음에는 8자 중심을 `in == 2 && out == 2`로 잡으면 될 거라 생각했는데, 생성 정점이 하필 8자의 중심을 직접 가리키는 경우(in-degree가 3이 되는 경우)를 놓치는 반례가 있었다. `in == 2`가 아니라 `in >= 2`로 조건을 완화하니 생성 정점이 어디를 가리키든 상관없이 8자 중심을 안정적으로 잡을 수 있었다. 도넛 개수를 직접 세지 않고 전체에서 빼서 구한 것도 같은 이유(도넛 후보 패턴이 8자와 겹칠 수 있다는 것) 때문이었다.
