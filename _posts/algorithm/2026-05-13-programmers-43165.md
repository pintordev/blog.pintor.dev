## 문제

> 링크: [프로그래머스 43165](https://school.programmers.co.kr/learn/courses/30/lessons/43165)

`numbers` 배열의 각 숫자에 `+` 또는 `-`를 붙여 합산했을 때 `target`이 되는 경우의 수를 반환하는 문제.

## 접근

### DFS — 완전탐색

각 숫자마다 두 가지 선택(+/-)이 있으므로 전체 경우의 수는 최대 2²⁰. DFS 재귀로 모든 경우를 탐색한다.

- `cal(i, s)`: 인덱스 `i`에서 현재 합이 `s`일 때, `+numbers[i]` / `-numbers[i]` 두 갈래로 재귀
- `i == numbers.length`에 도달했을 때 `s == target`이면 카운트

## 풀이

```java
public int[] numbers;
public int target;
public int cnt = 0;

public int solution(int[] numbers, int target) {
    this.numbers = numbers;
    this.target = target;
    cnt = 0;

    cal(0, 0);
    return cnt;
}

public void cal(int i, int s) {
    if (i == numbers.length) {
        if (s == target) cnt++;
        return;
    }
    cal(i + 1, s + numbers[i]);
    cal(i + 1, s - numbers[i]);
}
```

## 회고

처음에 부호를 `f` 파라미터(+1/-1)로 넘기는 방식으로 짰다가, 합산을 직접 넘기는 방식으로 리팩터링했다. 그 과정에서 `solution`의 `cal` 호출을 두 번 그대로 남겨두는 실수를 했다. 이전 방식은 첫 숫자의 +/- 처리를 위해 두 번 호출했지만, 새 방식은 `cal` 내부에서 이미 두 갈래로 분기하므로 한 번만 호출하면 된다. 리팩터링 시 호출부까지 함께 점검해야 한다는 걸 다시 한번 확인했다.
