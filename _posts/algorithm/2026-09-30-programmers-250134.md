## 문제

> 링크: [프로그래머스 250134](https://school.programmers.co.kr/learn/courses/30/lessons/250134)

격자 위의 빨간 수레와 파란 수레를 규칙에 맞게 동시에 움직여 각자의 도착칸에 보내는 데 필요한 최소 턴 수를 구하는 문제. 불가능하면 0을 반환한다.

## 접근

### 두 수레를 동시에 움직이는 백트래킹

격자가 최대 4×4이고 수레마다 자신이 방문한 칸을 다시 밟을 수 없으므로, 각 수레의 이동 경로는 자기회피 경로다. 경로 수가 많지 않아 완전탐색이 가능하다.

한 턴에 두 수레가 동시에 한 칸씩 움직이므로, DFS의 한 단계에서 빨간 수레의 이동 방향과 파란 수레의 이동 방향을 이중 루프로 조합한다. 두 수레가 모두 도착칸에 있으면 현재 턴 수로 최솟값을 갱신한다.

- 도착한 수레는 제자리에 고정되므로 후보 이동이 "제자리" 하나뿐이다. 이때 방문 표시는 건드리지 않는다.
- 도착하지 않은 수레는 상하좌우 네 방향 중 격자 안이고, 벽이 아니며, 자신이 방문하지 않은 칸으로만 이동한다.
- 두 수레가 같은 칸으로 이동하는 경우와 서로 자리를 맞바꾸는 경우는 제외한다. 먼저 도착한 수레가 서 있는 칸으로 다른 수레가 가는 경우는 같은 칸 조건에 걸린다.
- 방문 기록은 `int[][]` 하나에 비트로 담는다. 1은 빨간 수레, 2는 파란 수레가 방문한 칸이다.
- 진입 시 비트를 켜고 복귀 시 끄는 방식으로 상태를 되돌린다.
- 현재 턴 수에 1을 더한 값이 이미 구한 최솟값 이상이면 더 탐색하지 않는다.

시간복잡도는 두 수레의 자기회피 경로 조합 수에 비례하며, 4×4 격자에서는 가지치기까지 더해져 충분히 통과한다. 공간복잡도는 재귀 깊이와 방문 배열을 합쳐 O(n·m)이다.

## 풀이

```java
int[][] maze;
int n;
int m;
int rer;
int rec;
int ber;
int bec;
int[][] visited;
int res;
int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};

public int solution(int[][] maze) {
    this.maze = maze;
    n = maze.length;
    m = maze[0].length;
    visited = new int[n][m];
    res = Integer.MAX_VALUE;
    int rsr = 0, rsc = 0, bsr = 0, bsc = 0;
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < m; c++) {
            if (maze[r][c] == 1) {
                rsr = r;
                rsc = c;
            } else if (maze[r][c] == 2) {
                bsr = r;
                bsc = c;
            } else if (maze[r][c] == 3) {
                rer = r;
                rec = c;
            } else if (maze[r][c] == 4) {
                ber = r;
                bec = c;
            }
        }
    }
    visited[rsr][rsc] = 1;
    visited[bsr][bsc] = 2;
    dfs(rsr, rsc, bsr, bsc, 0);
    return res == Integer.MAX_VALUE ? 0 : res;
}

public void dfs(int rr, int rc, int br, int bc, int turn) {
    boolean rDone = rr == rer && rc == rec;
    boolean bDone = br == ber && bc == bec;
    if (rDone && bDone) {
        res = Math.min(res, turn);
        return;
    }
    if (turn + 1 >= res) return;
    for (int i = 0; i < (rDone ? 1 : 4); i++) {
        int nrr = rDone ? rr : rr + dr[i];
        int nrc = rDone ? rc : rc + dc[i];
        if (!rDone && !isAvailable(nrr, nrc, 1)) continue;
        for (int j = 0; j < (bDone ? 1 : 4); j++) {
            int nbr = bDone ? br : br + dr[j];
            int nbc = bDone ? bc : bc + dc[j];
            if (!bDone && !isAvailable(nbr, nbc, 2)) continue;
            if (nrr == nbr && nrc == nbc) continue;
            if (nrr == br && nrc == bc && nbr == rr && nbc == rc) continue;
            if (!rDone) visited[nrr][nrc] |= 1;
            if (!bDone) visited[nbr][nbc] |= 2;
            dfs(nrr, nrc, nbr, nbc, turn + 1);
            if (!rDone) visited[nrr][nrc] ^= 1;
            if (!bDone) visited[nbr][nbc] ^= 2;
        }
    }
}

public boolean isAvailable(int r, int c, int bit) {
    if (r < 0 || r >= n || c < 0 || c >= m) return false;
    if (maze[r][c] == 5) return false;
    return (visited[r][c] & bit) == 0;
}
```
