## 문제

> 링크: [프로그래머스 12936](https://school.programmers.co.kr/learn/courses/30/lessons/12936)

n명의 사람을 사전순으로 나열했을 때 k번째 순열을 구하는 문제.

## 접근

### 팩토리얼 기반 자릿수 결정

각 자리에 올 수 있는 숫자를 팩토리얼로 직접 계산한다.

n개의 원소가 남아있을 때, 첫 번째 자리에서 하나를 고정하면 나머지 (n-1)!개의 순열이 만들어진다. 따라서 `(k-1) / (n-1)!`이 현재 자리에서 선택할 후보의 인덱스가 되고, `k`를 `(k-1) % (n-1)! + 1`로 갱신하면 다음 자리 문제로 축소된다. 이를 n번 반복하면 k번째 순열을 구할 수 있다.

n ≤ 20이므로 최대 20!까지 다뤄야 해 팩토리얼 배열은 `long` 타입으로 선언한다.

## 풀이

```java
import java.util.ArrayList;

public int[] solution(int n, long k) {
    long[] dp = new long[n];
    dp[0] = 1;
    for (int i = 1; i < n; i++) dp[i] = dp[i - 1] * i;

    ArrayList<Integer> candidates = new ArrayList<>();
    for (int i = 1; i <= n; i++) candidates.add(i);

    int[] res = new int[n];
    for (int i = 0; i < n; i++) {
        int idx = (int) ((k - 1) / dp[n - 1 - i]);
        res[i] = candidates.remove(idx);
        k = (k - 1) % dp[n - 1 - i] + 1;
    }
    return res;
}
```
