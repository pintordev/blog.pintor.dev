## 문제

> 링크: [프로그래머스 87694](https://school.programmers.co.kr/learn/courses/30/lessons/87694)

x축, y축에 평행한 직사각형들이 겹쳐 만들어진 다각형 지형의 테두리를 따라, 캐릭터 위치에서 아이템 위치까지 이동하는 최단 거리를 구하는 문제다.

## 접근

### 좌표 2배 확장

캐릭터는 다각형의 "면"이 아니라 "테두리(선)" 위만 이동할 수 있다. 원본 좌표계에서는 어떤 점이 테두리 위인지 내부인지를 정수 좌표만으로 구분하기 애매하다. 그래서 모든 좌표를 2배로 확장한 격자(0~100)에서 작업한다.

### 사각형을 순서대로 병합

각 사각형을 하나씩 처리하면서 `board`에 상태를 기록한다.

- 이미 다른 사각형에 의해 순수 내부(2)로 확정된 칸은 건드리지 않는다.
- 아직 확정되지 않은 칸은, 지금 처리 중인 사각형 자신의 테두리(`r==r1 || r==r2 || c==c1 || c==c2`)에 해당하면 경계(1), 아니면 내부(2)로 표시한다.

두 사각형이 겹칠 때, 어느 한쪽 사각형 기준으로라도 순수 내부라고 확정되면 그 상태가 이후에도 유지된다. 처리 순서를 바꿔도 결과가 같다.

### BFS

경계(1)로 표시된 칸만 지나갈 수 있는 그래프로 보고, 캐릭터 위치에서 아이템 위치까지 BFS로 최단 거리를 구한 뒤 2로 나눠 원래 좌표계의 거리로 되돌린다.

## 풀이

```java
import java.util.ArrayDeque;
import java.util.Queue;

int[][] board;
boolean[][] visited;
int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};

public int solution(int[][] rectangle, int characterX, int characterY, int itemX, int itemY) {
    board = new int[101][101];
    for (int[] rec : rectangle) {
        merge(rec);
    }
    return bfs(characterX * 2, characterY * 2, itemX * 2, itemY * 2) / 2;
}

public void merge(int[] rec) {
    int r1 = rec[0] * 2, c1 = rec[1] * 2, r2 = rec[2] * 2, c2 = rec[3] * 2;
    for (int r = r1; r <= r2; r++) {
        for (int c = c1; c <= c2; c++) {
            if (board[r][c] == 2) continue;
            board[r][c] = (r == r1 || r == r2 || c == c1 || c == c2) ? 1 : 2;
        }
    }
}

public int bfs(int sr, int sc, int er, int ec) {
    visited = new boolean[101][101];
    Queue<Node> q = new ArrayDeque<>();
    q.add(new Node(sr, sc, 0));
    visited[sr][sc] = true;
    while (!q.isEmpty()) {
        Node cur = q.poll();
        if (cur.r == er && cur.c == ec) return cur.dist;
        for (int i = 0; i < dr.length; i++) {
            int nr = cur.r + dr[i], nc = cur.c + dc[i];
            if (!isAvailable(nr, nc)) continue;
            visited[nr][nc] = true;
            q.add(new Node(nr, nc, cur.dist + 1));
        }
    }
    return -1;
}

public boolean isAvailable(int r, int c) {
    if (r < 0 || r >= 101 || c < 0 || c >= 101) return false;
    return board[r][c] == 1 && !visited[r][c];
}

class Node {
    int r, c, dist;

    public Node(int r, int c, int dist) {
        this.r = r;
        this.c = c;
        this.dist = dist;
    }
}
```
