## 문제

> 링크: [프로그래머스 77885](https://school.programmers.co.kr/learn/courses/30/lessons/77885)

양의 정수 x에 대해 x보다 크고 x와 비트가 1~2개 다른 수 중 가장 작은 수를 구한다.

## 접근

### trailing 1의 개수로 분기

x를 이진수로 표현했을 때 trailing 1의 개수를 k라 하면, f(x) = x + 2^max(0, k-1)이다.

- **k = 0 (짝수)**: 최하위 0 비트를 1로 뒤집으면 1비트 차이로 x + 1이 된다.
- **k ≥ 1 (홀수)**: 위치 k(0→1) + 위치 k-1(1→0)을 조작하면 2비트 차이로 x + 2^(k-1)이 된다. 1비트만 바꾸면 x + 2^k가 되어 더 크므로, 2비트 조작이 최솟값이다.

### 단일 식으로 통합

`Long.lowestOneBit(~x)`는 내부적으로 `~x & (-~x)`로, ~x의 최하위 1비트 = 2^k를 반환한다.

여기에 `(lowbit + 1) >> 1` 트릭을 적용하면 분기 없이 증가폭을 계산할 수 있다.

| k | lowbit | `(lowbit + 1) >> 1` |
|---|--------|---------------------|
| 0 | 1 | 1 |
| 1 | 2 | 1 |
| 2 | 4 | 2 |
| 3 | 8 | 4 |

`+1`의 역할: k = 0일 때 `lowbit >> 1 = 0`이 되는 것을 막는다. k ≥ 1일 때는 `+1`로 세운 bit-0이 `>> 1`에 버려지므로 무해하다.

## 풀이

```java
public long[] solution(long[] numbers) {
    long[] result = new long[numbers.length];
    for (int i = 0; i < numbers.length; i++) {
        long x = numbers[i];
        result[i] = x + ((Long.lowestOneBit(~x) + 1) >> 1);
    }
    return result;
}
```
