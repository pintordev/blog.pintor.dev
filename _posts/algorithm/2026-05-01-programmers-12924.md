## 문제

> 링크: [프로그래머스 12924](https://school.programmers.co.kr/learn/courses/30/lessons/12924)

자연수 n을 연속된 자연수의 합으로 표현하는 방법의 수를 구하라.

## 접근

### 연속합 → 홀수 약수 개수로 변환

i개의 연속 자연수를 `m+1, m+2, ..., m+i` (m ≥ 0)로 놓으면 합은 다음과 같다.

```
n = i * m + i * (i + 1) / 2
m = (n - i * (i + 1) / 2) / i
m = n / i - (i + 1) / 2
i == n의 홀수인 약수
```

m이 자연수가 되려면 i가 n을 나누어 떨어져야 하고, i가 홀수일 때만 `(i+1)/2`가 정수로 떨어진다.
따라서 유효한 표현 방법의 수는 **n의 홀수 약수의 개수**와 같다.

약수 쌍을 O(√n)으로 탐색하되, i가 홀수이면 카운트, n/i가 홀수이면 추가 카운트한다.

## 풀이

```java
public int solution(int n) {
    int cnt = 0;
    for (int i = 1; i * i <= n; i++) {
        if (n % i != 0) continue;
        if (i % 2 == 1) cnt++;
        if (i != n / i && (n / i) % 2 == 1) cnt++;
    }
    return cnt;
}
```

## 회고

연속합 문제를 그대로 브루트포스로 풀 수도 있지만, `2n = a * b` 꼴로 변환하는 순간 "홀수 약수 개수"라는 깔끔한 문제로 바뀐다. 약수 탐색도 O(√n)으로 줄어드는 보너스가 있다.
