## 문제

> 링크: [프로그래머스 60061](https://school.programmers.co.kr/learn/courses/30/lessons/60061)

n×n 격자 벽면에 기둥과 보를 설치·삭제하는 명령을 순서대로 처리하고, 최종 구조물 목록을 반환한다.

## 접근

### 명령마다 시뮬레이션하고 삭제 시 전체 재검증

구조물 존재 여부를 `boolean[n+1][n+1][2]`에 저장한다. `[x][y][0]`은 기둥, `[x][y][1]`은 보다.

설치 규칙을 판정하는 함수 `canBuild(x, y, a)`를 만든다.

- 기둥: 바닥(`y == 0`) / 아래 기둥 / 왼쪽·오른쪽 보의 끝
- 보: 한쪽 끝 아래 기둥 / 양옆 보와 동시 연결

교차점 기준으로 보는 오른쪽, 기둥은 위쪽으로 뻗는다는 점을 좌표로 옮기면, 기둥 `(x, y)`를 받치는 보는 `(x-1, y)`(오른쪽 끝)와 `(x, y)`(왼쪽 끝)이고, 보 `(x, y)`의 양끝을 받치는 기둥은 `(x, y-1)`과 `(x+1, y-1)`이다.

각 명령은 다음과 같이 처리한다.

- **설치**: 일단 켜고 그 구조물만 `canBuild`로 검사한다. 실패하면 되돌린다. 구조물을 추가하는 것은 다른 구조물의 지지력을 늘리기만 하므로, 새로 놓은 것 하나만 확인하면 충분하다.
- **삭제**: 일단 끄고 남아 있는 모든 구조물을 `canBuild`로 재검사한다(`isValid()`). 하나라도 규칙을 어기면 삭제를 취소한다. 삭제는 지지력을 줄여 위쪽·옆 구조물을 무너뜨릴 수 있으므로 전체 검증이 필요하다.

좌표 `x-1`, `x+1`, `y-1`을 참조할 때 배열 범위를 벗어날 수 있으므로, 범위 밖이면 `false`를 돌려주는 `isBuilt(x, y, a)`로 조회를 감싼다.

결과는 `x → y → a` 오름차순으로 격자를 순회하며 모으면 "x 오름차순, y 오름차순, 기둥 먼저" 정렬 조건이 자연히 맞는다.

명령 수 M ≤ 1,000이고 삭제 1회당 재검증이 O(n²)이므로 전체 O(M · n²) ≈ 2 × 10⁷로 통과한다.

## 풀이

```java
import java.util.ArrayList;
import java.util.List;

int n;
boolean[][][] built;

public int[][] solution(int n, int[][] build_frame) {
    this.n = n;
    built = new boolean[n + 1][n + 1][2];
    for (int[] cmd : build_frame) {
        int x = cmd[0], y = cmd[1], a = cmd[2], b = cmd[3];
        if (b == 1) {
            built[x][y][a] = true;
            if (!canBuild(x, y, a)) built[x][y][a] = false;
        } else {
            built[x][y][a] = false;
            if (!isValid()) built[x][y][a] = true;
        }
    }
    List<int[]> res = new ArrayList<>();
    for (int x = 0; x <= n; x++) {
        for (int y = 0; y <= n; y++) {
            for (int a = 0; a < 2; a++) {
                if (built[x][y][a]) res.add(new int[]{x, y, a});
            }
        }
    }
    return res.toArray(new int[0][]);
}

public boolean isValid() {
    for (int x = 0; x <= n; x++) {
        for (int y = 0; y <= n; y++) {
            for (int a = 0; a < 2; a++) {
                if (built[x][y][a] && !canBuild(x, y, a)) return false;
            }
        }
    }
    return true;
}

public boolean canBuild(int x, int y, int a) {
    if (a == 0) return y == 0 || isBuilt(x, y - 1, 0) || isBuilt(x - 1, y, 1) || isBuilt(x, y, 1);
    return isBuilt(x, y - 1, 0) || isBuilt(x + 1, y - 1, 0) || (isBuilt(x - 1, y, 1) && isBuilt(x + 1, y, 1));
}

public boolean isBuilt(int x, int y, int a) {
    if (x < 0 || y < 0 || x > n || y > n) return false;
    return built[x][y][a];
}
```

## 회고

처음엔 설치·삭제를 대칭으로 보고 둘 다 매번 전체 재검증하는 `isValid()`를 호출하려 했다. 설치는 새로 놓은 구조물 하나만 `canBuild`로 확인하면 되고, 전체 순회가 필요한 쪽은 삭제뿐이라는 비대칭을 짚고 나니 반복문 한 겹이 사라졌다.
