## Summary

- HashSet은 내부적으로 **HashMap을 사용**한다. 요소가 key, 더미 값이 value로 저장된다.
- 중복 체크는 `hashCode()`로 버킷 위치를 찾고, `equals()`로 동일성을 확인하는 2단계로 이루어진다.
- 평균 **O(1)** 으로 중복 체크가 가능한 이유는 해시 함수로 탐색 범위를 즉시 좁히기 때문이다.

---

## Background

배열이나 리스트에서 중복을 제거하려면 매번 전체를 순회해야 한다. 요소가 N개면 O(N) 비용이 든다.

HashSet은 이 문제를 해시 테이블 구조로 해결한다. 어떻게 O(1)에 가까운 중복 체크가 가능한지 내부 동작을 통해 이해할 수 있다.

---

## 내부 구조

HashSet은 `HashMap<E, Object>`를 내부 필드로 가진다. 요소를 추가하면 HashMap의 key로 저장되고, value는 공유 더미 객체(`PRESENT`)로 채운다.

```java
// OpenJDK 기준 (단순화)
public class HashSet<E> {
    private HashMap<E, Object> map;
    private static final Object PRESENT = new Object();

    public boolean add(E e) {
        return map.put(e, PRESENT) == null;
    }

    public boolean contains(Object o) {
        return map.containsKey(o);
    }
}
```

결국 HashSet의 중복 제거 동작은 **HashMap의 key 중복 방지 메커니즘**과 동일하다.

---

## 중복 제거 메커니즘

### 1단계: hashCode()로 버킷 위치 결정

요소를 추가할 때 `hashCode()`를 호출해 어느 버킷(배열 인덱스)에 넣을지 결정한다.

```
버킷 인덱스 = hashCode() % 버킷 수
```

같은 `hashCode()`를 가진 요소들은 같은 버킷에 모인다.

### 2단계: equals()로 동일성 확인

같은 버킷 안에 있는 요소들과 `equals()`로 비교한다. `true`가 나오면 중복으로 판단해 추가하지 않는다.

```java
String a = "hello";
String b = "hello";

a.hashCode() == b.hashCode() // true → 같은 버킷
a.equals(b)                  // true → 중복 판정, 추가 안 함
```

### 흐름 요약

```
add("hello")
  ↓
hashCode() → 버킷 위치 계산
  ↓
해당 버킷 내 요소들과 equals() 비교
  ↓
일치하는 것 없음 → 추가
일치하는 것 있음 → 무시 (중복)
```

---

## O(1)이 가능한 이유

일반 리스트의 중복 체크는 전체를 순회해야 해서 O(N)이다.

HashSet은 `hashCode()`로 버킷을 바로 찾아가므로 **비교할 후보 자체가 극소수**다. 충돌이 없다면 버킷에 요소가 1개뿐이므로 `equals()` 비교도 1번으로 끝난다.

| 구조 | 중복 체크 시간복잡도 |
|:--:|:--:|
| List | O(N) |
| HashSet | O(1) 평균 |

---

## 주의: hashCode와 equals 계약

HashSet이 올바르게 동작하려면 두 메서드가 일관되게 구현되어야 한다.

> `a.equals(b)`가 `true`면 `a.hashCode() == b.hashCode()`도 `true`여야 한다.

이 계약이 깨지면 같은 값임에도 다른 버킷에 들어가 중복이 제거되지 않는다.

```java
// 잘못된 예: equals만 오버라이드하고 hashCode는 안 함
class Point {
    int x, y;

    @Override
    public boolean equals(Object o) {
        Point p = (Point) o;
        return this.x == p.x && this.y == p.y;
    }
    // hashCode 미구현 → 같은 좌표도 다른 버킷에 저장됨
}
```

---

## Key Point

> **HashSet은 hashCode()로 버킷을 찾고 equals()로 동일성을 확인한다. 해시로 탐색 범위를 O(1)로 좁히는 것이 효율적인 중복 체크의 핵심이다.**
